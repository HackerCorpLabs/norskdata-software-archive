This is an OWS base setup with the Desk Top Manager suite (version C) for the Norsk Data "Butterfly" PC-based workstations. 

DTM was for some time used as the main suite for OWS-based software on these workstations, 
although this would later seem to be replaced with the VKM system after the release of Windows 3.0.
