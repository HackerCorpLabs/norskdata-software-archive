ON-Word er PC versjonen av NOTIS-WP. 
NOTIS produktene på PC fikk «familie-navnet» Open Notis (ON-). 

Det ble også laget ON-Mail og ON-File. ON-Word ble ikke solgt til mange, men ON-Mail og ON-File ble solgt til mange kunder. 
ON-File var bygget på NOARK standarden.

ON-Word Win. 1.0.img
=====================
ON-Word v1.01 for Windows 3.0. 
This is a Norwegian word-processor application by Norsk Data, from the "Open NOTIS" software suite for PC. 
While NOTIS originally ran under SINTRAN for the Nord mainframe computers, this program is designed to give the same user-experience standalone on a PC.

Due to this, this word-processor supports the extra 20 NOTIS keys on some Tandberg Data TDV-5000 series keyboards.

ND Keyboard Drivers For DOS & VKM
=================================
Keyboard drivers for the Norsk Data PC-version of the "Office Workstation" (OWS) client software. 
This mainly covers PS/2 keyboards from the Tandberg Data TDV-5000 series, for instance their keyboards with 20 extended keys for the NOTIS text-editor.
