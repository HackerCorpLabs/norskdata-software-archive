# Installation Procedure

The desired user, for example DIALOG-SYS, should be given 230 pages. Copy all files to this user-area.

The file PLANC-LIB-F00 should be copied to user DIALOG-SYS if it does not already exist. Then you must give 20 more pages to this user. The library must be loaded before loading UNIQQUICK.

An example of how to load PLANC-LIB is shown below:

```
@ND-500_LINKAGE_LOADER
ND-Linkage-Loader - F      10.september 1983 Time: 00:07
NII entered:               15.April 1983 Time: 16:44
NII: SET-DOMAIN 'PLANC-LIB-F00'
NII: SET-SEGMENT-NUMBER 290
NII: OPEN-SEGMENT 'PLANC-LIB-F00', P
NII: TOTAL-SEGMENT-LOAD PLANC-LIB-F00
NII: END-DOMAIN
NII: EXIT
```

Run the PERFORM system to load UNIQQUICK. An example is shown below:

```
@PERFORM_UNIQQUICK-I-A

PERFORM Version G

Macro name [Default = UNIQQUICK-I-500]
*** Load UNIQUE UNIQQUICK ISAM on ND-500 ***
Username for UNIQQUICK:NRF files (Default = DIALOG-SYS)
Username for FORTRAN library (Default = DIALOG-SYS)
Username for PLANC library (Default = DIALOG-SYS)
Type version of UNIQUE-II (1 for A, 2 for B, etc.) [Default = 2]

@MODE MACRO1:MODE,,,

```

When the mode file has finished, UNIQUE UNIQQUICK ISAM for ND-500 is ready to be run.

Start the program by typing:

```
@ND-UNIQQUICK-I
```
