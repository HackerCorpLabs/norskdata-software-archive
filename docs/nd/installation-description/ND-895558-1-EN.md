## Description of Product

This product provides you with the keyboard drivers you need to use the NORTEXT Enhanced Keyboard together with the Norsk Data PC software.

- The VKM (Virtual Keyboard Manager) drivers convert the PC keyboard codes to NORTEXT Keyboard codes (DOSVKMxx is for DOS applications, WINVKMxx is for Windows applications).
- The diskette also contains the Windows drivers you need to install Windows for this keyboard.
- Installation description, ND-891080

**Product name**

**Nature of dependency**

If you want to use NOTIS-WP, S-LINK or DTM with the NORTEXT Enhanced Keyboard you need one of the versions which are listed above.

## 3 Languages Supported

The Windows drivers now support the following languages:

- Norwegian
- Swedish
- Danish
- French
- German
- Swiss-French
- UK, English

For the Finnish keyboard, use the Swedish driver.
