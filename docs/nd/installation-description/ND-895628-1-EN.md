The product consists of a SIBAS/R Backend Software Licence Key and a description of how to activate the Backend-module for the general purpose database management system SIBAS/R over COSMOS and/or TCP/IP communication.

## 4 Installation Procedure

- All applications using SIBAS must be stopped. All SIBAS processes of version SIBAS-II-F, SIBAS/R-A, and SIBAS/R-B must be PASSIVE. Use SIBAS-SERVICE/STATUS/ALL DATABASES to check if there are active processes.

### 4.1 Automatic Installation

- Log in as user SYSTEM

- Use the utility program SOFTICE (ND-211846A) to install the Backend Software Licence Key on the database machine. The Software Licence Key is delivered on a Software Licence Key Certificate following this product.

```
@ND SOFTICE
STORE-SOFTWARE-KEY 220004 <software key> <SIBAS/R Backend>
EXIT
```

### 4.2 Completing the Installation

When the Software Licence Key has been installed:

- How to run SIBAS Backend:

  It may be necessary to increase the following parameters for the XMSG, (by using XMSG-IN), on the application machine:

  ```
  X5PRT (number of ports)  : one for each application
  X4MES (number of message elements) : one for each application
  X4BPG (buffer space in pages) : max. one page per active application.
  ```

  The SIBAS Backend name of the database machine should be defined in XMSG, for both the application machine and the database machine. This is done by the use of the following commands:

  ```
  @XMSG-COMMAND-
  DEFINE-REMOTE-NAME,-*SIBn,<Database-machine-system-number>-
  EXIT-
  ```

  where "n" should be an integer value between 1 and 326. This means that it is possible to communicate with up to 326 database machines from one application machine. `<Database-machine-system-number>` is the CPU-number of the database machine.

Read the rest of this section if you are going to use your SIBAS/R Backend over TCP/IP, in addition to COSMOS.

- Fetch the AIP-HOSTS:SYMB file in your OpenLAN network used for manual updating. Update the file with information concerning the computer where the SIBAS Backend has been installed, as follows:

1. Isolate all records concerning the Ethernet III controllers where the TCP/IP Basic Module/III is installed. (If you don't know the addresses of these controllers, you can find them by reading the file AIP-CONFIG:SYMB which contains information on all the local Ethernet-controllers running TCP/IP. All controllers with TCP-device number >= 4 are running the TCP/IP Basic Module/III)

   - Remove the service SIB=551 if defined for any of the controllers.
   - Define the service SIBRCOM-561 (in the comment-field) for ALL the controllers.

2. Isolate all records concerning the Ethernet III controller where the TCP/IP Basic Module/III is installed as TCP-device number 4. (If you don't know the address of this controller, you can find it by reading the file AIP-CONFIG:SYMB which contains information on all the local Ethernet-controllers running TCP/IP).

   - Define the SIBAS Backend name ('**sibN') of the computer as Alias name for the controller. See the DIALOGUE Operations (830072.2 EN for information on the name).
   - Define the service SIB=560 (in the comment-field).

Example:
```
130.067.006.009  dbmachine *sibl  # SIB=560 SIBRCOM=561
```

Be sure to distribute the updated file to all computers concerned.

See the OpenLAN Network Supervisor Guide (830107.3 EN) for more information.
