## Description of Product

This product consists of one floppy:

230143A00-XX-01D

The PC-NOTIS Server is a part of the PC-NOTIS system. It consists of IDSAS - a RT program handling requests to the ID and DS servers, and HOST-AS - a ND-100 program to start applications on the ND-HOST from a PC.

## Reason(s) for New Product or Version

PC-NOTIS Server makes it possible to use ID and DS on the PC, and to start applications on the ND HOST from an application on a PC.

## 4 Installation Procedure

### 4.1 Automatic Installation

Log in on user `SYSTEM`.

Insert the floppy in a 1.2 Mb floppy drive.  
Enter the directory on the floppy:

```
@ENTER-DIRECTORY,230143A-XX-01D,FLOPPY-DISC-n,m
```

where `n` is the drive number and `m` is the unit number.

Start the installation by typing:

```
@(230143A-XX-01D:FLOPPY-USER)IN-230143A
```

The files on the floppy will be copied to the SINTRAN user area OPENLAN.

You will be asked if you want to install only HOST-AS. If you answer yes to this question, you will not be able to run PCDS or PCID on any PC connected to this host.

### 4.2 Non-Automatic Installation

To install only Host-as:  
Copy the two files with names starting with HOST-AS from the floppy to SINTRAN user area OPENLAN, and dump the program by running the mode job:

```
@MODE (OPENLAN)HOST-AS:MODE
```

To do a full installation:  
Copy all the files from the floppy to the SINTRAN user area OPENLAN  
Dump the programs by running the mode jobs:

```
@MODE (OPENLAN)HOST-AS:MODE
@MODE (OPENLAN)IDSR-TL0:MODE
```

```
@ND (OPENLAN)IDSAS-SERVICE START
```

## 4.3 After Installation

When the installation is finished, do the following:

If you only installed host-as, you should include the statement:

```
@MODE (OPENLAN)HOST-AS:MODE,,,
```

into the file HENT-MODE:MODE on user SYSTEM, or into the file DUMP-REENTRANT:MODE which is started by HENT-MODE.

If you did a full installation, you should include the statements:

```
@MODE (OPENLAN)IDR$RTLO:MODE,,,
@MODE (OPENLAN)HOST-AS:MODE,,,
```

into the file HENT-MODE:MODE on user SYSTEM, or into the file DUMP-REENTRANT:MODE which is started by HENT-MODE, and include the statement:

```
@END (OPENLAN)IDSAS-SERVICE START
```

into the file LOAD-MODE:MODE on user SYSTEM.

The files might have other names on some systems. If so, use the name of your COLD-START modefile instead of HENT-MODE:MODE, and the name of your WARM-START modefile instead of LOAD-MODE:MODE.

## 4.4 Use of User Environment Menus

If the UE menu system is in use, it is necessary that:

- The entry HOST-AS is defined somewhere in the menu hierarchy.
- This entry starts the program HOST-AS with the parameters given on the command line.

For a description on how to define new menu entries in UE, see the manual:

User Environment Reference Manual ND-860194.3
