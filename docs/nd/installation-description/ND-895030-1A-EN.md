## 1. Changes in Revision B03 Compared to Revision B01

Corrected errors in the ND-500/5000 Swapper.

This means that if you already have installed the ND-500/5000 Monitor revision J04, you do not need to install it again.

To see which version of the Monitor (or Swapper) you have installed, you can use the VERSION command to the ND-500/5000 Monitor.

## 2. Installation

- Enter the directory on the diskette:

```
@ENTER-DIRECTORY↵
DIRECTORY NAME: 211305↵
DEVICE NAME: FLOPPY-DISC-<controller>↵
DEVICE UNIT: <unit>↵
```

### 2.1 ND-500/5000 Monitor (background part)

- If you already have installed revision J04 of the ND-500/5000 Background Monitor, you should skip this section.

- Log into the SINTRAN III user area where you keep :PROG files to be dumped as reentrant subsystems (or user SYSTEM).

- Copy the file containing the ND-500 Background Monitor to disk:

```
@COPY-FILE↵
DESTINATION FILE: "NO-500-MON-J<rev>:PROG"↵
SOURCE FILE: (211305:FLOPPY-USER)NO-500-MON-J<rev>:PROG↵
```

- Log out and log in as user SYSTEM

# 4. ND-500/5000 SWAPPER

## 4.1 ERRORS CORRECTED IN REVISION K04 OF THE ND-500/5000 SWAPPER

- Error in updating LegalDevices.  
  Symptom: error message "FATAL ERROR FROM SWAPPER".  
  Errcode = 1208.

- Error in cache-clear routine for multi-CPU. Cache was cleared on all CPUs except the one on which the swapper was running.  
  Symptom: Different traps in user processes.

- Handling of errors in connection with SIBAS BIM-LOG.  
  If the message "NO MORE PAGES AVAILABLE" was given on expansion of the BIM-LOG file (indexed), the restarting after @GIVE-USER-SPACE produced the error message "FATAL ERROR FROM SWAPPER".  
  Errcode = 478a.

- The mechanism for detection of swapper jamming processes (caused by wrong restarting after 'Programmed Trap'), has been improved.

## 4.2 MODIFICATIONS

### 4.2.1 IMPROVED FUNCTIONALITY

- The previous limitation on total memory size of 32 megabyte is changed. The new limitation applies to the multiport memory only, and is changed to 128 megabyte.  
  The change applies to ND-5000 systems only.

### 4.2.2 IMPROVED PERFORMANCE

- A process which has enabled the program trap locally (by using LOCAL-TRAP-ENABLE) may handle errors reported from the ND-500/5000 Swapper itself, and such errors will then not be reported to the ND-500/5000 System Monitor.  
  A new limitation is introduced to allow a maximum of 10 consecutive page faults on the same address causing a program trap.  
  If this limit is reached, the program trap enable is ignored and the error reported to the ND-500/5000 System Monitor.

  The reason for introducing this limit is as follows:  
  The cause of a program trap can be unaffected by the trap handling routine before the instruction that caused the trap is re-executed.  
  In such cases, the process could get an infinite number of page faults causing a program trap on the same instruction.  
  This would require approximately 70% of the CPU.

## 4.3 Postmortem Dump of ND-500/5000 Swapper

- After a fatal error from the swapper (Message 'SWAPPER STOPPED'), the swapper's data segment may be dumped to a file for later analysis by ND.
- The error flag in the ND-500 data field must be reset first. The address of the data field is found in B-register of the RT-program 5SWAP. The error flag has displacement 13₈ within the data field. Use the following procedure to reset the error flag:

Log in as user SYSTEM

```plaintext
@LIST-RT-DESCRIPTION 5SWAP

ACTIVE  I/O-WAIT  ...... .... .... ..... ..... ..... .....

SEGMENTS 1 AND 2  REENT  NPIT APIT RING PRIORITY
INITIAL : 0B 0B 108 78 2 100B
ACTUAL  : 0B 0B 10B 7B 2 100B

START ADDRESS: 126464B  LAST STARTED: 5928 MINS 28 SECS
ND-100 CPU TIME USED: 51 SECS

P       X       T       A       D       L       S       B
022776  012453  000114  000004  003335  126523  000001  053220

RESERVED  DATAFIELDS LOGICAL UNIT  FIRST WAITING
112167B

In this example, the B-register = 53220₈
The address of the error flag is thus 53220₈ + 13₈ = 53233₈
Calculate the address on your installation.

@ND-500-MONITOR

ND-500/5000 MONITOR Version J04 88. 6.16 / 86. 8.17
N500: SET-ND-500-UNAVAILABLE

N500: @LOOK-AT S3DPIT
READY:
53233/  2047  0
177777
-END
N500:
```
