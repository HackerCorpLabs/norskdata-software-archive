# 1 GENERAL

ND-PILOT runtime system will run all programs developed by the ND-PILOT programming environment, ND-211184A<rev> for the ND-500/5000, ND-211300A<rev> for the ND-100.

**how to use ND-PILOT runtime system**

To start a ND-PILOT program type:

```
@PDS /<lang> <file name>
```

The default file extension (filetype) of a ND-PILOT program file is `:PIL`.

PDS will only execute ND-PILOT program files made by the ND-PILOT programming environment. All other files will be refused, even if their contents are legal ND-PILOT statements.

See the ND-PILOT User Guide Addendum, ND-50.332.1 EN for more information.

# 2 INSTALLATION PROCEDURE

ND-PILOT for ND-500/5000 is supplied on two double density diskettes with directory names 211253A<rev>-XX-01D and 211253A<rev>-<lang>-01D.

ND-PILOT will not be available on single density diskettes.

Any version of ND-PILOT already installed will not be lost, but only the installed version/revision will be available as standard domains.

We recommend the deletion of old versions before beginning this installation.

## Installation Instructions

1. **Log in as user SYSTEM**

   Make sure that the required numbers of files and pages are available (prerequisites, page 1).

2. **Insert the first floppy**

   Insert the floppy (211253A<rev>-XX-01D) into one of your floppy units and execute this command:

   ```
   @ENTER-DIRECTORY↵
   DIRECTORY NAME: 211253A<rev>-XX-01D↵
   DEVICE NAME: <DEVICE-NAME>↵
   DEVICE UNIT: <DEVNO>↵
   ```

   Where `<DEVICE-NAME>` is the name of your floppy station, normally FLOPPY-DISC-1 or FLOPPY-DISC-2, and `<DEVNO>` is the unit number, normally 0 or 1.

3. **Start the installation job**

   Start the installation job by executing the following command:

   ```
   @MODE (211253A--01D;FLOPPY-USER)INST-PILOT-A<rev>:MODE.,↵
   @INST-PILOT-A<rev>↵
   ```

   The installation job will now start and display this main menu:

   ```
   -----------------------------------------------------------------------------
   * 211253A<rev> PDS installation procedure: ND500/5000
   * Entered <TIME> <DATE>
   -----------------------------------------------------------------------------

       1. Install language independent parts.
       2. Install a language (NO, EN)
       3. Install course (or example) files.
          (Needs BACKUP-SYSTEM)
       4. Exit installation procedure.

       Type a number 1..4 and CR to select a menu option.
       Type 1?..3? and CR to get more info.

       What do you want to do? (default 1)? 
   ```

   Type a number 1..3 and hit CR to select a menu option. Type 4 and CR to exit the installation procedure.

   For the initial installation, it is recommended to execute the menu options in the listed order.

   After the initial installation, parts (2) and (3) may be repeated to install different sets of course files and languages.

   Note that you may execute SINTRAN commands at all prompts.

   Type an '@' and the command followed by CR. The question will be repeated when the command has finished.

```
ooo  ND Norsk Data  ooo
```

## Language Installation

1. Select (2) in the main menu to install a language.

```
------------------------------------------------------------
- 211253A<rev> PDS installation procedure ND500/5000
- 2. Install language dependant parts
------------------------------------------------------------
```

The floppy 211253A<rev>-<lang>-01D contains files for one language.  
<lang> is the language code; EN-English, NO-Norwegian etc.

Which language do you want to install (Default: EN)? _

2. Type CR twice to install the English files.

Or:

Type NO and press CR to install the Norwegian files.

The installation procedure will copy UE-ERMSG-<lang>-D<rev>:ERR onto user SYSTEM.

When the installation procedure has terminated, delete all superfluous revisions of the UE-ERMSG-<lang> file, keeping the newest.

For example, if you have the D00, and the D02, delete the D00 revision.

If you have the C06 and the D02 versions, do not delete any of them! Other software may need older versions (as C06) to execute properly.
