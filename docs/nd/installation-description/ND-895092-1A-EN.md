## Description of Product

File System Verification is a program for checking the consistency of the data structure on a directory. You may select any directory on the system, and get information about error conditions, if any, existing on the directory.

## Reason(s) for New Product or Version

File System Verification now support discs up to 630 Mb.

## 4 Installation Procedure

### 4.1 Automatic Installation

Before you start installing File System Verification, check that all the prerequisites listed above are fulfilled.

The installation must be run from SINTRAN.

To install File System Verification, follow this procedure:

- Log in with SINTRAN user name SYSTEM.
- Insert the diskette containing the directory name 211073A<rev>-XX-01 in the diskette station.
- Execute the following commands (operator input is underlined and parameters are enclosed with angle brackets).

```
@ENTER-DIRECTORY~
DIRECTORY-NAME: 211073A-XX-01~
DEVICE-NAME: FLOPPY-DISC-<drive no.>~
DEVICE-UNIT: <floppy-unit>~
@(211073A-XX-01:FLOPPY-USER)IN-OEV~
```

The installation procedure will now start. Read the messages that appear on the screen, and follow the directives which are given. After the initialization, the main menu of the installation system will appear on the screen:

1. Get start information
2. Delete product files
3. Check environment and resources
4. Copy product files
5. Exit program
6. Get help information

Execute the options 1 through 4 in sequence to install File System Verification (just press return when you are asked about which option you want to choose, because the sequence 1,2,3,4,5 is defined as default).

If one of the operations fail (for example if deficiencies regarding environment and resources are discovered), you will get a message telling what to do in order to proceed.

## 4.2 Non-Automatic Installation

- Assure that user area ND-OPERATIONS has 160 free pages and 4 free object entries.

- Insert the diskette in the floppy station and copy these files to user area ND-OPERATIONS:

  ```
  OEV-VERIF-A05:PROG 
  OEV-VERIF-EN-A05:CONF 
  OEV-VERIF-NO-A05:CONF
  ```

- Check if you already have the correct version of the UE-ERMSG files and the DDBTABLES file on your system. If not, check if there is enough space, and copy the needed files to user area SYSTEM:

  ```
  UE-ERMSG-NO-C<rev>:ERR
  UE-ERMSG-EN-C<rev>:ERR
  DDBTABLES-E<rev>:VTM
  ```

## 5 Additional Information

Users running SINTRAN-K with patch file 7400 or earlier, have to run a patch to enable File System Verification to successfully re-open the scratch-file. This must be done from user SYSTEM in the following way:

```
@MODE (ND-OPERATIONS)OEV-PATCH:MODE.-
```

The patch (included on your installation diskette) needs only to be run once, and every time SINTRAN has been installed, and it will take effect the next time the system is cold-started.

The error concerning re-opening the scratch-file, has been corrected in SINTRAN-K with patch file >= 10100, and SINTRAN-L
