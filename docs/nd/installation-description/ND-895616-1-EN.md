## Description of Product

The SQL Library allows application programs to access the SIBAS/R database using SQL-oriented function calls. Ordinary SIBAS calls can also be used and mixed with SQL calls.

To make the interface as easy to use as possible, there is a library for each of the languages COBOL, FORTRAN, PLANC and C.

There are precompilers for COBOL and FORTRAN with embedded SQL.

**NOTE:**

To test out queries and verify that the database system works correctly, we recommend the product:

211575B SIBAS/R Interactive SQL for ND 500/5000

## 4 Installation Procedure

The installation process is simple. Just copy the files to SINTRAN user (SQL-SYS). Create this user if it does not already exist.

If you want the library for all languages, then copy the whole diskette. If you only want the library for one language, just select the files you need from this list: (use for example, the BACKUP-SYSTEM)

The following files are always needed:

| File                  | Description |
|-----------------------|-------------|
| sort-merge:nrf        | ORDER BY is executed by SQL library. |
| planc-lib-j:nrf       | PLANC library. The SQL programming libraries are written in PLANC, so all this library must be loaded with all programs. (vers J is not required, H or I will do) |
| mon-call-lib:nrf      | Monitor call library. |
| planc-util:nrf        | Standard PLANC utilities |
| uelib-p5-d00:nrf      | The library use UE to convert error codes to text, and to the correct name of the user. |
| uelib-d5-d00:nrf      | |
| ue-plib-p5-d:nrf      | |
| ue-plib-d5-d:nrf      | |

Copy these files if you intend to use the programming language COBOL:

| File                  | Description |
|-----------------------|-------------|
| sqllib-cob-B01:nrf    | SQL library for the programming language COBOL. |
| SQL-PRE-COB-B01:DOM   | SQL precompiler for COBOL. |
| ex5-pre-cob:symb      | Programming example in COBOL with embedded SQL statements. |
| pre-cobol:mode        | JEC file to precompile and load the programming example. |

Copy these files if you intend to use the programming language FORTRAN:

| File                  | Description |
|-----------------------|-------------|
| sqllib-for-B01:nrf    | SQL library for the programming language FORTRAN. |
| SQL-PRE-FOR-B01:DOM   | SQL precompiler for FORTRAN. |
| ex5-pre-for:symb      | Programming example in FORTRAN with embedded SQL statements. |
| pre-fortran:mode      | JEC file to precompile and load the programming example. |

### 7.1 Limitations

SIBAS/R B05 can only handle one SQL-thread.  
SQL statements are therefore not permitted in transactions.  
The library may sometimes find the SQL server busy. In this case the library will wait until the server is ready.
