# 3 Installation Procedure

## 3.1 Loading Procedure - Stand Alone

The machine must be in STOP. Press MASTER CLEAR and type 15604 on the console.

If autoload is not disabled (see description of FLOPPY-MON-H), TPE-MONITOR will start up and give the prompt:

```
TPE>
```

Manual loading:

```
  FLOPPY-MON-H02 
* LOAD TPE-MON-100
```

When TPE-MONITOR is started, use the command LOAD-PROGRAM to load the desired program:

```
TPE> LOAD-PROGRAM <program name>
```

or just:

```
TPE> <program name>
```

The program is loaded if no error messages appear.

To list the programs available on diskette, use the command LIST-FILES:

```
TPE> LIST-FILES <file-name>
```

## 3.2 Online Installation

The TPE-MONITOR can execute under SINTRAN in different modes.

Installation on-line:

1. Log in under the user where you want to execute the programs.
2. Place the floppy diskette in floppy controller 1 unit 0.
3. Type the command:

   ```
   @ENTER-DIRECTORY 210523I FLOPPY-DISC-1 0
   ```

4. Start the TPE-MONITOR with the command:

   ```
   @LOAD-BINARY (210523I:FLOPPY-USER)TPE-MON-100-B01-
   ```

The TPE-MONITOR now starts and you can load the different test programs by using the command LOAD-PROGRAM.

```
TPE>LOAD-PROGRAM (210523I:FLOPPY-USER)<program name>
```

### 4.3 DISK-MM-C03

#### Modified Commands:

```
>SELECT-DEVICE <Adaptor> <ID_number> / <Device name>
```

When running stand alone, the program asks for "Adaptor" and "ID number", and online it will ask for "Device name".

Selection of device online with `<Device name>`. The device name is either the mass storage name as printed by the SINTRAN command @LIST-MASS-STORAGE-UNITS or the DOMINO device name as printed by the DP-SERVICE program command LIST-DEVICE-NAMES.

If the device selected has subunits (e.g. DISC-2-SCSI-1), all the subunits are selected.

#### New Commands:

```
>COPY-DATA <To device> <To address> <From device> <From address> <Amount>
```

This command will copy data from one to another disk or the same disk. The copy operation will continue even if there are media errors on source or destination disk, unless the error is fatal.

```
>LOOK-AT-DATA <Medium address>
```

By using this command, data on the disk can be inspected and modified. Modification of data is normally only allowed in the data partition.

When inside the look-at mode, the first word in the selected medium address is displayed, and input commands are accepted. The syntax for output is:

```
   ┌────────────────┐
   │ Partition name │
   └────────────────┘
   ┌────────────────────────┐
   │ Medium address         │
   │ ┌────────────────────┐ │
   │ │ Word number within │ │
   │ │ block              │ │
   │ └────────────────────┘ │
   │ ┌────────────────────┐ │
   │ │ Data in word       │ │
   │ └────────────────────┘ │
   │────────────────────────│
   │       <Partition>      │
   └────────────────────────┘
<Address>:<Word> / <Hex> <Oct> <Dec> <string>
```

The "partition" field will be printed if the disk has been initialized. If the disk is not initialized, the entire disk will be treated as a data partition.

After the first line of data is written DISK-MM is ready to accept an input parameter. This could be:

- New data content in address.

The new data is typed and will be deposited after `<CR>`. The radix used is default decimal or the radix set with the sub command **SetData-Input-Radix**. Current radix is found by using the sub command **List-Parameters**. A string value could be typed (max two characters) enclosed in `< >` (e.g. `<NO>` `<CR>`). The default radix could be over ruled by adding a descriptor character to the data: "B", "D", "H" or "X" (NBI in hex mode "B" and "D" will be taken as data).

- New address to examine.

Displaying the next address is done by typing `<CR>`.

The new address to examine is set by typing the address terminated by `/`. The radix used is the radix in which the address is printed out. A new radix could be set by the subcommand **Set-Address-Radix**. The radix could be over ruled here as well.

- Command.

The commands are:
- **Data-16bit**: Data is displayed with 16 bits for each line.
- **Data-32bit**: Data is displayed with 32 bits for each line. The word in sector address will be incremented by two for each line.
- **Dump-Data**: Dumps a continuous area of data to the printer device. The output syntax is equal to the syntax used during data examination.
- **Exit, "."**: Terminates the "LOOK-AT-DATA" command. If data has been modified in the current medium address, the data will be written back after a confirmation question.
- **Explain-Command**: Further explanation for the commands in the help list.
- **Help**: Print all available commands.
- **List-Parameters**: Prints the value of dynamic parameters.
- **Set-Address-Radix**: Sets the radix in which the address is printed and input accepted.

## - Set-Data-Input-Radix

Sets the default data radix.

## - List-Disk-Partitions

Prints the medium address and length of the different partitions for a formatted disk.

There are three modes of write protection: Off, Normal, On. Protect OFF means that writing is allowed in any partition (NBI: This mode should be used with care). Protection NORMAL has write protected all partitions except the data partition. Areas outside any partition is not protected in NORMAL mode. Protect ON has write protect on the entire disk.

Initial protection is NORMAL. Using the **Write-Protect-On** command, protection is set to a higher level, and by using the **Write-Protect-Off** command, protection is set to a lower level.

When the user inputs an address, it has a special syntax:

```
Address = Medium address : Word in block
```

The field "Medium Address" is optional, and if not specified it is the current medium address.

Max word or medium address is defined as "$:", and the current word or medium address is defined as "*:*" (E.g. "$:*" means current word number in the last medium address).

When data has been modified it could be written back to the disk. This is done upon termination of the command or by examination of an address outside the current medium address.

```
>MATCH-DATA <To_device> <To_address> <From_device> <From_address> <Amount>
```

This command will compare data on one disk against an area on another disk or the same disk. The match operation will continue even if there are media errors on source or destination disk, unless the error is fatal.

## Symptom

*** Error *** yyyy-mm-dd hh:mm:ss  
(PB) No memory available.

### Reason

The program fails if there is too little memory available for swapping in SINTRAN.

If the error message appears when loading the program, use the ND-500/5000 monitor to take some memory from the 500(0) processes.

Use the following commands before reloading the program:

```
@ND-500
N500: TAKE 100
N500: EXIT
```

## Symptom

Several terminals may run the program on the same disk.

### Reason

There is no check in SINTRAN if the disk was already reserved for special use.

The program that first releases the disk, will also release the reservation in SINTRAN. A release is done with "Exit" or select of another device. This only applies to disks not entered.

## NET-ONE-AQ0

### Symptom

Test 2 fails if timer units are greater than 7.

Test 2 fails if timer units are greater than 7. Test 2 is the Timer-Ident test which tests the NOTS timer, and in this test, the returned ident code must have the expected value.

The "timer units" is a subcommand in the >NOTS-DEBUG command. Timer units changes the timer value for the Timer-Ident test. See the manual 899159.1 EN (Test program description for ND-100/ND-110 - Addendum) for more information.

# Norsk Data Product Information

## Product Name
Test programs for ND-100/110/120

## Product Number
210523I

### Symptom
The command "Increase-DMA-Load Disc" does not work properly on 15MHz SMD disk.

## OCTOBUS-BOO

### Symptom
Error message in test 4

#### 4. Check Octobus configuration.
*** ERROR *** In test 4. Time: ...

```
Controller number.......: 18
Hardware device number..: 100400B
ND-100 do not see Octobus station 2D
Octobus station 2D is seen by Octobus station 8D
```

This error message is repeated for all octobus station numbers available for domino, and is not seen from the ND-100.

### Solution
To avoid the problem, skip test 4 in the command RUN:

```
TPE>Run 1:3.5:6
```

## PIOC-ETHERNET-BO1

### Symptom
Failing in test 12 on Ethernet II (ND-324534) with ECO J (ECO 100-776). Error message:

```
*** ERROR *** IN 12. System timing contr. check
Timer exceed seriously the expected cont limits
(Calculated freq: 1256xxxx Hz)
```

### Solution
When using the program om cards with ECO J or later, use this patch (the underlined text should be typed):

```
TPE>Load PIOC-ETHERNET-
TPE>Opcar~
115263/ 000277DPE~   (Old value 000230)
127706DPE~            (Old value 113200)
000004DPE~            (Old value 000003)
177706DPE~            (Old value 000160)
<ES>
```

Now test 12 should not give any error messages. When using this patch on old cards, test 12 will fail.
