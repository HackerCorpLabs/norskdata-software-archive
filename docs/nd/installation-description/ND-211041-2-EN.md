**NOTE:** `<rev>` is to be replaced by the current revision of the DIRECTORY or FILE. The revision level is found on the preceding "ND SOFTWARE LIBRARY DISKETTE" pages.

## 1 THE PRODUCT

- The ND-500/2 Micro Test Programs II, TEMICS, is a total revision of the old ND-500/2 Micro Test Programs (210521B03). 211041B00 will be a direct replacement for 210521B03, but 210521B03 is possible to use as a stand-alone program. On the other hand, 211041B has many new facilities which the version 210521B03 did not have. (See the "Test Microprogram II Description for ND-500/2 (Reg.no. 30.100.1 EN) ).

## 2 ERRORS CORRECTED

- All the subtests are updated according to new micro cycle timing definition. See the command `>NEWS` in the program.

- In the old Micro Test Programs (210521B03) the ND-500/2 was not reserved for special use when no memory was reserved. This is corrected in TEMICS.

## 3 KNOWN, BUT NOT CORRECTED ERRORS

- TEMICS is running as a RT-program called TPEMON. The product TPE-MONITOR version A02 (as TEMICS is loaded under) contains an error seen when running the command `>MODE with outputfile=TERMINAL`. This causes stack overflow on the TPE-MONITOR. If using ‘output filename’ as a user file, no problems have been seen.

## 4 CHANGED PREREQUISITES

- The ND-500/2 Micro Test Programs II - Version B00 is loaded under the TPE Monitor version A02 for ND-100/ND-110 and this monitor must be started first before testing the ND-500/2 system. (See chapter STARTING UP THE ND-502 MICRO TEST PROGRAMS.)

## 6 Installation Procedure

This installation procedure makes it possible to install and start the ND-500/2 Micro Test Programs:

A) Make sure you are running SINTRAN III - VSX/500 on a ND-500/2 machine.

B) Log in as user RT. Check that user RT has a minimum of 20 free pages:

```
@USER-STATISTICS RT,←
```

C) Enter the directory 211041B<rev>-XX-01D in floppy-unit 0. The user FLOPPY-USER contains all files:

```
@ENTER-DIRECTORY-
DIRECTORY NAME: 211041B<rev>-XX-01D-
DEVICE NAME: FLOPPY-DISC-<drive-no.>,<floppy-unit>-
```

D) Run the mode file:

```
@MODE (211041B:FLOPPY-USER)INST-TPE-FLO-B:MODE,←
```

(This installs the TPE-MONITOR on a segment and copies the TPE-MONITOR start-up program TPE-RT-MONIT-B<rev>:PROG to user RT).

E) Log in as user SYSTEM

F) 

```
@DELETE-FILE SIN-PATCH-J:OUT←
```

(if such a file exists).

```
ooo ND Norsk Data ooo
```

## Instructions

### G)

`@LIST-TITLE-` (to get the SINTRAN revision number in octal).

### H)

If you have a SINTRAN III VSX/500 J-VERSION with revision/patch earlier than 11000B, patch SINTRAN III by running the mode job:  
`@MODE-`  
INPUT FILE: `(211041B:FLOPPY-USER)SIN-PATCH-J:MODE-`  
OUTPUT FILE: `"SIN-PATCH-J:OUT"-`  

### I)

Inspect the file SIN-PATCH-J:OUT to verify that there are no errors.  
`@PED SIN-PATCH-J:OUT-`  
or  
`@COPY TERMINAL,SIN-PATCH-J:OUT-.`

If the MODE job stops here, qualified personnel must be contacted.

### J)

Now you must decide whether you want to load and start the tests from the DISC drive or the FLOPPY drive!

**NOTE:**  
If you want to load and start the tests from the FLOPPY drive you should now proceed at once to the chapter *STARTING UP THE ND-5002 MICRO TEST PROGRAMS.*

The following steps make it possible to load and start the tests from the DISC drive:

### K)

Log in as user SYSTEM

### L)

Create the user N502-TEMICS with minimum 610 pages:  
`@CREATE-USER N502-TEMICS-`  
`@GIVE-USER-SPACE N502-TEMICS 610-.`

### M)

Log in as user N502-TEMICS.

### N)

Install the TEMICs by running the mode file:  
`@MODE (211041B:FLOPPY-USER)INST-TEMICS-B:MODE,,,-`

This file copies all the test program files into the user N502-TEMICS on the disk.

### O)

Release the directory 211041B<rev>-XX-01D

### Instructions

**B)** Start the Test Program Environment Monitor for ND-100 or ND-110 by starting the program TPE-RT-MON:PROG :

```
@TPE-RT-MON:PROG,,,
```

**C)** Start TEMICS by using the following commands:

a) from disk:

```
TPE>LOAD-PROGRAM (N502-TEMICS)TEMICS-
```

or just

```
TPE>(N502-TEMICS)TEMICS-
```

b) from diskette:

```
TPE>LOAD-PROGRAM (211041B;FLOPPY-USER)TEMICS-
```

or just

```
TPE>(211041B:FLOPPY-USER)TEMICS-
```

Now you should be able to type any command taken from the TPE>HELP list. (To get the test parameters automatically, the test investigation is started by the TPE)>INVESTIGATE-AND-RESERVE command or if low system level: TPE)>SET-PARAMETER. For details, refer to the "Test Microprogram II Description for ND-500/2."

(Remember to release the directory 211041B<rev>-XX-01D after testing if you are running the tests from the floppy).

### NOTE:

- **After warm-start of SINTRAN:** No special actions required.

- **After cold-start of SINTRAN:** The RT-program TPEMON will disappear, but by logging in as user RT and running the file:

```
(211041B<rev>-XX-01D:FLOPPY-USER)INST-TPE-FLO-B:MODE
```

or the file

```
(N502-TEMICS)INST-TPE-DIS-B:MODE
```

you will reload this RT-PROGRAM.
