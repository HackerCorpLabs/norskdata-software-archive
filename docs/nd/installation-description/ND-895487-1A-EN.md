## Description of Product

This product provides you with the keyboard drivers you need to use the NOTIS PC Keyboard together with the Norsk Data PC software.

- The VKM (Virtual Keyboard Manager) drivers convert the PC keyboard codes to NOTIS Keyboard codes (DOSVKMxx is for DOS applications, WINVKMxx is for Windows applications).

- The diskette also contains the Windows drivers you need to install Windows for this keyboard.

- Installation Description ND-no. 891053.2 <lang>

## Reason(s) for New Version

```
This new version of the VKM drivers has been rewritten to work 
with almost any PC AT.
The Windows keyboard drivers support a wide range of languages.
```

## 2 Dependencies

### 2.1 Hardware Dependencies

None

### 2.2 Software Dependencies

**Product name**

- NOTIS-WP for PC/ND-OWS ver. N06 or later
- S-LINK ver. B00
- DTM ver. C02

**Nature of dependency**

If you want to use NOTIS-WP, S-LINK or DTM with the NOTIS PC Keyboard you need one of the versions which are listed above.

## 3 Languages Supported

The Windows drivers now support the following languages:

- Norwegian
- Swedish
- Danish
- French
- German
- Dutch
- Swiss-French
- Swiss-German
- United Kingdom, English
- United States, English
