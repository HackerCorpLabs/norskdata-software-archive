# ERRORS CORRECTED

- Constructions like "If a= then" now give a proper error message instead of restarting the compiler!
- It is now possible to start an internal subroutine sequence (invoked by GOSUB) with a DEF statement. This crashed at execution time in old versions.
- Writing records greater than the input/output-buffer size (e.g. MARGIN setting greater than 136), generated an extra rubbish character. This is now corrected.
- The error message "SCRATCH-FILE OVERFLOW; SAVE PROGRAM!!" is changed to the more correct message "STORAGE OVERFLOW; SAVE PROGRAM!!".

## 2 Modifications

### 2.1 Changed Commands

- Lower case letters are converted to upper case except in text strings. Thus BASIC now accepts statements and variable names in lower case.
- If BASIC is used from a screen, CTRL A and CTRL O really erase characters instead of printing response characters. The delete key now operates as CTRL-A.

### 2.2 New Commands

- Following an If...THEN statement, ELSE can now be used to provide an alternative course of action. Note that this is a single line statement, with the following syntax:
  IF <condition> THEN <statement(s) or number> ELSE <statement(s) or number>.

### 2.3 Improved Performance

- Two access codes, READ and WRITE, in the OPEN statement give faster sequential file access. A buffer of 256 words will be allocated for each open file, but the access time is reduced by approximately 50% compared to INPUT and OUTPUT access.

## 3 Installation Procedure

If compiler is to dump reentrant, you must be logged in as user SYSTEM.

Insert floppy diskette in a vacant floppy-drive, and enter directory by type:

```
@ENTER-DIRECTORY,10034H00,FLOPPY-DISC-<device-no.>,<floppy-unit>+!
@[10034H:FLOPPY-USER]INS-BAS-F32-H!
```

For proper installation, answer all questions!

## 4 Notes

- Version E, F and G has been omitted.
