## Prerequisites

The following things are **required** in order to use this product.

### Hardware Prerequisites

The following hardware must be present for this product to be used:

Computer type (any of the following):

- Office Workstation OWS-12 with minimum 640 KB memory
- Office Workstation OWS-55 with minimum 640 KB memory
- Office Workstation OWS-85 with minimum 640 KB memory

### Software Prerequisites

The following software must be installed on the system for this product to be used:

Operating system:

- Name: MS-DOS
- Version/Revision: 3.10 for OWS-12, 3.21 for OWS-55 and OWS-85.

Other software:

- Product name: Microsoft (R) Windows 2.03
- Product number: ND-230021B

## Resources Required

The following list shows the resource requirements for this product:

- Base memory: minimum 460 Kb before MS-Windows and Excel is started.
- Disk space: 2,7 Mb

## Known Limitations

### Starting Excel

Excel should be started from MS-DOS Executive (as described on the ND reference card Microsoft Excel on your workstation - Installing it and making it work. ND-99.097.1) instead of from Desk Top Manager. The system may hang if you have Expanded memory installed and you start Excel from DTM and then close DTM.

### Keyboard

The `<SHIFT>` key does not work in combination with certain keys on the ND keyboard. The `<HYPERSHIFT>` key must be used instead (described in detail in the reference card Microsoft Excel on your workstation - Installing it and making it work. ND-99.097.1).

### Fonts

If the Format Row Height dialogbox (displayed when you select Format Row Height) is set to standard row height, Excel adjust the height of rows to accommodate the largest font on each row. This is not always the case. For a few large printer fonts, the output on the screen looks correct. On the printout, however, the row height is too small, and the text will be cut off. You must adjust the row height to get a correct output.

### NOTIS-PET Remote Printers

When installing NOTIS-PET, you can define remote printers. These printers cannot be used with Excel, since this version of Excel does not support remote printing.

## International Version of Excel

The problems described below occur if you use Windows with other country settings than US together with the international version of Excel.

### National version of Windows

If you use the international version of Excel together with a national version of MS-Windows (for instance Norwegian Windows), the control menu in Excel will appear in the same language as Windows (the Excel specific menus are still in English). This can cause problems in the documentation and in the Tutorial and the Feature Guide, since the shortcut keys probably will be different. You will for instance not be able to run Tutorial lessons that rely on the control menu.

## Starting Windows Applications from Excel's Control Menu

On the control menu in Excel, a "Run..." menu item will be appended. From this Run menu item you can start the Clipboard and the Control Panel. But Excel assumes that the names of these two applications are in English. If you run a national version of Windows, and Clipboard and Control Panel are called something else in that version, you will have to make another copy of both applications with English names.

To do this do the following:

1. Select MS-DOS Excecutive (Norwegian: MS-DOS-sentralen) by pressing Alt+TAB until you are there.
   
2. Select the File menu (Norwegian: Fil) by pressing Alt+F.

3. Move to the Copy menu item (Norwegian: Kopier) by using the down arrow key.

4. Select the Copy menu item by pressing ↲ (return).

5. Enter the directory and the name of the national version of the Control Panel application in the COPY edit box (Norwegian: Kopier).

   (Move between the two edit boxes by using the TAB key.)

6. Enter the directory name and CONTROL.EXE in the TO edit box (Norwegian: Til) and press ↲.

Now you will get two copies of the Control Panel application. One called CONTROL.EXE (which Excel can find) and one with the original national application name, for instance KONTROLL.EXE for Norwegian Windows.

7. For Clipboard repeat step 2 to 6, but this time you specify the directory and name of the national version of Clipboard in the COPY edit box, and use directory and CLIPBRD.EXE in the TO edit box.

If you have the Norwegian version of Windows and the International version of Excel (assuming ND directory structure) you should write the following in the edit boxes.

## Tutorial and Feature Guide

The Tutorial and the Feature Guide will only work if the thousand separator is set to comma, the decimal separator to period and the list separator to comma. (described in the Reference card Microsoft Excel on your workstation - Installing it and making it work. ND-99.097.1).

## Number Formats

For some countries the format number list box (displayed when you select Format Number) will be displayed with comma as decimal separator and period as thousand separator. When you create customized number formats, you must use comma as decimal separator and period as thousand separator. However, you must use period as the decimal separator and comma as thousand separator when entering numbers into cells, even though the Format Number list box shows something else (assuming ND default WIN.INI settings).

## Currency Symbol

Excel has a cosmetic error when it displays currency in the Tutorial and the Feature Guide. Dollar ($) will often be displayed instead of the currency symbol for the country selected. The user will also be asked to enter $ (which is not available) as a number format. This will not interfere with the execution of the program.

If you change the currency symbol for your country from the default value, using the Control panel, this will not be reflected in Excel.

## Name of Months

The name of the months come out in English even though everything else is set up for another country.

## National Version of Windows

If you use the international version of Excel together with a national version of MS-Windows (for instance Norwegian Windows), the control menu in Excel will appear in the same language as Windows (the Excel specific menus are still in English). This can cause problems in the documentation and in the Tutorial and the Feature Guide, since the shortcut keys probably will be different. You will for instance not be able to run Tutorial lessons that rely on the control menu.

## Sort

The non-US characters are not sorted correctly. (For example the Norwegian characters Æ,Ø,Å.)
