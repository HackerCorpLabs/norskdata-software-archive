## 3 Installation

Before you start the installation of ND LAN Connect, please make sure you have installed the ND PC Starter Kit, and rebooted the workstation.

Insert the ND LAN Connect floppy in drive A or B. Log to correct floppy by typing `A:` or `B:` depending on which floppy drive you are using. After you have logged to correct drive type: `INSTALL`.

The installation program will guide you through a complete setup of ND LAN Connect.

## 4 Manual Installation

To install ND LAN Connect manually you must first locate your ND-OWS directory. If this does not exist, the ND PC Starter Kit might not be installed. Please install this kit before continuing manual installation of ND LAN Connect. If you already have installed it, please reboot your workstation in order to activate parameters set by ND PC Starter Kit.

Insert floppy with ND LAN Connect into floppy drive A or B, and log to correct floppy by entering `A:` or `B:` depending on which floppy drive you are using.

Copy the files with the following commands:

```
COPY SETINIT.* <ND-OWS directory> ~
```

where `<ND-OWS directory>` is the directory where Norsk Data software is installed. For example: `C:\ND-OWS`

Copy the `CONNECT.EXE` file with the following command:

```
COPY CONNECT.EXE <ND-OWS directory>\COMMS ~
```

where `<ND-OWS directory>\COMMS` is the same directory as mentioned above, with `\COMMS` appended to it. For example: `C:\ND-OWS\COMMS`. This is the directory where all Norsk Data communications software is installed.

The last step of the installation is to update the NDCONFIG file. This is done with the NDCONFIG program which is enclosed on the floppy with ND LAN Connect. (The NDCONFIG program can also be found in the MAINT directory under the workstations ND-OWS directory.)

## Commands

Issue the following commands:

```
NDCONFIG -S CONNECT-LAN-INTERRUPT <INT. NO>
```

where `<INT. NO>` can have the following two values: `14H` or `6BH` depending on which software interrupt your network software is using. If you are unsure about this, ask your system supervisor, or consult your network software documentation.

```
NDCONFIG -S OWS-COMM-MEDIUM SERIAL
```

tells the ND Software that you are using SERIAL line type communication which is necessary in order to communicate via interrupt 14 or interrupt 6B (hexadecimal).

## 5 Interrupt Setup After Installation

When the installation program has completed its task, three files have been copied to the hard-disk; `CONNECT.EXE`, `SETINT.EXE` and `SETINT.PIF`.

`SETINT.EXE` will let you easily select which interrupt number you want `CONNECT.EXE` to use when communicating with the network software. This program is started by entering `SETINT` from the MS-DOS command line, or by double-clicking on the `SETINT.PIF` file under MS-Windows. The program is self-explaining.

The interrupt selection can be done even if ND LAN Connect has been installed in the workstation's memory (This is done automatically at startup time). Each time you enter the terminal emulator ND LAN Connect will check which interrupt number that is selected, and use that one.

The interrupt number can also be set manually by using the `NDCONFIG.EXE` program file which resides in the `MAINT` directory under the PC’s `ND-OWS` directory.

Setting interrupt number for ND LAN Connect manually:

```
NDCONFIG -S CONNECT-LAN-INTERRUPT <INT. NO>
```

where `<INT. NO>` can have the following two values: `14H` or `6BH` depending on which software interrupt your network software is using. If you are unsure about this, ask your system supervisor, or consult your network software documentation.
