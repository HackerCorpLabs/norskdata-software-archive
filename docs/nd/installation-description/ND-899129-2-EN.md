## What Does the Product Consist Of

The product consists of one 5 ¼" floppy disk, and one 3 ½" floppy disk with product number ND-230036B01-XX-01D.

The MS-DOS Printer Driver for ND Applications consists of a number of printer drivers, each one representing the different printers supported on the ND Office Workstation. The printer drivers are:

- EPSRX80.PRM supporting EPSON RX80 and PT-88S printers.
- EPSLX80.PRM supporting EPSON LX80/LX86 printers, ND-420 and Ink-jet.
- LINEPRNT.PRM supporting line-printers with simple ASCII output.
- ND720PP.PRM supporting ND-720 and ND-730 printers.
- ND460TPR.PRM supporting ND-460 printers.
- ND-PSCRI.PRM supporting ND-715 PostScript printers.

The different printer drivers are used by ND applications on the Workstations using SSY-LIB for printing. To be able to print from NOTIS-WP for example, one or more printer drivers from the diskette must be installed.

The printer drivers are installed by running the utility program NDPRINT.EXE, which is both a Windows application and a DOS program. In addition to this program, the diskette contains:

- INSTALL.BAT for installing NDPRINT.
- INSTALL.PIF supporting installation under Windows.
- LANG-xx.DAT language file used by DOS program.
- DRIV-xx.DAT temporary file used by DOS program.
- DEF.FIL default values for ND printers.

Whenever a new printer for the workstation is supported by ND, a new printer driver will be released, containing the updated printer drivers and a new DEF.FIL.

## Known Limitations

`^in-bg /^in-graph`

The WP directives `^in-bg` and `^in-graph` are not supported for printing to a local printer.

If printing to a host connected printer, the graphical-file used in the `^in-bg` or `^in-graph` directives, must be stored on the host computer.

## Modifications

Installation of printer drivers will use the environment variable ND-SHARED to find the path to the driver directory and to where the Sprint Information File is located thus making it possible to install printer drivers on a server. If ND-SHARED does not exist, the environment variable ND-OWS is used.

- Error message if installation of a driver fails or writing to SSYINF.DTA fails due to error in I/O.

- Maximum number of feeder types, emulations and destinations is 10. The documentation says 32 but in real life only 9 were possible.
