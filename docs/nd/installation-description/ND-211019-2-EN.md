## 6 Preparing the Devices

### 6.1 Preparing the NOTIS Terminal

Set these values in the Communications Switches Menu for TDV-2200 terminals that will be used to run NOTIS-DRAW:

- Communication handshake: XON/XOFF
- Transmission Code Length: 7 bits
- Transmission Code Parity: Even
- Transmission Code Stop Bits: 2
- Transmission Delay: 42 ms

For TDV-1200 terminals the corresponding settings are found in the COMM.A or COMM.B setup menu (A is used for RS-232 and B for current loop):

- Receive handshake: XON/XOFF
- Communication Code Length: 7 bits
- Communication Code Parity: Even
- Communication Code Stop Bits: 2
- Transmission Delay: 40 ms

Set the same values for the terminal line as follows:

Find the terminal's Logical Device Number with the SINTRAN command @WHO-IS-ON. Continue as shown here, typing the underlined commands and parameters. XXXX represents a number provided by the computer.

```
@SINTRAN-SERVICE↓
*CHANGE-DATA <Logical Device Number>,I,Y,Y,N↓
DFLAG/ XXXX 1001↓
CNTREG/ XXXX 44005↓
*EXIT↓
```

IMPORTANT! The Logical Device Number must be followed by a "D".

### 6.2 Preparing the HP-Plotters

Equipment:

- HP-7475 or HP-7550 A3/A4 plotter
- 325488 Cable between ND-100 and the HP-plotter OR
- 2 local KM-10 modems connected to each other, with a 325345 Cable between the ND-100 and one modem, and a 325651 Cable between the other modem and the HP-plotter

## Connection

- Set the switches at the plotter.

### HP-7475

Set the dip switches at the back of the plotter for 9600 BAUD, A4 paper, direct line and even parity (7-bit character length): 01000100. For further details, see pages 2-21 and 2-23 in the Operation and Interconnection Manual accompanying the HP-7475.

### HP-7550

Set the switches by operating the Front-Panel on the front of the plotter. The Front-Panel looks something like this.

```
 ---------------------------
| Auto         |      Enter |
| feed         |            |
|              |(Display)   |
| Load/        |      Next  |
| Unload       |     Display|
 ---------------------------
```

Turn the power ON, and press the `<ENTER>` key immediately followed by the `<NEXT DISPLAY>` key to enter setup mode. The following should be displayed.

```
 -------------------------
|  HP-IB   MONITOR        |
|  STANDARD SERIAL        |
 -------------------------
```

The unnamed function keys on the front panel corresponding to the text shown on the display are used to set the switches.

Press the STANDARD key, and the text on the display will change to ENHANCED. Press the SERIAL key to enter the communication setup menus. The first menu looks like this:

```
 ----------------------
|  DATA FLOW            |
|  BYPASS HANDSHAKE     |
 ----------------------
```

When you press the DATA FLOW key a submenu appears on the display.

```
 -------------------------
|  REMOTE          *      |
|                STANDALONE|
 -------------------------
```

Set the data flow to REMOTE and STANDALONE by pressing the function keys several times until the correct settings are shown on the display. Press the `<ENTER>` key to exit and save the switch settings. Continue and do the same with BYPASS and HANDSHAKE.

BYPASS is set to OFF.  
HANDSHAKE is set to XON/XOFF and DIRECT.

## 7 How to edit the DRAW-PRINTER file

The printer description file DRAW-PRINTER-B:SYMB on user NOTIS contains information used by NOTIS-DRAW during printing. After the installation is finished, you should check if some of these parameters have to be changed.

The first line:

```
@ENTER <sintran-user>,<passw.>,<proj.passw.>,<no. of min.>
```

This is the first line of a batch input file. This line will be used by NOTIS-DRAW to create the batch input file for printing jobs. On the example file supplied on the floppies, the SINTRAN user is FLOPPY-USER without a password. You may change this to be any SINTRAN user, but remember that you have to supply the user's password! (The batch job may take several minutes).

When the spooling system SPRINT version A02 is available, the drawings will be prepared for printing by SPRINT. The DRAW-PDRIVER program will then append the drawings to the SPRINT spooling queue instead of the SINTRAN spooling queue.

The second line:

```
1
```

This is the batch process number to which the job will be appended.

### NOTIS:

This is a tag the system uses to find other NOTIS products that should be possible to reach directly from NOTIS-DRAW. The tag must remain unchanged.

The NOTIS definitions follow immediately after the NOTIS tag

```
<NOTIS product abbreviation>,<Standard domain name>
```

- `<NOTIS product abbreviation>`: Abbreviated product name. Ex: WP
- `<Standard domain name>`: Name of standard domain. Ex: NOTIS-WP-N

For the time being the following products are available to be included here:

- NOTIS-WP version N
- NOTIS-DS version C

## 8 Include Pictures in Text Documents

You may integrate your drawings in documents made by NOTIS-WP. There are two print directives in NOTIS-WP for this purpose: `^IN-BG;` and `^IN-GRAPH;`. The first of these directives requires the NOTIS-WP-M07. The latter requires the N version of NOTIS-WP and the spooling system SPRINT version A02 or later. `^IN-BG;` will also work with the N version of NOTIS-WP. NOTIS-DRAW uses a batch processor to convert a drawing to the `:PICT` format required for the `^IN-BG;` directive. The output file for the batch processor is the peripheral file DUMMY on SINTRAN user area SYSTEM.

**NOTE:** The M07 version of NOTIS-WP needs a patch to be able to handle the `^IN-BG;` directive properly. Run the MODE job WP-100-M07-PATCH, distributed on the installation floppy, to set the patches.

1. Enter SINTRAN user area SYSTEM
2. Run the mode job by typing

```
@MODE WP-100-M07-PATCH:MODEJ
```

This patch will only change the NOTIS-WP segments and should be run whenever a cold start is performed. Add the following in the mode job used during a cold start (usually called DUMP-REENTRANT:MODE or HENT-MODE:MODE).

```
@MODE (SYSTEM)WP-100-M07-PATCH:MODE
```

Note that the mode job must be run after NOTIS-WP has been defined as a reentrant program.

For more detailed instructions of this patch, see the Customer Support Information report for September 1987.
