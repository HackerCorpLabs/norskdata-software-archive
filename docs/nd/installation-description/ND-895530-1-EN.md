## Description of Product

SOFTICE - Software Installation Control Environment - stores down software activation keys on a file. You will not be able to run protected software before this is done. The software activation key is the string found on the software key certificate.

This certificate is obtained when buying a piece of software from ND. The software itself may be delivered on a floppy disk or as part of the streamed-in software platform. You cannot copy these pieces of software to other machines.

## 4 Installation Procedure

### 4.1 Automatic Installation

None.

### 4.2 Non-Automatic Installation

Copy the file SOFTICE-A:DOM to user SYSTEM or any other user where you want to have it. Insert the floppy disk and type:

```
@ENTER-DIRECTORY,,F=0-1,0,,,
@COPY-FILE "SOFTICE-A:DOM" (211846:FL-US)SOFTICE-A:DOM
@RELEASE-DIRECTORY,211846
```

The floppy disk also contains the program as an old format domain. Use this if your SINTRAN III is too old to accept :DOM files. You can then install SOFTICE on SINTRAN versions older than K-500.

Optional online documentation is available on the floppy disk as a set of :HELP files. You probably do not need them. They can be read into NOTIS-WP. To install them, you create a UE user group called ND-PRODUCTS. Then make a NOTIS-DS user called ND-PRODUCTS. Create a drawer called HELP and a folder called SOFTICE-A01. Store down all the :HELP files in this folder. Assure that all users have read access. The :HELP files are displayed on typing the command names and pressing the HELP-key.

## 5 Modifications

### 5.1 New Functions/Commands

The command STORE-SOFTWARE-KEY installs a software key. You are asked for the information written on the software activation key certificate. The information is stored on (SYSTEM)SOFTWARE-KEY:DATA. Do not edit this file with an editor adding parity to the file.

This is an example of how to install a software key:

    SICE: STORE-SOFTWARE-KEY  
    Product number: 121212  
    Software key: Xc4qhJKWQs  
    Product name: MA/MPS system version B02  

Note that upper and lower case letters are significant in the software key.

Other commands are LIST-SOFTWARE-KEYS and DELETE-SOFTWARE-KEY. The ND-SHELL user interface is used.
