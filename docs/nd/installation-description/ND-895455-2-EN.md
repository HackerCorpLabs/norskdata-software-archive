## DESCRIPTION OF PRODUCT

The NOTIS-MEMO Bridge will offer a connection between the IBM Mail system MEMO and the ND Mail system NOTIS-ID. Notes and documents can be exchanged in both directions.  
Software needed is installed both in the ND system and in the IBM system. The communication is carried out using ND SNA 3270 Program Access via the ND SNA Gateway-II on the ND system and via MEMO/LU2 on the IBM system.  
The Bridge performes conversions of addressing and documents between MEMO and NOTIS-ID. Correctly installed the bridge will be transparent to the end-users.

## REASON(S) FOR NEW PRODUCT OR VERSION

Approved version after β-testing.

# 4 Installation Procedure

The product is delivered on two double density product diskette.

## 4.1 Automatic Installation

Preferably check that there are sufficient space free on user SYSTEM (305 pages and 7 files), decide which directory You want to put the Bridge in and if it has enough of free space.

Log in as user SYSTEM.

Insert the floppy labelled 211677A04-EN-01D in the floppy disc unit, and enter the directory:

```
@ENTER-DIRECTORY 211677A04-EN-01D FLOPPY-DISC-1 <UNIT NR>↵
@(211677A04:FL-US)INST-MEMO-A04↵
```

The installation program will now start. As the installation proceeds, all necessary instructions will be given. All files will be copied to the user <sna-memo-bridge>. Old versions of the product will be deleted.

To complete the installation You have to run a mode file to load the RT programs.

```
@MODE (SNA-MEMO-BRIDGE)MEMO-LOAD-A04:MODE↵
```

Continue with following preparations with help of the Supervisor guide.

- Configure the LU’s on the SNA GATEWAY.
- Configure COMMUNICATIONS and MAIL-SYSTEM using the program MEMO-SUP
- Create UE (UE-PMAN) and DS users on ND for the MEMO users
- Create the MEMO-USER-LIST containing NOTIS-ID and MEMO users.
- Start the Bridge using MEMO-SUP.

MODE files for starting and stopping the Bridge are enclosed.

## 4.2 Non-Automatic Installation

## 5 Modifications

This chapter describes modifications done after the β-testing was finished.

### 5.1 New Functions/Commands

None

### 5.2 Changed Functions/Commands

Error reporting phrases are fetched from UE-ERMSG-EN-D11 which contains errorcodes for NOTIS-MEMO-Bridge.

The NOTIS-MEMO-Bridge Supervisor user interface is modified according to ND standard.

### 5.3 Removed Functions/Commands

None

### 5.4 Other Modifications

If a MEMO user not defined in UE/OS on the ND system sends mail to ND, the mail will be delivered with an user identification telling that a letter has been received from a not listed MEMO user. No status report will be returned to MEMO in this case.

## 6 Errors Corrected

This chapter describes errors corrected after the β-testing was finished.

Address conversions between NOTIS and MEMO is corrected to be able to exchange letters with other MEMO networks than the one the NOTIS-MEMO-Bridge is connected to.

## 7 Errors Known But Not Corrected

No known in the Bridge.
