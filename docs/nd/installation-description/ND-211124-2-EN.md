## 1 Note

<rev> is to be replaced by the current revision of the DIRECTORY or FILE. Revision is found on the "ND SOFTWARE LIBRARY DISKETTE" pages.

## 2 Errors Corrected

- **LOOK-AT-REGISTER**: It was impossible to write a value into X4 register.

- Prior to starting each test, the AIB register is checked for valid content. If it contains valid data, it is cleared to inhibit false data for the test.

- MM verify, tests 5 and 6 wrote in MF memory outside reserved area.

- On CPUs of type ND-5800, the following tests failed in the previous version of SEMICS: Cache test, tests 7 and 16-20; IDA verify, test 1; IDU register, tests 15, 17, 20 and 22; DAC test, test 26. These tests are now corrected.

- In some special cases (PAL specs., Temperature etc.), Cache test, tests 1 and 8-12 may fail in version A00 of SEMICS. This is now corrected.

## 3 Known, But Not Corrected Errors

- The LOOK-AT-CACHE command: On CPUs of type ND-5800, the fields 'LA' and 'DDIR' in data cache are not valid.

## 4 Changed Prerequisites

- This version needs work mode 406, or newer, of SINTRAN for ND-5000.
- The ACCP PROMS should be dated 06.07.87 or later.

## 5 Modifications

### 5.1 Changed Commands

- The LOOK-AT-CONTROL-STORE and LOOK-AT-MEMORY commands now display next location after a deposit. In version A00 of SEMICS, the current location was redisplayed.
- The LOOK-AT-CONTROL-STORES subcommands which access files are changed. The files will now be searched under current user (SYSTEM) if no user name is specified.
- The LOOK-AT-CONTROL-STORES disassembler is now able to disassemble the mnemonic 'NEXT*'.

### 5.2 New Commands

- CHANGE-CPU is used to move to another CPU in multi-CPU systems (ND-5900). This command runs only from SINTRAN work mode 500.
- EXPLAIN-ABBREVIATION is implemented. It explains words which are used in the ND-5000 terminology.
- CONTROL-STORE-TEST is implemented.
- NEWS command is implemented, telling about changes from previous versions.

# 6 INSTALLATION PROCEDURE

ND-5000 Test Microprograms is delivered on two double sided/double density floppy diskettes.

1) The floppy diskette 211124B<rev>-XX-01D contains :
   - TPE monitor
   - SEMICS command overlays
   - Abbreviation table
   - Extended Error Information

2) The floppy diskette 211124B<rev>-XX-02D contains the collection of microtests.

The microtests can be run in two ways:

1) From the hard disk.
2) From the floppy disk.

We recommend you to copy all files to the hard disk. The other way, which is slower, should only be used when you are out of disk space. In both cases the TPE monitor and SEMICS itself must be loaded to the hard disk. If the extended error information is to be used, the microtests must be run from the hard disk too. (Regarding extended error information, see the SEMICS User Guide (20.024.2).)

## 6.1 Preparations for running SEMICS.

1) Running SEMICS from the hard disk requires approximately 155 pages. (TPE monitor, SEMICS command overlays and the abbreviation table.)

2) Running microtests from the hard disk requires approximately:
   - 710 pages if the extended error information is not used.
   - 855 pages if the extended error information is used.

### 6.1.1 Loading the TPE monitor and SEMICS command overlays.

1) Log in as user SYSTEM.

2) Create the user ND5000-SEMICS.

   @CREATE-USER ND5000-SEMICS

### 6.2 Starting the TPE monitor

To start the TPE monitor:

1. Log in as user SYSTEM.
2. Type the following:

```
@(ND5000-SEMICS)TPE-MON-100-:PROG↵
```

When the TPE monitor has started, it will identify itself with this heading:

*TPE Monitor, ND-100 / ND-110 - Version: Inn - yyyy-mm-dd*

The TPE monitor is now ready to accept your commands.

### 6.3 Starting SEMICS

When the TPE monitor is running, you can load the test program as follows:

```
>Load (ND5000-SEMICS)SEMICS↵
```

The program will identify itself and the SEMICS program commands will be available.

Remember that the first command used after starting SEMICS is INVESTIGATE-AND-RESERVE.

Exception: When the ND-5000 CPU has very poor HW status it may be impossible to run this command. System parameters are then set with the command SET-PARAMETER.

If you are running the microtests from the floppy diskette, after entering the floppy diskette 211124B<rev>-XX-02D, you must specify directory and user name when you run the first test. Example:

```
TPE>RUN↵
Test system: (211124B<rev>-XX-02D:FLOPPY-USER)<Test name>↵
```

The commands NEWS and INFO may be useful. They give information about the current version of SEMICS.
