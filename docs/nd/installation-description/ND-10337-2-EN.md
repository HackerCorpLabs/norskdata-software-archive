**LOADING/OPERATING PROCEDURE, USE**

COPY THE FILE BACKUP-SYSTEM:BPUN FROM THE FLOPPY CALLED ND-10337B (BACKUP-SYSTEM FOR SINTRAN-III) TO THE USER WHERE YOU KEEP THE :BPUN FILES (SYSTEM,UTILITY,BPUN-FILES....)

**EXAMPLE:**

LOG IN UNDER THE USER WHERE YOU KEEP THE :BPUN FILES:
```
@ENTER-DIRECTORY ND-10337B,FLOPPY-DISK-1<,0>
@COPY-FILE "BACKUP-SYSTEM-B:BPUN" (ND-10337B:F-U)BACKUP-SYSTEM:BPUN
```

LOG IN UNDER USER SYSTEM
```
@DUMP-REENTRANT BACKUP-SYSTEM-B 0 0 (???)BACKUP-SYSTEM
```

**ONLINE DOCUMENTATION**

ONLINE DOCUMENTATION CAN BE OBTAINED FROM THE BACKUP-SYSTEM BY THE FUNCTIONS HELP AND (?)

**HELP**

FUNCTION FOR LISTING COMMANDS OR A SUBSET OF COMMANDS.
HELP HAS COMMAND-NAME AS PARAMETER. IF HELP IS TYPED AS PARAMETER TO HELP, THE COMMANDS WILL BE LISTED WITH CORRESPONDING EXPLANATIONS.

**(?)**

A (?) FOLLOWING AN AMBIGUOUS COMMAND ACTS AS HELP WITH THE COMMAND-NAME AS PARAMETER. IF THE COMMAND IS UNIQUE, AN EXPLANATION OF THIS COMMAND IS GIVEN. A (?) GIVEN IN PLACE OF A PARAMETER WILL EXPLAIN THIS PARAMETER.

THE BACKUP-SYSTEM WILL ACCEPT SEVERAL COMMANDS WRITTEN ON THE SAME LINE. WHEN THESE COMMANDS ARE PROCESSED, THE BACKUP SYSTEM WILL TRACE THEM BY OUTPUTTING THE LEAD-TEXT,COMMAND-NAMES AND PARAMETERS COLLECTED.

# CHANGES

- LABELS ARE CHANGED TO INCLUDE MAX BYTE POINTER ALSO WHEN COPYING IN STANDARD VOLUME MODE. THIS WILL ENSURE CORRECT BYTE POINTER ON DESTINATION FILES WHEN INTERCHANGING TAPES BETWEEN BACKUP-SYSTEM AND SINTRAN COPY-USERS-FILES.

- CORRECTED ERROR IN INPUT ROUTINE WHEN SELECTING FILES TO BE COPIED. FILE-TYPE WAS SOMETIMES IGNORED.

- CORRECTED ERROR WHEN CHECKING ON OWNER OF VOLUME. USERS WITH NAMES LONGER THAN 13 CHARACTERS WERE NOT ALLOWED TO ACCESS THEIR VOLUMES.

- ERRORS LIKE NOT-READ-ACCESS WHEN ACCESSING SOURCE-FILES CAUSED THE BACKUP-SYSTEM TO ABORT COPYING. THE BACKUP-SYSTEM WILL NOW PRINT THE FILE-NUMBER, ERROR MESSAGE AND CONTINUE COPYING THE FOLLOWING FILES.

- WHEN SOURCE-FILES ARE DEFINED FROM A PARAMETER-FILE, THE BACKUP-SYSTEM WILL NOT TERMINATE IF NO FILES ARE FOUND UNDER A GIVEN FILE KEY. THE BACKUP-SYSTEM TERMINATES AT END-OF PARAMETER-FILE.

- MAG-TAPE UNIT WAS NOT RESERVED WHEN A COPY WAS EXECUTED FOLLOWING A LIST- OR CREATE-VOLUME COMMAND. THE MAG-TAPE UNIT IS NOW RESERVED WHEN ACCESSED AND STAYS RESERVED UNTIL A NEW UNIT IS ACCESSED OR EXIT FROM THE BACKUP-SYSTEM IS PERFORMED.

- CHANGES HAVE BEEN MADE IN THE TAPE INPUT ROUTINES OF THE BACKUP-SYSTEM TO ACCEPT VARIOUS IMPLEMENTATIONS OF THE ANSI-LABEL STANDARD. THE BACKUP-SYSTEM WILL TURN ON MANUAL-CHECK IF FILES AND NAMES ARE INCOMPATIBLE WITH ND-FILESYSTEM. A POSSIBILITY TO REDEFINE THE NAMES IS THEN GIVEN AND THE FILE WILL BE CREATED ACCORDING TO THE NEW NAMES. THIS MIGHT MAKE IT POSSIBLE TO COPY FROM FOREIGN ANSI-LABELLED TAPES WITH THE BACKUP-SYSTEM.

- MANUAL CHECK WILL NOW ACCEPT LOWER-CASE CHARACTERS.

- MINOR CHANGE IN LIST-VOLUME TO ALLOW 4 DIGIT FILE-NUMBERS.

- CORRECTED ERRORS IN USER- AND MASTER-LOG MODES CONCERNING OPENING OF LOG-FILES.
