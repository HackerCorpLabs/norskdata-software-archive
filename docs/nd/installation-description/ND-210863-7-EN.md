## 1. Error Correction

1. Error when an implied do-loop inside a do-loop was compiled with ARRAY-INDEX-CHECK ON.

2. Error when using '!' in format statement and as inline-comment.

3. Close for unit 100 (scratch file) is corrected.

4. The values of FORMATTED and UNFORMATTED parameters in INQUIRE statement are corrected.

5. The unformatted I/O of arrays over 32 kB is corrected.

6. By unsuccessful unformatted reading from outside of a file, the max-byte-pointer was increased.

7. Programs trying to open more than 20 files were hanging.

8. Close(-1) closed only 1 file.

## 2. Changes/Addition

1. **NEW FILE-FORMAT FOR SEQUENTIAL UNFORMATTED I/O WITH VARIABLE RECORD-LENGTH.** Four bytes before and beyond each record is used to hold the record length. This new file-format is used in the cases when READ and WRITE statements do not have REC or FMT specifiers, and the OPEN statement does not have RECL specifier. As a consequence of this new format, it is now possible to backspace, skip records when reading and have empty records in the file. This is all part of the FORTRAN'77 standard. The only place where this new format will cause trouble is when using unformatted sequential I/O with variable record-length, and the file is written with the old format and read with the new format.

   When using unformatted sequential I/O with fixed record length, the old file format is used if the RECL specifier in the OPEN statement is used.

2. Inquire for remote files is now implemented. Because of some restrictions in Sintran INQUIRE by Name returns only deabbreviated file-name.

3. The testing of correct values of the parameters to runtime routines that was done only at runtime, is now done at compile-time when possible.

## 3 Installation Procedure

FORTRAN Crosscompiler and runtime system for ND-100 is supplied on five diskettes, with directory name 210863G<rev>-<lang>-01S to 210863G<rev>-<lang>-05S. If you have ordered DS/DD diskette, the name is 210863G<rev>-<lang>-01D.

- Installation procedure to generate the FORTRAN system:

Log in as user SYSTEM and perform the following commands:

```
@ENTER-DIRECTORY 210863G<rev>-<lang>-01,F-D-1,,,
@(210863G<rev>-<lang>-01:FLOPPY-USER)IN-FORTW
```

The installation program will ask for and give the necessary information to install the system.

## 4 Change Default Values

It is possible to change the default value of some system variables permanently. The change is achieved by executing the following commands (or mode file):

```
@ND∟
N500: LOOK-AT-DATA <addr>,FORTRAN-100-G<rev> ∟
PER∟
<value>∟
EXIT∟
EXIT∟
```

`<addr>` is the address of the system-variable, and `<value>` is the value to be inserted.

| `<addr>`    | `<value>`          | effect                                 |
|-------------|--------------------|----------------------------------------|
| 1'14110B    | 1/0                | same as: STANDARD-CHECK ON/OFF         |
| 1'14124B    | 1/0                | cross-ref is default/not default       |
| 1'14144B    | 1/0                | program-map is default/not default     |
| 1'14314B    | num                | same as: PAGE-SIZE num                 |
| 1'14060B    | 1/0                | same as: SEPARATE-DATA ON/OFF          |
| 1'14160B    | 62010B/63010B      | same as: IMPLICIT ON/OFF               |
| 1'14164B    | 6002432B/6002422B  | same as: UNASSIGN-VAR-CHECK ON/OFF     |
