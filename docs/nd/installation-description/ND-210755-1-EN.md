## 2 Installation Procedure

- Enter the directory named 210755A<rev>-XX-01D, and do as follows:
  - ACC Procedure for generating the BASIC-LIB-A<rev>:
    - @COPY-FILE↲
    - DESTINATION FILE: "BASIC-LIB-A<rev>:NRF" ↲
    - SOURCE FILE: {210755A<rev>-XX-01D:FLOPPY-USER}BASIC-LIB-A<rev>:NRF↲
  - ACC
  - ACC Procedure for generating the BASIC-500-A<rev> domain:
    - @CC
    - @ND_LINKAGE-LOADER↲
    - ND-Linkage-Loader - X
    - N1l:ABORT-BATCH-ON-ERROR OFF↲
    - N1l:DELETE-DOMAIN BASIC-500↲
    - N1l:COPY-DOMAIN (210755A<rev>-XX-01D:FLOPPY-USER)BASIC-500-A<rev> "BASIC-500 A<rev>"↲
    - N1l:EXIT↲
  - ACC
  - ACC Procedure for making the BASIC-500-A<rev> a standard domain:
    - ACC Now, You must be user SYSTEM!
    - @ND↲
    - ND-500 MONITOR Version X
    - N500:DEFINE-STANDARD-DOMAIN BASIC-500-A<rev> BASIC-500-A<rev>↲
    - N500:EXIT↲
  - ACC Now, the BASIC compiler can be started as follows:
    - @BASIC-500-A↲
    - ACC or:
    - @ND BASIC-500-A↲
