## 5 Installation procedure

### 5.1 Automatic installation

None

### 5.2 Non-automatic installation

- Check prerequisites listed in chapter 2.
- Log in as user PROG-FILES.
- Insert the floppy 300000A00-XX-01D into a vacant floppy unit.
- Enter the directory and do as follows:

```
@COPY-FILE
DESTINATION FILE: "Y-XX-A00:PROG"
SOURCE FILE: (300000A00-XX-01D:FLOPPY-USER)Y-XX-A00:PROG
```

- Release the directory and remove the floppy.
- Log in as user SYSTEM and do as follows:

```
@DUMP-PROGRAM-REENTRANT Y-XX-A00 (PROG-FILES)Y-XX-A00:PROG
```

### 5.3 Updates to the system operation files

- Remember to update the (SYSTEM)DUMP-REENTRANT:MODE file (or corresponding) with the following commands:

```
@DELETE-REENTRANT Y-XX-A00
@DUMP-PROGRAM-REENTRANT Y-XX-A00 (PROG-FILES)Y-XX-A00:PROG
```

## 6 Limitations

Y does not work on TDV-1200 terminals if the terminal is in Native mode.

## 7 Information

Y will clear the screen on the following terminals (and all terminals that use CTRL-Y as "clear screen").

- TDV-21xx
- TDV-22xx
- TDV-12xx (in 2115 mode only)
