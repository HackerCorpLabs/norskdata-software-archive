## 5 Installation procedure

### 5.1 Automatic installation

None

### 5.2 Non-automatic installation

- Check prerequisites listed in chapter 2.
- Log in as user DOMAIN-USER.
- Insert the floppy 300001A00-XX-01D into a vacant floppy unit.
- Enter the directory and do as follows:

```
@COPY-FILE
DESTINATION FILE: "Y-XX-A00:DOM"
SOURCE FILE: (300001A00-XX-01D:FLOPPY-USER)Y-XX-A00:DOM
```

- Release the directory and remove the floppy.
- Log in as user SYSTEM and do as follows:

```
@ND-500-MONITOR
N500: DEFINE-STANDARD-DOMAIN
Standard domain name: Y-XX-A00
Domain name: (DOMAIN-USER)Y-XX-A00
N500: EXIT
```

### 5.3 Updates to the system operation files

- Remember to update the (SYSTEM)ND500-HENT-MODE:MODE file (or corresponding) with the following commands:

```
@ND-500-MONITOR
DELETE-STANDARD-DOMAIN Y-XX-A00
DEFINE-STANDARD-DOMAIN Y-XX-A00 (DOMAIN-USER)Y-XX-A00
EXIT
```

## 6 Information

Y will clear the screen on the following terminals (and all terminals that use CTRL-Y as "clear screen").

- TDV-21xx
- TDV-22xx
- TDV-12xx (in 2115 mode only)

## 7 Limitations

Y does not work on TDV-1200 terminals if the terminal is in Native mode.
