# 4 Installation Procedure

## 4.1 Automatic Installation
None

## 4.2 Non-Automatic Installation

- Before you start installing the patch file, check that SIBAS Manager A05 is installed and passive, and not defined as standard domain.

Log in as user: `SYSTEM`

```
@ND-
LIST-STANDARD-DOMAINS-
DELETE-STANDARD-DOMAIN SIBAS-MANAGER-A05-
EXIT-
```

- Log in as user: `SIBR-B`

- Insert the floppy 380862A05-XX-01D in floppy drive 0

```
@ENTER-DIRECTORY 380862A05-XX-01D,F-D,1,O-
```

- Run the mode file:

```
@MODE (380862:FLOPPY-USER)SM-PATCH-A05:PATC "SM-PATCH-A05:POUT"-
```

- Check the output file for errors

```
@RELEASE-DIRECTORY 380862A05-XX-01D-
```

- Define the standard domain again.
Log in as user: `SYSTEM`

```
@ND-
DEFINE-STANDARD-DOMAIN SIBAS-MANAGER-A05 (SIBR-B)SM-OPERATOR-A05-
EXIT-
```

- The installation of this product is now completed.
