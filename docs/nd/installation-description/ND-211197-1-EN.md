## 1 INTRODUCTION

COSMOS X.25 Program Access is offered to ease the use of the message interface for the COSMOS X.25 Options, for both PIOC and HDLC. Intended users are software houses and ND departments with a good knowledge of COSMOS/XMSG programming.

The product consists of a set of library routines which format the messages going to the X.25 Packet Level module, and react to events stemming from the X.25 Packet Level. The library resides in the user address space, and acts as a part of the RT-process or Background program.

The COSMOS X.25 Program Access was delivered as an intrinsic part of the COSMOS X.25 Option (for HDLC), 210573C. For later versions of that product it will be separate. This is because it is a common part for both the COSMOS X.25 Options (ND no. 210570 and ND no. 210573), and because the XMSG programming involved here is too complicated to be categorized as a standard product.

## 2 SYSTEM PREREQUISITES

The following are prerequisites for the installation of the product COSMOS X.25 Program Access:

### SOFTWARE:

- **COSMOS X.25 Option:** The libraries may be used with both COSMOS X.25 Option (HDLC-based version) - ND no. 210573C, and the COSMOS X.25 Option for PIOC - ND no. 210570A.
- **Operating System:** SINTRAN III version J or later.
- **X-MESSAGE:** Version J or later with a minimum of 15 ports.

## 3 SYSTEM OVERVIEW

The system consists of the three library files, definition and import files necessary for compilation, and examples of use. The examples may be used both as an extension of the documentation, and as a base for building one's own programs.

# INSTALLATION PROCEDURE

## 4.1 Copying the files from the diskettes

In the following instructions, replace `<rev>` with the current revision number.

- Log in as the user which should contain the library files.
- Make sure that this user has at least 60 pages of disk space available.
- Insert the diskette with the directory name 211197A<rev>-XX-01D (double density diskette) or 211197A<rev>-XX-01S (single density diskette).
- Execute the following commands (operator input is underlined):

```
@ENTER-DIRECTORY,211197A<rev>-XX-01,FLOPPY-DISC-1,0-_
```

```
@PERFORM (211197A<rev>-XX-01:FLOPPY-USER)INST-X25PA-A:MCRO-_
```

```
PERFORM 2412F
```

Macro name (Default = INSTALL-X25) : _

The installation procedure will then start. It will perform the following tasks:

- Check the user specified.
- Delete old product files if of the same version.
- Copy the new files to the given user.

A remote copy mechanism is available, using COSMOS File Transfer. It can be started by the command sequence:

```
@ENTER-DIRECTORY,211197A<rev>-XX-01,FLOPPY-DISC-1,0-_
```

```
@PERFORM (211197A-XX-01:FLOPPY-USER)INST-X25PA-A:MCRO-_
```

```
PERFORM 2412F
```

Macro name (Default = INSTALL-X25) : REMOTE-I-X25-_

## 4.2 Loading

When you have installed the new COSMOS X.25 Program Access files, you can load your program as shown in the file X25PA-LOADEX-A:MCRO.

## 5.1 Facility negotiation.

To provide for compatibility between the A-version of X.25 and later versions, facility negotiation is done after a special scheme. This applies to the Connect Accept command in the four-step connect procedure.

If no facilities are given here, (Fac. length = 0), the X.25 Packet Level will choose Standard Default Values for Window and Packet Sizes (W.S.=2 and P.S.=128 Bytes). If facilities are given, these are of course used by the X.25 Packet Level, and a corresponding Connect Accept Packet will be sent if values are correct.

The X.25 Packet Level will _always_ negotiate the Packet Size to its Standard Default Value, which is 128 Bytes.
