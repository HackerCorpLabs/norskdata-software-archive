## Purpose

To provide an interactive version of the relational language SQL for use with SIBAS databases.  
The A version of SQL will only include the DML part of the SQL language, which makes it possible to query existing SIBAS databases.  
New databases must be defined with SIB2-DRL.

# 1 INSTALLATION PROCEDURE

The system may be delivered on:

- **A** - 1.2 Mbyte, 8 inch or 5 1/4 inch double-sided diskettes
- **B** - 0.3 Mbyte, 8 inch single-sided diskettes

You must use the same kind of diskettes ("A" or "B") throughout the whole installation procedure. The installation procedure is fully interactive, which means that once started, it will continuously check the operation. It will inform the operator if any error(s) occur, and what to do to continue.

## 1.1 How to run the installation procedure

- Log in as user SYSTEM.
- Ensure that you have the H-version of LINKAGE-LOADER available on your system.
- If you want to install the example database used in the SQL User Manual you must have a version of SIB2-DRL on user SYSTEM.
- Insert the diskette containing the directory name 211049A-XX-01 into the diskette station.
- Execute these commands (operator input is underlined and parameters are enclosed in brackets and must be terminated by ⏎ (carriage return)).

```
@ENTER-DIRECTORY 211049A-XX-01⏎
DEVICE NAME: FLOPPY-DISC-<drive-no.>⏎
DEVICE UNIT: <floppy-unit>⏎
@(211049A:FLOPPY-USER)SQL-INSTALL-A⏎
```

The installation procedure has now started. It is self-explanatory. If errors occur during installation, the program will display the reasons.

When the installation program terminates, give the SINTRAN command:

```
@DELETE-FILE SQL-INSTALL-A:XCOM⏎
```

## 1.2 Patching in SIBAS

If your SIBAS is version E10 or older, the patch file SQL-PATCH:SYMB must be run from the SIB2-500 user.

This must be done **before** you use the SQL system.

Give this command to run the patch:

``` 
@MODE SQL-PATCH-A<rev>:SYMB,,↵
```

## 1.3 How to start the SQL program

When the installation program terminates normally, a standard domain named SQLI-A<rev> has been generated. The program is started by giving the command:

``` 
@SQLI-A<rev>↵
```

The program will display a log-in form and you enter the database you want to use and the password. You can also enter the log-in parameters on the command line by typing:

```
@SQLI-A<rev> <db-name>,<password>↵
```

If you have a password, this log-in method will display the password.

## 2 REGENERATING THE SQL PROGRAM

If the ND-500 domain should be destroyed, or if a new version of SIBAS is installed on your system, do the following:

- Log in as user SYSTEM and delete the standard domain by typing:
  ```
  @ND↲
  DELETE-STANDARD-DOMAIN SQLI-A<rev>↲
  ```
- Log in as the user where SQL has been installed and run:
  ```
  @MODE SQLI-A<rev>:LOAD,,,↵
  ```
- Log in as user SYSTEM and define SQLI-A<rev> as a standard domain by typing
  ```
  @ND↲
  DEF-STANDARD-DOM SQLI-A<rev> (<sql user>)SQLI-A<rev>↲
  ```

## 3 SAVING DISK SPACE ON YOUR SYSTEM

If you have little disk space available on your system, the :NRF files on the user where SQL is installed can be deleted.

If the SQLI domain needs to be reinstalled, the installation program has to be rerun.

## 4 HOW TO USE NEW DATABASES

New databases are made available by defining them in the (SYSTEM)SQL:BASE file.

A description of this is found in Appendix E of the SQL User Manual.

## 5 How to Set SQL in Read/Readwrite Mode

The SQLI program has a flag telling if the program is allowed to perform SIBAS updates.

This ReadWrite flag can be turned on/off in the following way:

```plaintext
Read Only                  Read Write
@ND-                       @ND-
LOOK-AT-DATA 1'4B SQLI-A-  LOOK-AT-DATA 1'4B SQLI-A-
PERMIT-                    PERMIT-
0-                         1-
EXIT-                      EXIT-
EXIT-                      EXIT-
```

## 6 Languages Available in SQL

SQLI supports two languages, English and Norwegian.

- When logged in via SINTRAN, English is the only language available.
- When logged in via User Environment, you will automatically get the language defined in your User Profile in User Environment. If the language does not exist (i.e. other than English or Norwegian), the default language is English. You are only authorized to give SINTRAN commands inside SQLI if it is granted in the User Profile.

Please note that the SQL language itself will always be in English. This is because SQL is an international standard.

## 7 Storing Queries in Existing Databases

In order to fetch and store queries, the database has to be redefined.

A detailed description of this is given in Appendix D of the SQL User Manual.
