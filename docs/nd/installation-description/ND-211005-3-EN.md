## 2 Installation Procedure

### 2.1 Introduction

All messages/texts used by Unique products come from the language dependent UNIQUE Text System files under user DIALOG-SYS.

The Text System must be properly installed before any UNIQUE products may be run.

Some language dependent examples are included on the diskette, but to install these you must run the installation program for UNIQUE or XTRA and select the option INSTALL EXAMPLES.

**Note:** There is no example of 'Exit to editor' (NOTIS-WP/Wide-column), but it is possible to include this if you use SIBAS/R. In the DIALOGUE - UNIQUE Programming Examples Manual there are examples on how to do this.

### 2.2 Installation

The installation is done by a program provided on the floppy.

The following is an example of the installation of UNIQUE Text System (user input underlined).

Log in as user SYSTEM:

```
@ENTER-DIRECTORY 211005C<rev>-<lang>-01 F-D-1 0J
@{211005C:FLOPPY-USER}TEXT-SYS-INJ
```

This program will copy all the files from the floppy to user areas DIALOG-SYS, ND-OPERATIONS and SYSTEM. The user area will be created or expanded if necessary. If using single-sided diskettes, replace the diskettes as instructed. The installation program will guide you through the installation.

## 3 Error Messages

If the Text System has been incorrectly installed or is out of date, the following error messages may appear when running a UNIQUE product:

- 'Can not open message file (DIALOG-SYS)UNIQUE-<lang>-C:UTXT'

This will result if you do not have read and common (RC) access to the file or the file does not exist. Check that the language file you requested exists on user DIALOG-SYS with public read and common (RC) access. Also check if the program that you tried to run requires a newer version of the Text System. Contact your distributor for the latest version of the Text System.
