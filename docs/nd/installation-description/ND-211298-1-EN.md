# Program Description

| Product | Name | Reg. no. | Category |
|---------|------|----------|----------|
|         | NORTEXT Mathematic Composition Package | 211298A | STNC |

## 1 The Product

The format package contains a set of formats for composing mathematic formulas on phototypesetters and PostScript laser printers.

## 2 Customize

Before utilization, the setup parameters described for each format should be adjusted to fit the fonts and pointsizes normally used for mathematic formulas.

## 3 Phototypesetter Requirements

1. The phototypesetter ought to work in increments of 1/10 of a point for pointsize and leading.
   
2. Mathematical symbols like integral, root, sum, parenthesis, brackets etc., are all made up by using pointsize and setwidth. The phototypesetter should therefore be able to mix pointsize and setwidth without any range restrictions.

## 4 Installation Procedure

1. Log in as a legal NTX-user.

2. Enter the directory on the floppy diskette 211298A<rev>-XX-01D.

3. Use the BACKUP-SYSTEM to copy the format file from the floppy diskette to the disk.

4. Activate the format file in the parameter file: (PARAMETERS-NTX)NTKWP-PARAM:NTWP

5. Delete and load LAMU.
