# Description of Product

NOTIS-ID is ND's electronic mail system aimed at distribution of messages and documents in a COSMOS network. This diskette contains the Norwegian version of NOTIS-ID Main User Program to be run on the PC.

The product consists of one 5 1/4" floppy 230146B10-NO-01D

or one 3 1/2" floppy 30146N01B10

containing the installation program and datafile, the NOTIS-ID Main User Program and the screen layout language dependent datafile.

**Documentation:**

NOTIS-ID Brukerveiledning  
863011.02 NO

# Reason(s) for New Version

```
This version of NOTIS-ID is the first version running on PC. It
is a part of the PC-NOTIS product range. The differences in user
interface between NOTIS-ID for ND-500(O) and PC-NOTIS ID are
kept on a minimum.
```

## 5 Modifications

### 5.1 New Functions/Commands

PC-NOTIS ID is a part of the PC-NOTIS product range. The complete environment consists of NOTIS-WP Word Processing, NOTIS-CALC Spreadsheet, NOTIS-DS Document Storage and a common NOTIS menu system, all running on the PC. From the menu system it is possible to start applications running both on the PC and on the SINTRAN server. Full integration between PC-NOTIS products and SINTRAN-based NOTIS products is supported.

A new version of Bms is included making it possible to move back and forth between programs in HOST and programs in PC.

Code is added to get correct filetype when copying to and from MS-DOS. :TEXT <=> .TXT and :CLCB <=> .CLC. Implemented as parameters in NDCONFIG.

### 5.2 Changed Functions/Commands

- Added CALC as possible NOTIS menu entries on PC.
- Added code to take enclosures from MS-DOS.
- Added code to make it possible to answer MS-DOS as answer to "Drawer:" and any MS-DOS path as answer to "Move letter to folder:" when using the "Move" or "COPY" keys.
- Added code to expand filename with seconds and hundreds of a second if the name of a MS-DOS file gives a name conflict.
- Changed code to avoid marking a letter as read if read by a friend of the receiver. Mailcount will not be decremented and no receipt is sent.

### 5.3 Removed Functions/Commands

- Removed @ and ! as commands for PC.

## 5.4 Other Modifications

PC-NOTIS ID uses a text compiler for handling language dependent texts. When PC-NOTIS ID is started the first time after installation, these texts will be compiled. This results in a longer startup time the first time after installation.

For more details on differences, please refer to the "PC-NOTIS Brukerhåndbok".
