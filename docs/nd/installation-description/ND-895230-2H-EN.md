### How to install Special Modification reports

Customer-specific modification patches (Referred to as Special Modification or SM) are stored on this patch file diskette, but they will not be automatically installed when running the patch file, unless specified. Each SM report is identified by a special symbol called a library mark. The library mark consists of the letters PN and the report number.

If you want to install SM reports on a system the first time patch file 3200 is run, the file PF-MODIF-M:FADM must exist under user area SYSTEM. The library marks for the SM reports wanted must be written to the file before running the patch file.

#### Example:

1. You want to install SM reports SSR-31 and SSR-35 together with the patch file.

2. `@CREATE-FILE PF-MODIF-M:FADM 0`

3. The file PF-MODIF-M:FADM should look like this (REMEMBER 7 BITS FORMAT):

   ```
   PN031
   PN035
   @
   ```

4. Install SINTRAN from diskette and run the patch file.

If you don’t want any SM reports, install SINTRAN and run the patch file as usual. The file PF-MODIF-M:FADM will still exist under user area SYSTEM. This file will only contain the `@` character, and should be kept for future use.

When an SM report is wanted later on, the library mark for the corresponding SM report has to be written to the file PF-MODIF-M:FADM before SINTRAN is installed from diskette together with the patch file.

#### Example:

1. Edit the file PF-MODIF-M:FADM so it contains the library mark for the wanted SM-report.

2. Install SINTRAN from diskette, and run the patch file.
