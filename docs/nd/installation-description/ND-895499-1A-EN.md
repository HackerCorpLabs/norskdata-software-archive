## 6 Installation

Regarding installation of Connect on diskless PC’s, please refer to the installation description in the Product Information sheet for 3Station Start volume ND-380722.

Before you start the installation of the ND Connect Module, please make sure you have installed the ND PC Starter Kit, and rebooted the client.

You will, during the installation, need the TCP/IP floppy valid for your network adaptor. You may choose not to install the TCP/IP software, if it is already installed on directory `\ND-OWS\COMMS`.

Insert the ND Connect Module floppy in drive A.

Type `A:INSTALL`

The installation program will enter a menu of different network adaptors.  
If you are installing on a client running 3+Open client software, choose 4 NDIS from the menu, otherwise choose the entry that corresponds to your hardware.

The installation program will guide you through a complete installation of ND Connect module and the TCP/IP module chosen.

All the files will be copied to the `\ND-OWS\COMMS` directory.  
CONFIG.SYS will be updated with necessary changes.

If you need a more detailed description of the parameters and settings for the different adaptors, please refer to the documentation that comes with your TCP/IP software.
