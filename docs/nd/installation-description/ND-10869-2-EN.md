A) 1 SIBAS process. (1 SIBAS process means one SIBAS system no., to be used for the database 'DIALOGUE', delivered with DIALOGUE Example). For easy installation: use SIBAS system no. 2.

C) 1 batch processor for exclusive use by the special ACCESS DDI process mentioned above. For easy installation: use batch no. 2. In addition, batch process no. 1 should be available for ordinary batch jobs.

D) 2 user areas defined on a MAIN directory (DEMOMBASE and BACK-DEMOMBASE).

2 file entries on the SYSTEM user area, altogether 6 SINTRAN pages must be available for them.

## G) Minimal Software Requirements

The minimal software requirements are as listed on page 1. Some other software is used in some parts of DIALOGUE Example (but is not absolutely necessary for the example to be useful):

- ACCESS-100 version D
- NOTIS-RG-100 version B
- UNIQUE-II-100 version A
  - Note: UNIQUE-II-100 needs the BRF-LINKER version A and FORTRAN-100 version D to be able to use a user-written 'special' routine)
- COSMOS version B or later.
- ABM version A.

If a new version of NOTIS-WP is installed, or a new language version of one of the other products, it may be necessary to reinstall DIALOGUE Example to get it to work perfectly.

## 2 Changed Prerequisites

- User Environment version B is required, and therefore also SINTRAN III version J.

Changeovers to the SYSTEM user area are done automatically when required and allowed. Some help texts and additional menus have been added.

# Installation Procedure

## I) First-time installation

(DIALOGUE Example does not already exist on the computer): Start from "Create user areas", step 1, below.

## II) To install the B version when the A version exists:

1) Give user BACK-DEMOBASE 400 extra pages.

2) Make sure that users SYSTEM and RT are friends of user DEMOBASE, with friend access RWACD and RWA, respectively.

3) Continue from step 1 in "Copy files from the floppies" (page 7).

## III) To re-install the B version

(In case of errors during installation, etc.): Start from step 1 in "Copy files from the floppies" (page 7).

# Create User Areas

1) Log in with the SYSTEM user area as current (through USER-ENVIRONMENT, - or through SINTRAN).

2) Give the command

```
@DIRECTORY-STATISTICS
```

*For the next step you will need to know how many pages are unreserved in each directory, and which directories are default.*

3) Find three directories that meet the following specifications:

| Directory   | No. of pages unreserved | Additional requirements                 |
|-------------|-------------------------|-----------------------------------------|
| "PACK-DEMO" | 1500                    | Default directory                       |
| "PACK-BACK" | 1200                    | Default directory                       |
| "PACK-LOG"  | 100                     | Higher directory index than "PACK-DEMO", or non-default |

## Generate Files

1) Move to a VDU (screen) terminal, preferably a NOTIS terminal (if you are not already using one).

   Some of the steps later in this installation procedure can only be performed from a VDU terminal.

2) Log in with SYSTEM as your user area, in SINTRAN, not in USER-ENVIRONMENT.

   Do `ØVE-FUNC SINTRAN` to get out of the USER-ENVIRONMENT menus, if that is where you are.

   SINTRAN is necessary because you cannot use MODE or PERFORM from USER-ENVIRONMENT menus directly.

3) Fill in the two lists of parameters below before you run the perform macros (patch-1 and patch-2) that need these parameters.

   If you are installing DIALOGUE Example on a machine where DIALOGUE Example does not already exist, there is not yet a UE user called DIALOGUE-USER. Therefore, when the installation macro asks for the password, you can choose freely, but you will have to give DIALOGUE-USER this password when you create it later.

   In the lists below, the 'Line mode' names of the commands in NOTIS-WP are given in English and Norwegian. If you have a NOTIS-WP that is neither English nor Norwegian, you can find these command names as follows:

   Start NOTIS-WP and give the command `#` (to get into line mode). Then write HELP in the appropriate language to get a list of the commands.

   For questions regarding DIALOGUE products which are not installed on your machine, giving the default answers will not cause serious problems.

   Note that DIALOGUE Example uses a separate version of UNIQUE so that the users can create their own ‘special functions’ without interfering with an operational UNIQUE on the machine. The special version must have the name DUNIQUE-II-A.
