## Description of Product

NOTIS-DS is a document storage system available for use by all other NOTIS products. This diskette contains the Norwegian version of NOTIS-DS Document Manager to be run on the PC.

The product consists of one 5 1/4" floppy 230147D05-NO-01D

or one 3 1/2" floppy 30147N01D05

containing the installation program and datafile, the NOTIS-DS Document Manager executable code and the screen layout language dependent datafile.

## 5 Modifications

### 5.1 New Functions/Commands

PC-NOTIS ID is a part of the PC-NOTIS product range. The complete environment consists of NOTIS-WP Word Processing, NOTIS-CALC Spreadsheet, NOTIS-DS Document Storage and a common NOTIS menu system, all running on the PC. From the menu system it is possible to start applications running both on the PC and on the SINTRAN server. Full integration between PC-NOTIS products and SINTRAN-based NOTIS products is supported.

Included a new version of Bms making it possible to move back and forth between programs in HOST and programs in PC.

Added code to get correct filetype when copying to and from MS-DOS: :TEXT <=> .TXT and :CLCB <=> .CLC.

### 5.2 Changed Functions/Commands

The command "Funksjoner/Kopier fra SINTRAN" is changed to "Funksjoner/Kopier fra MS-DOS".

Changed Copy and Move to work against MS-DOS in addition to SINTRAN.

### 5.3 Removed Functions/Commands

Removed @ and ! as commands for PC.

Removed BG and DRAW as possible NOTIS menu entries on PC.

### 5.4 Other Modifications

PC-NOTIS DS uses a text compiler for handling language dependent texts. When PC-NOTIS DS is started the first time after installation, these texts will be compiled. This results in a longer startup time the first time after installation.

For more details on differences, please refer to the "PC-NOTIS Brukerhåndbok".
