## 1 Additional Prerequisites

A) 1 SIBAS process. (1 SIBAS process means one SIBAS system number, to be used for the database 'DIALOGUE', delivered with DIALOGUE Example). For easy installation: use SIBAS system no. 2.

B) 2 internal devices (or SIBAS devices), for an ACCESS DDI process. The devices are to be used exclusively for this example. For easy installation: use numbers 128 and 129.

C) 1 batch processor for exclusive use by the special ACCESS DDI process mentioned above. For easy installation: use batch no. 2. In addition, batch process no. 1 should be available for ordinary batch jobs.

D) 1 user area defined on a MAIN directory (DEMOBASE).

E) 2 files on the SYSTEM default user area, altogether 6 SINTRAN pages must be available for them.

F) The minimal software requirements are listed on page 1. Some other software is used in some parts of the DIALOGUE Example, but is not absolutely necessary for the example to be useful:

| ND-no  | Product                                 |
|--------|-----------------------------------------|
| 210185 | ACCESS for ND-100 version E.            |
| 210193 | NOTIS-RG for ND-100 version C.          |
| 210729 | UNIQUE-II SIBAS for ND-100 version B.   |
| 210374 | COSMOS Basic Module version B or later. |
| 210713 | ABM for ND-100 version A.               |
| 210724 | NOTIS-BG for ND-100 version B or later. |

If a new version of NOTIS-WP is installed, or a new language version of one of the other products, it may be necessary to re-install DIALOGUE Example to get it to work perfectly.

## 2 Changed Prerequisites

SIBAS version F is required. The other DIALOGUE products should, if you have them, be the versions listed above.

## 3 Modifications

The menu hierarchy has been split into six separate hierarchies, each of which can be accessed by two User Environment users.

Three of the NOTIS-RG applications now use NOTIS-BG to output diagrams.

## 4 Installation Procedure

If you have the A or B version of DIALOGUE Example, do the following:

1. Delete all files on user area BACK-DEMOBASE, and then the user area itself.

2. If you want to save any of the files on the user area DEMOBASE, we suggest you move them, at least temporarily, to another user area, and then delete user area DEMOBASE.

   Alternatively, you can leave user area DEMOBASE as it is. The installation macros will in any case give DEMOBASE 1700 pages, so you will need to ensure that there is enough space on the directory, and reduce DEMOBASE's number of pages after you have finished installing. Most of the files on DEMOBASE will be replaced with new ones during installation.

### Create User Areas

1. Log in with the SYSTEM user area as current (through User Environment, - or through SINTRAN).

2. Ensure that the directory on which DIALOG-SYS is located has at least 1600 free pages.

3. If the user area DIALOG-DEMO exists, ensure that the directory on which it is located has at least 250 free pages. If it does not exist, find a directory for it with at least 250 free pages.

4. Find a directory with at least 1900 free pages for the user area DEMOBASE. This should preferably be a different directory than the one for DIALOG-DEMO. It should have a higher directory index or be a non-default directory.

5. Put the first floppy into FLOPPY-DISC-1, UNIT 0.

6. Log in with SINTRAN user SYSTEM as current user area.
