# Description of Product

This product is the basic program for the PC-NOTIS product family. It contains a menu program, a terminal emulator, a program which connects NOTIS applications running in PC with those in ND-500/5000 and support programs.

Floppy 230142A01-NO-01D - 5 1/4" or 30142N01A01 - 3 1/2"

contains the installation program for the menu system, the terminal emulator, the application starter for PC programs, examples of log in and out script files and utility programs.

## 2 Dependencies

The included terminal emulator is based on the SLINK terminal emulator and is thus using parts of the SLINK package. PC-NOTIS Platform will install needed software if SLINK is not previously installed. If SLINK is installed after the PC-NOTIS Platform, it will overwrite the software that PC-NOTIS Platform has installed. (This is mainly screen colours - entries that start with EMUL-E- in NDCONFIG - and the HELP-files TERMINAL.STR, TERMINAL.HLP and VKM.HLP.)

### 2.1 Hardware Dependencies

None.

### 2.2 Software Dependencies

| Product name                 | Product number  |
|------------------------------|-----------------|
| NOTIS-WP for ND-500/5000     | 210526 >=001    |

**Nature of dependency**

To start NOTIS-TF from the PC, or to start applications on the PC from NOTIS-WP (HOST), you need WP 001 or newer.

### 2.3 Other Dependencies

You should also be aware of the following dependencies:

| Product name                 | Product number  |
|------------------------------|-----------------|
| NOTIS-ID for ND-500/5000     | 210792 >=B10    |
| NOTIS-DS for ND-500/5000     | 210794 >=D05    |
| NOTIS-CALC for ND-500/5000   | 210716 >=E04    |

**Nature of dependency**

To start NOTIS applications on the PC from these programs on the ND-HOST you need these versions or newer.

## 4 Installation Procedure

### 4.1 Automatic Installation

To install PC-NOTIS Platform, please insert the floppy in diskette drive A: on your PC, and type

```
A:INSTALL↵
```

The installation job will guide you through a complete installation of PC-NOTIS Platform.

### 4.2 Non-Automatic Installation

Not recommended.

### 4.3 Automatic PC-NOTIS Starting

If you want to have automatic start of PC-NOTIS when booting the PC the following line must be added to AUTOEXEC.BAT:

```
C:\ND-OWS\NOTIS.BAT
```

This will only take effect after a reboot.

### 4.4 Starting PC-NOTIS

If you have chosen to start PC-NOTIS manually every time it’s needed give the following commands:

- Change to subdirectory ND-OWS (Not necessary if ND-OWS is part of the defined path in AUTOEXEC.BAT).
- Give the start-command: NOTIS.

### 4.5 PC-NOTIS on Monochrome Monitor

When running PC-NOTIS on monochrome monitors the colour settings should be changed to give a better result in black and white. This could easily be done by running a batch-job:

```
C:\ND-OWS\SETMONO.BAT
```

# 7 Errors Known But Not Corrected

During installation it might happen you will get an error message:
"Out of environment space".
The size of the environmental space is defined in the CONFIG.SYS file.
See the MS-DOS manual for details.

During installation you might get an error message:
"Cannot find match for <systemname>"
This will normally happen because your NDCONFIG.EXE program is too old.
The problem can be solved by installing a new version og NDCONFIG.EXE:

1. Copy NDCONFIG.EXE from PC Starter Kit floppy no. 2 to the directory
   C:\ND-OWS\MAINT.
2. Copy NDCONFIG.SAx (if more .SAx'es, choose the one with the highest
   number) from directory C:\ND-OWS to a new file NDCONFIG (without
   any extension).
3. Start installation all over again.

The PC-NOTIS menu system will not run if you have installed the DOS
SHARE utility. The error message 'Mangler definisjonsfil for PC-NOTIS
menyen - Trykk en tast' will occur. To run PC-NOTIS properly you must
run without the DOS SHARE utility.
