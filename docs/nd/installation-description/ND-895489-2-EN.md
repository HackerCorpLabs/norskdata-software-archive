## Description of Product

- NOTIS-SPELL is a spelling checker based on "Proximity Linguistic Technology". It consists of a program part, ND-250383C ND SPELL Segment for ND-500/5000, and a dictionary part, ND-211573C ND SPELL Dictionaries for ND-500/5000. The program part is loaded on a separate segment, which is integrated with NOTIS-WP.

  This product is synchronized with the product NO-211306C NTX-SPELL for ND-500/5000, which consists of the same program and dictionary parts. The first release of NOTIS-SPELL is **version 8**.

- To start NOTIS-SPELL, you give the command "Functions/Check-words" in NOTIS-WP. An alternative way to enter the spelling checker is to press FUNC followed by `,` (comma); in this case it does not matter whether the cursor is in home position or in the work area.

- NOTIS-SPELL may check a whole region or part of a region. Words are checked against a main dictionary and user-defined dictionaries. A word detected as misspelled may be edited, ignored, deleted, added to a user dictionary, or replaced by another word proposed by the spelling checker program.

- NOTIS-SPELL may also be run in auto mode, i.e. the entire region is automatically checked, and a list holding the unknown words, the line numbers where they occurred, and, if possible, a proposal for how to correct each word, is generated in a separate region. To enter auto mode, press the following keys in sequence: FUNC 5 FUNC , (comma).

- The program part of NOTIS-SPELL is language-independent. All text (commands, menus, messages, etc.) are read from the UE-ERMSG file. There is no connection between your UE-language and the language you are checking, i.e., you may check an article written in German even if your UE-language is English.

## Reason(s) for New Product or Version

- New version of the Spell Checker using new file formats.
- Nynorsk and Finnish dictionaries.
- Correction of errors.

## 4 Installation procedure

### 4.1 Automatic installation

Before you install NOTIS-SPELL, make sure no one is using programs linked to the (ND-SPELL)ND-SPELL:SEG file. E.g. NOTIS-WP, WP-PRINT and NOTIS-PRO. The installation procedure will delete the standard domains.

Insert one of the diskettes in the diskette unit (it does not matter which diskette you insert first), and enter the directory by typing:

```
ØENTER-DIRECTORY_F-D-1.unit
```

To start the installation program, type:

```
Ø\250383:FLOPPY-USER\IN
```

if you start with the ND SPELL Segment diskette, and

```
Ø\211573:FLOPPY-USER\IN
```

if you start with the ND SPELL Dictionaries diskette. When started, the installation program will guide you through the installation procedure.

Before exiting the installation procedure will redefine the standard domains deleted at the beginning.

### 4.2 Non-automatic installation

None.

## 5 Modifications

### 5.1 New functions/commands

New languages in ND-SPELL: Brazilian, Finnish and Nynorsk. In addition, new versions of all dictionaries except Norwegian and Swedish.

Dynamic language change made possible because NOTIS-SPELL now reacts to the NAI directive.

User dictionary names in the Word-Check menu must contain the characters ιι (wildcard for language) to enable NOTIS-SPELL to switch user dictionaries. In SINTRAN the ιι should be actual language in the user dictionary.

E.g. In the menu: 

```
(:)BIGWORD-ιι:DICT
In SINTRAN (:)
      BIGWORD-04:DICT (British English) and
      BIGWORD-05:DICT (Norwegian)
```

### 5.2 Changed functions/commands

**Important:**  
New data format in all dictionaries. User dictionaries must be fetched with Func/F and stored again with Func/S before storing new words.

Copyright information is now fetched from the :LEX-file, and not from a separate :COPR-file.

### 5.3 Removed functions/commands

None.
