## Description of Product

UNIQUE Text System contains language dependent files for all UNIQUE CONCEPT products. It includes error messages, help texts and some common files.

The Text System must be properly installed before any UNIQUE products may be run.

Some language dependent examples are included on the diskette, but to install these you must run the installation program for UNIQUE-II and select the option INSTALL EXAMPLES.

The following languages are available:

- EN - English
- GE - German
- NO - Norwegian
- SW - Swedish

The language code is written on the diskettes.

## Reason(s) for New Product or Version

| Compatibility with UNIQUE CONCEPT version C10 and later. |

## 3.2 Installation from floppy

- Insert the diskette 211005C<rev>-<lang>-01D into the machine.
- Log in to user area SYSTEM.
- Enter directory 211005C<rev>-<lang>-01D.
- Run the TEXT-SYS-IN program on the diskette.

**EXAMPLE:** How to enter the directory and start the installation program.

```
@ENTER-DIRECTORY 211005C-EN-01 FLOPPY-DISC-1 0J
@(211005C:FLOPPY-USER)TEXT-SYS-IN
```

This program will copy all the files from the floppy to user areas DIALOG-SYS, ND-OPERATIONS and SYSTEM. The user area will be created or expanded if necessary.

## 3.3 Error messages

If the Text System has been incorrectly installed or is out of date, the following error messages may appear when running a UNIQUE product:

`Can not open message file (DIALOG-SYS)UNIQUE-<lan>-C:UTXT`

This will result if you do not have read and common access to the file or the file does not exist. Check that the language file you requested exists on user DIALOG-SYS with public read and common (RC) access. Also check if the program that you tried to run requires a newer version of the Text System. Contact your distributor for the latest version of the Text System.
