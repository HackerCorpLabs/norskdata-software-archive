This product is the software licence key allowing use of the general purpose database management system SIBAS/R for developing new application systems.

## 4 Installation Procedure

### 4.1 Automatic Installation

Use the utility program SOFTICE (ND-211846A) to install the Software Licence Key on the database machine.  
The Software Licence Key is delivered on a Software Licence Key Certificate following this product.

Log in as user: `SYSTEM`

```
@ND SOFTICE~
STORE-SOFTWARE-KEY 220005 <software-key> <SIBAS/R Development Access>~
EXIT~
```

### 4.2 Non-Automatic Installation

None
