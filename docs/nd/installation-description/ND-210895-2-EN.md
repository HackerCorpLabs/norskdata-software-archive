# 1 Known, But Not Corrected Errors

- If the specified default file cannot be opened, default values are used. But no error message or warning is given. The user will think the default file was OK, and will not understand why wrong defaults are given.

- The accumulate function is not working properly if the field is not in the database.

- Groups cannot be used in expressions (compute, if etc.). The compiler will not inhibit this and the application will not run correctly if groups are used in expressions.

- The :UNIQ compiler gives wrong error message (field width too small) if format code is not correct (eg '00001','33').

- If a field is defined to be longer on the screen than in the database, UNIQUE is not handling this properly (the correction of this error will cause this to be illegal).

- UNIQUE cannot handle remote printers/files when using the print command.

- MENU-COMM may be used to enter a new application with current record. Problem: current record is set from next field, not from the calling field. If next field is in another record, then this record will be transferred.

- If F7 gives no result using a group key, all the fields in the group are set to zero. This makes the use of F7 very little user-friendly.

- If the file (SYS)DDBTABLES-Exx:VTM is not available (does not exist, no access, ambiguous etc.), UNIQUE gets suspended without giving any error message.

## Modifications

- Modifications to chapter 11.6 SINGLE-USER VS. MULTIUSER and 12 DIFFERENCES BETWEEN ISAM AND SIBAS:
  - ISAM and :DATA files have to be predefined for both single- and multiuser ISAM mode.

- There is a new option available in the :BASE file, called OWNER. You can now specify the owner of all the registers belonging to one database (ref. data-base-name in the :BASE file). If the OWNER option is used, UNIQUE expects to find all the register files (:ISAM & :DATA) and the register description file (:INFO) on this user. If the option is not used, the default is your own user.

  - **Example:**
    ```
    data-base-name=COMPANY,isam-mode=0,owner=USER
    data-base-name=ORDRBASE,isam-mode=0
    ```

- Instead of having all the registers on one USER (ref. OWNER option), you can override this in the :INFO file. Here you specify the owner of each register as a prefix to the register name(s). The owner must be written inside brackets ().

  - The second possibility is to override the ISAM-MODE in the :BASE file, and have one isam-mode for each register. This is specified after the register name, separated by a comma.

  - Default values for the owner and isam-mode of each register are those used in the :BASE file.

  - **Example:**
    ```
    (USER-X)CUSTOMER,1
                   └── isam-mode of the CUSTOMER register
       └── owner of the CUSTOMER register
    ```

## 3 INSTALLATION

### 3.1 SOFTWARE KEY PROTECTION OF THE UNIQUE-II PRODUCT

To avoid unauthorized installation of the product, UNIQUE-II uses the Software Key system of SINTRAN III. The Software Key is delivered along with UNIQUE-II. Assure that the Software Key is properly installed before starting UNIQUE-II.

If UNIQUE-II still does not start correctly, check with your local ND office that the CPU number of your SINTRAN III is correct. If SINTRAN III is generated with incorrect CPU number, it must be regenerated.

### 3.2 INSTALLATION PROCEDURE

Create a user (default=DIALOG-SYS) and give the user 570 pages if you want to install both UNIQUE-II and the examples. You need 153 extra pages if you want to copy FORTRAN-LIB, EXCEPT-LIB and UE-PLIB to the same user.

Some of the files form an EXAMPLE system for introduction purposes. The EXAMPLE system consists of applications (:UNIQ), ISAM database (:INFO), ISAM-files and :DATA-files. These examples are also found in the manuals.

Copy the two files named UNIQUE-II-I-B-0:DEFL and UNIQUE-B<rev>:BASE to user SYSTEM. The file names must not be changed with exception for the :DEFL-number and the revision number.

Copy the file UE-PLIB-B<rev>:NRF only if it is not already present in your system (normally under user USER-ENVIRONMENT).

Copy the files FORTRAN-LIB-I<rev> and EXCEPT-LIB-C<rev> only if they are not already present in your system (normally under user SYSTEM or DIALOG-SYS).

If UNIQUE is supplied on one double density diskette then insert the diskette into a floppy drive and enter the directory 210895B<rev>-<language>-01D. Use the BACKUP-SYSTEM to copy the required files to a suitable user.

If single density diskettes are supplied, enter the directory 210895B<rev>-XX-01S and copy the required files using the BACKUP-SYSTEM. Repeat this process for the diskettes 210895B<rev>-XX-02S, 210895B<rev>-XX-03S and 210895B<rev>-<language>-01S.
