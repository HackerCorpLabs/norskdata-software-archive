## 2 NOTICE

- This is the first release of the ND-ADA compiler, which has been successfully validated against version 1.9 of the Ada Compiler Validation Suite.

- The version of the microcode needed for the ND-500 must be at least 15x12. This is 15112 for ND-580, 15212 for ND-550, 560 and 570 and 15312 for ND-530. Earlier microcodes will cause the Ada exception NUMERIC_ERROR to be raised for some comparisons involving real values.

## 3 MODIFICATIONS to the Ada User Guide

The User guide was produced for the beta test version and the following changes are needed for this version.

### 3.1 NEW COMMANDS

**Page-Size**  
This command should appear in chapter 3, Compiling a program. It sets the size of the page to be used when producing the listing file.

**Pragma-Inline**  
This command should appear in chapter 3, Compiling a program. This controls the effect of pragma inline. The parameter OFF means that pragma inline will be ignored, ON means that only subprograms mentioned in the pragma will be inlined and AUTOMATIC means that any subprogram may be inlined if the compiler decides it is suitable. Note that inlining is only done within a single compilation unit.

**Closure-Check**  
This command should appear in chapter 4, Using the Library. It will check that the units required by the given unit are present in the Ada library. The options SPEC and BODY restrict this to the units required by the SPEC or BODY respectively, while the option FULL checks the transitive closure (i.e. all units required directly or indirectly by the given unit).

### Delete-Library

This command should appear in chapter 4, Using the Library. It will delete the Ada library database file "ADA:DBTA" and all the :DI, :BOD, :SNRF and :NRF files resulting from compilations into that library (but not those introduced by the FOREIGN-BODY command). Confirmation is requested before the command is executed. An extra option "LIST" may be given. This causes a list of the units deleted to be displayed on the terminal.

### Remove-Unit

This command should appear in chapter 4, Using the Library. It will remove the given unit from the Ada library. The option BODY removes only the body and the option SUBUNITS removes all subunits of the given unit. A second option "LIST" may also be given. This causes a list of the units and subunits deleted to be displayed on the terminal.

## 3.2 OTHER CHANGES

- In section 1.4, the list of components should include the preparser and the list of packages should include SEGMENT_IO and INTERACTIVE_IO.

- In section 2.9 and appendix E, the list of file types should not include :CON and :XRF.

- In chapter 4, under the LINK command, the default stack size is now 32K and the default memory size is now 2MB.

- In chapter 6, delete section 6.2 as this method is not reliable. In section 6.3 point 1, note that some type declarations are not allowed.

- In section 8.4.3, 32 bit floating point values are returned in the F1 register and unconstrained arrays are returned in W1/W2.

- Ignore appendix D and refer to the specifications found under the user ADA-PACKAGES after the installation has been performed. Note that the two new packages SEGMENT_IO and INTERACTIVE_IO both use MONITOR_CALLS which must be installed first.

## 4 INSTALLATION PROCEDURE

The system is delivered on nine 1.2 Mb 5 1/4 inch or 8 inch double-sided diskettes. You must use the same kind of diskettes and the same disc drive throughout the installation procedure.

### 4.1 How to install

- Check prerequisites, see page 1.

- Note that you do not actually have to set up the users described in the prerequisites, but slots must be available for them, and it must be possible for the installation program to give these users enough space and enough files, as described on page 1.

- Installation must be run from SINTRAN, log in as user SYSTEM. Insert the diskette containing the directory 211114-A<rev>-XX-01D into the diskette station. Execute these commands (operator input is underlined and parameters are enclosed in angle brackets.)

```
@enter-directory,211114A<rev>-XX-01d
DEVICE NAME: floppy-disc-1
DEVICE UNIT: <FLOPPY-UNIT>
@(211114A<rev>-XX-01D:floppy-user)install-ada
```

The installation procedure has now started. It is self-explanatory, but you will be asked to insert the appropriate diskettes as the installation proceeds until the installation is completed.

## 4.2 Alterations to the SINTRAN environment

You will also then need to make the following alterations to the SINTRAN environment: Add the following lines to the HENT-MODE file:

```
@mode ada-timer-a:mode,,
@nd-500-monitor
delete-standard-dom ada-compiler
delete-standard-dom ada-preparse
delete-standard-dom ada-librarian
delete-standard-dom ada
define-standard-dom ada-compiler ((DOM_USER>)ada-compile-a
define-standard-dom ada-preparse ((DOM_USER>)ada-prepars-a
define-standard-dom ada-librarian ((DOM_USER>)ada-librar-a
define-standard-dom ada ((DOM_USER>)ada-interfac-a
```

Where `<DOM_USER>` is the username you have selected for the location of the domains to be built.

Add the following line to the LOAD-MODE file:

```
@rt adatm
```
