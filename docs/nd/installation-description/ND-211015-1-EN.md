## 1 Prerequisites

- NOTIS-DE requires version J or later of SINTRAN III.
- NOTIS-DE requires USER ENVIRONMENT.

## 2 Installation Procedure

NOTIS-DE for ND-500 is supplied on three SS/SD diskettes with directory names 211015A<rev>-<lang>-01S, 211015A<rev>-<lang>-02S, and 211015A<rev>-<lang>-03S, where `<lang>` denotes the corresponding language code and `<rev>` the relevant language version. If you have ordered DS/DD diskettes, one diskette 211015A<rev>-<lang>-01D is supplied.

The procedure to load NOTIS-DE is as follows:

1. Log in as user SYSTEM.
2. Make sure that the required number of files and pages is free on user SYSTEM (prerequisites, page 1).
3. NOTIS-DE may be installed on any SINTRAN user; we recommend user DOMAIN-USER. This user must have some free pages (see prerequisites, page 1). Make sure that the user exists, and has enough free pages.
4. Insert the diskette 211015A<rev>-<lang>-01 in your diskette station.
5. Enter this directory by typing `@ENTER-DIR,FL0PPY-D-<floppy drive>,<unit>↲`
6. Start the installation program by typing `@(211015A:FL0PPY-USER)INST-DE↲`

The installation program will then guide you through the installation.

If using SS/SD diskettes, you are asked to insert the remaining diskettes when required.

## 3 THE TERMINAL DESCRIPTION FILE

If you already have an earlier revision of the terminal description file `DDBTABLES-E:VTM`, the file `DDBTABLES-E04:VTM` will be copied to a file named `DDBTABLES-E04:NEW` on user SYSTEM.

If you want to use this new file, please delete the old terminal description file `DDBTABLES-E:VTM`, and rename the new file by typing:

```
@DELETE-FILE (SYSTEM)DDBTABLES-E:VTM__
@RENAME-FILE (SYSTEM)DDBTABLES-E04:NEW :VTM__
```

## 4 THE ERROR MESSAGE FILE

If an earlier revision of the error message file `UE-ERMSG-<lang>-B:ERR` is present, the file `UE-ERMSG-<lang>-B06:ERR` will be copied to a file on user SYSTEM named `UE-ERMSG-<lang>-B06:NEW`.

If you want to use this file, please delete the old error message file `UE-ERMSG-<lang>-B:ERR`, and rename the new file by typing:

```
@DELETE-FILE (SYSTEM)UE-ERMSG-<lang>-B:ERR__
@RENAME-FILE (SYSTEM)UE-ERMSG-<lang>-B06:NEW :ERR__
```

Note that `<lang>` in the file names above denotes the respective language code.
