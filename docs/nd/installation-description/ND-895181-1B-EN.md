# Installation Procedure

## 4.1 Automatic Installation

### 4.1.1 Preparations

Prior to the installation, please verify the following:

- Ensure that the user areas specified in Chapter 1.3 exist with the required number of free pages and free files. If not, find a directory having enough space to hold the user areas. The installation program will try to allocate space whenever needed, but you may need to specify on which directory to create user areas.

- The following files will be loaded/linked to XTRA:

| Abbrev. | File Name   | Default User Area(s)        |
|---------|-------------|-----------------------------|
| ● SIBAS library | SIB-LIB    | SIB-500                     |
| ● UE library | UE-PLIB    | USER-ENVIRONMENT             |
| and, if desired | |                             |
| ● NOTIS-WP (N) | WP-500-N  | NOTIS, DOMAIN-USER, SYSTEM  |
| or | |                             |
| ● NOTIS-WP (M) | NOTIS-WP--M | NOTIS, DOMAIN-USER, SYSTEM  |

Check where these files are installed. If not installed on the default user area, the installation program will ask where to find these files.

- If you already have a version of XTRA installed, you should make sure it is not defined as a standard domain. Delete it prior to the installation.

- Ensure that your configuration fulfills all other requirements mentioned in Chapter 1 and 2.

```
NOTE: 
To install XTRA on an ND-500/5000 machine with the new ND-LINKER, the non-automatic installation procedure must be used (see chapter 4.2).
```

## 4.1.2 Installation from Floppy

- Put the diskette 211248C<rev>-XX-010 into the floppy drive.
- Log in to user area SYSTEM.
- Enter directory 211248C-XX-01D.
- Run the INSTALL program on the diskette.

Example: How to enter the directory and start the installation program.

```
@ENTER-DIRECTORY 211248C-XX-01D FLOPPY-DISC-1 0-
@(211248C:FLOPPY-USER)INSTALL-
```

The following screen will appear:

```
+---------------------------------------------------+
|                   INSTALLATION                    |
|                XTRA SIBAS ND500                   |
|                  VERSION C x x                    |
+---------------------------------------------------+
| Unique A/S                           Date : 22-JUN-87 |
|                                           |
| You may ESCAPE at any time to abort the installation procedure. |
| Choose one of the following options:        |
|                                           |
| 1 - CREATE : Create user and allocate space |
| 2 - COPY   : Copy files from floppies       |
| 3 - LOAD   : Make and run load procedure    |
| 4 - DUMP   : Define system as standard domain |
| 0 - EXIT   :                               |
|                                           |
| Make your selection (1/2/3/4/0):           |
+---------------------------------------------------+
```

The installation program will ask you for some information (e.g. user areas, directory names etc) but will usually suggest reasonable default values. You can answer these questions by typing ↵ (the ENTER key) thus using the default value.

You may install XTRA on any user area, but DIALOG-SYS is used as default in the installation program.

The installation program can do the following:

- **CREATE**  
  Create a new user area (or verify an existing one) for XTRA.

- **COPY**  
  Copy all files from the floppy to the desired user area.

- **LOAD**  
  Write the load procedure and load the XTRA ND-500 domain.

- **DUMP**  
  Dump XTRA as a standard domain.

- **EXIT**  
  Leave the installation program and return to SINTRAN.

The first time, run all the tasks 1-4, one at a time, in sequence.  
To reload XTRA, run tasks 3 and 4. To re-dump XTRA, run task 4.

When selecting the CREATE or COPY option, and an (old) version exists on the selected user area, you are asked if these files should be deleted. You may answer Yes, No or Manually. When answering YES, program files, domain files, :MODE and :LIST files of current and previous versions/ revisions will be deleted. Afterwards the program checks if there are enough free pages on the user area.

When selecting the LOAD option, there are some questions that need an explanation:

- **SPECIAL**  
  'Do you want to load any SPECIAL routines (Y/N)? /N/'

  If you answer Y, the program will ask for the name of the :NRF file which the special routine has been compiled into. Answer N (or ↵) if you don't have any special routines. See also chapter 4.1.4.

- **LANGUAGE**  
  'Language to be used if UE is not active? /NO/'

  By default UNIQUE will use the language found in the user profile in User Environment. The answer to this question selects the language to be used if UE is NOT active on the terminal running UNIQUE.

- **NOTIS-WP**  
  'Which version of NOTIS-WP will be used (M or N) /M/'

  Answer M (or ↵) if you have the M version of NOTIS-WP.  
  Answer N if you have the N version of NOTIS-WP.

## 4.1.4 Implementing Special Routines

To install a special routine the following must be done:

- Write the routine in PLANC, COBOL or FORTRAN.
- Compile it with the appropriate compiler.
- Run the installation program and select the load option.
- When the program asks if you want to load a special routine you must answer YES.
- The next question is which programming language the special routine is written in. Possible are FORTRAN, COBOL and PLANC.
- Finally you have to give the name of the object file (:NRF) the special code is compiled into.
- A file named XTRA-LOAD-S5-C:MODE including the load job will be created. You may run it from the installation program if desired. If you have special requirements for the load procedure or the special routine is split on more than one :NRF file, you may edit the load file in an editor before running it.

If you at a later time want to recompile/reload the special routine, you will have to run the load job after compiling:

```
@MODE XTRA-LOAD-S5-C:MODE XTRA-LOAD-S5-C:LIST-\
```

- Due to changes in the S-format required in different versions of the NOTIS products, a new file must be present on user DIALOG-SYS. This file is named UQ-ND-S:INI and must have public read access.

All S-format files produced by UNIQUE products will have the same S-format header as the file (DIALOG-SYS)UQ-ND-S:INI.

UQ-ND-S:INI is an 'empty' file containing only an S-format header matching the version of NOTIS-WP you are using on your machine. By storing the S-format header in a file, it is possible for you to define the default settings and rulers. UNIQUE will read the default header from this user defined file, if it exists.

If you start using a version of NOTIS-WP with a new S-format, e.g. going from WP version M to N, just repeat the procedure described below and UNIQUE will produce documents readable by the new WP version.

You have to install/create this file manually:

```
1. Log in on user area DIALOG-SYS.
2. Start NOTIS-WP.
3. Use the internal menus in WP to set the wanted default values.
4. Make sure you define it to be an S-format document.
5. Type some blanks so WP will store it as a document.
6. Save this 'empty' document to the file "UQ-ND-S:INI".
7. Set public access to READ: @set-file-access UQ-ND-S:INI R R,,,
```
