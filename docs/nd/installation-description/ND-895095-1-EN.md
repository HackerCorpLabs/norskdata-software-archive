## Description of product

User Area Manager displays information about all SINTRAN user areas on all entered directories. It also gives you the possibility of performing various operations regarding user areas: Create, Delete, Rename user area, give/take user space, set max number of files allowed and create an existing user area on another directory.

## Reason(s) for new product or version

Operator Environment which, up till now has been released as a package containing a number of "modules" (OEA, OEB, OEC etc.) is now splitted up, and the modules will now be released as separate products.

The "new" products are:

- User Area Manager
- Configuration Dictionary (also contains OEF)
- File System Verification
- File Manager
- Operator Environment Menu System

## 4 Installation procedure

### 4.1 Automatic installation

Before you start installing User Area Manager, check that all the prerequisites listed above are fulfilled.

The installation must be run from SINTRAN.

To install User Area Manager, follow this procedure:

- Log in with SINTRAN user name SYSTEM.
- Insert the diskette containing the directory name 211070A<rev>-XX-01 in the diskette station.
- Execute the following commands (operator input is underlined and parameters are enclosed with angle brackets).

```
@ENTER-DIRECTORY↵
DIRECTORY-NAME: 211070A-XX-01↵
DEVICE-NAME: FLOPPY-DISC-<drive no.>↵
DEVICE-UNIT: {floppy-unit}↵
@(211070A-XX-01:FLOPPY-USER)IN-OEA↵
```

The installation procedure will now start. Read the messages that appear on the screen, and follow the directives which are given. After the initialization, the main menu of the installation system will appear on the screen:

```
1: Get start information
2: Delete product files
3: Check environment and resources
4: Copy product files
5: Exit program
6: Get help information
```

Execute the options 1 through 4 in sequence to install User Area Manager (just press return when you are asked about which option you want to choose, because the sequence 1,2,3,4,5 is defined as default). If one of the operations fails (for example if deficiencies regarding environment and resources are discovered), you will get a message telling what to do in order to proceed.

## 4.2 Non-automatic installation

- Assure that user area ND-OPERATIONS has 155 free pages and 3 free object entries.

- Insert the diskette in the floppy station and copy these files to user area ND-OPERATIONS:

  ```
  OEA-AREAS-A<rev>:PROG
  OEA-AREAS-EN-A<rev>:CONF
  OEA-AREAS-NO-A<rev>:CONF
  ```

- Check if you already have the correct version of the UE-ERMSG files and the DDBTABLES file on your system. If not, check if there is enough space, and copy the needed files to user area SYSTEM:

  ```
  UE-ERMSG-NO-C<rev>:ERR
  UE-ERMSG-EN-C<rev>:ERR
  DDBTABLES-E08:VTM
  ```
