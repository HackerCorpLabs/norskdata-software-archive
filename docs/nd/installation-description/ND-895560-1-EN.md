## Description of Product

Basic System Package for ND EServer is a part of the Basic System Package for ND EServer (ND-211731), which is a prepackaged system for the ND EServer with menu-oriented operation routines for easy operating.

## Reason(s) for New Product or Version

The reason for this product is to give Supervisors and other persons responsible for system operation an easy and quick way to upgrade the basic software on all ND EServer models. This product is designed to be used when a new version/revision of the basic software on the ND EServer is required. All the software on this product is pre-packed and may easily be installed. This product will be installed and prepared by ND on all deliveries of ND EServer models.

Rules concerning Es platform systems.

The Es platform consists of four directories:

```
PACK-BASIC      -----> DISC-4-SCSI-1,0,0
PACK-MAIN       -----> DISC-4-SCSI-1,0,1
PACK-EXTENSION  -----> DISC-4-SCSI-1,0,2
PACK-APPLICATION -----> DISC-4-SCSI-1,0,3
```

a) PACK-BASIC contains system files and has to remain  
   as it is when delivered from NORSK DATA A.S.  
   Some few exceptions exist.

b) PACK-MAIN contains configuration files for the  
   system, USER-ENVIRONMENT and customer-defined  
   users. Available space is free for the customer to use.

c) PACK-EXTENSION contains your additional ND applications  
   such as NOTIS, SIBAS, TCP-IP and so on.

d) PACK-APPLICATION is reserved for the different  
   business units belonging to NORSK DATA and their  
   application packages.

# 6 Manual Installation Procedure

This procedure should be followed when a new version of the Basic System Package is to be installed.

```
+--------------------------------------------------+
| CAUTION!                                         |
|                                                  |
| All software located on PACK-BASIC-A will be     |
| destroyed and a new version of PACK-BASIC-A will |
| be restored from the streamer. On user SYSTEM    |
| there may be files belonging to other products   |
| than those listed in chapter 10 (libraries, init |
| files etc.). Backup of these files must be taken |
| before the disk is restored.                     |
+--------------------------------------------------+
```

1. **Preparations before stopping the ND EServer:**

    a) Check that the file `(MODE-FILES)DEF-PERIPHERALS:MODE` corresponds to your system before you take the system down.

    b) Save user files to a scratch streamer cassette using the Backup Manager:

    - Insert a scratch streamer cassette into the streamer drive.
    - Log in as user SYSTEM and start the BACKUP-MANAGER from the ND EServer System Administrator menu option 3.0 (backup) or from SINTRAN by doing the command `@BM-OPERATOR-`.
    - Use the backup set `BACKUP-FILES` to save not standard platform files to streamer. All files and users **NOT** listed in the file `(PROG-FILES)EXCLUDE-FILES:SYMB` will be copied to the streamer cassette.

    When the new Basic System Package is installed, these files can be copied back to user SYSTEM on PACK-BASIC-A (ref. point 1h.).

## Redefining of OL-printers When You Have Installed a New Platform on Your System

1. From user area SYSTEM use an editor to read the file  
   `SYMBOL-2-LIST:SYMB`.
   - Find the text string F1731.
   - Write down the value corresponding to F1731 (on most systems the address will be 070322).

2. `@ABORT COSPO`

3. Exit the editor and type the following underlined text after the Sintran prompt:

```
SINTRAN-SERVICE-PROGRAM↔
*INSERT-IN-LOGICAL-UNIT-TABLE↔
LOGICAL UNIT NUMBER (OCT):23xx↔
    (23xx is the sintran logical device
    number in octal from S3-CONFIG)
INPUT OR OUTPUT? OUT↔
DATAFIELD ADDRESS (OCT):ffffff↔
    (ffffff is the data field address from
    step 1. above)
MEMORY? YES↔
IMAGE? YES↔
SAVE-AREA? YES↔
*EXIT↔
```

4. Type the following underlined text:

```
@SET-PERIPHERAL-FILE "OL-<name>" <23xx>↔
    (OL-name is the printer’s OpenLan name)
@SET-FILE-ACCESS OL-<name> WA RWA RWA↔

@CREATE-NEW-VERSION OL-<name>:;x,0↔
    (x is the number of spooling files)
@SET-FILE-ACCESS OL-<name>:1,1,,,rwacd↔
```

5. Step 3. and 4. have to be done for each OL-printer on your system.

6. `@SPRINT /START-SPRINT`

7. `@START-SPOOLING COSMOS-SPOOLING`

## EServer System Administration Menu

On this platform (A01) you have the possibility to have the EServer administration menu in two languages, English or Norwegian. To change from Norwegian to English or the other way around you have to do the following:

- Log into UE-user SYSTEM
- Call the User Environment profile manager by typing `@UE-PMAN`
- Then you get into a menu where you are asked for user name, and there you put in SYSTEM.
- Further down in the menu you are asked for language and here you have to put in the wanted language (Norwegian or English).
- The menu system name is `(SYSTEM)ES-MENU`
- To get out of the menu, press the EXIT button.

## Defining of Extra Swap- and Segment-Files

If you need more swap- or segment-files you have to update two different files:

- `(ND-OPERATIONS)BM-PARAMETER-B:DATA`
- `(MODE-FILES)USER-DISKS:MODE`

1. `@PED (ND-OPERATIONS)BM-PARAMETER-B:DATA`

   Here you put in the following:
   ```
   IMAGE-NO-COMPARE-FILE = (SWAP-USER)SWAP-FILE-<X>:SWAP
   for extra swap file, or
   IMAGE-NO-COMPARE-FILE = (SWAP-USER)SEGFIL<X>:DATA
   for extra segment file.
   (SWAP-USER) = Name of the user containing the
      SWAP or SEGMENT file
   <X> = SWAP or SEGMENT file number
   ```

2. `@PED (MODE-FILES)USER-DISKS:MODE`

   At the end of this file you put in the following:
   ```
   @ND
   DELETE-SWAP-FILE (SWAP-USER)SWAP-FILE-<X>:SWAP
   DEFINE-SWAP-FILE (SWAP-USER)SWAP-FILE-<X>:SWAP
   EXIT
   ```
