## 1 Installation Procedure

Copy the files to user UTILITY (or any other selected user).

## 2 Use

The following examples illustrate the loading procedure for Planc and Fortran.

### Using PLANC for ND-100 (1-bank):

```
@CC LOAD A 1-BANK ND-100 PROGRAM USING THE PLANC INTERFACE
@NRL
*PROG-FILE "<name>"
*LOAD <name>, (UTILITY)CB-YBP-100-1
*LOAD (UTILITY)X25P-100-1, (UTILITY)XMP-100-1
*LOAD PLANC-1BANK
*EXIT
```

### Using PLANC for ND-500:

```
@CC LOAD AN ND-500 PROGRAM USING THE PLANC INTERFACE
@ND-500 LINKAGE-LOAD
N11: SET-DOMAIN "<name>"
N11: LOAD-SEGMENT "<name>", (UTILITY)CB-YBP-500
N11: LOAD-SEGMENT (UTILITY)X25P-500, (UTILITY)XMP-500
N11: LOAD-SEGMENT PLANC-LIB
N11: EXIT
```

### Using FORTRAN for ND-100 (2-bank):

```
@CC LOAD A 2-BANK ND-100 PROGRAM USING THE FORTRAN INTERFACE
@NRL
*PROG-FILE "<name>"
*LOAD <name>, (UTILITY)CB-YBF-100-2, (UTILITY)CB-YBP-100-2
*LOAD (UTILITY)X25P-100-2, (UTILITY)XMP-100-2
```

## 3 Demonstration Programs

Two demonstration programs are enclosed. They can not show that your YBTS works, but that the official YBTS can work with your X.25 and the X.25 characteristics to which you have subscribed from the network authority. You must know your X.25 network number (the DTE number) to run the demonstration programs. If you know nothing about your X.25 connection, the safest thing to do is to use what the following examples use.

The enclosed examples show how to use the programs. Your input is underlined. Parameters you must enter are:

- **X.25 connection type:** 
  This depends on your X.25 subscription. If you do not know, use basic format (B).

- **Reset procedure:**
  If you answer Y, the YBTS reset procedure will be tested. This may not work if you run through a gateway, for example, like the JANET/PSS gateway. If both programs run on the same machine, you can answer yes (Y) and run the reset procedure.

- **YBTS address:**
  A YBTS address consists of the DTE number (X.25 network number) and a YBTS suffix. The two parts are separated with a '++'. When you run the test, replace the DTE number with your own, but use the suffices in the example. The DTE number in the example is 234263500140.

- **Number of data units to send:**
  You can indicate how many data packets (128 octets each) you want to send. A counter in each program will tell how many packets were sent and received.
