## 4 Installation procedure

### 4.1 Automatic installation

The installation should be done before running the program:  
`@(EXTRA-SYSTEM)SYSTEM-CONFIG`

Insert the floppy `380739A<rev>-XX-01D` in floppy unit 0, enter the directory `380739A00-XX-01D` and run the mode file `PAT-211470B01:MODE`

The missing UE-ERMG-XX-Cyy:ERR where yy is equal or newer than 13, is in the case of the languages ENGLISH, GERMAN and NORWEGIAN included.

For other language options **THIS HAS TO BE INSTALLED EXTRA**.

### 4.2 Non-automatic installation

None

## 5 Error Correction

### 5.1 Errors known but not corrected

The following are known but not corrected errors on streamer 211470B01.

The errors should be corrected before running the program:  
`@(EXTRA-SYSTEM)SYSTEM-CONFIG`

as described in the installation procedure.

A) Some mode files on user MODE-FILES are incorrect.

**Solution:**  
Use BACKUP-SYSTEM and copy all files from LANGUAGE:SAVE-MODE to PACK-BASIC:MODE-FILES before configuring the system.

### B) ND-LINKER Issue

The name of the new domain format linker is ND-LINKER. This gives problems in some mode files calling the ND-500-MONITOR using the shortened call `@ND` only.

**Solution:**
Edit the file `(MODE-FILES)ND-500-HENT:MODE` using PED. Substitute ND-LINKER with LINKER.

### C) File Access Problem

File access on the file `(SYSTEM)ORIGINAL-SYSTEM:LIST` is wrong.

**Solution:**
Use the command:
```
@SET-FILE-ACCESS ORIGINAL-SYSTEM:LIST,,r,rwaod
```
before configuring the system.

### D) Backup-Manager Unknown Server/System Issue

Backup-Manager has problems (unknown server or system) after running `@(EXTRA-SYSTEM)STOP-MODE::MODE`.

**Solution:**
The reason is that UE is enabled also on the console, and UE-files are open after stopping the UE-server. The user (as always on other terminals after stopping the UE-server) has to log out and then log in again before using the Backup-Manager. Eventually, UE can permanently be disabled on the console.

### E) Backup-Manager Error Message Issue

Backup-Manager gives the wrong error message texts if using the NON-English version.

**Solution:**
Install `UE-ERMSG-<rev>-C13:err` (or NEWER c-version) where `<rev>` is the relevant language version.
