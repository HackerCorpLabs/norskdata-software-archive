## Description of Product

The OpenLAN SNA 3270 Emulator for Xenix is a software package that allows a user on any terminal connected to a Uniline model 10, 20 or 40 to access an IBM mainframe as if working on a 3270 type terminal. The connection may go through an OpenLAN SNA Gateway on a XENIX machine, or through a SINTRAN SNA Gateway II.

Further, by using the XCONF utility that is part of the product, the user may tailor the mapping of keys present on the terminal in relation to those of an 3270, and the conversion of characters between the ASCII set and the EBCDIC set used internally on the IBM mainframes.

## Reason(s) for New Product or Version

To offer a 3270 emulator on XENIX using OpenLAN SNA Gateway on XENIX or SNA Gateway II on SINTRAN III.

| OpenLAN SNA Gateway for XENIX    | 110822         |
| or                               |                |
| ND SNA Gateway II                | 211277         |

**Nature of dependency**

To be able to connect to an IBM computer, one of the above products must be available on your network. The OpenLAN SNA Gateway may also be installed on your local XENIX machine.

An "OpenLAN SNA 3270 Emulator" MODE TABLE entry should look like:

- X3270 (SNA 3270 Emulator for XENIX)

```
MODEENT LOGMODE=X3270
COMPROT=X'3080' X

PSERVIC=X'02800000000000000000200' X
RUSIZE=X'87C7'  X

```

The only difference is in the PRESENTATION SERVICES (PSERVIC) where the differing "8" signifies the use of Extended Attributes.

# Installation Procedure

## 4.1 Automatic Installation

To install the product, do the following:

- Log in as user root
- Remove the file /etc/perms/sna3270
- Insert the diskette with OpenLAN SNA 3270 software
- Start custom and select option 4 (Add a Supported Product)
- Follow the instructions given by `custom` using option 1 (Install one or more packages)

**NOTE:**

The files will be copied to the directories /usr/bin and /usr/sna/3270. If the user `sna` is to be used later on, this user must be created before the installation of the SNA 3270 Emulator is done.

## 4.2.2 How to Define Your First Configuration

Now turn to the OpenLAN SNA 3270 Emulator for XENIX User Guide, chapter 4, for configuring the product with respect to SNA Server System Name, SNA Gateway Name, 3270 Devices, Keyboard Layout, etc.
