# Product Information

**Product name**  
ND SNA Remote Terminal Server II  

**Product number**  
211283A  

## Description of Product

The product works as a server (on the ND computer) to SNA Remote Terminal Access on the IBM mainframe, when communicating from the 3270 terminal on IBM to an ND application. It makes the 3270 terminal appear as a ND terminal type 6 (screen-oriented) to the ND system. The product can only be installed on a ND computer that holds the SNA Gateway hardware and software.

## Reason(s) for New Product or Version

To make it possible to run RTA/RTS using SNA-Gateway-II (ND211277).

## 4 Installation procedure

### 4.1 Automatic installation

The product is delivered on one double density product diskette. Log in as user SYSTEM. Insert the floppy labeled 211283A<rev>-EN-01D in the floppy disk unit, and enter th directory:

```
@ENTER-DIRECTORY 211283A<rev>-EN-01D FLOPPY-DISC-1 <unit>
@(211283A;FL-US)INSTALL-RTS:
```

The installation program will now start. As the installation proceeds all necessary instructions will be given.

All files will be copied to the user <SNA-RTS>. Old versions of the product will be deleted.

At the end of the installation 3 files will be created on the user RT:

1. The CONFIG-file SNARTS-CONFIG-A<rev>:DATA copied from <SNA-RTS>.
2. The log-file SNARTS-LOG:LOG, which is a continuous file with 50 pages.
3. The file PF-KEYS:DATA with 3 pages, holding the definitions of the PF-keys.

The mode file SNARTS-LOAD-A<rev>:MODE will be updated to contain the correct user-name.

After the installation, use SNA Remote Terminal Server Supervisor Guide to make the preparations needed to run the product.
