## 1 NOTES:

- This is the first version of NOTIS-WP Examples. Versions A to L have been omitted in order to coincide with the relevant version of NOTIS-WP.
- This product must always be delivered together with a delivery of NOTIS-WP.

## 2 USE

The purpose of this product is to help users of the new version of NOTIS-WP learn to use the word processor easier. This product must be installed in order to use the NOTIS-WP User Guide ND-63.018.2.

## 3 Installation Procedure

To install the NOTIS-WP Examples, log in as user NOTIS.

Use the same national variant of NOTIS-WP Examples as NOTIS-WP. The national variants are marked with a two letter combination in the name of the directory:  
Example: 210960M<rev>-<language>-01S/D

    210960M00-EN-01D

You may have several national variants in the same user area.

Below is an example of loading the English language variant. For other languages, simply substitute the language code -EN- with either -NO- for Norwegian, -SW- for Swedish, or -GE- for German.

```
@ENTER-DIRECTORY↵
DIRECTORY NAME: 210960M<rev>-EN-01↵
DEVICE NAME: FLOPPY-DRIVE-<drive>,<unit>↵
@BACKUP-SYSTEM↵

BACKUP-SYSTEM / G04  85.08.26

Ba-sy: COPY-USERS-FILES↵
  Destination type: D↵
  Destination directory name ’’: ↵
  Destination user name ’NOTIS’: ↵

  Source type: D↵
  Source directory name ’’: 210960M<rev>-EN-01↵
  Source user name ’NOTIS’: FLOPPY-USER↵
  Source file name ’’: ↵

  Manual selection: N↵

Number of files copied: 5

Ba-sy: EXIT↵

@RELEASE-DIRECTORY↵
DIRECTORY NAME: 210960M<rev>-EN-01↵
@
```

NOTE: `<rev>` must be replaced by the current version of the product.

The files are now copied to the user area NOTIS.
