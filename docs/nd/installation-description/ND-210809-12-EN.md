### MODIFICATIONS AND ERRORS CORRECTED:

All modifications and new features in the L version of the justification program are available in Auto Justification. Details are described in the manual NORTEXT-100 Typographic Function Codes ND-61.029.1 EN. A short summary of new features is found in NORTEXT Release Information, L-version.

### INSTALLATION PROCEDURE:

**NOTE:**

This installation procedure requires BACKUP-SYSTEM version F or later.

If you want to preserve any files from your "old system", do make backup copies now. The "old files" are of type :BPUN whereas the new ones are of type :SEGP and :SEGD. Delete old files on user REALTIME-NTX named AUTOJ->BPUN  
`@DELETE-USERS-FILES AUTOJ::BPUN,N`

#### 1) Installing the product

a) Log in as user SYSTEM.

b) Put the installation floppy in the floppy drive and enter it with:  
`@ENTER-DIRECTORY, (FLOPPY-DISC-<drive-no.>,<floppy-unit>)`

c) Start the installation by typing:  
`@X (210809::FLOPPY-USER)INSTALL`  
This XCOM file will copy all files from the floppy to the actual users on disk. Note: All the old files will be deleted before copying takes place.

d) This installation job will start the customizing procedure, i.e. (REALTIME-NTX)CUSTOMIZ-NTX::XCOM will be started. You will then have to answer the question: "Number of Autojustification programs ?".

The answer to this question will be stored in the NORTEXT-100 system definition file, called DEFINE-NORTEXT::XCOM under user REALTIME-NTX.

e) When the installation job is finished the directory will be released and the floppy may then be removed.

f) Log out (from user SYSTEM).

## 2) Parameter File Customization

a) Log in as user PARAMETERS-NTX. The Autojustification programs (lines) in NORTEXT-100 need a parameter file. The parameter files contain new status value and eventually a logical device number for a test device.  
The naming convention for this file is:  
\<AUTOJnn\>-PARAM:NTXP     nn= 01, 02, 03 and so on.

Multiple parameter files for the same type of lines may be created with:  
`@X_CREATE-PARAM-`

Carefully inspect and edit this file under this user to make sure that all parameters have the right value. An editor like PED or -WP may be used for this.

b) Log out (from user PARAMETERS-NTX).

## 3) Building AUTOJ Program Lines

You are now ready to build the real-time part of NORTEXT-100. The real-time part of NORTEXT-100 will be built according to the answers you gave during the customize dialogue. Each subsystem is built by its own BUILD-file called BUILD-XX:XCOM. You may build individual subsystems if necessary without changing the rest of the system. First, you must make sure that the corresponding RT-programs (lines) in question are not running.

a) Log in as user SYSTEM.

b) Build the Auto-justification line by typing:  
`@X_(REALTIME-NTX)BUILD-JU-`

The Auto-justification lines will be built according to the specifications in (REALTIME-NTX) DEFINE-NORTEXT:XCOM.
