## 2 Installation Procedure

NOTIS-DE for ND-100 is supplied on two diskettes with directory names 211011A<rev>-<lang>-01S and 211011A<rev>-<lang>-02S, where '<lang>' denotes the corresponding language code. If you have ordered DS/DD diskettes, one diskette 211011A<rev>-<lang>-01D is supplied.

The procedure to load NOTIS-DE is as follows:

1. Log in as user SYSTEM

2. Make sure that the required number of files and pages is free on user SYSTEM (prerequisites, page 1).

3. NOTIS-DE may be installed on any SINTRAN user; we recommend user NOTIS. This user must have some free pages (see prerequisites, page 1). Make sure that the user exists, and has enough free pages.

4. Insert the diskette 211011A<rev>-<lang>-01 in your diskette station.

5. Enter this directory by typing `@ENTER-DIR,♁FLOPPY-D-<floppy drive,<unit>`

6. Start the installation program by typing `@(211011A:♁FLOPPY-USER)INST-DE`

The installation program will then guide you through the installation.

You are asked to insert the other diskettes when required.

## 3 Installation from Dump-Reentrant File

Update the DUMP-REENTRANT (or HENT-MODE) file with this command:

`@DUMP-PROGRAM-REENTRANT NOTIS-DE-A<rev>,(user specified)NOTIS-DE-A<rev>`

where "user specified" denotes the user the NOTIS-DE program file is copied to (generally user "NOTIS").

## 4 The Terminal Description File

If you already have an earlier revision of the terminal description file DDBTABLES-E:VTM, the file DDBTABLES-E04:VTM will be copied to a file named DDBTABLES-E04:NEW (on user SYSTEM).

If you want to use this new file, please delete the old terminal description file DDBTABLES-E:VTM, and rename the new file by typing:

```
@DELETE-FILE (SYSTEM)DDBTABLES-E:VTM↲
@RENAME-FILE (SYSTEM)DDBTABLES-E04:NEW :VTM↲
```

## 5 The Error Message File

If you already have an earlier revision of the error message file UE-ERMSG-<lang>-B:ERR, the file UE-ERMSG-<lang>-B06:ERR will be copied to a file named UE-ERMSG-<lang>-B06:NEW (on user system).

If you want to use this file, please delete the old error message file UE-ERMSG-<lang>-B:ERR, and rename the new file by typing:

```
@DELETE-FILE (SYSTEM)UE-ERMSG-<lang>-B:ERR↲
@RENAME-FILE (SYSTEM)UE-ERMSG-<lang>-B06:NEW :ERR↲
```

Note that 'lang' in the file names above denotes the respective language code.
