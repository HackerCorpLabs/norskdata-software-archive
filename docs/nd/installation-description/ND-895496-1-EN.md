## Description of product

Revision B01.

This product contains the TECHNOVISION modules TECH2D, TECHFIN, TECHLIST, TECHARC, TECHAPT, TECHIGES, TECHVAR, TECHSURF, TECHMILL, TECHSOLID and TECHSHEET.

It is identical with the TECHNOVISION software release 103 for TECH2D and TECHMILL and release 102 for all other modules on the cartridge.

It is only for installations of TECHNOVISION software on TECHNOSTATIONS.

The installation procedure checks if Technovision is already installed using user T2000-CAD and Technovision configuration file (SYSTEM)TECH-CONF:CONF and handles the cases:
a) Technovision not installed  => complete new installation
b) Release 101 installed       => update of release 101 to 103
c) Release 103 installed       => rebuilding directory APPLICATION
d) Undefined installation status => stop installation

The device number of the peripheral file PLOT will be checked. Only 44B (T1 on old plug carrier for 8 Terminal interface) and 52B (L3 on new plug carrier for Leonardo/MTAD) are allowed.

The installation procedure will create the necessary users and friends on the customer dependent directories PACK-MAIN (in the previous version it was named PACK-USERS-1), PACK-USERS-3 (drawing users) and for a local archive also on PACK-USERS-2.

The following users are copied to customer directories:
- APPLICATION:SAVE-CAD -> PACK-MAIN:T2000-CAD *1)
- APPLICATION:SAVE-OVERLAY -> PACK-MAIN:TECH-OVERLAY

If local archive:
- APPLICATION:SAVE-SIB -> PACK-USERS-2:TECH-SIB *1)

\*1) In case b the users are updated

For case a:
- User T2000-PLCT will be created on PACK-MAIN and the initialized plot queue file PLOT:QUE will be copied to this user.

- A first TECHNET configuration with the following areas and users are created:

  |                 |                                      | Pages | Files |
  |-----------------|--------------------------------------|-------|-------|
  | WRITE-AREA      | PACK-USERS-3:TECH-WRITE-01           | 10000 | 1024  |
  | READ-AREA       | PACK-USERS-3:TECH-READ-01            | 4000  | 1024  |
  |                 | PACK-USERS-3:TECH-READ-02            | 2000  | 1024  |
  | PLOTWR          | PACK-MAIN:T2000-PLOT                 | 1000  | 256   |

- Three test drawings ND1, ND2, ND3 and a test macro FXM0100 will be copied to user TECH-WRITE-01.

The users SAVE-CAD, SAVE-OVERLAY, SAVE-SIB and TECH-INSTALL will be deleted.

User APPLICATION:SWAP-FILE-2 with a swap file of
- 14500 pages if version 1
- 9000 pages if version 2
- 7000 pages if version 3

will be created and defined.

- The archive will be initialized on user TECH-SIB with a size for about 1000 drawings and one norm part package. The archive
- logfile (RLOG) will be created on user PACK-USERS-2: XLOG with a size of 1500 pages. Archive access number 100 will be created and the three test drawings ND1, ND2, ND3 and the test macro FRA0100 will be entered to the archive.

## INSTALLATION PROCEDURE:

### IMPORTANT:

The device DISC-6-SCSI-1 is used for 310 MByte discs.  
The device DISC-3-SCSI-1 is used for 155 MByte discs.

- Enter as **user environment** user SYSTEM (standard password ND).
- Make sure that directory APPLICATION is released.
- Use the BACKUP MANAGER to copy one version of directory APPLICATION (see above) from streamer tape 211471B01 to device DISC-6-SCSI-1 0 1. (For 155 Mbyte device DISC-3-SCSI-1)

```
@BM-OPERATOR

Parameter: COPY

from: VOLUME SINTRAN IMAGE TECHNOVISION STREAMER-1 0  
to: DIRECTORY DISC-6-SCSI-1 0 1 00,CD  
for version 1: INCLUDE APPLICATION DISC-6-SCSI-2 0 1  
for version 2: INCLUDE APPLICATION DISC-6-SCSI-2 0 3  
for version 3: INCLUDE APPLICATION DISC-6-SCSI-2 0 4

STOP-ON-ERROR
```

- `@ENTER-DIRECTORY APPLICATION DISC-6-SCSI-1 0 1`  
  (For 155 Mbyte device DISC-3-SCSI-1)

- `@SET-DEFAULT-DIRECTORY APPLICATION`

- If a local archive is needed:
  - (210706 TBCHARC ordered and
  - no host computer with archive on customer site and
  - disc capacity equal or greater 310 MB)

```
@ENTER-DIRECTORY PACK-USERS-2 DISC-6-SCSI-1 0 3  
@SET-DEFAULT-DIRECTORY PACK-USERS-2
```

- For the drawing users:

```
@ENTER-DIRECTORY PACK-USERS-3 DISC-6-SCSI-1 0 4  
@SET-DEFAULT-DIRECTORY PACK-USERS-3
```

## Installation Instructions

- If you do not install this streamer 211471B01 inside the installation procedure of streamer 211470B01 (after running `(EXTRA-SYSTEM)SYSTEM-CONFIG` and before starting `@MODE (MODE-FILES)COLD-START:MODE`) run mode file:

  ```
  @MODE (APPLICATION-MODE)APPLICATION-INIT::MODE,,
  ```

- If you install for the first time on a TECHNOSTATION with the old plug carrier (without plugs L1 to L8) execute the command:
  
  ```
  @SET-PHERIPHERAL-FILE "PLOT" 44B
  ```

- Start the installation procedure: `@(TECH-INSTALL)TECH-ST-INST-I03`

- Answer the following questions with YES or NO:
  - Do you want HEWLETT-PACKARD instead of CALCOMP-907?
  - Do you want a local archive?

- The configuration will be listed. To start the installation answer YES to the question: Do you want to start the installation? If your answer is NO the installation stops and nothing is changed.

- If the installation is stopped, afterwards directory APPLICATION must be copied again to device DISC-6-SCSI-1-0-1 because some files on the directory are modified during installation!  
  If you are performing a complete new installation and only if you are performing a complete new installation start

  ```
  @MODE (APPLICATION-MODE)APPLICATION-DELE::MODE,,
  ```

  to remove all Technovision specific users from PACK-MAIN, PACK-USERS-2 and PACK-USERS-3 before you start the installation procedure again.

- The installation procedure will write some messages to the error device telling what is going on.

- Wait for message: TECHNOVISION IS READY FOR USE!

- Inspect file `(SYSTEM)TECH-INST:LIST` to see if installation is ok!

Do not forget the installation of the necessary softkeys!
