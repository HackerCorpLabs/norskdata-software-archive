## What does the product consist of?

Graph Plus - ND-230044

Graph Plus is a program for making business charts and diagrams. It runs on an OWS under MS Windows.

## Hardware requirements

One of the following computers must be available:

| Computer | Type  |     |
|----------|-------|-----|
| OWS-12   | PC-AT | ND-150003 |
| OWS-55   | PC-AT | ND-110356 |
| OWS-85   | PC-AT | ND-110357 |

Graph Plus is able to produce output on any of these ND printers:

- HP 7475 plotter - ND-102180
- HP 7550 plotter - ND-110261
- ND 715 Postscript printer - ND-110347
- ND 720 Page printer - ND-110223
- ND 730 Page printer - ND-110224
- EPSON personal printers

Graph Plus can also produce output on many other printers if they are supported by MS Windows. When a local printer is used on the OWS-12, an additional serial port is needed.

## How to read NOTIS-WP files into Graph Plus

It is possible to read tables written in NOTIS-WP into Graph Plus. This is done the following way:

The table you want to use must be stored as a separate document. Store (or copy) it locally on your workstation in 7-bits format and give it the file type extension SPC.

You may now start Graph Plus and give the command File/Worksheet to enter the worksheet. Give the command File/Open Data to read your table.

Select file type SPC and type the name of your table. Select OK, and the table will be read into the worksheet.

This will work fine for space-delimited tables. Remember that you cannot write names which include spaces and treat them as a single element ("Buenos Aires" will be divided into two elements).

Comma-delimited tables can also be imported in the same way, just use extension PRN instead.

## Known deficiencies

### Keyboard

The following shortcut keys for the menu choices in the Edit menu do not work with the ND keyboard:

| Shortcut key | Menu choice | Use instead    |
|--------------|-------------|----------------|
| SHIFT + DEL  | (Edit/Cut)  | HYPERSHIFT + DEL |
| SHIFT + INS  | (Edit/Paste)| HYPERSHIFT + INS |
| CTRL + INS   | (Edit/Copy) | Menu choice     |
| F11          | (Edit/Close)| Menu choice     |
| SHIFT + F11  | (Edit/Open) | Menu choice     |

The <HYPERSHIFT> keys are located at the lower left and right corners of the main keyboard.

### NOTIS-PET remote printers

When installing NOTIS-PET, you can define remote printers. These printers cannot be used directly from Graph Plus, since Graph Plus does not support remote printing.
