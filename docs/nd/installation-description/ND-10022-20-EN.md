## Loading/Operating Procedure, Use

Place the diskette in the floppy disk drive, unit 0.  
Press MASTER CLEAR. Type 1560&.  
When the terminal responds with an asterisk, type  
LOAD FILESYS-INV  

After power fail, the program should be restarted.

SET-PRINTER-DEVICE should not be used with device number 0.

FILESYS-INV:BPUN can be used to update your directory size for your use in two ways.

1. You only do a directory size update and don’t use the new spare track allocation method. In which case you proceed as follows: load the program into memory as described in the program description document. Do a PAGE-LIST and enter E for errors only. This will ensure that you have no errors in your bit file, or errors in the page entries. If you have any errors in the bits for the bit map or error in pages used in the page entries, YOU MUST start Sintran and correct the errors with Sintran or as a last resource use the Sintran command REGENERATE-DIRECTORY look at your Sintran III System Supervisor Manual test run explanations for the FILESYSTEM-INVESTIGATOR to fix errors in question! Otherwise ND cannot be responsible for what may happen to you disc data. After you have regenerated the disc run a PAGE-LIST entering E for errors again to ensure the disc is free of errors and ready for updating. Now execute a DIR-SIZE-UPDATE command (DO NOT STOP THE PROGRAM WHEN THIS COMMAND IS BEING EXECUTED!! DANGER!!), once this is finished, your disc is compatible with the latest versions of Sintran.

2. Switch to Sintran III using spare track allocation. You proceed as in 1 above, when DIR-SIZE-UPDATE completes, then you get another disc, and make a disc to disc copy of your updated disc. Once you have copied to another disc, you format your original disc with the new formatting program that formats with the spare tracks. Then you copy your data back to your newly formatted disc, and you are finished. You use the DISC-TEMA stand alone utility program to copy disc to disc and to format disc’s with the spare track allocation.

   If you don’t have more than one disc unit, then you use the stand alone program MCOPY to copy your updated disc to a magtape. Once you have copied the disc to the magtape, then format your disc and copy back data to the disc from the magtape using the MCOPY.

## CHANGES

Some minor errors are corrected.

The latest version of the ECC disk driver, with spare track allocation, has been included.

The floppy driver for the new floppy interface (double density, double side) has been added. The old driver has not been deleted. Device names for the floppy drive are still FLOPPY-DISC-1 and FLOPPY-DISC-2, regardless of drive type and diskette type.

The driver for the new (winchester) disk is included. The new device names are DISC-2MB-1, DISC-2MB-2, DISC-14MB-1, and DISC-14MB-2.

The test monitor and monitor library have the version D, as before.

Includes a new command DIR-SIZE-UPDATE, that updates the directories of Sintran Versions A,B,C,D to the smaller size of the latest versions of Sintran. This applies only to 288MB, 75MB, and Phoenix discs.
