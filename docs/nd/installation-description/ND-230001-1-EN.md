# 1 INTRODUCTION

The installation procedure will copy the Butterfly 110 PC system software to the DOS partition of the hard disk i.e. drive C:.

In addition it will:

- install DOS 3.10 (product no. **ND-230004**) into the sub-directory C:\DOS.
- save any existing files named C:\AUTOEXEC.BAT or C:\CONFIG.SYS into C:\AUTOEXEC.BAK and C:\CONFIG.BAK. (After the installation is complete you may wish to merge together the old and new files.)

## 1.1 Pre-requisites:

The hard disk has been partitioned to give an active DOS partition of 5 Megabytes and a SINTRAN partition of the remainder. The DOS partition should also have been formatted as a system disk.

## 1.2 NOTIS/IBM Compatibility

On a standard IBM PC keyboard in the CAPS LOCK state, pressing SHIFT will produce Lower Case characters. On a NOTIS keyboard SHIFT CAPS LOCK will produce Upper Case characters. The Butterfly keyboard is PC compatible, and may therefore cause some inconvenience for some users.

## 1.3 Mouse Compatibility

The mouse connected to the keyboard can be used by PC programs if they support MICROSOFT mouse. We have seen one example of a program (Sigma Paint) that did not initialize the mouse correctly. The vertical movement was very sluggish, and could be repaired in the following manner:

## 3 INSTALLATION PROCEDURE

To run the installation procedure insert the diskette 230001A<rev>-EN-01D in floppy drive A: and close the door. Then if the machine is turned on, reset it by pressing the `<CTRL> <ALT>` and `<DEL>` keys together. If the machine is not turned on then turn it on.

During the installation procedure you will be prompted to insert the two diskettes of DOS 3.10 (ND-230004) so that DOS 3.10 can be installed, this procedure may be skipped over if you have already installed DOS 3.10 into the sub-directory C:\DOS.

Note that it may seem as if the installation program allow you to print the batdrack file, but this is not the possible during installation. If you want a printout, the DISKPREP program must be run.

After copying the PC system software files to the hard disk and installing DOS 3.10 the installation procedure will run the maintenance program DISKPREP to prepare a file containing the list of any re-allocated tracks your hard disk may have.

When the installation procedure is complete you should remove the diskette from the floppy drive A.

If the ND software (ND-211087J SINTRAN and ND-211092A ND System Software) is already installed on the SINTRAN partition you should now re-boot your machine by holding down the `<CTRL>`, `<ALT>` and `<DEL>` keys together. This will automatically start-up the ND-110. See the chapter Start Modes.

If the ND software is not already installed you should now proceed with its installation.

## 4 Define Country and Keyboard Nationality

Four aspects must be considered when adapting a machine to a specific country.

A) Language that the User communication of a program is written in.

B) The way date and time are represented in different countries.

C) Interpretation of different nationality variants of keyboards.

D) Display of different nationality characters on the screen.

A) Depends on which translations of the software that is available from the national subsidiaries. The software languages are designated as specified below, but there is no one-to-one correspondence between Country and language. For instance it is possible to run English software on a Machine with Norwegian keyboard and display. However, the english [, \ and ] would be displayed as Æ, Ø and Å.

B) The country is either defined in Config.sys. file by `Country=nnn`, where nnn is the international country telephone code - or by keyboard nationality. The accepted codes and nationalities are:

| Country       | Teleph. code | Keyboard+Display Nationality | Software Language |
|---------------|--------------|------------------------------|-------------------|
| Denmark       | 045          | DA                           | DA                |
| France        | 033          | FR                           | FR                |
| Germany       | 049          | GE                           | GE                |
| Norway        | 047          | NO                           | NO                |
| Sweden        | 046          | SW                           | SW                |
| United Kingdom| 044          | EN,UK                        | EN                |
| United States | 01           | US                           | EN                |

**NOTE!** There is a difference between Nationality and Language codes. For instance UK and US have different keyboard nationalities, UK and US, but they have the same language EN (more or less).

C) The keyboard nationality is determined when installing the keyboard driver by specifying the nationality as an extra parameter, `KEYBOARD XX`, where XX is one of the nationality codes above.

When `KEYBOARD XX` is specified in the initial batchfile, the country definition will be changed to match the XX. If the nationality, XX is omitted, the keyboard will follow the country definition:

```
In Config.sys: Country=XX Country=XX
In ND-110.bat: KEYBOARD   KEYBOARD YY
Results:       XX         YY
```

D) The nationality of the display follows the country definition.

## 5 Power Fail and Watchdog Shutdown

Sintran is able to shut down in a controlled manner on two occasions:

A) A Mains Power Failure is detected by the power supply.  
B) The ND Watchdog discovers that the PC is not working properly.

In both cases a Power Fail interrupt to level 14 is generated, and Sintran shuts down as quickly as possible and stops. The last thing it does is to set the **Shutdown OK flag** true.

### 5.1 Watchdog

The Watchdog is checking two things:  
A) Every 20 ms it handshakes with the MS-DOS timer routine to see if it is running correctly.  
B) If the PC does not respond to an IOX instruction within 8 seconds.

ND-110 will therefore "go to sleep" in a controlled manner if the PC has crashed, is reset or rebooted, or is running a non-Butterfly version of MS-DOS.

If someone comes to the PC and starts to run a Game on it, for instance, Sintran will go into a controlled shut down, and can later be awakened and resume operation where it was cut off.

### 5.2 Power Fail

If there is a real power failure causing shutdown, the Memory needs battery backup in order to resume Sintran after Power Fail. This is possible on Butterfly-110 as on any normal ND-100 if the Backup Battery option is installed. (Available in release 2.) The ND-110 will resume as described below, but everything in the PC is lost.

## 5.3 Resume Sintran from Memory

The condition for being able to resume Sintran from memory is that

* Autoboot=1 and Ald=13 and Shutdown OK=1 and Memory Valid=1.

The Butterfly default values are set so this will happen if the conditions are right. The Resuming of Sintran from Memory takes about 40 seconds compared to Warm Starting of Sintran from Disk that takes about 3 minutes.

* Resume Sequence:
  - Instead of loading from disk, the CPU starts to execute code at address 20. The memory content is valid if:
    * Memory power has not been away, and
    * Sintran has shut down properly earlier. I.e. "Sintran is Intact."
  - Sintran comes up after 15 seconds with the following Console Message: SYSTEM IS RUNNING AFTER BREAK. PLEASE CONTINUE.
  - The users will be able to continue at the same place as they were interrupted.

## 5.4 Recover Screen Picture after Resume

When Sintran resumes operation after the PC being Reset or Power Fail, the screen picture is blanked and is not refreshed automatically. (Because Sintran does not know what the user's application programs did when they were interrupted.)

The cursor may therefore appear in strange positions on a screen with no text. The first thing to do should be to push the HOME key to see if it moves to the upper left corner. Several of ND's Notis products will redraw the screen if you push CTRL + Spacebar.

If you don't know what was going on on the terminal before it was interrupted it may be tricky to figure it out. The sequence of keys that should be attempted is

1) HOME
2) Cursor UP, DOWN, LEFT and RIGHT
3) RET
4) EXIT
5) ESC

When pushing ESC you may either break out of a program or attempt to log in. Have a little patience after hitting ESC, because it may take some time until the machine reacts.

If the terminal seems locked up, the Desk Supervisor may stop the terminal from Sintran or the Supervisor menu. If Resume was not successful it is also quite simple to do a Warm Start that initializes the whole machine again.

## 6 USE OF CPU NUMBER AND INSTALLATION NUMBER

Each Butterfly-110 is equipped with a unique number stored in PROM, called Hardware Installation Number. This is related to the machine cabinet, rather than the CPU card or the hard disk. The number stored on the disk is called System or CPU number, and it is primarily used by Sintran and Cosmos. (In documentation System and CPU numbers are used interchangeably.)

If the disk is changed or Sintran re-installed, there will become a discrepancy between the Installation number in hardware and the System number on the disk. (A fresh Sintran has System number 0.) Just after Sintran has started it reports the value of the Installation number. Then it checks if the Installation and System numbers are the same. If they differ, it resets the System number to the virgin value and reports that it is 0.

The task of making the System Number equal to the Installation number is very involved and requires a special program to be run. To run the program start the Sintran subsystem @DO SUPERVISE-SYSTEM. Then select choice 4: Update CPU Number.

**NOTE!** It is not possible to run COSMOS until the System number has been updated from 0 to the hardware Installation number. In correctly set up systems the two numbers shall be equal. This can be verified by running @DO SYSTEM-INFO.

## 7 START MODES

This chapter contains an overview of the different ways the Butterfly-110 may be started.

### 7.1 Choice of System Startup Modes

In the beginning of the ND-110.bat the user is offered a choice of which hardware to use and how ND-110 shall be started. The 3 choices are:

A) If you don't want to USE ND-110 at all - Press key 0 within 5 sec.  
B) If you don't want to AUTO START ND-110 - Press key 1 within 5 sec.  
C) Any other key or waiting 5 sec. will cause AUTO START of ND-110.

In the Standard ND-110.bat file the AUTOBOOT and ALD parameters in NVRAM are programmed to be in each of the three cases:

A) No changes  
B) AUTOBOOT=0, ALD=13 Sintran/Disk  
C) AUTOBOOT=1, ALD=13 Sintran/Disk

If these settings do not suit your particular needs, they may be taken out of the file ND-110.bat, or changed as described below.

## 7.1.1 Setting of Start Parameters in NVRAM

It is possible to set ND-110 NVRAM parameters individually from the PC with the program NVSET. It can be executed as an MS-DOS command or included in a batchfile. The commands are:

```
NVSET 4 0 = Set Autoboot flag to 0 = AUTO- (Disable)
NVSET 4 1 = Set Autoboot flag to 1 = AUTO+ (Enable)
NVSET 2 5 = Boot from Hard Disk                   (ALD= 5)
NVSET 2 6 = Boot from Floppy Disk                 (ALD= 6)
NVSET 2 7 = Stop (No boot)                        (ALD= 7)
NVSET 2 D = Resume Sintran if intact else boot from Hard Disk (ALD=13)
NVSET 2 F = Resume Sintran if intact else stop.   (ALD=15)
```

## 7.2 Start the PC Only and Don’t Initialize ND-110

- Push CTRL+ALT+EXIT, CTRL+ALT+DEL or the Power Button. When the question about System Startup appears, press 0 within 5 seconds. The machine is immediately ready to accept MS-DOS commands.

This mode is used when PC programs which require lots of memory space will be run. By not initializing ND-110 266 kbyte is released for PC programs. (See section PC Memory Usage.)

In the minimum PC-mode it is not possible to program the Push keys because the System Manger is not loaded. It may be loaded at any time by the command: `cd \bfly-110\bfly`  
followed by: `sysmgr FA` (FA must be upper case!)

If you want to initialize ND-110 afterwords from this mode type:  
`cd \bfly-110\bfly` followed by: `nd-110.bat`

## 7.4 Resume Sintran from Memory if it is Intact

* Push CTRL+ALT+EXIT or CTRL+ALT+DEL and wait for 40 seconds. When the Console Message "False Interrupt" or "System is Running After Break. Please Continue." appears, press any key to continue.

This is the default mode when power has not been away, and you don't need to do anything to make it happen. However, you can save 5 seconds if you type spacebar as soon as you see the System Startup question at the screen.

See also section "Recover Screen Picture after Resume".

This is the default mode when power has been away, and you don't need to do anything to make it happen. However, you can save 5 seconds if you type spacebar as soon as you see the System Startup question at the screen.

## 7.6 Load Sintran from Hard Disk Save Area (Cold Start)

This mode is only used after special system software is installed or when a serious error has appeared in Sintran that cannot be repaired by Warm Start. This procedure is automatic but takes a long time. (Have a magazine ready.) When the loading has finished, the operator must type @Restart-System to do a Warm Start.

### 7.6.1 After Reset or Power Up

- Push CTRL+ALT+EXIT, CTRL+ALT+DEL or the Power Button. When the question about System Startup appears, press 1 within 5 seconds. When the System Manager appears 15 seconds afterwards - push RET.
- Type Supv to start ND-Supervisor program. Type the System Password and push RET to enter Main Menu. Push 5 to select and initiate Cold Start. After the initial phase you can push RET twice and be connected to the ND console. When the HENT-MODE file has finished, log in as user System and do the command @Restart-System to execute a Warm Start.

### 7.6.2 When Sintran is Running

- Log in on the ND Supervisor Console as user System and give the command @COLD-START. When the HENT-MODE file has finished, log in as user System and do the command @Restart-System to execute a Warm Start.

## 8 Possible Conflicts Between ND-110 and Standard PC-Programs

An important reason for crashes in general is several programs trying to use the same resources. Since the PC has no resource reservation, conflicts may arise when there are many resident programs. The I/O server programs for ND-110 are resident programs, and the potential conflict areas are: Use of interrupts, routines in the timer chain and programs fiddling with keyboard input.

# 8.1 Software Interrupts

Below follows a list of the interrupts used by the resident PC software in Butterfly-110.
- Int 60H - Comms call
- Int 62H - Comms area
- Int 63H - Terminal 1 I/O
- Int 64H - Terminal 1 I/O
- Int 65H - Reset NDIO
- Int 6FH - ICBM call

# 8.2 Hardware Interrupt

The ND-110 PCX board uses the line IRQ5 to interrupt the PC. This is not possible to change and may cause conflicts with certain adapter boards. For example Microsoft Bus Mouse may use this interrupt.

# 8.3 Programmed I/O

The ND-110 PCX board is programmed from the PC by means of I/O addresses in the range 160H - 167H.

# 8.4 ND-PC Shared Memory

The exchange of data between the two processors takes place through a 64k byte window. The PC accesses it as segment D (832k - 896k). After booting, the memory is readable, but not writeable. Unless it is opened for write by a special procedure, it will therefore appear as PROMS to normal PC programs. This use may block the use of Expanded Memory boards if they require a contiguous unused 64k area.

# 8.5 Timer

All ND I/O server programs are removed from the standard timer driver. They are all attached to the hardware timer interrupt and are therefore handled _before_ the standard driver is entered.

# 8.6 Keyboard

The compatibility between the NOTIS keyboard driver and the standard is apparently very good. An area of potential risk is the 64 deep buffer compared to the standard 16. This is introduced in order to give room for a max length Push key sequence.

Many resident programs intercept the normal keyboard handling. If several are installed at the same time, there is a high risk of trouble even on a standard PC-AT. Examples of potentially dangerous resident programs that do work are: Sidekick, Turbo Lightening, PC Automator.
