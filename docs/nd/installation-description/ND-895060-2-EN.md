# Product Information

**Product Name:** CMS Access Server for ND-500/5000  
**Product Number:** 211325B

## Description of Product

To provide access to services (DS UE SSY SIBAS) for a max. of 124 OWS connected to an Ethernet local area network, using ND-5000, or for a max. of 48 OWS connections using ND-500.

## Reason(s) for New Product or Version

- Synchronized release with SIBAS/R Backend.
- Enhanced security by utilizing new options in SINTRAN patch level 3100.

## 4 Installation procedure

### 4.1 Automatic installation

- Insert the floppy 211325B-XX-1D in the floppy-drive  
  `@ENTER-DIRECTORY,,F-D-1,80/1A`

- Log in as user SYSTEM

- Run the installation program:  
  `@(211325:FL-US)IN-OWS`

### 4.2 Non-automatic installation

When the installation program has been run:

- Update the mode file that is run after a cold start (usually called HENT-MODE:MODE) by including the following line:  
  `@MODE (OPENLAN)OWSAS-LOAD-B:MODE,,`

- Update the mode file that is run after a warm-start (usually called LOAD-MODE:MODE) by including the following line:  
  `@(OPENLAN)OWSAS-SERV15,START-SERVERS`  
  AFTER 500(0), TCP/IP, and TABS has been started.  
  Remember that (SET-AVAILABLE must also has been executed.  
  If your system is a 500 system, this line should be already  
  present in the startup mode file for TCP/IP.

- You may start the OWS Access Server at any time IF the TCP/IP  
  and 500(0) has been started, by the following command:  
  `@(OPENLAN)OWSAS-SERV15,START-SERVERS`

- Please refer to "The OWS Server" in the manual OpenLAN Network  
  Supervisor Guide concerning how to set up the services (DS, SSY,  
  UE, SIB) in the AIP-HOSTS:SYMB file, if you have not already done  
  it.

- Insert the line into your "stop-system" mode file if necessary:  
  `@(OPENLAN)OWSAS-SERV15,STOP-SERVERS,0`  
  BEFORE stopping XMSG and TCP/IP.

## 5 Modifications

### 5.1 New functions/commands
None.

### 5.2 Changed functions/commands
None.

### 5.3 Removed functions/commands
None.

### 5.4 Other modifications
- Listing of remote SINTRAN documents is implemented in DSP$startlist by utilizing new monitor call in SINTRAN L (GNFIL).
- Enhanced system security check.

## 6 Errors corrected
Error in document deabbreviation if DSP$open performed on a SINTRAN document with user name included and file type not included.

## 7 Errors known but not corrected
Deabbreviation of SINTRAN document names may still fail under certain conditions due to errors in the monitor calls, but some "workarounds" will now (hopefully) give correct results.

- **Limitation**: Server may only concurrently open a total of 48 SINTRAN documents due to open file table size limitations in background program system segment. May be increased to max 64 by using S3-CONFIG, menu BACKGROUND, to configurate system segment size from 5 to 8 pages.

- **Limitation**: DS-server may accept 40 concurrently connected services on a ND-500/5000 DS-server and 24 on a ND-100 DS-server.
