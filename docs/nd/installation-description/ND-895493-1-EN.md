## Description of Product

This product is a SNA Gateway to an IBM mainframe. The Gateway is running on XENIX using a PCB SNA SDLC-card for XENIX. This version of the OpenLAN SNA Gateway supports SNA 3270 on XENIX and SNA 3270 on MS-DOS.

## Reason(s) for New Product or Version

The previous versions of the SNA Gateway (I and II) were running in ND-100 on SINTRAN III. This OpenLAN SNA Gateway is running in ND Uniline x0 on XENIX.

## 4 Installation Procedure

### 4.1 Automatic Installation

Install the PCB SNA SDLC-card for XENIX following the instructions in the "ND PC and the ND Uniline 10/20/40 Mechanical installations" - ND-891041.1 EN

**Install hardware:**

- Turn off the power
- Take off the cover of the computer.
- Find a free slot and mount the SDLC card.
- Connect the modem cable to the port on the back of the card
- The SDLC card coexists with the sio (Serial Input Output device) in the computer. The only way to achieve this is to remove the COM2 port from the sio. This is not as complicated as it may seem. The following is what you should do in the different types of computers:

| |  | |
|---|---|---|
| ▢ | if (Uniline 10 - WYSE) then | - remove the sio card <br> - get the WYSE Installation and Assembly Manual <br> - turn to the Chapter 4 Installing Options and then to subchapter Serial/Parallel Interface Board for information on the 2F jumper <br> - remove the 2F jumper on the sio card <br> - reinstall the sio card |
| ▢ | if (Uniline 20 - ACER) then | - get the ACER 1100/xx USER'S GUIDE <br> - turn to the chapter 3.2.2 How to Set Switches and Jumpers <br> - remove the cover marked SWITCH on the back panel. Now you have access to the SW2 switches <br> - Change SW2 (section 3 (COM2) as given in table 3.2) from OFF to ON|
| ▢ | if (Uniline 40) then | - do nothing |

- Put on the cover.
- Turn on the power.
- Reboot

## Install software:

- Log in as user root
- Remove the file /etc/perms/snagtw
- Insert the diskette with OpenLAN SNA Gateway software
- Start custom and select option 4 (Add a Supported product)
- Follow the instructions given by 'custom'
- Shut down the system using the command 'shutdown'
- Turn off the power
- Turn on the power.
- Reboot

**NOTE:**

The files will be copied to the directories /usr/bin, /usr/sna/sdlc, /usr/sna/files and /usr/sna/gtw. If the user 'sna' is to be used later on this user must be created before the installation of the SNA 3270 Emulator is done.

## 4.2.2 How to define your first configuration

Refer to the OpenLAN SNA Gateway User Guide, chapter 3 for configuring the product. Both the SNA Gateway and the LUs must be configured before the Gateway can be started.
