## 4 Installation Procedure

### 4.1 Automatic Installation

#### 4.1.1 Preparations

Prior to the installation, verify the following:

- Ensure that the user areas specified in Chapter 1.3 exist with the required number of free pages and free files. If not, find a directory having enough space to hold the user areas. The installation program will try to allocate space whenever needed, but you may need to specify on which directory to create user areas.

- The following files will be loaded/linked to UNIQUE-DOC:

| Abbrev. file name | Default user area(s)           |
|-------------------|--------------------------------|
| SIBAS library     | SIB-LIB       | SIB-500              |
| UE library        | UE-PLIB       | USER-ENVIRONMENT     |
| NOTIS-WP (N)      | WP-500-N      | NOTIS, DOMAIN-USER, SYSTEM |
| NOTIS-WP (M)      | NOTIS-WP--M   | NOTIS, DOMAIN-USER, SYSTEM |

Check where these files are installed. If not installed on the default user area, the installation program will ask where to find these files.

- If you already have a version of UNIQUE-DOC installed, you should make sure it is not defined as a standard domain. Delete it prior to the installation.

- Ensure that your configuration fulfills all other requirements mentioned in Chapter 1 and 2.

```
NOTE:
To install UNIQUE-DOC on an ND-500/5000 machine with the new
ND-LINKER the non-automatic installation procedure must be used
(see chapter 4.2).
```

## 4.1.2 Installation from Floppy

- Put the diskette 211250C<rev>-XX-01D into the floppy drive.
- Log in to user area SYSTEM.
- Enter directory 211250C-XX-01D.
- Run the INSTALL program on the diskette.

Example: how to enter the directory and start the installation program.

```
@ENTER-DIRECTORY 211250C-XX-01 FLOPPY-DISC-1 0↵

@(211250C:FLOPPY-USER)INSTALL↵
```

The following screen will appear:

```
┌───────────────────────────────────────────────┐
│                  INSTALLATION                 │
│ UNIQUE-DOC SIBAS ND500 VERSION C xx           │
│                                               │
│ Unique A/S           Date : 20-JUN-88         │
│ --> Initialising - please wait -->            │
│ --> Sintran version:K Revision:I300 Generated:15-MAY-86  │
│ --> Cpu number :6200                          │
│                                               │
```

The installation program can do the following:

- **CREATE**  
  Create a new user area (or use an existing one) for DOC.

- **COPY**  
  Copy all files from the floppy to the desired user-area.

- **LOAD**  
  Write the load procedure and load the UNIQUE-DOC domain.

- **DUMP**  
  Dump DOC as a standard domain.

- **EXIT**  
  Leave the installation program and return to SINTRAN.

If you are installing DOC for the first time, you must run all the tasks 1-4, one at a time, in sequence. To reload DOC, run tasks 3 and 4. To re-dump DOC, run task 4.

When selecting the CREATE or COPY option, and an (old) version exists on the selected user area, you are asked if these files should be deleted. You may answer Yes, No or Manually. When answering YES, program files, domain files, ⋅MODE and ⋅LIST files of current and previous versions/revisions will be deleted. Afterwards the program checks if there are enough free pages on the user area.

When selecting the LOAD option, there are some questions that need an explanation:

- **LANGUAGE**  
  'Language to be used if UE is not active? /NO/'

  By default DOC will use the language found in the user profile in User Environment. The answer to this question selects the language to be used if UE is NOT active on the terminal running DOC.

- **UNIQUE-II**  
  'Which version of UNIQUE-II is used on your system (B/C)? /C/'

  Answer B if you want UNIQUE-DOC to document applications made by UNIQUE-II B-version.

- **NOTIS-WP**  
  'Which version of NOTIS-WP will be used (M or N) /M/'

  Answer M (or :) if you have the M version of NOTIS-WP.  
  Answer N if you have the N version of NOTIS-WP.

## 4.1.3 Subsequent Installation

If at a later date you want to reload or re-dump DOC, you can use the installation program that is automatically copied from the floppy disc during the first installation. To re-run the installation program, log in as user SYSTEM and type:

```
@(DIALOG-SYSTEM)DOC-IN-S5-C
```

To reload DOC, run tasks 3 and 4. To redump DOC, run task 4. You may of course also reuse the created load/dump procedures (:MODE).

## 4.2 Non-Automatic Installation

Create a user area with the number of pages mentioned before and copy all the :NRF and :MODE files from the floppy into it.

### Loading with Linkage Loader:

Log in to the user area containing the :NRF files. Edit the file `DOC-LOAD-S5-C:MODE` to suit your installation and run it by typing:

```
@MODE DOC-LOAD-S5-C:MODE "DOC-LOAD-S5-C:LIST"
```

### Loading with ND Linker:

Log in to the user area containing the :NRF files. Edit the file `DOC-DOM-C:MODE` to suit your installation and run it by typing:

```
@MODE DOC-DOM-C:MODE "DOC-DOM-C:LIST"
```

# 5 Modifications

## 5.1 New Functions/Commands

**Revision C10**

- There is a new command called DOCUMENT-LEGAL-COMMANDS=YES/NO.  
  When the default value NO is used, legal-commands will not  
  be documented in the user documentation.

- System documentation will now also document fields with storage  
  WIDE-COLUMN and keyword (multi index).

**Revision C13**

- A new command DS = `<CHAR>` is available in :UDOC files.  
  If the command is omitted, the default is ~.

  It is used to specify which Directive Start character should be  
  generated for NOTIS-WP when ^ can not be used. It is required e.g.  
  when including :XTRA reports or :UNIQ applications using ~ as  
  lead-in character.

## 5.2 Changed Functions/Commands

**Revision C10**

- The parameter 'OFF' has been added to the command CROSS-REFERENCE.

## 5.4 Other Modifications

**Revision C13:**

- Improved support for NOTIS-WP version N is implemented.  
  This will be valid for NOTIS-WP version N09 or newer.  
  - NOTIS-TF with DS syntax in the filename parameter may be used  
    provided the following is done in SW-CONFIG:SYMB:

  ```
  system-name: <the actual system name>
  NOTIS-TF =’NOT-TF SINTRAN,,’
  ```

  NOTE the syntax!!!

- Due to changes in the S-format required in different versions of the NOTIS products, a new file must be present on user DIALOG-SYS.  
  This file is named UQ-ND-S:INI and must have public read access.  

  All S-format files produced by UNIQUE products will have the same S-format header as the file (DIALOG-SYS)UQ-ND-S:INI.

  UQ-ND-S:INI is an 'empty' file containing only an S-Format header matching the version of NOTIS-WP you are using on your machine. By storing the S-Format header in a file, it is possible for you to define the default settings and rulers. UNIQUE will read the default header from this user defined file, if it exists.

  If you start using a version of NOTIS-WP with a new S-Format, e.g. going from WP version M to N, just repeat the procedure described below and UNIQUE will produce documents readable by the new WP version.

  You have to install/create this file manually:

  ```
  1. Log in on user area DIALOG-SYS.
  2. Start NOTIS-WP.
  3. Use the internal menus in WP to set the wanted default values.
  4. Make sure you define it to be an S-Format document.
  5. Type some blanks so WP will store it as a document.
  6. Save this 'empty' document to the file "UQ-ND-S:INI".
  7. Set public access to READ: @set-file-access UQ-ND-S:INI R,,,
  ```
