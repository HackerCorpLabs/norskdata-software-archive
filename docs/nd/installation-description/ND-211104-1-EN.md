## 1 SYSTEMS PREREQUISITES

The following are prerequisites for the installation of COSMOS Network Monitor:

- SINTRAN III version J or newer.
- X-MESSAGE version J or newer.

## 2 INSTALLATION CONSIDERATIONS

The COSMOS Network Monitor consists of three parts:

- **test part**, which checks status of connections and servers.
- **report part**, which allows the operator to produce reports.
- **monitory part**, which does online monitoring of status on a terminal whenever started.

The test part should only be installed on one machine (per operator domain) in the network. This machine should be a central one and have good access to other parts of the network. The test part is installed under user RT.

The configuration file and the logging file from the test part are input files to the report part. To prevent that the operator has to copy these files to another machine when producing reports, the report part is installed on the same machine as the test part. It may be installed under any user. **NOTE** that you also have to install the enclosed report production tool REPRO for ND-100 on your machine.

The monitory part may be run on any system in the network which has access to the system where the test part is running. It may be installed under any user.

# 3 INSTALLATION PROCEDURE

The installation procedure allows you to choose whether to install the test & report part AND/OR the monitory part.

## 3.1 Running the installation program

Installing the different parts of the COSMOS Monitor is done as follows:

- Log in as user SYSTEM.

- Make sure that the user(s) you want to copy the files to has enough free user space. The amount of space is given on the front page of this PD-sheet.

- Insert the first release floppy in the floppy drive.

- Enter the directory on the floppy

```
@ENTER-DIRECTORY↵
DIRECTORY NAME: 211104A<rev>-XX-01↵
DEVICE NAME: FLOPPY-DISC-<drive-no.>↵
DEVICE UNIT: <floppy-unit>↵
@
```

- Start the installation program with the command:

```
@(211104A:FLOPPY-USER)INST-COSMON↵
```

The two messages:

USER-BREAK TERMINATION ENABLED and  
FATAL-ERROR TERMINATION ENABLED  

are _not_ error messages, but simply informing you that the error handling is ready.

- Choose which part(s) of the COSMOS Monitor you want to install; test & report AND/OR monitory part.

- When you are asked for user name, you should write the name without any abbreviations. The files concerned with the report production will be placed on this user area. The file in the monitory part will also be placed on this area if you choose to install it. The RT- program will be placed under user RT.

### 3.2 What the installation program does

When you run the installation procedure, the following will be done:

#### If you install the test & report part:

The following files will be copied from the diskette:

To user RT:

- **COSMON-MAIN-A:PROG** (RT-program doing the testing).
- **COSMON-DEF-A:CONF** (Configuration file).
- **COSMON-LOAD-A:MODE** (Load file for RT-program).

To user area given by you:

- **COSMON-SERV-A:PROG** (Saves logfile and starts REPRO for producing reports).
- **REP-COSMON-A:RPRT** (Library used by REPRO).
- **COSMON-STAT-A:LOOK** (Lookup file used by REPRO).

The following files will be created:

On the user area given by you:

- **COSMON-INRP-A:SYMB** (Infile to REPRO).
- **COSMON-OUTRP-A:TEXT** (Default outfile from REPRO).

#### If you install the monitory part:

The following files will be copied from the diskette:

To user area given by you:

- **COSMON-WIND-A:PROG** (Operator's monitor program).

### 4 Ending the installation procedure

When the installation program has terminated successfully, you should give the command:

```
@DELETE-FILE (SYSTEM)INST-COSMON:PROG
```

## 5 Further Procedures

### 5.1 Loading the COSMON Main RT-program

To load the COSMON-Main RT-program you do as follows:

- Log in as user SYSTEM or RT
- Run the mode file COSMON-LOAD-A:MODE on user RT.

```
@MODE (RT)COSMON-LOAD-A:MODE,,,,
```

This mode command should be inserted in the SINTRAN file HENT-MODE:MODE, to ensure that the COSMON-Main RT-program is loaded after a cold start.

### 5.2 Starting and stopping the COSMON Main RT-program

Before you start the COSMON Main RT-program, you must use PED (or any other text editor with 7-bit storage format) to build up your own version of the configuration file

```
COSMON-DEF-A:CONF
```

A sample version is copied from the diskette which will be useful for keeping the required format. A description of the format of this file is found in the COSMOS Network Monitor Operator Guide.

Remember the cost if testing connections over public networks.

To be able to check the status of servers on a system in a network, this system must run XMSG K or later. If not, an error message will be returned.

The logging file, COSMON-LOG:LOGS, will be created when the RT-program is started.

Start the COSMON Main RT-program using the SINTRAN command

```
@RT COSMONJ
```

You should add this command in the SINTRAN file LOAD-MODE:MODE (or LOAD-SYSTEM:BATC) so that the COSMON Main RT-program is restarted after a warm start.

# 5.3 Running the COSMON Window program

The monitoring part of the COSMOS Network Monitor consists of only one program. When this is started

    @COSMON-WINDJ

the operator is asked on which system the COSMON Main RT-program is running. The operator may in this way be miles away from the machine where the test part is running and still get a status display on his/her terminal. When this has been specified, the status display on the terminal will start.

You may shift pages with the <|> and <|> keys. Status will be continuously updated until the operator wants to stop it. This is done by pressing the <EXIT> or the <CR> key.

Only one COSMON Window program per running RT-program may be started at the same time. Remember the cost if you choose to set up a connection between the test part and the monitor part over a public network.

# 5.4 Producing Reports

The COSMON Main RT-program logs all changes in status for those entries in the configuration file which have been specified to be logged. Since this logging file is rather tiresome to read, you may produce reports which are easier to read. You may also produce statistics reports over the network access.

Install the enclosed standard report production tool REPRO for ND-100 (Reg.no. 250196C) by running the REPRO installation job, unless it is already installed on your machine.

Log in as the user where you have installed the report part. The reports are produced through the COSMON-SERV(ICE) program. Before you produce a report from the logging file you must merge the configuration file and the logging file. This is done in

## 6 APPENDIX A

### 6.1 Finding out the status of the COSMON Main RT-program

A useful command is the SINTRAN command:

```
@LIST-RT-DESCRIPTION COSMONJ
```

It gives the status of the RT-program, which should be

```
ACTIVE         or
IN TIME QUEUE
```

when the program is running. If the state is PASSIVE, the COSMON Main RT-program needs to be restarted or in some cases reloaded.
