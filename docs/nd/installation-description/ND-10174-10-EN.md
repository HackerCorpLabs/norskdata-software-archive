# 1. CHANGED PREREQUISITES

SINTRAN III/VSE-500 is not supported in the J-version. This means that the ND-100 part of a ND-500 must be a ND-100/CX to run the J-version.

# 2. MODIFICATIONS

A detailed description of new and modified commands and monitor calls is found in the SINTRAN III J-version Release Information, ND-60.230.01.

## 2.1 MODIFIED COMMANDS

- **CHANGE-BACKGROUND-SEGMENT-SIZE**  
  First parameter changed from terminal number to segment number/name.

- **LOOK-AT**  
  New parameter value is PHYSICAL to inspect/change physical memory.

- **COLD-START**  
  This command now has an optional parameter, terminal number.  
  This is the number of the terminal to be used as console for the cold start operation.

## 2.2 NEW COMMANDS

- **UE-AUTOMATIC-LOGIN**  
  Enable/disable User Environment automatic login on all or selected terminals.

- **CLEAR-BATCH-QUEUE**  
  Delete all entries in the batch queue of a specified batch process.

- **DEFINE-SPOOLING-FILE-MESSAGE**  
  Reinstalled command. Defines text to be printed on error device when spooling file is to be output.

## 2.3 Modified Monitor Calls

- **BRKM** (MON 4)  
  New break tables 8 and 9.

- **FIXC5** (MON 61)  
  Two new functions added.

- **ABSTR** (MON 131)  
  Two new functions for STC magtape.

- **LAMU** (MON 315)  
  Two new functions added and the monitor call is now available from background.

## 2.4 New Monitor Calls

- **FSMTY** (MON 327)  
  File system multifunction monitor call.

- **TERST** (MON 330)  
  Terminal status.

- **TREPP** (MON 332)  
  Terminal and line report.

- **UDMA** (MON 333)  
  Transfer data between memory and universal DMA interface.

- **GETXM** (MON 334)  
  Get error message text.

- **EXABS** (MON 335)  
  Execute Mon ABSTR (MON 131) from programs running on PT 1, 2 or 3.

- **IOMTY** (MON 336)  
  I/O multifunction monitor call.

- **SPCHG** (MON 337)  
  Segment and page table change monitor call.

## 3. SUBSYSTEMS AFFECTED BY SINTRAN III J-VERSION

- In order to run ND-500 with SINTRAN III/VSX-500 version J, you should use ND-500 Monitor (ND-10333) version F only. Earlier versions of the ND-500 Monitor will not run under the J-version of SINTRAN III, and the F-version of the ND-500 Monitor will not run under version I or earlier of SINTRAN III.

- You should only use the COSMOS Basic Module (ND-10374) version C with the J-version of SINTRAN III.

- Only XSMG (ND-10373) version H or later versions can be used with SINTRAN III version J.

## 4. MISCELLANEOUS CHANGES

- Scratch files may now have NO public access.

- The default file access when a user is created is now:

  ```
  Public: NONE
  Friend: RWACD
  Own:    RWACO
  ```

- Default value of the EXSECURITY variable is now:

  - No listing of command lines in the TERMINAL-STATUS command unless user SYSTEM or same user as giving the command.

  - The background segment will be set to zero when logging out.

  - The pages on the scratch file written to in last session will be set to zero when logging out.
