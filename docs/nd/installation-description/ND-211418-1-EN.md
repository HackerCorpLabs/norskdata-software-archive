## 2 INSTALLATION PROCEDURE

DIALOGUE SIBAS/R ONLINE TUTORIAL for ND-500/5000 is supplied on two double density diskettes with directory names 211418A<rev>-XX-01D and 211418A<rev>-<lang>-01D. The tutorial will not be available on single density diskettes.

The installation procedure will, if necessary, install ND-PILOT runtime.

Any version of ND-PILOT runtime already installed will not be lost, but only the installed version/revision will be available as standard domains.

We recommend the deletion of old versions before beginning this installation.

1) Log in as user SYSTEM

   Make sure that the required numbers of files and pages are available (prerequisites, page 1).

2) Insert the first floppy (211418A<rev>-XX-01D) into one of your floppy units and execute this command:

   ```
   @ENTER-DIRECTORY
   DIRECTORY NAME: 211418A<rev>-XX-01D
   DEVICE NAME: <DEVICE-NAME>
   DEVICE UNIT: <DEVNO>
   ```

   Where `<DEVICE-NAME>` is the name of your floppy station, normally FLOPPY-DISC-1 or FLOPPY-DISC-2, and `<DEVNO>` is the unit number, normally 0 or 1.

3) Start the installation job by executing the following command:

   ```
   @MODE (211418A<rev>-01D:FLOPPY-USER)INST-PILOT-A:MODE,,
   @INST-PILOT-A
   ```

### 3 RE-INSTALL AFTER COLD START:

The installation program makes a `:MODE` file on user SYSTEM. This file should later be used to re-install ND-PILOT after a COLD START. Remember to update the DUMP-REENTRANT (or HENT-MODE) file with the following command:

```
@MODE DUMP-PILOT-A<rev>:MODE,,,
```

### 4 HOW TO USE THE TUTORIALS:

The tutorial is split into two sections. The first section, called "SIB", provides an introduction to DIALOGUE and SIBAS/R in general. The second section, called "DRL", provides a more specific introduction to defining SIBAS databases using the DRL tool.

The tutorial may be accessed from any user in your system. After logging in, use this command to start the first section:

```
@PDS,,(PILOT-A`)SIB-PROG-A<rev> ↵
```

If UE MENUS are used, make the command into a menu selection. We recommend the selection be called ´SIBAS/R Introduction´.

Give this command to start the second section:

```
@PDS,,(PILOT-A`)DRL-PROG-A<rev> ↵
```

If UE MENUS are used, make the command into a menu selection. We recommend the selection be called ´SIBR-DRL Introduction´.

Type this command to restart the last executed section: (Within the same terminal session.)

```
@PDS ↵
```

The restart facility will not work if you have logged out and in since you started the tutorial with its given name.

*) The user name may be different. See section 2.3.
