# Description of Product

TECHPPG is a general software tool for generating postprocessors on ND500/5000. The product will be delivered to customers as FORTRAN sources, NRF libraries and specification files. The main program is only delivered as NRF to the customers.

The product consists of:

- 10 example specification files in ASCII format
- 4 library files (NRF) which are used for linking the generated postprocessor
- 2 example mode files for the compiling procedure of modified subroutines and for the link procedures
- 7 COMMON block declaration files which are included during compilation source code of all FORTRAN written subroutines and the block data program which initializes the dialogue texts.
- 1 mode file for the compiling procedure of the complete FORTRAN source to a new NRF library file.

## 4 Installation procedure

### 4.1 Automatic installation

None

### 4.2 Non-automatic installation

Log in as user SYSTEM. Create the user TECHPPG. Give 330 pages to this user. Insert the floppy labelled 211469A00-XX-01D into drive 0 and issue the following commands:

```
@ENTER-DIRECTORY 211469A00-XX-01D FLOPPY-DISC-1 0
@SET-DEFAULT-DIRECTORY 211469A00-XX-01D
```

Using the Backup-System, copy all the files from the floppy to the user TECHPPG:

```
@BA-SY
@COPY DIR,,TECHPPG DIR 211469A00-XX-01D FLOPPY-USER,,L
@EXIT
@RELEASE-DIRECTORY 211469A00-XX-01D
```

Remove the floppy from the drive.
