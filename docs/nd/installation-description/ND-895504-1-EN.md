## Description of product

The NOTIS-MAIL Application Programmers Interface (API) is used by application programmers to write programs which send and receive mail.

This version of the API runs against the NOTIS-MAIL product on SINTRAN. The application program must be located on the same system as NOTIS-MAIL, or on another machine in the same cosmos network.

The API is available for the ND-500 or ND-5000 only. The old domain format must be used.

This product information gives details about the installation of this product.

## 2 Dependencies

In addition to the hardware and/or software prerequisites listed above, the following dependencies exist between this and other products. The hardware and software listed here may, for example, be necessary to use the product's full functionality.

### 2.1 Hardware dependencies

None

### 2.2 Software dependencies

There are dependency relationships between this product and the following software:

**SIBAS**

When using the API from an application which uses SIBAS, you may run into problems with the current SIBAS device, since NOTIS-MAIL uses an optimized version of SETDV. This can be overcome in one of two ways:

1) Make sure your application uses the same SETDV as the API, which is located on the segment ML-LIBRARY.

2) Set bit 2 in the mlcApiFlags this will turn off the optimalization for your application, and any version of SETDV may be used. See section "Other modifications" for information on how to modify this new flag.

## 4 Installation procedure

### 4.1 Preparation

Before you start the installation you should prepare your system:

- Look at the "Errors known but not corrected" section of this Product Information.
- Get the required resources and prerequisites as defined in the section for prerequisites.

### 4.2 Manual installation

This chapter gives details of the installation of the NOTIS-MAIL API.

- Put the floppy into the floppy drive.
- Enter the directory 211696 from the floppy.
- Use BACKUP-SYSTEM or COPY-FILE to copy the files on the floppy to user area NOTIS-MAIL (or another user with enough free space).
- Remember to release the floppy before removing it.

## 5.4 Other modifications

### Calling from Cobol

Since Cobol (and other programming languages) does not accept routines with an outvalue, a set of routines with the prefix mlg is available. These are exactly the same as the other ml routines, but have status as the last parameter instead of as outvalue.

### New flags

Three new bits in the mlcApiFlags are introduced:

- **BIT 1** `mlFIgnoreRunning = 2B`
  - If this bit is set, the API will NOT check if NOTIS-MAIL is running when sending a letter using mlSend.

- **BIT 2** `mlFISetDvNormal = 4B`
  - You can set this bit if your application also uses SIBAS, and you have problems with the sibas device. Only for the version with local Sibas.

- **BIT 3** `mlFIIntStorage = 10B`
  - If this flag is set, incoming documents (body parts) will be stored in the Queue / Journal database, and NOT in NOTIS-DS. This will improve performance and security, but it will NOT be possible to look at these documents from the NOTIS-MAIL user interface or from NOTIS-WP. It is necessary to write an application which uses the NOTIS-MAIL API to fetch the body parts from the QJ database.

To modify these flags, call mlRIAttr to fetch the mlcApiFlags word, use AND to set the flag, and use mlWIAttr to store the flag word.
