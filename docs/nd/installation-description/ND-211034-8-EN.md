## Installation Procedure

Log in as user system.  
Put the program diskette in a floppy unit.  
If you have a double density diskette, insert the floppy `211034H<rev>-XX-01D` in `FLOPPY-DISC-<drive-no.>`.  
If you have a single density diskette, insert the floppy `211034H<rev>-XX-01S` in `FLOPPY-DISC-<drive-no.>`.

```
∅ENTER-DIRECTORY 211034H-XX-01 FLOPPY-DISC-1 0
∅COPY-FILE SWAPPER:PSEG (211034:FLOPPY-USER)SWAPPER-H:PSEG
∅COPY-FILE SWAPPER:DSEG (211034:FLOPPY-USER)SWAPPER-H:DSEG
∅RELEASE-DIRECTORY 211034H-XX-01
```

## Note:

**Postmortem dump of ND-500 SWAPPER**

After a fatal error from swapper (Message 'SWAPPER STOPPED'), the swapper's data segment may be dumped to file for later analysis by ND.

The error flag in the 500 datafield must first be reset. Address of the datafield is found in B register of the RT-program 5SWAP. The error flag has displacement 13B in the datafield.

Use the following procedure to reset the error flag: (User input is underlined)

Log in as user SYSTEM

1. `@LIST-RT-DESCRIPTION 5SWAP`

```
ACTIVE    I/O-WAIT        ...... .... .... ..... ..... ..... .....

          SEGMENTS 1 AND 2   REENT NPIT APIT RING PRIORITY
INITIAL  : 0B  0B  5B  7B  2  100B
ACTUAL   : 0B  0B  5B  7B  2  100B

START ADDRESS: 35510B   LAST STARTED: 2575 MINS  29 SECS
. ND-100 CPU TIME USED:  47 SECS

P     X     T     A    D    L    S    B
03446 057363 000062 000004 056031 035554 000201 021422

RESERVED DATAFIELDS  LOGICAL UNIT           FIRST WAITING
                     100671B
```

> Note:
> 
> 1. In this example, B register = 21422B.
> 2. The address of the error flag is thus 21422B + 13B = 21435B.
> 3. Calculate the address on your installation.

2. `@ND`

ND-500 MONITOR Version H00 86.5.6 / 86.4.2B  
N500: `SET-ND-500-UNAVAILABLE`

N500: `@LOOK-AT S3DPIT`  
READY:  
`21435/  2047  0`  ; Replace 21435 with your value  
`177777  _`  
`-END`  
N500:
