## How to Check Prerequisites

### 1.1 User Space

By using the command `@USER-STATISTICS` check that you have sufficient free pages for the user OPENLAN for the OWS Access Server software.

### 1.2 Computer Type

The computer type and operating system version is checked by the SINTRAN command `@LIST-TITLE`.

**Example**

```
@LIST-TITLE

SINTRAN III - VSX/500 K HANS
STANDARD CONFIGURATION:       E
BETA TEST (WORK MODE NO.):    312B
REVISION (PATCH FILE NO.):    8000B
CPU TYPE:                     100
CPU NUMBER:                   1644
GENERATED:                    13.14.00    15 SEPTEMBER 1987
@
```

### 1.3 RT Descriptions and RT Segments

You need minimum 1 free RT description and 1 free segment. Use the RT-loader to check those prerequisites with the commands:

```
@RT-LOADER
*LIST-FREE-SEGMENTS
*LIST-FREE-RT-DESCRIPTIONS
```

# Installation Procedure

## Installation

The installation-program will copy all the files necessary to load and start the OWS Access Servers.  
To load the RT program OWSRT-A07. Change user area to user SYSTEM and type the command:

```
@MODE (OPENLAN)OWSRT-RTLO-A07:MODE,,,
```

OWSRT will be loaded.

## Starting the Servers

Enter user System. Run the program OWSAS-SERVIC. You will see the following header:

```
OWS Access Servers service program. Version A07 August 8, 1988
```

OWSAS-Serv:

To start the servers type 'start-server' as shown below.

```
OWSAS-Serv : start-server
Please wait, this operation may take some time.
Ok, servers are started.
OWSAS-Serv : ex
```

## Stopping the Servers

You must be logged in as user SYSTEM to stop the OWS access servers.  
The servers can be stopped by the OWS service command STOP-SERVER. You will be prompted for a period (in minutes) within which you would like the command to come into effect. e.g. STOP-SERVER 5 will stop the servers within 5 minutes, and new requests for services will be refused immediately. STOP-SERVER 0 will stop the servers immediately.

## 3 Disabling Timeouts

The program `OWS-DISTIME-A07:PROG` distributed with the product is to be used to disable timeouts on TELNET connections from OWSs to the host machine. The program generates the node file `OWS-DISTIME:MODE` which must be run as a node job to disable the timeouts. The mode file `TCP-START:MODE` distributed with TCP/IP contains the necessary commands to generate and run this mode file. If you are re-installing the product and files with the name format `OWS-DISTIME-<ver>:MODE` exist under user SYSTEM then you should remove them before running `TCP-START:MODE`.
