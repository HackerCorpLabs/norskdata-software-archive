## Description of Product

PC-NOTIS WP is a general purpose text processor. It consists of two 5 1/4" floppies:

- 230144N09-NO-01D and 230144N09-NO-02D

or three 3 1/2" floppies:

- 30144N01N09, 30144N02N09 and 30144N03N09

which contain the installation program, NOTIS-WP, help file, init file and hyphenation files.

```
# 4 INSTALLATION PROCEDURE

## 4.1 AUTOMATIC INSTALLATION

To install PC-NOTIS WP, please insert the first floppy in diskette
drive A: on your PC, and type :

A:INSTALL↩

The installation job will guide you through a complete installation
of PC-NOTIS WP.

PC-NOTIS WP may also be installed as part of the PC-NOTIS Platform.

## 4.2 NON-AUTOMATIC INSTALLATION

Not recommended.

## 4.3 STARTING NOTIS-WP FROM DTM

If you have an earlier version of NOTIS-WP installed (Version N06 or
older) and wish to have the newly installed NOTIS-WP replace the
older version, you must enter DTM and under "Applications" first
delete the NOTIS-WP entry and then define the newly installed
NOTIS-WP. Next edit the WIN.INI file in the WINDOWS directory (use
NOTEPAD). Localize the APPn= entry containing the NOTIS-WP entry and
change the first parameter after APPn= from "WIN" to "NOTIS". Then
save the WIN.INI file. The old NOTIS-WP system may then be deleted.

## 4.4 IF YOU WILL USE NOTIS-WP FROM WINDOWS

Preparing the NOTIS-WP for WINDOWS and WIN Start involves the
following:

1. Copy the files PCWP.COM, STPCWP.EXE, EXECLIB.EXE and
   CLOSELIB.EXE from the PC-NOTIS PCWP installation kit.
   Insert the last floppy of the kit (no 2 for 5¼" floppies and no 3
   for 3½" floppies). Copy the file to the \ND-OWS\NOTIS directory.

   ```
   COPY A:PCWP.COM   \ND-OWS\NOTIS\PCWP.COM
   COPY A:STPCWP.EXE \ND-OWS\NOTIS\STPCWP.EXE
   COPY A:EXECLIB.EXE \ND-OWS\NOTIS\EXECLIB.EXE
   COPY A:CLOSELIB.EXE \ND-OWS\NOTIS\CLOSELIB.EXE

## 4.5 Configuration Parameters

Below are a description of some configuration parameters, and how to change them. The elements are marked with (I) if the state is saved in the init file, and with (D) if WP must be dumped (with the & command) to have the state set.

### FUNC 5 RUB +/-

Set/reset new delete mode. When on a `~` is displayed on the status line. In this mode the RUB key (marked as slashed a) always deletes characters to the left and the DELETE key always deletes characters under the cursor. (I)

### FUNC 5 RUB CR +/-

Set/reset delete field start/end mode. This mode only works if the above delete mode is on. When this mode is on UNSPLIT is performed when the above delete keys reaches the end of the current line field. (I)

### FUNC 5 # M +/-

When set to + the status line will display Mail:? when not logged in to a host. (I)

### FUNC 5 # A +/-

Advertisement mode on/off. When this mode is on, WP will display an "adverticement" during startup. (D).

### FUNC 5 # T 0/1/2

This should be set to FUNC 5 # T 1. It sets the mode for the hot-key terminal emulator:

- **0** = loaded with WP (not implemented)
- **1** = start the terminal emulator as a MS-DOS subprocess (the recommended method). In this mode both WP and the terminal emulator is in memory at the same time.
- **2** = the terminal emulator replaces WP in memory.

(D)

## 5 Modifications

### 5.1 New Functions/Commands

PC-NOTIS WP is a part of the PC-NOTIS product range. The complete environment consists of NOTIS-CALC Spreadsheet, NOTIS-ID Electronic Mail, NOTIS-DS Document Storage and a common NOTIS menu system, all running on the PC. From the menu system it is possible to start applications running both on the PC and on the SINTRAN server. Full integration between PC-NOTIS products and SINTRAN-based NOTIS products is supported.

### 5.2 Changed Functions/Commands

The NOTIS menu is changed. It is now configurable. Up to eight entries may be defined. Do this only in cooperation with a service person!

The commands "Ø" and "Tjenester/SINTRAN" have now been redefined to start the terminal emulator included with PC-NOTIS Platform. The emulator is quitted by pressing ALT + F4.

Notice that the emulator may not be used from Inspect mode even if there is a menu entry for "SINTRAN".

The Services/List-printers (Tjenester/Vis-skrivere) command also list local PC-connected printers (as in NO6). These are marked with an asterisk (*) in the list.

When fetching a file with unknown storage format WP asks for a file with conversion table. The files WSWP.TXT and ANSI.TXT is copied during installation and contains conversion table for PC8 format and ANSI format. These files may be edited. There is now built in an conversion function for these formats. Answer PC8 or ANSI to the WP question to use the built-in conversion. The storage format will then change to either PC8 or ANSI. This storage format may otherwise only be set from the Environment menu.

During installation the file CURSORS.TXT is copied to the NOTIS directory. This file is an example of how the cursors within WP may be programmed. To automatically program the cursors in WP, ensure that the following line is present in \ND-OWS\NDCONFIG under SYSTEM-NAME : WP

```
WP-CURSORS=C:\ND-OWS\NOTIS\CURSORS.TXT
```
