## Description of Product

An Operating System Customization package for the Uniline x0 series running UNIX. It is a menu driven tailoring package for the SCO UNIX System V/386 operating system. The package includes:

- a general OS tailoring utility
- a SCSI device preparation utility
- a UNIX kernel reconfiguration and relink utility, adapted to Uniline 40

## Reason(s) for New Product or Version

To have a unified operating system customization package for the entire Uniline x0 series running SCO UNIX System V/386.

**NOTE:** The COO version of the product can only be run on Uniline 10/20 systems.

## 4 Installation Procedure

### 4.1 Automatic Installation

Installation is done with the custom utility. Follow the online instructions given.

The following gives guidelines to the instructions (users actions are underlined, ↵ means press the carriage return and → means select menu option):

**Explanation:**

1. Log in as root (superuser)

2. 
   ```
   # custom ↵
   → Install   Start the custom utility.
   → A new product   Select a new product to install.
   → Packages   Only install the CUST package.
   → Continue   Insert diskette in diskette drive.
   → CUST   Select ND UNIX Customization package.
   → Continue

   A ↵   (A)utomatic installation procedure.
          You have entered the UNIX
          Customization package. Follow the
          online instructions. Reasonable
          default values are available in all
          user interaction.
   ```

# 5 MODIFICATIONS

## 5.1 NEW FUNCTIONS/COMMANDS
None.

## 5.2 CHANGED FUNCTIONS/COMMANDS

**Help data files:**

The XENIX 2.3 help utility is not available on UNIX 3.2. However ndcu, ndibu and fsize help data files are still contained on the distribution floppy as machine readable documentation. They may be manually inspected, and are kept in the directory `/usr/nd/usr/lib/help` as before.

**VPIX customization package:**

The VP/ix customization package is not supported. However the old XENIX package is still contained on the distribution floppy, as ASIS software.
