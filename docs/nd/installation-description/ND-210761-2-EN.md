## 1. Error Correction

1) The following errors have been corrected:

2) Floating point constants were compiled wrong in several ways.

3) Missing `#endif`s were not reported.

4) Programs containing large structures, over 8k byte, could not be compiled in debug mode.

5) `sscanf()` could sometimes fail.

6) Random access write's after the end of a file could sometimes be mishandled.

7) Invalid debug is corrected.

## 2. Changes / Addition

1) To use command lines longer than are allowed by SINTRAN-III, there exists a possibility to put text from a file into the command line. This is done by writing @filename on the command line when starting a C-program.

2) A new library function `tused()` that executes the SINTRAN monitor call with the same name, `tused()` returns -1 on error.

# Installation Procedure

## Installation procedure for double density diskettes

Log in as user SYSTEM, create the user `<C-Include>` with 50 pages if it doesn't already exist, and perform the following commands:

```
@ENTER-DIRECTORY 210761B<rev>-XX-01D,FLOPPY-DEVICE-<device>,<unit>,
@MODE (210761B:FLOPPY-USER)INSTALL-1DA-B:MODE,...
```

Enter `<C-Include>` and perform:

```
@MODE (210761B:FLOPPY-USER)INSTALL-1DB-B:MODE,...
@RELEASE-DIRECTORY 210761B<rev>-XX-01D
```

## Installation procedure for single density diskettes

Log in as user SYSTEM and create a new user `<directory:dummy-user>` with 250 pages and the user `<C-Include>` with 50 pages, if it doesn't already exist. Perform the following commands:

```
@ENTER-DIRECTORY 210761B<rev>-XX-01S,FLOPPY-DEVICE-<device>,<unit>,
@MODE (210761B:FLOPPY-USER)INSTALL-1SA-B:MODE,...
```

Enter `<Dummy-user>` and perform:

```
@MODE (210761B:FLOPPY-USER)INSTALL-1SB-B:MODE,...
@RELEASE-DIRECTORY 210761B<rev>-XX-01S
@ENTER-DIRECTORY 210761B<rev>-XX-02S,FLOPPY-DEVICE-<device>,<unit>,
@MODE (210761B:FLOPPY-USER)INSTALL-2S-B:MODE,...
@ND LINK-LOADER
N1:RENAME-DEFAULT (<directory:dummy-user>)
N1:EXIT
@RELEASE-DIRECTORY 210761B<rev>-XX-02S
```

Enter `<C-Include>` and perform:

```
@ENTER-DIRECTORY 210761B<rev>-XX-03S,FLOPPY-DEVICE-<device>,<unit>,
@MODE (210761B:FLOPPY-USER)INSTALL-3S-B:MODE,...
@RELEASE-DIRECTORY 210761B<rev>-XX-03S
```

Now the compiler is created on the user `<dummy-user>`. The compiler may be copied to a `<domain-user>` with the command `COPY-DOMAIN` in the Linkage-Loader.
