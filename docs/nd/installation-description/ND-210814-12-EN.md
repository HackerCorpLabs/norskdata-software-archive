## Changed Environments

New versions of UE-ERRMSG:ERR and DDBTABLES:VTM are required. To run the 500-version of HYPHEN-TEST you must be logged in via USER-ENVIRONMENT.

## Modifications

### Hyphen-Test

Hyphen-test is now a FOCUS program. A new FOCUS formfile "HYPHEN-TEST:FORM" is used by the program. The file "HYPHEN-TEST:FORM" must be changed with version G of FOCUS-DEF only, otherwise it will be destroyed. All other formfiles in NORTEXT-L require version F and FOCUS.

## Changes in This Version

- The 500-version of the Program now also available.
- After a language is compiled new LAMUs must be loaded before the compiled hyphenation is activated.
- Version G of FOCUS-DEF only could be used to change the formfile for this program.
- Number of LAMUs used in hyphenation is now increased from 1 to 10. This means much more space available for exception words.

## Installation Procedure

### Note:

This installation procedure requires BACKUP-SYSTEM version F or later. If your machine is a ND-500 the "LINKAGE-LOADER" and "ND" 500 monitor must be available under the names in quotation marks. If you have a ND-500 machine the 500-version of HYPHEN-TEST will be installed, otherwise the 100-version is installed.

1. Log in as user SYSTEM.
2. If you want to preserve any :PROG files from your "old system" do make backup copies now.
3. Put the installation floppy in the floppy drive and enter it with:
   ```
   @ENTER-DIRECTORY,,FLOPPY-DISC-<drive-no.>,<floppy-unit>/
   ```

## Installation Instructions

4) Start the installation by typing:

```
@X (210814:FLOPPY-USER)INSTALL:↲
```

This XCOM file will copy all files from the floppy to the actual users on disk. Note: All the old :PROG files will be deleted before copying takes place.
If this product has been installed earlier and the :FORM files are found in your system, you will be asked if you want the new form files installed (and the old one deleted). The only reason to prevent the new form file being installed should be if you already have translated the texts in the formfile. The form files in this release are all with English texts.

5) When the installation job is finished the directory will be released and the floppy may then be removed.

6) Delete the "HELP" file for the installation on user SYSTEM.
```
@DELETE-FILE TABMA-INSTALL2:XCOM↲
```

## The Maintenance-Men Program

All maintenance programs are located under user MAINTENANCE-NTX.
These programs may be started by: `@(MAINTENANCE-NTX)<PROGRAM-NAME>`.
There is however a maintenance menu program which can be used to select different maintenance programs called `(MAINTENANCE-NTX)MAINTENANCE:PROG`. This program should be dumped reentrant.

Log in under user SYSTEM and type:
```
@DUMP-PROGRAM-REENTRANT MAINTENANCE (MAINTENANCE-NTX)MAINTENANCE:↲
```

Remember also to insert the statement in the `(SYSTEM)HENT-MODE:SYMB` file or the `(SYSTEM)DUMP-REENTRANT:SYMB` file.
