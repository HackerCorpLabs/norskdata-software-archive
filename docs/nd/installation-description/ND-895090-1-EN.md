## Description of product

Configuration Dictionary displays information about the hardware and operating system configuration on your system. From a menu, you can select the subjects you want to get detailed information about. Key words are: CPU, memory, disk, terminals, communication, operating system, segments, TAD's, batch processors, background programs etc.

## Reason(s) for new product or version

Operator Environment which, up till now has been released as a package containing a number of "modules" (OEA, OEB, OEC etc.) is now split up, and the modules are now released as separate products.

The "new" products are:

- User Area Manager
- Configuration Dictionary (also contains OEF)
- File System Verification
- File Manager
- Operator Environment Menu system

## 4 Installation procedure

### 4.1 Automatic installation

Before you start the installation of Configuration Dictionary, check that all the prerequisites listed above are fulfilled.

Note also that if the OE-server is running on your system, you must stop the server before you install a new version of OEC. You stop the OE-server with the command: @(ND-OPER)OEF-FUNC Stop, otherwise, the two RTOPEN files OEC-DATA-A:DATA and OEC-SYS-A:DATA may not be closed properly.

The installation must be run from SINTRAN.

To install Configuration Dictionary, follow this procedure:

- Log in with SINTRAN user name SYSTEM
- Insert the diskette containing the directory name 211071A<rev>-<lang>-01 in the diskette station
- Execute the following commands (operator input is underlined and parameters are enclosed with angle brackets)

```
@ENTER-DIRECTORY↵
DIRECTORY-NAME: 211071A-<lang>-01↵
DEVICE-NAME: FLOPPY-DISC-<drive no.>↵
DEVICE-UNIT: <floppy-unit>↵
@(211071A-<lang>-01:FLOPPY-USER)IN-OEC↵
```

The installation procedure will now start. Read the messages that appear on the screen, and follow the directives which are given. After the initialization, the main menu of the installation system will appear on the screen:

1. Get start information
2. Delete product files
3. Check environment and resources
4. Copy product files

## 5 Additional information

- Insert the following command in the file LOAD-MODE under user SYSTEM after the point where User Environment is started:

```
@(ND-OPERATIONS)OE-FUNC start-server
```

This command checks that current time is later than stop-time. If not, it sets completion code to 34747B and LOAD-MODE must take appropriate actions to handle it (see next section).

- If OE-FUNC stop-server has been done when the computer was taken down, it is possible to check for correct time at system startup. (note that transaction systems require that the time is correct!) On startup OE-FUNC start-server should be run. This line must therefore, as mentioned, be included in the LOAD-MODE file. Using JEC, the status returned from the call to OE-FUNC can be checked. If OE-FUNC finds that the current time is more than 30 days later than the time recorded, the status value 34747B is given. This should be checked in the LOAD-MODE file, and may be done like this:

```
@JEC BEGIN
 :
 :
@(ND-OPERATIONS)OE-FUNC start-server
@CC is not within the range of stoptime to stoptime + 30 days

@JEC IF COMPLETION-CODE < 34747B GO TO 200 % no error
@JEC IF COMPLETION-CODE = 34747B GO TO 100 % clock error
```
