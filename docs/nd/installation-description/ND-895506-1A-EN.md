## Description of Product

OpenLAN printing on XENIX is a product that enables machines which have EXCELAN or FUSION network cards to print on printers connected to a Terminal Interface Unit (TIU). The product comes with an installation program and a set of model files which enable printing from the standard XENIX Spooling System (lp) to printers connected to the TIU.

## Reason(s) for New Product or Version

To enable the printers connected on the OpenLAN network to be accessible from XENIX.

## 4 Installation Procedure

You install OpenLAN printing for XENIX using the utility `custom(C)`.

Existing versions of OpenLAN printing for XENIX should be removed from the system before this version of OpenLAN printing for XENIX is installed. Removing an existing version is described after the installation description.

### 4.1 Automatic Installation

To install OpenLAN printing for XENIX, you do as follows:

- Log in as Superuser. (Usually root)
- Type `custom` and press `<return>`.
- Select option 4: Add a supported product.

  You see the prompt: Insert distribution volume 1  
  and press `<RETURN>` or enter q to quit:

- Insert the diskette marked 230186A<revision>-XX-01D, e.g. 230186A01-XX-01D, in the diskette drive and press `<return>`.

  The `custom` utility displays a menu.

- Choose option 1: Install one or more packages.

  `custom` displays the name of the package OPRT and prompts you:

  Enter the package(s) to install or enter q to return to the menu:

- Select `OPRT` when you install the product.

  You are prompted:

  Insert OpenLAN printing for XENIX (<Language>) volume 1  
  and press `<RETURN>` or enter q to return to the menu:

  You already have the correct diskette in the diskette drive, so you just press `<return>`.

## 4.2 Removing Old Versions and Revisions

Existing versions and revisions of OpenLAN Printing for XENIX should be removed from the system before this version of OpenLAN Printing for XENIX is installed. The utility `custom(C)` is used for this purpose.

- Log in as root
- Start `custom`. If OpenLAN Printing for XENIX is installed there is an entry for this in the menu. Select this entry.
  
  - `custom` displays a menu.  
    Choose option 2: Remove one or more packages.
  
  - `custom` displays the package OPRT which contains the OpenLAN printing for XENIX and prompts you:
    
    Enter the package(s) to remove or enter q to return to the menu:
    
    Select all.

- Quit the custom utility.
- Remove the file `/etc/perms/OpenlanPrint`

## 4.3 NON-AUTOMATIC INSTALLATION

Use `tar xvf` to retrieve the files from the diskette and put them in the directory. Read the file `tmp/perms` from the directory you have just retrieved. This file tells you where the files should reside in the directory structure. Copy the files to the relevant place in the directory structure. Change to the directory `/usr/nd/usr/OpenlanPrint/bin`. List the files in the directory. Depending on whether you have EXCELAN or FUSION network software, rename either ExcelanSender or FusionSender to OpenlanSender. Use `inst.printer` to install the printers. If the installation script `inst.printer` fails, then to install the printer on Openlan the following must be done:

1. Ensure that all the files needed for running Openlan Printing on XENIX are in the correct directory structure. The user manual gives a description of which files lie under which directories.

2. The following lp commands are to be executed in the sequence shown:

   1. Log in as root
   2. `/usr/lib/lpshut`
   3. `/usr/lib/lpadmin -p<name of printer> -v/dev/null -i/usr/nd/usr/OpenlanPrint/model/<name of model file>`
   4. `enable <name of printer>`
   5. `/usr/lib/accept <name of printer>`
   6. `/usr/lib/lpsched`
