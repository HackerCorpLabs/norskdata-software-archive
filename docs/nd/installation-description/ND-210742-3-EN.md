## 1 Errors Corrected

- Corrected error in the print module regarding 3270 DS print. Each line was printed with one character too many.
- Corrected error in the print module during startup. If you get an 'Error in Bind', you would also get the message 'Message is in a queue', infinitely.
- If a printer tried to reserve an LU that was in use, it would receive the message 'OK', but the LU would still be reserved for the other printer. You will now get the error message 'LU reserved' when trying to reserve an LU that is in use.
- Sometimes an old command was appended to every succeeding command in the Terminal Emulator.
- The character 'space' is no longer allowed in a numeric field.
- The cursor was occasionally placed in a wrong position after response to user input.
- All other known errors were corrected.

## 2 Changed Prerequisites

### 2.1 Supported Terminal Types

The SNA 3270 Terminal Emulator supports the following terminals:

- ND-246X - NOTIS Display Terminal TDV 2200/9
- ND-3200 - NOTIS Display Terminal TDV 2200/S
- ND-248 - NOTIS Display Terminal FACIT 4420
- ND-242X - Display Terminal Tandberg 2215
- DEC VT-100 (80 col. mode)
- Tandberg 2115
- FACIT Twist (24 lines or 72 lines)

## 3. MODIFICATIONS.

### 3.1 Changed commands.

One parameter is changed in the command DEFINE-GATEWAY in the SNA 3270 Configurator. When you give the gateway name, you should now only write e.g. 'GATE1', instead of '*SNAGATE1'. This conforms with the way the gateway name is written in all the other ND SNA products.

### 3.2 New commands.

If you use a terminal with 24 lines, the message line will only be written if the message is important. If not, the message lamp is set, and you may display the message line through the command FUNC Z.

There is a new command in the SNA 3270 Configurator. It is called SYSTEM-SECURITY, and may only be given by user SYSTEM. If you change one of the parameters, the change will be written to all the configuration files in the entire system. The possible subcommands are:

- **DEFINE-IDLE-TIME**

  Defines the amount of idle time allowed before the emulator is stopped.

- **SET-MAX-PASSWORD-COUNT**

  Sets the maximum number of attempts to give the correct password.

- **TEMPORARY-EXIT**

  Enables/disables the function Shift/EXIT.

There is a new VDU-variable, DEFINE-ALTERNATIVE-PC-KEYBOARD. This command will enable you to use your IBM PC keyboard in almost the same way as an IRMA keyboard. IRMA is a trademark of DCA Inc.

## 3.3 Other changes

4 colour support for Colortrend 210 is implemented in the SNA 3270 Terminal Emulator.

Performance is improved for applications which only update parts of the screen. Only the fields that are changed, are written to the screen.

## 3.4 The SNA 3270 Print module

### 3.4.1 After "Cold Start"

Same as after "master clear and load".

### 3.4.2 After "Master Clear and Load"

**NOTE:**

Run the load files SNA-LOAD-PRT-nnn:MODE, where nnn is the printer number. The number of the printer is the same as the number of the LU used by that printer.

Start the printers by using the command START-SERVER in the print supervisor, once for each printer.

If you want to add printers or change the printer numbers, you may use the installation procedure and answer REGENERATE, when asked if you want to install or regenerate. The installation procedure will then only generate new load-files for the printers.

## 4 Installation Procedure

The loading of SNA 3270 Terminal Emulator is quite simple:

- Log in as user SYSTEM.

- Make sure that the user you want to copy the files to has enough free user space.

- Insert the first floppy in the floppy drive.

- Enter the directory on the floppy and give the command:

  ```
  @(210742:FLOPPY-USER)SNA-3270-INSTALL
  ```

- Answer INSTALL when asked whether you want to install or regenerate.

- When you are asked for user name, you should write the name without any abbreviations.

The files on the floppy will now be copied to a user specified by you (default is UTILITY).

A file which loads the 3270 print module RT program is also created, one for each printer. You will be asked for the number of printers in your system, and for the LU number of each printer. If you answer `<CR>` to the first question, you will not get any printers. If you answer `<CR>` to the second question, you will get the number 31.

The name of the load files will be SNA-PRT-LOAD-nnn:MODE, where nnn is the number of the printer which is loaded with that file.

These files will be run in the installation procedure, and they should also be run after each restart of the system.

When the installation program has terminated successfully, you should give the command:

```
@DELETE-FILE INSTALL-SNA-3270:PROG
```

Insert the following command in your HENT-MODF file:

```
@DUMP-PROGRAM-REENTRANT SNA-3270-NO (UTILITY)SNA-3270-NO
```
or
```
@DUMP-PROGRAM-REENTRANT SNA-3270-EN (UTILITY)SNA-3270-EN
```
or
```
@DUMP-PROGRAM-REENTRANT SNA-3270-GE (UTILITY)SNA-3270-GE
```

dependent upon the language you choose. Substitute UTILITY with the user containing the file.
