## Description of product

Backup Manager is a program system for backup and restoring on ND-500 and ND-5000 computers. Backup Manager consists of four modules:

- **BM-Definition** - To predefine sets for backup and restore.
- **BM-Operator** - To run predefined sets, do occasional copying and service functions.
- **BM-Scheduler** - To schedule backup sets and ordinary SINTRAN batch-jobs in a COSMOS network.
- **BM-FileRestore** - To restore single files from image (device) backups stored in volume format on tape or disk.

## Reason(s) for new product or version

- Handling of backup devices connected to the DOMINO/SCSI Mass Storage System.
- Automatic and integrated handling of mirroring on DOMINO/SCSI disks.
- Improved functionality concerning SIBAS database backup: Automatic "on-the-fly" backup (incremental or based on mirroring), and database verification as part of the backup procedure.
- Possible to do copy and compare when copying SINTRAN main directory.
- Error corrections and some functionality improvements.

## 4 Installation Procedure

### 4.1 Automatic Installation

- Before you start installing Backup Manager, check that the prerequisites listed in Chapter 1 are fulfilled.
  
- Note that it is possible to install Backup Manager without an interface to SIBAS. This is selected during the installation procedure.

If an interface from Backup Manager to SIBAS is wanted, the following 3 possibilities exist:

- SIBAS/R-B interface (new domain format-automatic inst. proc.)
- SIBAS/R-A interface (old domain format-manual inst. procedure)
- SIBAS-F interface (old domain format-manual inst. procedure)

In any case, Backup Manager should be installed the standard way by use of the installation program. For the two latter possibilities (old domain format) the standard installation should be performed with NO SIBAS interface. Thereafter the BM-Operator domain should be reinstalled in the old domain format with link to the correct SIBAS version as described in section 4.4. The 2 floppies 211226B04-XX-05D and 211226B04-XX-06D are exclusively delivered for this purpose and are therefore not requested by the installation program. For the manual reinstallation of the BM-Operator domain in old domain format in order to interface SIBAS/R-A or SIBAS-F see section 4.4.

- Log in on user area: **SYSTEM**.

## 4.2 Updates to the system operation files

If you are **not** installing on a ND tpServer:

- Remember to update the (SYSTEM)HENT-MODE (or corresponding) file with the following command:

  ```
  @MODE (BACKUP-MANAGER)BM-SERVER-B<rev>:MODE,...,
  @MODE (BACKUP-MANAGER)BM-DUMP-B<rev>:MODE,...,
  ```

- Remember also to update the (SYSTEM)LOAD-MODE (or corresponding) file with the following command to start the BM-Scheduler server:

  ```
  @MODE (BACKUP-MANAGER)BM-START-B<rev>:MODE,...,
  ```

- The load-file for the DMA-server segment (BACKUP-LOAD-I:MODE), should be updated with the patch-file

  ```
  @MODE (BACKUP-MANAGER)BM-DMAPTC:MODE,...,
  ```

## 4.3 Defining new backup/restore jobs

Due to changes in the internal format of the Backup Manager database from the A to B version (BM-JOBDB-A:DATA -> BM-JOBDB-B:DATA), you are strongly advised to redefine all of your previously defined (A-version) sets when using BM-Definition version B.

When installing Backup Manager B, a new version of the BM-JOBDB:DATA file is copied to user ND-OPERATION. This file includes a set of examples which can be modified to your needs. (This gives you the opportunity to implement the new features offered by the B-version.)

If you already have an earlier B-revision installed (B01/B02/B03) and you want to keep the old SET and JOB definitions, the file (ND-OPERATION)BM-JOBDB-B<rev>:DATA should be renamed before the installation is started and copied to the file : (ND-OPERATIONS)BM-JOBDB-B04:DATA afterwards.

## 6 Errors known but not corrected

- When Backup Manager creates a temporary mirror to perform an image copy of a directory on a DOMINO/SCSI disk, the error message 'NO MORE TO COPY' will be written on the error device when the backup procedure is finished. THIS MESSAGE CAN BE IGNORED!.

- Restore of spooling files from volume does not work properly. They have to be created manually.

## 7 Limitations

- Indexed files larger than 65000 pages cannot be copied by Backup Manager. (Contiguous files can be copied when logged in as user SYSTEM!)

- When performing image copying in batch mode (for example, via BM-Scheduler) you cannot copy the directory where the input and output batch files for this job is located. (Normally the directory where user area SYSTEM and ND-OPERATIONS is located.)

- You cannot copy TO a DOMINO/SCSI tape-device from a remote computer.

## 8 Information and hints

- When doing image backup, it is possible to skip compare of selected CONTIGUOUS files (for example, Segfiles and Swapfiles). These file names must be registered in the (ND-OPERATIONS)BM-PARAMETER file! The maximum number of contiguous files that may be specified to be excluded from the compare operation is 12.

  **Example:**

  ```
  IMAGE-NO-COMPARE-FILE = (SYSTEM)SWAP-FILE-0:SWAP
  IMAGE-NO-COMPARE-FILE = (SYSTEM)SEGFILE0:DATA
  ```

- To maximize performance:

  NEVER specify the 'Computer name' field when copying files between local devices.

  When copying to/from/between remote computers, try to specify as much selection information (directory, user area, file name, etc.) as possible to speed up file searching.

- To recognize backup devices connected to the ND-100 bus, Backup Manager must have access to the peripheral files for the devices. The peripheral files are created via the SINTRAN III command: QSET-PERIPHERAL-FILE. The relationship between peripheral file names, device numbers and device names is:

  | Peripheral file name | Device number used in peripheral file | Device name used in BM |
  |----------------------|----------------------------------------|-------------------------|
  | Streamer-1           | 2226B                                  | Streamer-1              |
  | Streamer-2           | 2227B                                  | Streamer-2              |
  | Mag-Tape-0           | 40B                                    | Mag-Tape-1              |
  | Mag-Tape-4           | 32B                                    | Mag-Tape-2              |
  | Mag-Tape-8           | 1232B                                  | Mag-Tape-3              |
  | Mag-Tape-12          | 1225B                                  | Mag-Tape-4              |

- Devices connected to the DOMINO/SCSI adapter are defined via the program DP-SERVICE. (See the manual, DOMINO SCSI Operator Guide, ND-814009 for further information.)

No peripheral files are necessary in SINTRAN III for these devices. They can be given any name.
