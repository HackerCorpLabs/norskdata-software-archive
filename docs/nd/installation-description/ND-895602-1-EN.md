## Description of Product

This product is a part of the general purpose database management system SIBAS/R.  
This product contains the access libraries for ND-100/500/5000, the control program for the DBMS server and the utility programs SIBR-SERVICE and SIBR-INTER.  
See ch. "Dependencies" for a list of other parts of SIBAS/R.

## Reason(s) for New Release

```
- Errors in previous revision have been corrected
- Increased performance in the control program, SIBRC
- Increased performance in the utility program, SIBR-SERVICE
- SIBAS library can handle several DOMINO-controllers (4)
- New Software Licence Key system
```

# 4 Installation Procedure

## 4.1 Automatic Installation

None

## 4.2 Non-Automatic Installation

This product is the first part of SIBAS/R to be installed.

- Log in as user: `SYSTEM`

- Stop all databases on the system

- If SIBAS/R B is already installed on the machine:

  - Stop all programs linked to segments on user SIBR-B.  
    These segments are:
  
    ```
    SIBR-LIBRARY-B:SEG
    SIBR-MESSAGE-B:SEG
    SIBR-MESS-TS-B:SEG
    SIBR-FAST-B:SEG
    ```

  Programs linked to these segments are:

  - Application programs.
  - SIBAS utility programs:
    ```
    SIBR-SERVICE-B
    SIBR-INTER-B
    SM-SERVER-A
    SM-TRMH-A
    ```
  - Backup-Manager  
  - DS  
  - MAIL  
  - Several other programs using SIBAS.

  - Delete all standard-domains linked to segments on user SIBR-B.

  - Log in as user: `SIBR-B` and delete all files on this user (apart from your private files, SIBAS-macros (SEXMC), ...)

```
@BACKUP-SYSTEM~
Ba-sy: COPY-USER-FILES DIR.,SIBR-B,VOLUME,380853,F-D-1.0...L~
```

When the Backup-System asks if next floppy is ready, insert next floppy and answer `YES`.  
Answer `NO`, when end-of-volume is found (after floppy no. 5) and the Backup-System asks if more volumes are to be copied.

Ba-sy: `EXIT~`

- The installation can continue when all the floppies have been copied without any errors, run:

```
@MODE (SIBR-B)IN-380853B05:MODE."(SIBR-B)IN-380853B05:OUT"~
```

NOTE: You will be asked if you are going to install a nucleus- or message-version of SIBAS/R B.

The mode file terminates with:

```
<FINISHED, Check out-file for Errors>
```

## 4.3 Completing the Installation

- The file SW-CONFIG should be copied to user ND-OPERATION, unless the file already exists there. The file following this delivery, installed on user SIBR-B, holds a couple of examples of database definitions. This file should be edited to reflect the databases and systems you are running. The syntax used on the file is very important - any misspelt parameters on SW-CONFIG will be ignored and default value will be used. (In most cases without any warning or error message.) Refer to the manual DIALOGUE-Operation (ND-830072.2) for more information.

- Include the following line in the (SYSTEM)HENT-MODE:MODE (or corresponding).

  ```
  @MODE (SIBR-B)SIBRC-B:DUMP,(SIBR-B)SIBRC-B:OUT
  ```

- Include the following line in the (SYSTEM)LOAD-MODE:MODE (or corresponding).

  ```
  @RT SIBRC
  ```

- The installation of this product is now completed.

- Link all your application programs and other subsystems using SIBAS to the new SIBAS-library segments. The SIBAS utility programs are already linked to the right SIBAS-library.

  Example:

  ```
  @ND LINKER
    LINKER-SERVICE-PROGRAM
    CHANGE-FILE-REFERENCES ......
  .
  EXIT
  EXIT
  ```

- Define the deleted Standard Domains again - the following lines should be added to your HENT-MODE file:

  ```
  @ND-500
  DEFINE-STANDARD-DOMAIN SIBAS-SERVICE-B (SIBR-B)SIBR-SERVICE-B
  DEFINE-STANDARD-DOMAIN SIBR-INTER-B (SIBR-B)SIBR-INTER-B
  EXIT
  ```

## 4.4 Hints for Installation

- Due to previous abnormal system stops, some files may be open even if all databases is properly stopped. Deletion of the files will then fail. The files may be manually closed by patching the object entry of the file, as illustrated in the following example: (user input underlined)

- Log in as user SYSTEM

```
@LIST-FILES (SIBR-B)SIBR-MESS
FILE 0 : (PACK-EXTRA:SIBR-B)SIBR-MESS-TS-B03:SEG;1
FILE 1 : (PACK-EXTRA:SIBR-B)SIBR-MESSAGE-B03:SEG;1
FILE 12 : (PACK-EXTRA:SIBR-B)SIBRP-MESS-B03:NRF;1
@CHANGE-OBJECT-ENTRY~
USER NAME: PACK-EXTRA:SIBR-B~ MBI Remember dir.name
OBJECT INDEX: 0~  f i l e 0 i s open

22/ 000001 0~
xxxxxx  _
0
```

- The file may now be **manually** deleted.
