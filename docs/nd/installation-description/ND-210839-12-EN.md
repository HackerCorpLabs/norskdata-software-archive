## Installation Procedure

**Note:**  
This installation procedure requires BACKUP-SYSTEM version F or later.

1. If you want to preserve any `:PROG`, `:SEGP`, or `:SEGD` files from your "old system" do make backup copies now. If your "old system" was the NORTEXT J-version the "old files" are of type :BPUN. Please remember to delete these files before continuing the installation procedure. Log in as user REALTIME-NTX and type:  
   ```
   @DELETE-USERS-FILES --FO: YES--
   ```

2. Log in as user SYSTEM.

3. Put the installation floppy in the floppy drive and enter it with:  
   ```
   @ENTER-DIRECTORY,<FLOPPY-DISC-<drive-no.>,<floppy-unit>>
   ```

4. Start the installation by typing:  
   ```
   @X (210839: FLOPPY-USER)INSTALL
   ```
   This XCOM file will copy all files from the floppy to the actual users on disk. Note: All the old `:PROG`, `:SEGP`, and `:SEGD` files will be deleted before copying takes place.  
   If this product has been installed earlier and the `:FORM` file is found in your system, you will be asked if you want the new form file installed (and the old one deleted). The only reason to prevent the new form file being installed should be if you already have translated the texts in the formfile. The form file in this release are with English texts only.  
   The same procedure will be used for the TABFIL (the data file for the fotosetter), and for the parameterfile. These files are custom dependent and should not be replaced by the new ones unless the datastructure has been changed.

5. This installation job will start the customizing procedure, i.e. (REALTIME-NTX)CUSTOMIZ-NTX:XCOM will be started. You will then have to answer the questions concerning the fotosetter. The customizing procedure results in a NORTEXT system definition file called DEFINE-NORTEXT:XCOM.

## Instructions

6) Make a hardcopy of the definition file: DEFINE-NORTEXT:XCOM. This will give you information of what your system contains, and may be helpful later.
   
   ```
   @COPY-FILE LINE-PRINTER (REALTIME-NTX)DEFINE-NORTEXT:XCOM
   ```

7) When the installation job is finished, the directory will be released and the floppy may then be removed.

8) Log out and log in as user PARAMETERS-NTX.  
   The fotosetter programs (lines) in NORTEXT need parameter files. The parameter files contain device numbers, conversion table numbers, constants and strings necessary for the individual RT-programs. The naming convention for these files is: 

   ```
   FOTON-PARAM:NTXP
   nn = 01, 02, 03 and so on.
   ```
   Multiple parameter files for the same type of lines may be created with the CREATE-PARAM:XCOM
   
   ```
   @X_CREATE-PARAM
   ```

   Carefully inspect and edit each and every file under this user to make sure that all parameters have the right value. **NOTE:** The typesetter parameter files are in 16-bits format, and must be edited by use of the NORTEXT editor.

9) Log out and in as user SYSTEM.  
   You are now ready to build the real-time part of NORTEXT. The real-time part of NORTEXT will be built according to the answers you gave during the customize dialog. Each subsystem is built by its own BUILD-file called BUILD-XX:XCOM. You may build individual subsystems if necessary without changing the rest of the system. First, you must make sure that the corresponding RT-programs (lines) in question are not running.

10) Build the photo-typesetter output lines by typing:

    ```
    @X_BUILD-FO
    ```

    Photo typesetter output modules will be built as specified in DEFINE-NORTEXT:XCOM.
