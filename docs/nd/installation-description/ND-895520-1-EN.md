## Description of Product

The SINTRAN NFS Support will open the possibility to use a ND-5000 SINTRAN system as a NFS server (not client) with limited functionality.

This will give OWS and UNIX WS transparent access to SINTRAN files. By transparency it is meant that data is manipulated from the work stations in the same manner as if it had been stored locally. For example, there is no need for copying files before working with them.

## Reason(s) for New Product or Version

Why store data on a ND central server system?

- may benefit from superior disk space.
- a standard way of storing network shared data.
- access to several SINTRAN user-areas and systems.
- less duplicating of common data.
- easier backup and better data security.

## 4 Installation Procedure

### 4.1 Automatic Installation

- Insert the floppy 211299A-XX-1D in the floppy-drive  
  `@ENTER-DIRECTORY,211299A,F-D-1,£0/1Å`

- Log in as user SYSTEM

- Run the installation program:  
  `@(211327:FLOPPY-USER)IN-NFS`

- Update the files NFS-EXPORTS:SYMB, NFS-PASSWD:SYMB and NFS-NETGROUPS:SYMB and run the mode file (NFS-A)NFS-START:MODE.

### 4.2 Non-Automatic Installation

When the installation program has been run :

- Update the mode file that is run after a cold start (usually called HENT-MODE:MODE) by including the following line:

  ```
  @MODE (NFS-A)NFS-LOAD:MODE,,,
  ```

- Update the mode file that is run after a warm start (usually called LOAD-MODE:MODE) by including the following lines:

  ```
  @ND
  DEFINE-STANDARD-DOMAIN NFS-SERVICE (NFS-A)NFS-SERVICE:DOM
  EXIT
  ```

  ```
  @MODE (NFS-A)NFS-START:MODE,,,
  ```

These lines should be included at a point when all the directories have been entered, and the ND-5000 is started.
