## Description of Product

XNOTIS is a terminal emulator running in the X-window system. This product emulates the Tandberg 2200/9s terminal with all its character sets and functionality.

## Reason(s) for New Product or Version

To be able to run applications in SINTRAN without loosing the Notis functionality on X terminals.

## 4 Installation Procedure

This product is distributed on a standard streamer tape using the tar format.

### 4.1 Non-Automatic Installation

To install XNOTIS on all platforms, please do as follows:

- Log in as Superuser. (Usually root)

- `cd <tmpdir>`

  where `<tmpdir>` is a temporary directory (usually /tmp) with enough space.

- `tar xvf <tapedevice>`

  where `<tapedevice>` is:

  | Platform     | tapedevice    |
  |--------------|---------------|
  | Sun 3/60     | /dev/rst8     |
  | Uniline20    | /dev/rct0     |
  | Uniline88    | /dev/rmt/ctape|
  | Uniline88 WS | /dev/rmt/0    |

- `cd xnotis`

- `./install <platform>`

  where `<platform>` is:

  | System       | platform |
  |--------------|----------|
  | Sun 3/60     | sun3     |
  | Uniline20    | uni20    |
  | Uniline88    | uni88    |
  | Uniline88 WS | uni88ws  |

The next step will remove the installation directory and all its files. This step is optional.

- `cd <tmpdir>` (`<tmpdir>` as specified above)

- `rm -r -f xnotis`

XNOTIS is now installed and ready for use. Please refer to the manual page for options.
