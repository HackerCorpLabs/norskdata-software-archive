# 3 INSTALLATION PROCEDURE

This section describes how to install the Cb-Jft-Server into a Sintran III system. Sintran version J or later is necessary.

## 3.1

**PREREQUISITES** The following checks have to be made before starting to copy the product files from diskette.

a) The user COLOURED-BOOKS exists.

b) The user COLOURED-BOOKS has at least 1200 free pages and 35 free file entries.

c) User SYSTEM has at least 60 free pages and 4 free file entries.

The number of free pages available to a user is found by using the Sintran command:

```
@USER-STATISTICS <user name>,
```

If the user does not have enough space then more space can be allocated.

- Log in as user SYSTEM

```
@GIVE-USER-SPACE <user name>,<number of pages>
```

## 3.2

**COPYING THE PRODUCT FILES TO MASS STORAGE**

- Log in as user SYSTEM

- Insert the floppy disk labelled 210866B<rev>-XX-01S or 210866B<rev>-XX-01D into floppy drive 1 and type:

```
@ENTER-DIRECTORY 210866-XX-01,FLOPPY-DISC-1,<unit>,
```

- When the directory has been entered type:

```
@MODE (210866-XX-01:FLOPPY-USER)CB-JFT-NEW:MODE,
```

- This mode file will copy the installation file from the floppy disc to user SYSTEM, when this has completed type:

```
@CB-JFT-INST-B<rev>
```

### 3.4 INITIAL EDITING OF THE ADDRESS FILE

This is described more fully in the ND Coloured Books Operators Guide 30.047.2. Every site which the server can communicate with must have an entry in the CB-JFT-NDS:ADDR file under user COLOURED-BOOKS. The format for an address is as follows:

```
 1                                           34                     67  72
 |                                           |                      |   |
 SITE-NAME                                   12345678901234+        YB  CB.MAIL
```

If the entry in column 72 is given, then this string replaces the default Yellow Book suffixes for this site (FTP and FTP.MAIL).

This is the end of the installation procedure. The installation program should be deleted by logging in as user SYSTEM and executing the command

```
   @DELETE-FILE CB-JFT-INST-B<rev>:XCOMM
```

The server may now be loaded and started.

### 4 LOADING AND STARTING THE SERVER

To load and start the JFT server and the mail server, log in as user SYSTEM and execute the Sintran commands

```
   @MODE (COLOURED-BOOKS)CB-JFT-LOAD:MODE,↵

   @MODE (COLOURED-BOOKS)CB-JFT-START:MODE,↵
```

The state of all current transfers is stored on disc by the JFT Server to allow restart of the transfers after a machine crash. In release A, this information is stored in a file called (COLOURED-BOOKS)CB-JFT-DOCKX:SYMB. The format of this file is not compatible between releases A and B. This file should therefore be deleted before the server is started if release B is being installed to replace release A.

If the JFT server is running on another system in the local Cosmos network, only the mail server need be loaded and started. Log in as user SYSTEM and execute the Sintran commands:

```
   @MODE (COLOURED-BOOKS)CB-MAIL-LOAD:MODE,↵

   @MODE (COLOURED-BOOKS)CB-MAIL-START:MODE,↵
```

# SETTING UP THE NRS DATABASE  

If the NRS is being used at this site, then a copy of the derived NRS database should be copied from the central site. This requires the address of the central site to be included in the CB-JFT-NRS:ADDR file. The derived NRS database file should be copied to the file (COLOURED-BOOKS)CB-NRS-DER:SYMB. The mode file (COLOURED-BOOKS)CB-NRS-FETCH-B<rev>:MODE is provided to fetch the derived NRS database file. It assumes that the central site has been called 'NRS' in the NDS address file. If the derived NRS database file is successfully copied, the local NRS database may be generated by typing (when logged in as COLOURED-BOOKS),   

    @ND CB-NRS-GEN-B<rev>↵  

This will create the local NRS database file, CB-NRS-LOC:SYMB, and the NRS database version file, CB-NRS-VER:SYMB. The derived NRS database file may be deleted at this point. Note that the derived NRS database file and the local NRS database file are both very large and approximately 1000 free pages will be needed in user COLOURED-BOOKS before beginning the process of installing the database.
