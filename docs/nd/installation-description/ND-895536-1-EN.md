## Description of Product

PC-NOTIS CALC is a general-purpose spreadsheet used for calculations. The product consists of one 5 1/4" floppy 230145E04-NO-01D or two 3 1/2" floppies - 30145NO1E04 and 30145NO2E04 which contain installation files, program file, language dependent file and init-file.

#### Documentation:
- NOTIS-CALC Brukerhåndbok 863025.4 NO
- NOTIS-CALC Oppslagskort 899012.1 NO

## Reason(s) for New Version

This version of NOTIS-CALC is the first version running on PC. It is a part of the PC-NOTIS product range. The differences in user interface between NOTIS-CALC for ND-500/5000 and PC-NOTIS CALC are kept to a minimum - no additional training is needed.

## 4 Installation Procedure

### 4.1 Automatic Installation

To install PC-NOTIS CALC, please insert the floppy in diskette drive A: on your PC, and type:

```
A:INSTALL↵
```

The installation job will guide you through a complete installation of PC-NOTIS CALC.

### 4.2 Non-Automatic Installation

Not recommended.

### 4.3 If You Will Use NOTIS-CALC From Windows

Preparing the NOTIS-CALC for WINDOWS and WIN Start involves the following:

1. Copy the files PCCALC.COM, STPCCALC.EXE, EXECLIB.EXE and CLOSELIB.EXE from the PC-NOTIS PCCALC installation kit. Insert the last floppy of the kit (no. 1 for 5¼" floppies and no. 2 for 3½" floppies). Copy the file to the `\ND-OWS\NOTIS` directory.

   ```
   COPY A:PCCALC.COM \ND-OWS\NOTIS\PCCALC.COM
   COPY A:STPCCALC.EXE \ND-OWS\NOTIS\STPCCALC.EXE
   COPY A:EXECLIB.EXE \ND-OWS\NOTIS\EXECLIB.EXE
   COPY A:CLOSELIB.EXE \ND-OWS\NOTIS\CLOSELIB.EXE
   ```

2. Make a WINDOWS PIF file by starting WINDOWS and the PIFEDIT.EXE file (under the WINDOWS directory).

   Make a new PIF file for NOTIS-CALC, File/New.

The different parameters in the PIFEDIT program should have the following values (parameters not mentioned should be empty):

- Program name: `\ND-OWS\NOTIS\PCCALC.COM`
- Program title: PCCALC
- KB required: 0
- KB Desired: -1
- Directly modifies: Screen and memory should be marked with x (use the mouse or the space key)
- Program switch: TEXT
- Screen exchange: TEXT
- Close window on exit: Mark the box with x (use the mouse or the space key)

Save the parameters, File/Save, under filename `\WINDOWS\PIF\PCCALC.PIF`

Now you can execute PCCALC from WINDOWS simply by clicking on the STPCCALC.EXE file in the `\ND-OWS\NOTIS` directory.

If you are going to insert PCCALC in the WIN SMX menu or as an icon in the ND WinStart package you must use the `\ND-OWS\NOTIS\STPCCALC.EXE` file as file name for CALC (do NOT use PCCALC.EXE or PCCALC.COM). See related manuals for details on how to modify the SMX menu or the WinStart applications.

NOTE that the STPCCALC.EXE program will close all active WINDOWS applications and start PCCALC. When exiting from PCCALC you will return to WINDOWS as if you were starting WINDOWS for the first time.

## 5 Modifications

### 5.1 New Functions/Commands

PC-NOTIS CALC is a part of the PC-NOTIS product range. The complete environment consists of NOTIS-WP Word Processing, NOTIS-ID Electronic Mail, NOTIS-DS Document Storage and a common NOTIS menu system, all running on the PC. From the menu system it is possible to start applications running both on the PC and on the SINTRAN server. Full integration between PC-NOTIS products and SINTRAN-based NOTIS products is supported.

## 5.2 Changed Functions/Commands

The NOTIS menu is changed. BG is removed and ID, DS and SPRINT have been added. It is now possible to start the following programs from PC-NOTIS CALC's NOTIS menu:

- NOTIS-WP (on host or PC)
- NOTIS-ID (on host or PC)
- NOTIS-DS (on host or PC)
- SPRINT Spooling System (on host)

The commands @ and "Tjenester/SINTRAN" have now been redefined to start the terminal emulator included with PC-NOTIS Platform. The emulator is quitted by pressing ALT + F4.

The SHIFT + PRINT command will now also list local PC-connected printers. They are marked with an asterisk (*) in the list.

## 5.3 Removed Functions/Commands

None.

## 5.4 Other Modifications

PC-NOTIS CALC uses a text compiler for handling language dependent texts. When PC-NOTIS CALC is started the first time after installation, these texts will be compiled. This results in a longer startup time the first time after installation.

# 7 Errors Known But Not Corrected

NOTIS-CALC for ND-500/5000 and PC-NOTIS CALC may give slightly different results from calculations. Results from single expressions should be equal up to the ninth decimal, but inaccuracies may be enlarged in complex calculations.
