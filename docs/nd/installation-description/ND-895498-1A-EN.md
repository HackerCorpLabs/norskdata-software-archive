## 6 Installation

Before you start to generate the start volume, you have to edit the AUTOEXEC.BAT and a:\3open\doswksta\lanman\lanman.ini file on the 3Station start volume floppy. Make a backup floppy before you start to edit.  
Edit the home_server_name and home_server_security in AUTOEXEC.BAT line 21 and 22 as described below. Example:

```
set home_server=MYSERVER      %% This should be the name of your
                              %% server.
                              %% Do not type any spaces in front of
                              %% the server name.
set home_server_security=USER %% Your server's security level. This
                              %% should be either USER or SHARE.
                              %% Do not write any spaces in front
                              %% of the security level.
```

Edit the a:\3open\doswksta\lanman\lanman.ini line 93 as described below:

```
hmserver=myserver:u           %% u if user level security
                              %% s if share level security
                              %% Do not write any spaces in front
                              %% of the server name.
```

Default country code for this start volume is 47 (Norwegian).  
The code can be changed by editing the code in config.sys.

Example:
```
Country=<country code>,,country.sys
```

You may now generate the start volume from the diskbased client.  
A complete description of how to generate and maintain a start volume is described in the 3+Open Start Manual.  
You can also follow the quick installation description below.  
Boot your diskbased PC and log on to your server as user ADMIN.  
Start the XNS protocol by typing XNSTP. Insert the edited 3Station start volume floppy into floppy drive A.  
Link a drive to the STARTDIR sharename. Make this new drive as the current one. Start the 3S program and perform the CREATE ? command.  
The 3S program will guide you through the different parameters to this command, and finally generate the start volume.

Please observe that you cannot boot properly with this new start volume without having defined the IP/MAC address pair in the IP Address Manager database. Refer to the Product Information sheet for ND-380721 and the manual IP Address Manager Administrator's Guide ND-860427 for a complete description of how to install IP Address Manager and define the IP addresses.

## 7 PC Start, Connect + S-Link Installation

This is a short description of how to install ND PC Starter Kit, ND Connect Module and S-link for the users of the 3Station/2E PC's.

1. Create a user for every 3Station/2E that will use the new start volume, generated from the 3Station Start Volume floppy. All users MUST have a home directory with the same name as the user name. Please remember to modify user ADMIN and give it a home directory, if you also want to install ND PC Starter Kit etc. for user ADMIN.

   Have the list of IP addresses defined for the different 3Station/2E available, and start the installation as described below.

2. Start the 3Station/2E with the start volume generated from the 3Station Start Volume diskette, and log in as user ADMIN. If your 3Station/2E is configured to start automatically with the standard start volume called 3Station, refer to chapter 4 in the 3Station/2E Users Guide, on how to specify the start volume.

   The 3Station Start Volume will look for a AUTOEXEC.BAT file in the path h:\<username> and run this file if it exists. This AUTOEXEC.BAT file will be updated by ND PC Starter Kit with path, keyboard drivers etc. To get a correct keyboard driver at this stage, type:

   ```
   h:\C:\KEYB <KEYBOARD CODE>..\C:\KEYBOARD.SYS
   ```

   Please see your MS-DOS manual to get a list of valid country codes.

3. Place the ND PC Starter Kit floppy in the _server's_ floppy drive A.

   Type:

   ```
   h:\NET USE A: \\<SERVERNAME>\A$
   ```

   Create a new directory.

   ```
   h:\MKDIR I:\PC-START
   ```

   Copy the files from the floppy to the new directory.

   ```
   h:\XCOPY A: I:\PC-START /S
   ```

   Remove the ND PC Starter Kit floppy.

7. Do the following installation for EVERY user which you created in step 1.

### 7.1 Install an initial autoexec.bat for the user

```
h:\I:\COPYBAT <USER NAME>
```

This Autoexec.bat file will be edited by the ND PC Starter Kit installation program.

### 7.2 Install ND PC Starter Kit for this particular user

```
h:\I:\PC-START\INSTALL -K<keyboard> -S<display> -PH:\<USERNAME>
```

A complete list of keyboard and display codes can be found in the ND PC Starter Kit Installation Guide.

- **The code for NOTIS PC keyboard is**: 6  
- **The code for AT Enhanced Cherry keyboard is**: 2  

- **The code for VGA colour display is**: VC  
- **The code for VGA monochrome display is**: VM  

**Example**:  
You are going to install for user NR1. This user has a diskless PC with VGA colour display, and AT Enhanced Cherry keyboard connected.

ND PC Starter Kit should then be started as follows:

```
h:\I:\PC-START\INSTALL -K2 -SVC -PH:\NR1
```

## 7.4 Install S-link for this particular user

```
h:\I:S-LINK\INSTALL -PH:<USER NAME>
```

Answer the questions according to the following list:

Q1. **PRIVATE DIRECTORY: H:\<USER NAME>? (YES/NO)**  
Choose YES  
The installation gives you the correct alternative.

Q2. **PRIVATE DIRECTORY: I:\ND-0WS? (YES/NO)**   
Choose YES  
The installation gives you the correct alternative.

Q3. **DO YOU WANT TO COPY YO THE SHARED DIRECTORY? (YES/NO)**  
Choose YES during if this is the first installation,  
otherwise NO

Q4. **COMMUNICATION MEDIUM: ETHERNET (PC/TCP)? (YES/NO)**  
Choose YES if the installation gives you the correct  
alternative, otherwise type NO and choose ETHERNET (PC/TCP)  
from the list of alternatives.

Q5. Choose **NDIS ETHERNET** from the list of PC/TCP Cards.

S-link is now installed for this particular user.  
Remember to unlink the floppy drive when the installation  
is finished. This is done by the command `NET USE A: /D`

**NOTE**

If for some reason you do not want to copy the floppies as described  
above, but instead want to do the copying from the server, create the  
different directories (pc-start, connect, pctcpndis and s-link) as  
subdirectories to the NDSHARED directory.

Follow the above installation description from Step 6.
