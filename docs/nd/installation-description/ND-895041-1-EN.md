## What does the product consist of?

Designer ND-230042

Designer is a program for making drawings and illustrations. It runs on an OWS under MS Windows.

## Hardware requirements

One of the following computers must be available:

| Computer | Type  |          |
|----------|-------|----------|
| OWS-12   | PC-AT | ND-150003|
| OWS-55   | PC-AT | ND-110356|
| OWS-85   | PC-AT | ND-110357|

Designer is able to produce output on any of these ND printers:

- HP 7475 plotter - ND-102180
- HP 7550 plotter - ND-110261
- ND 715 Postscript printer - ND-110347
- ND 720 Page printer - ND-110223
- ND 730 Page printer - ND-110224
- EPSON personal printers

Designer can also produce output on many other printers if they are supported by MS Windows. When a local printer is used on the OWS-12, an additional serial port is needed.

## Known deficiencies

### Keyboard

The following shortcut keys for the menu choices do not work with the ND keyboard:

| Shortcut key | Menu choice        | Use instead      |
|--------------|--------------------|------------------|
| SHIFT + DEL  | (Edit/Cut)         | HYPERSHIFT + DEL |
| SHIFT + INS  | (Edit/Paste)       | HYPERSHIFT + INS |
| CTRL + INS   | (Edit/Copy)        | Menu choice      |
| F11          | (Arrange/Connect Close) | Menu choice |
| SHIFT + F11  | (Arrange/Connect Open)  | Menu choice |
| F12          | (Edit/Symbol ID)   | Menu choice      |
| SHIFT + F12  | (Edit/Transfer)    | Menu choice      |

The `<HYPERSHIFT>` keys are located at the lower left and right corners of the main keyboard.

### NOTIS-PET remote printers

When installing NOTIS-PET, you can define remote printers. These printers cannot be used directly from Designer, since Designer does not support remote printing.
