# Installation Procedure

The desired user, for example DIALOG-SYS, should be given **225 pages**. Copy the files from the floppy to this user-area.

Run the PERFORM system to load UNIQUICK. An example is shown below:

```
⊘PERFORM UNIQUICK-I-A⊘
```

PERFORM 2412F

Macro name (Default = LOAD-UNIQUICK-I) :[illegible]

```
!----------------------------------------------------------!
! Load UNIQUE UNIQUICK ISAM Version A on ND-100             !
!----------------------------------------------------------!
! NB! This macro will only load the system! If you want! 
!        UNIQUICK to be reentrant DUMP-UNIQUICK must be     !
!        run from user SYSTEM after the load is OK.         !
!----------------------------------------------------------!
```

User name for UNIQUICK.BRF files (Default = DIALOG-SYS) :[illegible]  
User name for FORTRAN library (Default = DIALOG-SYS) :[illegible]  
Name of FORTRAN library (Default = FORT-2B) :[illegible]  
Type version of UNIQUE-II (1 for A, 2 for B, etc.) (Default = 2) :[illegible]

```
⊘MODE MACRO1:MODE,,,
```

This :MODE file will now load UNIQUE-II. Log in as user SYSTEM and run the dump-reentrant job:

```
⊘PERFORM (DIA-SYS)UNIQUICK-I-A⊘
```

PERFORM 2412F

Macro name (Default = LOAD-UNIQUICK-I) :DUMP-UNIQUICK-I[illegible]

```
!----------------------------------------------------------!
! Dump UNIQUE UNIQUICK ISAM Version A reentrant             !
!----------------------------------------------------------!
! NB! If you want UNIQUICK to be reentrant you have to      !
!      run this macro from user SYSTEM                      !
!----------------------------------------------------------!
```

User name for :PROG file (Default = DIALOG-SYS) :[illegible]

```
⊘MODE MACRO1:MODE,,,
```

After this job is finished, the system is ready to be used.

Start the program by typing:

```
⊘UNIQUICK-I⊘
```
