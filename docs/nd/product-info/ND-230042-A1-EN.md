# Micrografx Designer

## Introduction

Designer, a highly interactive graphic design tool, is well-suited for the creation of technical illustrations, fashion design, medical diagrams, logos, maps, cartoons, architectural design, mechanical drawings, electrical schematics, engineering specifications, overheads—and more.

Designer is a member of ND’s desktop publishing family running in the MS-WINDOWS environment, closely integrated with NOTIS-PET, ND’s Page Editing Tool on the workstation.

## Product Description

Designer is a graphic design tool which, due to the Windows environment and self-explanatory menu choices, has a very low threshold for novices. However, since it makes extensive use of accelerators and shortcut keys, it is also very powerful when used by the expert.

The advanced drawing primitives, together with the reshape facilities, make it very easy for you to create what you want. Among the drawing primitives are arc, elliptical arc, circle, ellipse, rectangle, pie, freehand drawings, parabola, and different curves. When drawing objects, you don’t need to concentrate on getting the shapes perfectly correct at creation time. Designer lets you easily move vertices in your curves/lines, and you may even add and remove vertices in already created objects.

In addition to the reshape facility, you can modify Designer objects in many other ways. Resizing, flipping, smoothing and unsmoothing, rotating to mention some of them.

For creation of titles, labels, descriptions, and captions, Designer provides advanced text drawing capabilities. Text can be drawn into the drawing directly, or via a text editor window. You may also import text files created with other applications. There are many different fonts to choose from, and the size may be specified in picas or millimeters. You may also change the appearance of text already created.

Designer lets you preset or change a symbol’s colour and pattern and a line’s colour, width, style and end style. You can create and name new colours in three different colour standards (HLS, RGB, CMYK), and you can save your own colour palette sets. You may also edit a fill pattern to create your own unique pattern.

Designer lets you assign IDs to symbols (combined objects) in your drawings. This symbol IDs can be used to produce part lists, select symbols, replace symbols, and to load a symbol from file by typing the symbol ID. As you replace words with others in a text editor, you can replace graphic symbols in Designer.

For precision editing, Designer provides you with different snap features. Ruler snap for force, the cursor to snap to the nearest ruler. Another possibility is to choose object snap, which overrides the ruler snap. This feature is very useful when drawing combined symbols.

In Designer, you can use up to 64 layers in each drawing. These layers have numbers, but you may also give them names. Each layer can be restricted to one colour, for making output to traditional print-shops. You can lock one or more of the layers, to prevent editing on them. You yourself decide which of the layers are to be displayed or printed.

Designer makes full use of the Windows clipboard, which gives you the opportunity to cut and paste graphics to and from other Windows applications. Designer supports a wide range of clipboard formats.

Symbol libraries are drawing files where you store symbols you use repeatedly. You can extract a symbol from a library by specifying its ID, or by opening a Library Window to pick symbols from. You or your organization can produce these symbol libraries, or ClipArt libraries can be purchased from Micrografx. Micrografx has its own staff who are devoted to producing new ClipArt libraries. Among the libraries currently available are the Transportation, Architectural, Chemical, Electrical, Mechanical and Military ClipArt libraries. It is also possible to request Micrografx to design special ClipArt libraries for a specific organization.

The scanned image support makes it possible for you to scan in hand drawn sketches, and trace them in Designer. The scanned image is fetched into Designer from the scanning program via the Windows clipboard. The bitmap may be moved, scaled and stretched inside Designer. It is also possible to print out the image from Designer.

Designer drawings may be used as parts of your NOTIS-PET publications, or they can be printed out directly. Designer is closely integrated with NOTIS-PET, no conversion modules need to be run. Designer produces directly several graphics formats that NOTIS-PET understands. Designer supports hundreds of different printers, including the new colour PostScript printers.

# Micrografx Designer

## Features

In addition to basic tools, found in all "drawing programs", Designer provides:

- Polygon and curve editing.
- Curve smoothing and unsmoothing.
- Ability to connect and fill irregular objects.
- Rotation of graphics and text in 1/10-degree increment.
- Flexible symbol selection, identification, recall and replacement.
- Extensive symbol libraries with individual symbol management.
- Up to 64 layers in single or multiple colours, with user assigned names for overlays and spot colour separations.
- Scanned image support.
- Line widths in millimeters or 1/1000's of an inch, five line styles, 15 end styles.
- Associative dimensioning ranging from millimeters to miles.
- A ruler snap mode and object snap mode.
- Palette sets of over 3.6 million colours and gray scales.
- Ability to create and save custom palette files.
- Flexible labeling and text editing, including importing of text files.
- File and clipboard compatibility with Windows-DRAW, Graph Plus, NOTIS-PET (Aldus PageMaker), and most other Windows compatible applications.
- File compatibility with AutoCAD through the DXF file format.

## Prerequisites

The following products are needed in order to run Designer:

- OWS-12 (ND-150003) or OWS-55 (ND-110356) or OWS-85 (ND-110357) (or true compatible) with a minimum of 512k RAM (640k recommended)
- MS-DOS 3.10 or higher (included on OWS-12/55/85)
- MS-WINDOWS 2.03 or higher (included on OWS-12/55/85)

For hardcopy output, the following ND products may be used (connected locally to workstation).

- HP 7475 plotter ND-102180
- HP 7550 plotter ND-110261
- ND 7155 PostScript printer ND-110347
- ND 720 Page printer ND-110223
- ND 730 Page printer ND-110224
- Epson personal printers

In addition, Designer may produce output to all printers supported by a Windows printer-driver.
