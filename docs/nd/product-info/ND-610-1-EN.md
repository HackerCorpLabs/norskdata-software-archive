## WinLink from Norsk Data

WinLink is a program that allows communication between a Norsk Data server and your PC. WinLink gives you the best of two worlds. On the one side you have your personal computer with simple and integrated MS-Windows® applications. On the other side is the ND server machine with its routine security measures, shared resources, advanced electronic mail, and many other features. WinLink is the "link" that allows these two parts to work together in an effective and integrated way.

WinLink contains a set of fully integrated MS-Windows programs that can be run at any time, and like all Windows programs, can be iconised, resized, or placed in the background.

WinLink consists of several different programs that allow you to do the following:

- Link to a SINTRAN server, log on, and work as a terminal
- Copy files back and forth between the server and your PC
- Copy any text from SINTRAN and paste it directly into any Windows program (via the Clipboard)
- Back up your PC files by copying multiple files or entire directories to the server with a single command
- Define screen colours and preferences when you use your PC as a terminal
- Choose which server to link to (for Ethernet® only)
- Define communications parameters and options (for serial only)

## WinLink is a product that will increase your productivity — saving you time and effort!

## Compatibility

WinLink is compatible with Microsoft Windows/286 and Microsoft Windows/386 version 2.

## System Requirements

- IBM® PC/XT/AT, IBM PS/2, or Microsoft Windows-compatible personal computers
- Microsoft Windows/286 or Microsoft Windows/386 version 2.
- PC Starter Kit (ND 230123)
- For Ethernet connection: ND Connect Module (ND 230125)
- Either WinSMX (ND 230119) or WinStart (ND 230118) to start WinLink with
- Optional: Microsoft Mouse or compatible (can be used with only keyboard)
