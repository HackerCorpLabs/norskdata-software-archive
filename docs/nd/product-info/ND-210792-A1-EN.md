# Introduction

NOTIS-ID, Information Distribution is ND's electronic mail system aimed at effective distribution of messages and documents. Information can be sent from user to user, transparent in the COSMOS network. It is closely integrated with the NOTIS family and consistent with NOTIS-WP user interface.

# Features

- NOTIS-WP-like editor for creating/editing letters
- Menus or function keys for all tasks
- Mail sent from user to user/groups of users
- Reply function
- Timer for mailing
- Registered mail
- Automatic retry when destination cannot be reached
- Mailing lists - you can send mail to groups of users
- Separate Supervisor module

# Product Description

NOTIS-ID, Information Distribution is ND's electronic mail system belonging to the NOTIS family of Office Support products. NOTIS-ID can run as a single or multi-machine system. All users belonging to the mail system have an intray for received mail and an outtray for outgoing mail.

NOTIS-ID has good menus and function keys for all tasks. Letters can be written directly with the help of a NOTIS-WP-like editor and mailed with other documents enclosed, if desired. The sender can determine when the mail should be sent by the timing function. Mail can be sent as registered mail if the sender want to know when the recipient has read the message.

All items in the intray and outtray can be printed directly by the use of the PRINT key.

# Requirements

- NOTIS-WP, Word Processing, version M or later
- NOTIS-DS, Document Storage, version C or later
- UE, User Environment, version B or later
- SINTRAN III, version J or later
- COSMOS Basic Module
