## Introduction

A substantial part of the design engineer’s working day is spent in constructing families of related parts and, when working in the conventional manner, in altering drawings. Even new constructions include, many parts which are either standard parts or variations of parts that have already been included in other drawings. Alterations made to satisfy the customer’s requirements or which are prerequisites to manufacture must also be taken into account.

In essence, the process of generating variants involves defining a fictitious ‘mother’ form from a family of geometrically similar parts. The mother form contains every geometrical feature that occurs in the members of the family. In addition, you define which parameters are variable and the range over which these parameters can be varied. Variants can be produced from these defined parameters without reference to the geometrical data.

TECHVAR enables tabulated parameter values to be used to produce alterations in the dimensions and/or the structure of a part. The tabulated values can be entered directly or in the form of a mathematical expression which is evaluated before processing.

The variants of a family may differ in their dimensions or in their form. However, parts which differ only in their dimensions are not considered as variants since the same effect can be obtained by a simple change of scale. This is the case with parts defined as symbols (a standard function of TECH2D), which can be copied into a drawing at any desired scale.

The construction of variants is a highly productive method of working. Studies have shown that a productivity factor of 20 can be achieved when the construction of a variant has been well thought out. The key to this high level of productivity is the fact that TECHVAR is integrated with TECH2D. TECHVAR is a highly interactive module and demands no prior programming experience on the part of the user.

A point not to be neglected is that the installation of TECHVAR brings with it a reduction in the volume of data stored. The storage of whole families of parts in the form of separate drawings can be replaced by the storage of a mother part and several smaller files containing the parameter values currently being used. The consequent reduction in the amount of information that has to be input in order to generate a new part also means an increase in the standardization of parts.

The variant module TECHVAR is not the only way of producing variants, as TECHNOVISION includes in its range of products a FORTRAN interface (TECHFTN, ND 210704) which can also be used for this purpose. In contrast to TECHVAR, however, this method does require that the user has programming experience.

## Features

- Interactive description of the basic part
- No programming experience required
- Variables are fully integrated into the data structure
- User-defined registers
- Creation of parameter tables
- Value input via tables or registers
- Editing of variables
- Macro editor
- Macros can be nested in other macros
- Storage of macros in ASCII code

## Product Description

Variants can be produced either interactively or via macro functions.

## Macro Functions

To define a mother part, which need only be done once, a processor generates a model according to predefined rules of variation the user is intending to include in this part. These models can then be used to generate drawings by inputting the appropriate parameter values.

There is practically no limit to the number of macros which can be processed. The macros defined by the user can be stored under a field in one of the 99 tablet overlays, each of which has 100 fields. The same field can then be used to access and run the macro. By re-using a mother part which has already been defined in another macro, the work involved in describing other mother parts can be reduced considerably.

The following functions are used for the production and execution of macros:

- Identification of graphic elements
- Manipulation of register values
- Macro editor
- Direct input into a register
- Input into a register via value functions
- Listing of register values
- Output of register values into the drawing
- Setting of default values
- Deletion of register values
- Input via parameter tables
- The interactive dialogue can be switched on or off

## The Macro Editor

The macro editor of TECHVAR is accessed via the Archive Monitor Program and possesses the following features:

- Listing of macros on the alphanumeric screen or a printer
- Modification of macro parameters
- Modification of input parameters e.g. altering the input mode from constant to variable
- Conversion of graphic positions into XY coordinate values
- Deletion or alteration of macro names

Macros can also be converted into ASCII files and subsequently edited using the program editor PED or NOTIS-WP.

## The Interactive Method

Producing a macro for a mother part using the macro function can, depending on how complex the part is, involve a considerable investment of time. In addition, while the macro has to be constructed in such a way as to contain as many functions as possible which could be of relevance to the part families, it must also be kept general enough so that it can be extended as required.

The forerunner of every variant is a part produced using TECH2D. Once a part has been generated, the functions available under System function 07 (which are similar to those employed in dimensioning a part) are used to define the variable elements of its geometry (the parameters). This process of defining the parameters can be carried out separately from the procedures used in generating the geometry.

The different parameters that can be defined as variable include horizontal and vertical distances, the length of an element, the radius of a circle or arc, and the size of an angle. This information is stored together with the geometrical data of the part and therefore need not be redefined, although it can be modified interactively at any time. In order to produce a variant, the appropriate values can be entered either individually or via a table of values. In addition, the allocation of values is possible by means of macro functions or user programs (TECHFTN).

The logical processing of this information ensures the stability of the system, even when inaccurate input results in some aspect of the part having a dimension which is geometrically impossible.

A considerable advantage in producing variants using the interactive approach, as opposed to using macro functions, is that the procedure for describing the geometry of the variant is less time-consuming and the user can check the description of the mother part as the work proceeds.

## The Following Functions are Available When Using the Interactive Approach

1. **The Definition of Variables:**
   - distance
   - horizontal length
   - vertical length
   - diameter, radius, fillets
   - angle functions
   - contour (for cross-hatching)
   - parallel and perpendicular lines, tangents

2. **Editor Functions, Including:**
   - listing of defined variables
   - deletion of variables
   - output of variable names and values from registers
   - output of the names of variables as dimensioning text
   - register values can be used for generating variants
   - modification of the way dimensioning and hatching are displayed

3. **Control Functions:**
   - modification of a variable
   - modification of several variables via the registers
   - selection from a table of values
   - allocation of values through user programs

# Technovision 

TECHNOVISION is the 2D/3D CAD system developed by NORSK DATA for engineering design and related applications. It is an invaluable aid in every aspect of technical drawing (design, calculation and drafting) as well as in the management of all associated product data.

The modular nature of the system ensures that an economic configuration can be found to meet the requirements of every design office. In addition the open-ended structure of the system enables users to develop new functions themselves and incorporate them into the system, and facilitates the communication of product related information both within the company and to outside concerns.

A universal product data base represents the kernel of the CAD/CAM solution offered by TECHNOVISION and the key to the integration of product planning, product management, and office automation.
