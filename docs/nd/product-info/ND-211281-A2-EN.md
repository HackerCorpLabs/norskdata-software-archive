# SNA APPC – LU 6.2 LIBRARY II

## Introduction

Norsk Data's SNA APPC – LU 6.2 LIBRARY II is a software emulation of Advanced Program-to-Program Communication (APPC). It is designed to allow application programs on ND computers to communicate with CICS® application programs on IBM® hosts in an SNA network.

## Features

- IBM Advanced Program-to-Program Communication emulation
- Implements LU 6.2 for Program-to-Program communication
- Implements PU 2.0 for IBM host communication
- Compatible with CICS LU 6.2 support and DISOSS
- Application interface via IBM's architected Mapped and Basic Conversation Interfaces in PLANC, COBOL and FORTRAN
- Up to 4 parallel conversations per application program

## Product description

The ND SNA APPC – LU 6.2 LIBRARY II software package consists of a set of Library Routines through which the applications are connected. The ND SNA APPC – LU 6.2 LIBRARY II allows multiple LU 6.2 users to connect to the IBM host simultaneously. The Library Routines implement the architected verb interface to LU 6.2.

Application programs use the Conversation Verb Interface in the ND SNA APPC – LU 6.2 LIBRARY II to send and receive data from both custom LU 6.2 applications and IBM host-based applications like DISOSS.

The ND SNA GATEWAY II controls the allocations of SNA sessions to application programs, provides end-to-end error reporting capability and synchronizes processing when two applications are communicating.

ND SNA APPC – LU 6.2 LIBRARY II is part of a complete line of IBM-compatible data communication products from Norsk Data. These products are based on a consistent modular design utilizing the same SNA GATEWAY II for all the SNA-compatible software. This design allows a single system to support APPC concurrently with 3270 and RJE and other Logical Unit types.
