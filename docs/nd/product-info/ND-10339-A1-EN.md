# ND 10339 Honeywell Bull Remote Job Entry Emulator

## INTRODUCTION

The Remote Job Entry approach to data processing offers several significant advantages. Without having to incur large capital outlays, an RJE terminal user may share the processing power of a host mainframe computer and gain access to centrally stored programs and data.

The ND 10339 Emulator is specifically designed for remote job entry to Honeywell Bull 6000 systems, and provides a range of options that affords the user the freedom to configure the RJE terminal in accordance with particular applications and functional requirements.

The Emulator communicates through a Honeywell Bull DATANET 355/6600 Front-End Network Processor.

## FEATURES

- Easy connection to the RJE system
- Multi-user system
- Easy-to-use command syntax
- VDU oriented
- Local communication log
- A number of logical communication channels
- Job input independent of communication status
- Automatic output to ND machine
- Output routing to any ND file or peripheral device
- Command protection
- Easy system initialization
- System error log for easy diagnostics
- Safe and easy operation of the system
- Text/Commands available in several languages

## PRODUCT DESCRIPTION

The RJE-terminal may run with two types of communication line protocols:

- Honeywell Bull GRTS-115 procedure
- Honeywell Bull Multi-Message Interface (MMI) procedure

The actual procedure is chosen at system generation time.

```mermaid
flowchart TD
    GR1NA --> |
    GR1NA --> GR1NB
    GR1NB --> GR1N [GRTS-115 line procedure]
    GR1N --> MMI [MMI line procedure]
```

The MMI communication procedure allows a number of simultaneous logical communication channels on one physical communication line. This allows transmission of several jobs (input/output), on separate logical channels at the same time. The number of logical channels is set at system generation time.

Both procedures support full data compression (of all identical characters). Input data are expected in card images with a maximum of 80 characters per record. Output data may have any record length.

The following peripherals are supported: 

- **Job input**: Disk-files and cardreader. 
- **Job-output**: Disk-files (e.g. printer with spooling), devices (e.g. printer without spooling) and punch. 
- **Operator communication**: Multiple consoles (both VDU and TTY-types). The number of consoles supported is set at system generation time.

The RJE-system may run with different kinds of communication lines:

- Dial-up line
- Leased (fixed) line
- NPDN (Nordic Public Data Network) line

The system contains procedures for each type of communication line in order to give optimal utilization of any line.

The system utilizes an up-to-date screen (VDU) oriented operator interface. It is designed to minimize the operator intervention.

# Prerequisites

The Honeywell Bull RJE Emulator may be run on a NORD-10 or ND-100 computer under the SINTRAN III/VS operating system with the ND File System and synchronous modem or HDLC interface.
