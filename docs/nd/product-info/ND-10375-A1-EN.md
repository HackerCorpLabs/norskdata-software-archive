# ND-10375 TELEFIX

**Remote Diagnostics and Maintenance System**

## INTRODUCTION

ND-10375 TELEFIX was created to permit analysis of error situations in customers' computers directly from Norsk Data's Service Center. With TELEFIX most software errors may be corrected directly from the center without the need to wait for the arrival of a technician. The Service Center can directly transmit program files, new versions and patch files.

## BENEFITS

- Rapid response when a problem arises.
- Often no waiting for service engineer to arrive.
- Rapid analysis and correction of errors.
- Reduce need for customer to run diagnostics programs.
- System engineers can solve problems more quickly from ND's Service Center where technical expertise is at hand.
- Hardware engineers know in advance of visits enough about the customers problem to come equipped with correct parts & equipment.
- System engineers can run diagnostics, analyze error situations, patch software and reload SINTRAN from the ND Service Center.
- The customer gets a log of the activities on the console during the testing.
- May run terminals using either V.24 or current loop as a console terminal.

## DIAGNOSTIC PROCEDURE

The customer who experiences a problem calls Norsk Data's Service Center. A remote diagnostics diskette must be mounted and contact made with ND's diagnostics computer, whereupon the console is switched to REMOTE. This simple procedure puts the customer's system in contact with ND's service engineer who subsequently may:

- run hardware diagnostic program
- run software diagnostic program
- debug
- modify software
- copy files from the ND service computer
- stop & start computer
- reload & restart SINTRAN

## PREREQUISITES

In order to get TELEFIX a customer must have signed an appropriate Service Contract with Norsk Data.

An ND Remote Maintenance adaptor (including a current loop/V.24 converter) must be connected between the console port and the console terminal, and the console speed must be 300 or 600 baud. In addition, there must be a modem and telephone connection.
