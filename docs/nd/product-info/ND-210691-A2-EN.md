# NOTIS-DS version D

## Introduction

NOTIS-DS is a general system for document storage and retrieval. NOTIS-DS organises document storage in a way familiar to office personnel: cabinets, drawers and folders. All NOTIS and Wordplex Harmony products use NOTIS-DS as a storage medium.

NOTIS-DS has a user-friendly interface which allows the user to quickly scan a cabinet, its structure and content.

Norsk Data views NOTIS-DS as a strategic document storage system which will supply basic document storage functionality under present and future ND systems architectures.

## Product Description

NOTIS-DS is a general document storage and retrieval system for Norsk Data computers. Different users may share a single archive, which may be on any computer within a network.

### Users

Each user may have his own user area within the archive. Each user may have named friends with individual access rights to specific documents. DS user areas are associated with User Environment user names.

### User groups

User groups are groups of users who share all information and rights to an area within the archive. By defining user groups, the organisation can designate functions to individual personnel and can thereby ensure that the document database becomes a shared resource. Similarly, all documents relating to an office subject may be established as common for a particular group of users.

### View of the archive

Users store their documents in an archive seen as a hierarchy of drawers, folders and documents. A user may have any number of drawers, each drawer may contain any number of folders, and each folder may contain any number of documents. The user may list these elements, open them to reveal their content (which may be another list), and manipulate the hierarchy of lists with full ND-NOTIS functionality (including transporting documents to NOTIS-WP).

### Searching

Users may search for documents by document name, folder name or drawer name, or a combination of these. Names may be abbreviated. Each document may also be identified by up to 3 user-supplied keywords, which may be searched upon.

### ND-NOTIS

The ND-NOTIS family of products accesses information stored in NOTIS-DS directly. Each ND-NOTIS product contains functions for reading, writing and listing documents. Other software products may use the DS library for these functions. NOTIS-DS can store any type of document: text, spreadsheet, picture, graph, etc.

# NOTIS-DS version D

## Features

- ND-NOTIS standard menu-driven user interface, enabling the user to easily perform functions such as move, copy, delete etc. on the objects in the archive. This makes the product easy to learn and use.

- Hierarchically structured document storage, with well-known concepts such as documents stored in folders stored in drawers stored in cabinets.

- The archive structure is reflected in the screen pictures presented to the user following a list or search command. Indentation is used to reflect the hierarchical levels.

- All levels have attributes for setting access rights, subject explanations, keywords, etc.

- A user may search for documents, using keywords or abbreviated names as selection criteria.

- Same user concept as in User Environment.

- One NOTIS-DS archive may serve several systems in an ND-COSMOS network.

- The NOTIS-DS archive may be spread over several directories. This gives DS a database size to cover the needs of most office environments.

- Easy loading of SINTRAN documents.

- External (paper) documents may be referenced within the database.

- NOTIS-DS D together with BACKUP SYSTEM provide a high-quality operational environment. Database backup may be taken to disk, tape and streamer. Database backup may be taken over ND-COSMOS. Incremental backup may be taken. Individual documents may be recovered from a running backup database.
