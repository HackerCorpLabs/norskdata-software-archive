# ND 10073 Indexed Sequential Access Method (ISAM)

## INTRODUCTION

ISAM – Indexed Sequential Access Method – is a disk storage and retrieval of data. It may be used from FORTRAN and PLANC. As for COBOL, see «FEATURES».

Records may be retrieved by the aid of an index or in sequential order. ISAM is call-oriented, which means that ISAM services are performed by calling routines from the ISAM library.

The ISAM file is located on two SINTRAN files, the index part on one file, the data part on another.

## FEATURES

- Available in an upgraded version of COBOL’s indexed organized I/O system.
- Background oriented system
- Record identifier (key) is contained within the record
- Total number of keys may be as large as 6. All may have duplicates
- Maximum number of records 2²⁴ (i.e. no practical limitation)
- Fixed or variable record length
- Design is based on the ANSI-74 COBOL standard
- May be run in three different modi:
  - Single-user buffered input, immediate output
  - Single-user buffered I/O
  - Multi-user buffered input, immediate output
- One of the most advanced and progressive ISAM systems available

## PRODUCT DESCRIPTION

ISAM consists of 4 modules:
- ISAM library (ISAM-LIBRARY)
- ISAM service program (ISAM-SERVICE)
- ISAM interactive (ISAM-INTER)
- ISAM multi-user supervisor (ISAMRT)

The **ISAM library** contains all ISAM routines. ISAM library is to be loaded together with the user’s application.

The **ISAM service program** is a user-friendly interactive program including the following service functions:
- Verify the consistency of an ISAM file
- Unload/load an existing ISAM file
- Estimate the size of the index part of the ISAM file
- Change multi-user information contained in ISAM multi-user supervisor

The **ISAM interactive** is a user-friendly program to assist users in the easy manipulation of ISAM files. This means that data can be stored/retrieved interactively without writing special programs. All the ISAM library routines are available.

The **ISAM multi-user supervisor** is an RT program supervising an ISAM process, i.e. it resolves the currency problems that arise when several programs access the same ISAM files concurrently.

There is no need for logging or reprocessing facilities due to immediate output.
