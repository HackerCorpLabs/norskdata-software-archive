# ND 10177 ND COBOL - 500

## INTRODUCTION

The COBOL programming language is the industry-wide accepted high-level computer language oriented towards data processing tasks often found in business applications.

ND COBOL — 500 handles data types for

- **binary PICTURE 9 (n) COMPUTATIONAL**
  - range -32768 to +32767 where n < 5
  - range -2147483648 to +2147483647 where n ≥ 5

- **If PICTURE 9 (n) is not specified, COMPUTATIONAL is double binary**

- **packed decimal (COMPUTATIONAL-3)**
  - up to 18 digits

- **REAL (COMPUTATIONAL-2) external decimal (DISPLAY)**
  - up to 18 digits

- **report edited**

- **alphanumeric**
  - up to 18 digits plus edit characters
  - up to 32767 characters

## PRODUCT DESCRIPTION

The COBOL compiler conforms to the ANSI-74 COBOL standard as defined in American National Standards Programming Language COBOL, ANSI X3.23-1974 Level One. It contains many extensions from Level Two, thus providing large-scale business data processing capabilities to the mini-computer world.

It includes the following "modules" at level and extensions specified:

| NUCLEUS                  | TABLE HANDLING           |
|--------------------------|--------------------------|
| SEQUENTIAL I/O           | LIBRARY                  |
| RELATIVE I/O             | INTER-PROGRAM COMMUNICATION |
| INDEXED I/O              | SORT                     |
|                          | DEBUGGING                |

NUCLEUS at Level One, with many selections from Level Two. Among others:
- Levels 77, 01-49, 88
- 88-level condition names, with value series or range of conditions
- Conditional operators AND, NOT, OR, =, <, >, in conditions
- Procedure names consisting of digits only
- COMPUTE-verb with multiple receiving fields
- ADD, SUBTRACT, MULTIPLY, DIVIDE-verbs with multiple receiving fields
- DIVIDE-verb with REMAINDER
- PERFORM-verb with three indexes
- Qualification of names
- Sign and IS class tests
- Nested IF-statements, parenthesized conditions, abbreviated conditions, implied subject and/or relation
- Nested conditions
- ACCEPT-verb with DATE/DAY/TIME/CPU-TIME clauses
- INSPECT, STRING and UNSTRING-verbs

TABLE HANDLING at full Level One, and
- SEARCH-verb, format 1, format 2
- Relative indexing

INPUT/OUTPUT for Sequential, Relative and Indexed access organizations at Level One, with the following selections from Level Two:
- Multiple operands in OPEN and CLOSE-verbs, with individual options per file
- DYNAMIC access mode (READ NEXT)
- START-verb with/without key relations EQUAL, GREATER or NOT LESS
- Up to 5 alternate keys

Library module with Copy-verb at all divisions and sections.

Inter-Program Communication module with Linkage Section, Using-clause in Procedure Division, and Call-verb with Using-clause.

# Interactive Debugging

The ND COBOL system provides the user with a number of debug options indispensable to efficient program development. When the command DEBUG is entered prior to program compilation, the user can choose between a number of debug options during subsequent execution of the program.

The options that can be invoked in DEBUG-MODE are:

- HELP — List available DEBUG options
- BREAK-ADDRESS
- BREAK-RETURN
- ACTIVE-ROUTINES
- ALIGN-LISTING
- CHECK-OUT-MODE
- COMPARE-DATA
- COMPARE-PROGRAM
- DUMP-LOG
- FIND-SCOPE
- GUARD
- LOG-LINES
- LOG-CALLS
- DISPLAY variable
- EXIT — Exit to operating system
- STEP — Execute next statement in logical sequence
- RUN — Commence program execution
- LOOK-AT-DATA
- LOOK-AT-PROGRAM
- LOOK-AT-REGISTER
- LOOK-AT-STACK
- MACRO
- RESET-BREAKS

...and others.

One or more options may be active during program execution. Cross-reference list available.

The COBOL Compiler produces object code in the NRF format which is suitable for linking to the COBOL runtime system routines and separately compiled COBOL, FORTRAN, PLANC, or assembly program modules.

The LINKAGE LOADER is used to build executable programs from user program modules and to link to the necessary system run-time and library routines.

# Database Management

The inter-program communication module allows COBOL programs to interface with the advanced SIBAS Database Management System through the Call-verb. The SIBAS DBM system is designed for multi-user, on-line terminal applications in business environments with complex information structures.
