# Micrografx Graph Plus

## Introduction

Graph Plus is a program for making business charts - line, bar, area, pie, etc. The charts are generated from tables which either can be imported from other applications or entered manually.

Graph Plus is intended for users who work with numbers and want to make attractive charts for presentation purposes. Graph Plus is also a valuable tool when used together with NOTIS-PET and/or MICROGRAFX Designer for making good-looking reports, newsletters, publications, etc.

## Product Description

Graph Plus has a very low user threshold. It is easy for the beginner to start using Graph Plus and get the charts he wants. In addition, Graph Plus has many powerful functions that will help the expert in making the right chart.

There are no predefined areas, borders, limits, etc. in Graph Plus. This means that you can place the chart exactly where you want to. You can use images or drawings as backgrounds, draw extra borders, lines, text, etc. All this makes Graph Plus very powerful. You will be able to avoid producing stereotyped charts — it is easy to give them a personal layout.

Any graphic element can be freely edited in Graph Plus. You can point to one specific bar and change its colour, the width of its border line, the pattern it is filled with, etc. You control the whole chart in detail, and therefore you can make charts of very high quality. There is a wide range of fonts available, and you can mix your own colours to get exactly the tone you want.

Graph Plus can print its output on the wide range of printers and plotters supported by MS-WINDOWS. It is also possible to produce output to a camera for slide production.

# Micrografx Graph Plus

## Features

### Data entry/manipulation

- Graph Plus has an Excel-like worksheet for handling data tables. The worksheet can contain several tables, and a table must be marked to be used in a chart.
- There are several functions for editing the tables. These are cut & paste of rows/columns/areas, scaling of the whole worksheet, sorting, etc.
- Graph Plus can import data from many other applications. It has several import filters for other file formats, and it can read data from the Clipboard.

### Graphics

- Graph Plus offers different chart types: Area, Bar, Column, Line, Pie, Scatter and Table. It will show several different layouts of each chart type and ask you to select one of them.
- The drawing functions in Graph Plus are very powerful. The basic drawing functions from Designer are also present here, and it has also other drawing-related functions (smoothing, combining symbols, etc.)
- Graph Plus lets you scale the chart just as you like, place charts on top of each other, draw backgrounds, place texts, use additional illustrations, etc.

## Output

- Graph Plus can produce output on a wide range of ND printers, as well as a large number of additional ones supported by MS-WINDOWS.
- Charts and illustrations made in Graph Plus can be used in NOTIS-PET publications or imported into Designer for further work.

## Integration

- **Data input:**
  - Excel: Several file formats
  - Lotus 1-2-3, Symphony: Several file formats
  - Multiplan: SLK file format
  - NOTIS-WP, NOTIS-RG, NOTIS-CALC: 7-bits ASCII file (values separated by comma or space)
  - VisiCalc, dBase III: DIF file format
  
- **Graphics input:**
  - Designer: File formats and Clipboard
  - Excel: Clipboard
  - NOTIS-PET: .PIC file format and Clipboard
  - Scanned-in images: Clipboard

- **Graphics output:**
  - Designer: File formats and Clipboard
  - NOTIS-PET: .PIC file format and Clipboard

## Prerequisites

The following products are needed in order to run Graph Plus:

- OWS-12 (ND-150003) or 
- OWS-55 (ND-110356) or 
- OWS-85 (ND-110357) (or true compatibles)
- MS-DOS 3.10 or higher (included on OWS-12/55/85)
- MS-WINDOWS 2.03 or higher (included on OWS-55/85)

In order to produce hardcopy output, a printer is needed. The following ND printers can be used (connected to the workstation):

| ND 730 Page printer      | ND-110224|
| Epson personal printers  |          |

Graph Plus can also produce output on many other printers if they are supported by MS-WINDOWS.
