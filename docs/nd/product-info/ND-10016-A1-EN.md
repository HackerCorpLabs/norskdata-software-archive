# ND 10016 ND IDT 3270 Emulator

## INTRODUCTION

The Remote Job Entry approach to data processing offers several significant advantages. Without having to incur large capital outlays, an RJE terminal user may share the processing power of a host mainframe computer and gain access to centrally stored programs and data.

The ND IDT 3270 Emulator is specifically designed for remote job entry to IBM 3270 systems. It provides a range of options that afford the user the freedom of configuring the RJE terminal in accordance with particular applications and functional requirements.

With several years of experience in the field, NORSK DATA can offer RJE terminals for all major makes of mainframes, from simple core-only configurations to multiple remote operation systems with elaborate spooling facilities.

## FEATURES

- Up to 32 users may have simultaneous access to a program system residing in a central site (host) computer
- The user may switch between local background and 3270 processing
- From a remote ND computer the user may connect the terminal to the Emulator residing in a local ND computer
- A variety of display types, hard copy terminals and line printers may be handled by the Emulator
- A physical device may be replaced by internal devices in order to let a local application program handle the transaction processing
- An Emulator Service Program is implemented to obtain system status reports and to change the emulator configuration whenever needed
- A line trace facility is available to debug the communication line

## PRODUCT DESCRIPTION

ND IDT 3270 Emulator is a multidrop terminal system for on-line transaction processing to a remote computer capable of handling a 3270 terminal system.

Implementation of the ND IDT 3270 Emulator is done according to the specifications set forth in the manual: IBM 3270 Information Display System. Component Description. However, the 3270 Card Reader, light pen and the 3275 display unit are not emulated.

NORD-10 or ND-100 computers, with the SINTRAN III operating system and the ND IDT 3270 Emulator, provide the necessary tools.

```
+---------------------------------------------------+
|                       Mainframe                   |
|                          |                        |
|      +-------------------+----------------+       |
|      |            SNA Branch              |       |
|      |                |                   |       |
|      |       SNA KAN HUB 1                |       |
|      |                |                   |       |
|      +----------------+-------------------+       |
|                          | Terminals and          |
|                          | Line Printer Interfaces|
+---------------------------------------------------+
```

An emulator device may be a:

- TDV-2000, TDV-2115, VISTA, INFOTON-200, TDV-2215 if set in 2115 mode, hard copy terminal, or a line printer with or without spooling.

The emulator may handle up to 32 devices simultaneously. Within this limit, there is no restriction in the number of line printers and different terminal types.

# Requirements

Each device requires:

| Component      | Requirement |
|----------------|-------------|
| a buffer area  | 1.00 Kw     |
| a data field   | 0.08 Kw     |

Device independent:

| Component               | Requirement |
|-------------------------|-------------|
| reentrant code          | 7.50 Kw     |
| emulator service program| 4.00 Kw     |
| line trace buffer       | 4.00 Kw     |

KW = words, word length is 2 bytes.

## Interfaces:

In addition to terminal interfaces, etc., a binary synchronous modem interface is required.

## Modem:

A synchronous modem with suitable speed, maximum 9600 bits per second, is needed. A synchronous modem simulator may be used for local lines.
