# NDIX

## INTRODUCTION

NDIX is ND's complete implementation of the Berkeley 4.2BSD UNIX™ system for ND-500 series computers. NDIX provides the standard 4.2BSD environment and full source code compatibility at the system call level. The implementation of NDIX fully utilizes the hardware architecture with its demand paged, virtual memory management system. NDIX also incorporates utilities from System V, which facilitates the porting of applications onto NDIX.

In addition to 4.2BSD networking and communication capabilities, NDIX includes a gateway to SINTRAN (ND's proprietary Operating System). Thus, users are provided benefits of the world of UNIX and SINTRAN. The implementation of NDIX allows for running of SINTRAN concurrently in the ND-500 system. The result of this implementation approach is to provide a certain number of users the possibility of running SINTRAN applications while the rest of the users run NDIX applications. Therefore, NDIX is the enhanced system which provides more than just UNIX.

# NDIX

## PRODUCT DESCRIPTION

The NDIX package consists of the kernel, compilers, application tools, communication systems, and the SINTRAN operating system.

NDIX runs on ND-500 computer systems (Series II). An ND-500 computer systems comprise an ND-100 (16-bit) CPU and an ND-500 (32-bit) CPU. The NDIX kernel runs in the ND-500 CPU while the SINTRAN runs in the ND-100 CPU.

A software interface has been defined between the two operating systems. This interface utilizes the inter-machine monitor call feature of the ND-500 system architecture. The NDIX kernel is the master operating system and uses SINTRAN in the ND-100 CPU as an Input/Output handler. A set of interrupt contexts with specified priority have been defined to take care of the I/O interrupts between the two CPUs.

```plaintext
  +-------------+
  |   NDIX      |<-------------------+ 
  +-------------+                    |
                                     |
┌───────────────┐            +--------------------+
│ ND-500 CPU    |------------>|      SINTRAN      |
└───────────────┘            +--------------------+
                                     ^
                                     |
                            +-----------------+
                            |   I/O Drivers   |
                            +-----------------+
                           Structure of the NDIX and the SINTRAN in the
                           ND-500 computer system
```

The NDIX user process address space is divided into two segments, one for code and one for data. Memory is allocated to each segment in chunks of 2 KB. In NDIX, the virtual memory support of 4.2BSD has been optimized to take full advantage of the ND-500 architecture.

The physical multi-port memory of up to 256 MB can be shared between the two processors. A private memory for the ND-100 CPU is required. The extent of physical memory and other configuration information is passed to the NDIX system via a special initialization monitor call.
