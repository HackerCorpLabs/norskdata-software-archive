# NOTIS-DE

## Introduction

NOTIS-DE, data entry, is a very simple system for entering and maintaining small data registers such as telephone lists, address lists, or customer registers. The user produces a form in NOTIS-WP, with fields for the desired data: Name, address, customer codes etc. NOTIS-DE uses this form to enter and modify new data or to fetch/select information previously stored. NOTIS-DE is based on the use of regular NOTIS-WP text files, meaning that all data produced, and used by NOTIS-DE, is stored in a 'flat' file format. The data-entry program is very easy to learn and simple in use, and is supported by extensive online HELP information.

## Features

- Forms for input/output are easily produced with NOTIS-WP

- Existing WP files containing lists may easily be adapted and run against NOTIS-DE, and viewed on the screen with the forms previously created

- Simple search possibilities

- Efficient in use with NOTIS-TF (text formatter), for production of standard letters, memos, etc.

# NOTIS-DE

![Photo: Person working at a desk with a computer and papers](image-url)

## Product Description

Producing small registers with NOTIS-DE is easily done, in two steps: First you define the form layout containing the desired fields in NOTIS-WP, and store it. Then you call up NOTIS-DE and start entering your records. The file containing the form is stored as a form file (.DEFM file) separately from the records which are stored in a data file (.DEDA file). The next time you want to access your records, therefore, you must specify both the form file and the data file when you start working with NOTIS-DE.

## Prerequisites

- ND 210518 User Environment
- ND 210079 / ND 210526 NOTIS-WP
