# ND 10152 NOTIS-IR
## Information Storage and Retrieval Module

### INTRODUCTION

NOTIS-IR is a powerful, general tool for handling textual information. It is general in that it is not tailored to any particular application, but addresses all applications concerned with the storage and retrieval of documents. NOTIS-IR is powerful in that it is constructed in such a manner that document retrieval is fast, even when searching for information stored within a large archive. 

NOTIS-IR was developed as a cooperative enterprise between Norsk Data and The Norwegian Government's Institution for Organisation and Management under the SISU project.

### AREAS OF USE

- Abstract archive.
- Library records.
- Report archive.
- Personnel archive.
- Service records.
- Newspaper/Magazine cuttings.
- Catalogues.
- Plant and assets register.
- Accident & Safety regulations.
- Legal data.
- Correspondence archive.
- And many more.

### FUNCTIONS

- Define, Modify and Delete Forms.
- Enter, Modify and Delete Documents.
- Search within a given form or entire archive.
- Various auxiliary functions.

### FEATURES

- Query-by-example- easy to learn document retrieval.
- Retrieval of documents by key value or by content.
- Easy to use for occasional users.
- Powerful document editor.
- User designed forms.
- Interactive.

- Report Generator.
- HELP function.
- Documents created by NOTIS-WP Word Processor may be entered automatically.
- Entire information base, i.e. all archives, may be searched using search language.
- Security features:
  - Password protection against unauthorised access.
  - Consistency checking.
  - Logging.
  - Recovery.
- COMMON word list.
- Local language commands and HELP.

### PRODUCT SUMMARY

Data is entered using FORMS created by the user. The forms are created interactively using NOTIS-IR's powerful screen editor. Each field may have leading text. KEY fields are of predefined fixed length. TEXT fields are dynamic and of variable length.

Information is entered via forms, or may be created using the NOTIS-WP Word Processor, and then sent to NOTIS-IR. When using a form, the powerful NOTIS editor is used to create/modify text.

Documents are normally retrieved using the «Query-by-example»-like user interface. The searcher supplies sufficient information to define the document(s) required, using a form identical to that used to store the documents. If information is supplied to any text field, then all text fields in all documents stored using the particular form are searched.

### COMMON WORDS

Since the dictionary compiled by NOTIS-IR is an index over every word in every document, its size may become very large. There are a number of words in any language which are uninteresting when searching. These are common words like: if, the, and, or, then, etc. Such words are termed COMMON words. A list of these may be compiled and entered to NOTIS-IR. NOTIS-IR will then no longer reference these words in its dictionary, although of course they will remain in the documents. The size of NOTIS-IR's dictionary file may be reduced by around 30% if a suitable COMMON word list is compiled.

# REPORT GENERATOR

The NOTIS-IR Report Generator allows users to select information from the stored documents and create reports. The reports generated may be further processed using the NOTIS-WP Word Processor.

The format of a report is created in the same manner as an input form for documents. That is, the user creates a frame for the document interactively from her/his terminal.

- Documents selected by ~Query-by-example~ like search or using search language.
- Fields may be rearranged for a report.
- On-line, interactive report definition.
- Tabular output.
- Sorting of up to 5 fields.
- Output to terminal, printer or file.
- Automatic page numbering.
- Reports may be edited directly using NOTIS-WP.
- Title text may be supplied at the time the report is generated.

# System Specifications

- NOTIS-IR may be run on NORSK DATA's ND-100 range of computers under the SINTRAN III/VS operating system.
- A database may contain any number of different archives, each associated with a single input form.
- Each archive may contain any number of documents.
- «Query-by-example» searches using the input form search within an archive.
- Searches using the search language, search the entire database.
- Any number of databases may be constructed.
- Each document may have from 60–70 KEY and TEXT fields, and may be up to 200 lines long.
- Documents are entered into a queue of «Today's Documents». These documents are available for searching after an UPDATE program has been run. This program enters the documents to the NOTIS-IR system, creates the necessary dictionary information, prints out statistics, etc.
- Number of documents stored is only limited by storage capacity.
- A single query may result in a maximum of 6000 documents.
