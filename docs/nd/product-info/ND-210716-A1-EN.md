# NOTIS-CALC

## Introduction

NOTIS-CALC version E is a spreadsheet program, one of many products in Norsk Data's integrated office support system NOTIS. NOTIS-CALC is suitable for the rapid development and maintenance of budgets, simulations, forecasts, financial models and many other applications.

The NOTIS-CALC spreadsheet is based on the worksheet concept. It is a two-dimensional matrix with 100 columns and 500 rows. The intersection of each row and column is called a cell, and there are 50000 cells in one spreadsheet. Additional space is available, as NOTIS-CALC can operate on an unlimited number of worksheets simultaneously.

Each cell may contain a maximum of 60 characters of text or an expression of up to 120 characters. An expression may contain numbers, arithmetical operators, references to other cells, functions, or any combination of these.

There are five types of functions in NOTIS-CALC: Mathematical, Trigonometric, Statistical, Logic and Lookup and Financial. These are all listed below.

The new menu-oriented user interface simplifies the operation of NOTIS-CALC and matches the needs of both demanding as well as less demanding users. A NOTIS-CALC user in need of help can consult the hierarchically structured online HELP information.

Some of the new features available in the current version of NOTIS-CALC are:

- Larger worksheet: 100 columns and 500 rows
- Command menu
- Cutting and pasting between NOTIS-CALC, NOTIS-WP and NOTIS-BG
- Context switching between NOTIS-CALC, NOTIS-WP and NOTIS-BG
- Automatic reading of text files
- Regions
- Import "stacking"
- Freezing row and column
- Longer expressions (120 characters)
- Use of NOTIS-D document storage
- Use of SPRINT Spooling System for better printer control
- NOTIS-ID mail message status
- Trigonometric and logarithmic functions

## Features

### General

- Command menu. Command selected by moving through a two-level command menu or by typing the first letter of the command.
- NOTIS-CALC uses the same command-menu conventions as other ND-NOTIS products, insofar as these are applicable.
- PRINT uses the SPRINT spooling system to direct printout to one of the defined printers. Forms defined in SPRINT can be used to choose the format of printouts from NOTIS-CALC.
- National language keyboard and language versions. Easy to install several languages on the same computer.
- Hierarchically structured HELP facility. Specific information may also be accessed directly.
- Audible warning on illegal input.
- Processing of spreadsheets resident on other computers via the ND COSMOS network.

## Integration

- Areas and cells may be EXPORTED from one sheet and IMPORTED by another. Only the values of areas/cells are imported from their worksheets when the importing sheet is read.
- Text files may be connected to a worksheet and read in automatically with the worksheet.
- NOTIS-CALC can call NOTIS-BG from the menu. Clippings generated in NOTIS-CALC can be read in NOTIS-BG to make pie, bar, column or line charts. NOTIS-BG may draw these charts on NOTIS terminals with graphics option.
- Data from other ND products such as ACCESS, NOTIS-WP and NOTIS-RG may be read. Any file written in ASCII may be read.
- Clippings generated in other ND-NOTIS products may be used in NOTIS-CALC, and vice versa.
- The whole sheet or parts of a sheet may be written out in standard ASCII. Such files may be read by other ND-NOTIS products such as NOTIS-WP, NOTIS-BG, NOTIS-IR, NOTIS-RG and ACCESS.

## Worksheet

- Individual adjustment of column widths: up to 74 characters per column.
- Pre- and post-justification of both Text and Numeric cell contents: right, left and centre.
- Pre- and post-adjustment of the number of decimal positions displayed: any area may have between 0 and 14 decimal positions.
- Pre- and post-formatting of the numeric presentation: commercial, European, scientific, percent or normal.
- Insertion and deletion of up to 9 rows or columns simultaneously.
- Text in a cell may be up to 60 characters long. It will be displayed as long as the cells to the right are unoccupied.
- Worksheet size is 100 columns by 500 rows.
- An unlimited number of regions, each region containing one worksheet, may be present in memory and processed simultaneously.
- Cells and areas of cells may be LOCKED, i.e., protected from deletion, alteration and overwriting.

## Content

- Each cell may contain text or an expression consisting of numbers, functions and cell references.
- Comprehensive arithmetic facilities: addition, subtraction, area summation, multiplication and division.
- Comprehensive financial functions: Annuity, Future Value, Present Value, Net Present Value and Internal Rate of Return.
- General statistical functions such as mean, standard deviation and exponentiation.
- Both relative and absolute references may be made to individual cells and areas.
- Repeat function to fill a single cell or an area with the same character.
- Calculations with 14 digits.
- Two-dimensional table lookup: both horizontal and vertical tables.
- IF function.

## Navigation/Manipulation

- Comprehensive manipulation of cells and areas: single keys for COPY, MOVE and DELETE.
- Cursor movement using arrow, scrolling, tabulation, end of line, start of line and keys. The "go-to" command moves the cursor directly to a given cell.
- The cursor movement can be set on or off. When on, the cursor will move automatically in the most recently used direction after one entry.
- The current cursor coordinates may be transferred into a formula using the FIELD key; for area coordinates, use the PARA key.

## Numeric Precision

NOTIS-CALC-E uses 8-byte floating-point arithmetic. This provides 16 significant figures and a numeric range of approximately 10E-76 to 10E + 75.

If too many decimals are shown, results may look imprecise. All numbers are rounded on output.

## Table Functions

- Horizontal Lookup
  - `#HTL(index value, area, offset)`
- Vertical Lookup
  - `#VTL(index value, area, offset)`

These two functions are for choosing elements from a table. HTL performs a lookup in a horizontal table, VTL in a vertical one. The first row (HTL) or column (VTL) consists of values to be compared with the index value. The result is found by finding the first value in the first row of the defined area (HTL), or first column (VTL), which is less than or equal to the index value. The offset value tells how many rows/columns in the result row/column is offset from the first. The values in the ‘index’ column must be in ascending order. For example:

```
   A   B   C   D
  ----------------
   5   1   3   5   7
   6  12  45  78  34
  46  79  32  13 
```

```
#HTL(2,A5:D7,1) = 12      #VTL(1,A5:D7,2) = 5
#HTL(5,A5:D7) = 32        #VTL(56,A5:D7,1) = 78
```

## Import/Export

Data in worksheets can easily be utilised by other worksheets through the IMPORT/EXPORT feature. The worksheet(s) to export areas of data to other worksheets must declare an export for each area to be exported. The worksheets that are to use this data must define imports. One or more imports may be read into the same area. Overlapping imports will be added up, cell by cell. When an import is deleted it will be subtracted from the worksheet. Cells with text will take the value zero.

## Requirements

- NOTIS-CALC version E may be used on ND-500 and ND-5000 computers.
- A scratch file on user SCRATCH is used to store parts of the worksheet and clippings. An expanding worksheet will demand free space on user SCRATCH.
- NOTIS-CALC is about 285 pages long.
- NOTIS-CALC requires the DDBTABLES-G03:VTM version of Virtual Terminal Manager tables.
- The standard error message file UE-ERMSG-EN-C06:ERR will be used.
