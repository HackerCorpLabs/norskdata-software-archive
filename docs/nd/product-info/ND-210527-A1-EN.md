# NOTIS-IR (Information Retrieval)

NOTIS-IR (Information Retrieval) is a general tool for fast and flexible retrieval of recorded information about stored text documents. It is intended to solve the needs of medium to large companies, libraries, publishers and others who need quick retrieval of information about cases and events. Another important area of use is continuous and systematic recording of letters, offering the user an easy way of keeping track of correspondence.

The information is entered as key fields or free text on fill-in forms. The user can choose to store key information only, or include the document itself in the archive.

The simplest way of retrieving stored information is by filling in a search form. This technique is flexible enough for most users, but a sophisticated search language is also available. The user can design tailored forms according to the specific needs of the business.

NOTIS-IR also contains a powerful word processor function.

## Features

### General Features

- Simple document entry and retrieval
- Greek, graphic and mathematical characters
- A wide range of accented characters
- NOTIS-WP documents may be automatically transferred to NOTIS-IR
- Values, such as dates, may be defined for automatic generation

### Search Features

- Searching is fast, even in large databases
- Alternative methods: Easy form-filling or advanced search language
- Both these methods offer search operators such as AND, OR and NOT
- You may retrieve a document by specifying a word contained in it
- You may search using the first part of a word
- You may define equivalent words as synonyms for searching

### Database Administration and Security Features

- Online logging of database changes
- On the event of a hardware failure, all data may be recovered
- Test function for checking that the database is in order
- Simple utilities for maintenance database

# NOTIS-IR (Information Retrieval)

## Product Description

### Functions

- Define, modify and delete forms
- Enter, modify and delete documents
- Search within given archive or entire database
- Document and report printout

Data is entered in FORMS created by the user. The forms are created interactively, using NOTIS-IR screen editor. Each field may have a label. KEY fields have a predefined fixed length. TEXT fields are dynamic and of variable length.

Documents are normally retrieved using the "Query by example"-type user interface. The user supplies sufficient information to define the document(s) required, on a form identical to that used when storing the documents. If information about one text field is supplied, then all text fields in all documents are searched.

### Areas of Use

- Reports
- Correspondence log
- Catalogues
- Personnel records
- Newspaper cuttings
- Regulations and legal data

## Report Generator

The NOTIS-IR Report Generator allows users to select information from the documents stored, and create reports. The reports generated may be further processed using the NOTIS-VP Text Editor.

- Online, interactive report definition
- Fields may be rearranged for a report
- Sorting of up to five fields in ascending or descending sequence
- Output to terminal, printer or file
- Title text may be supplied at the time the report is generated
- It is possible to report from all documents, or from a set of documents found in a search

## System Specifications

- NOTIS-IR may be run on NORSK DATA'S ND 100 and ND-500 computers under the SINTRAN III operating system.
- A database may contain up to 70 different archives, each associated with a single input form.
- Each archive may contain any number of documents.
- Any number of databases may be constructed.
- Each document may have up to 50 KEY and TEXT fields.
- Documents are entered into a queue of "Today's Documents". These documents are available for searching after an UPDATE program has been run. This program indexes each document, and prints out statistics.
- The number of documents stored in one database is limited only by disk capacity.
- Maximum document size is 32,000 lines for each document.
