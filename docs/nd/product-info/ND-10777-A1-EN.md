# ND 10777 IBM 2780/3780-II Emulator

## Introduction

This software product is made for file transfers between ND computers and computers from any other manufacturer. Both computers must support at least one of the IBM binary synchronous communication (BSC) protocols 2770, 2780 or 3780. Such emulators are more or less standard for almost any computer on the market today.

The ND 10777 IBM 2780/3780-II Emulator is specifically designed for Remote Job Entry to IBM 360/370 systems and Sperry mainframes. It provides for general file transfer between different computer systems, and between two ND computers with terminal interface. It is also designed for interactive use with special applications programs.

## Features

- Text conversion from other text processing systems (Wang, Xerox, IBM, etc.) to NOTIS or Nortext, and vice versa
- Communication with Postgiro and Bankgiro (for Scandinavia)
- Space compression/expansion
- Supported protocols: IBM 2770, 2780, 3780
- Transmission rates from 1200 to 9600 bps
- Normal text transmission (non-transparent or transparent)
- Communication via private or dial-up lines
- Comprehensive repertoire of both local and remote commands
- Error correction and retransmission
- Support for easy character conversion by editing translation tables
- Status information and parameter setting from any terminal
- Facilities for automatic generation of file names for received data
- Support for asynchronous transmission (normal terminal line)

### Optional Features

- Automatic Data Transmission Scanners for sending files to a number of other systems after normal working hours
- Interchangeable slave/master status between ND and other computer types
- MASTER option allowing the remote computer to run batch jobs on the ND computer with print-results automatically directed back to the remote site
- Optional library routines for program control of most of the functions in the emulator

## Product Description

The IBM 2780/3780-II Emulator is a software system that runs on the ND-100 and ND-500 computers with SINTRAN III/VS operating system.

The software package consists of one real-time program, and a background program for operator control. With a high degree of modularity designed into the software, bottlenecks related to slow peripherals are circumvented in the system.

## Command Summary

The command repertoire for the IBM 2780/3780-II Emulator has been developed with the following objectives in mind:

- To simplify operation of the terminal
- To ensure a continuous job-flow
- To improve operator overview
- To maintain high throughput

All commands, such as requests for status information, etc., can be entered via the operator console. Likewise, messages and acknowledgements from the system are also routed to the console, providing smooth and uninterrupted operation of the terminal while boosting terminal throughput.

# Sample Commands

The following list contains a few sample commands:

- **TRANSFER-FILE**
  - puts files in transmission queue
- **SEND-FILE**
  - puts files in transmission queue
- **LIST-ENTRY**
  - lists all entries in the remote queue
- **LIST-REMOTE-QUEUE**
  - lists the remote queue
- **PREFIX-IN**
  - defines the prefix to be used in received text
- **COMPRESS ON**
  - compresses contiguous spaces into a two-character sequence
- **COMPILE-TABLE**
  - checks and converts the source translation table to a binary translation table
- **LOG-TRANSMISSION**
  - switches the transmission log on or off
- **START-TRANSMISSION**
  - starts the transmission of files in the remote queue
- **STATUS**
  - gives the status of the communication (number of retransmitted blocks, timeout, mode)
- **TERMINATE**
  - terminates communication and closes the files
- **ASSIGN-OUTPUT-FILE**
  - defines the naming rules for received files

# Requirements

THE ND 10777 IBM 2780/3780-II Emulator requires:
- ND 730 HDLC Interface (with synchronous modem driver), or
- ND 701 Synchronous Modem Controller
  - 1 segment
  - 1 RT-program
  - 1 internal device/line

Prerequisite:
- ND 10048 SINTRAN III version H or later
