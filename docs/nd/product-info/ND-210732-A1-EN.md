## INTRODUCTION

Telex has been widely used for several decades, and is now available to more than 1 million subscribers in approximately 190 countries. The international network is very reliable, and very stable. The main constraints are the slow transmission speed (50 baud or 7-8 characters/second) and the limited character set.

These constraints dictate the use of the message transfer system. The average Telex message is 70 words long, equivalent to 1 minute transmission time.

International organizations are the dominant users of Telex. Amongst such organizations there is a widespread need for greater integration of the Telex service with word processing systems.

ND Telex makes use of the functionality provided by a Telex/computer interface unit together with a software package, to allow any user on an ND computer to send a Telex message from any terminal to any subscriber on the international Telex network.

## FEATURES

- Integrated with NOTIS WP Word Processing System
- Telex messages are sent via a queuing system
- Journal (log) of status for messages sent/received/aborted
- Abbreviation codes can be defined for single or multiple Telex numbers
- Up to 9 Telex lines can be handled
- Dialogue possibility both for "outgoing" and "incoming" Telex messages
- Powerful service program for Telex supervisor and support. A DIAGNOSTIC command in service program will be useful in locating errors in Telex system and HASLER TELEX UNIT
- Possibility of specifying accounts and password to avoid unauthorized use of the Telex system
- Retry procedures if errors occur
- Sending can be done from any machine in a Cosmos network using the Telex Remote User Module (ND 210918)
- Priority, time for sending and account are optional parameters
- Combined ease-of-use and flexibility

# Product Description

ND Telex is a product for sending and receiving telex messages directly from an ND computer system.

With the ND Telex program, you can send documents created in NOTIS-WP Word Processing System. All you need to specify is the telex number or abbreviation code.

Hard-copy printouts of incoming and outgoing telex messages can be directed to a specified printer.

The JOURNAL lists compact information about the final status for messages sent or received. You can also get more detailed information about a specific message.

A STATUS command will list the current status for messages being sent or waiting to be sent. It is possible to stop messages being sent or remove waiting messages from the queue.

Abbreviation codes are a type of shorthand method of entering telex numbers. They may be used instead of telex numbers. One abbreviation code can reference up to 30 different telex numbers. Abbreviation codes are stored in a normal text file, and can be maintained by using NOTIS-WP or updated directly from the Telex program. The abbreviation of codes can be done from the Telex program.

Detailed HELP information is available at any time when you use ND Telex.

## ND Telex Consists of Three Components:

- **An interactive menu-driven command program** which communicates with the ND TELEX communications component by means of 2 SINTRAN internal devices.

- **Four real-time programs for communication** (number increases by one for each telex line connected).

- **A service program for maintaining the telex system.**

# Hasler Telex-To-Computer Interface Unit

- The HASLER TELEX UNIT is connected to the computer as an RS-232C line interface.

- The HASLER TELEX UNIT has to be approved by the national telecommunications authorities.

Connecting a baudot printer to the HASLER TELEX UNIT is recommended for printing incoming and outgoing telex messages. There are two printer possibilities: HASLER OKI baudot printer and COMSCRIBE from TRANSTEL.

# Requirements

- A NORSK DATA computer system running SINTRAN Version I or later.
- ND 210709 NOTIS-WP Word Processing System (version L or later).
- Two internal devices in SINTRAN.
- One semaphore in SINTRAN.
- Space for saving received and sent telex messages on two SINTRAN users.
- V.21 Telex line (in Norway and some other countries).
- Cable between ND-100 machine and the HASLER TELEX UNIT.
- Less than 15 meters: cable - 325618.
- More than 15 meters: cable - 325456 plus two local modems (ND 2107500 or ND 2107520).
- An OKI baudot printer or COMSCRIBE (TRANSTEL) baudot printer is recommended.
- Telex Remote User Module (ND 210918) requires basic ND Telex system (ND 210732), COSMOS between systems and remote file access to machine with the basic Telex system.
- HASLER TELEX-To-Computer Interface Unit.
