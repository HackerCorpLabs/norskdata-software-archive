## INTRODUCTION

ND BASIC is a simple and powerful high-level programming language that facilitates problem solving for scientific and educational applications.

BASIC was first developed in 1963/1964 and has since been revised several times. An advantage of BASIC is that its rules of form and grammar are quite simple and easy to learn. It was originally designed as an interactive language, and the user will find it convenient to solve mathematical problems directly from an alphanumeric display terminal or a printing terminal. BASIC can be used by many users in a time-sharing environment, and acts at the same time both as a compiler and as an interpreter.

## FEATURES

- A program, stored in BRF form, may be loaded and executed without the BASIC system in memory.
- Comprehensive facilities for editing program source lines.
- Multiple statements may be put on one line.
- ND BASIC programs can be used with the SINTRAN III Real-Time (RT) System.
- The statement ON ERROR GOTO continues program execution after an RT-error condition occurs.
- Integer, double integer, real and character explicit data types.
- Character arrays of one or two dimensions. Functions to allow the program to access a sub-string, determine the length of a string, convert a character to its corresponding ASCII value, or vice versa, search for a substring within a larger string and manipulate string character variables, e.g. concatenation.
- Use of type declaratement `REAL*` with 48-bit floating point hardware gives high precision accuracy with at least 9 significant digits. This is important for scientific applications.
- A comprehensive set of matrix manipulation functions.
- Ability to dynamically change dimensions of arrays.
- Printed data may be formatted by default formats or in formats specified explicitly by the user.
- Data stored in virtual arrays may be stored permanently on disk, in the same way as files. Virtual string arrays may be treated as random access files.
- Sequential files and random access files.
- The OPEN statement establishes a communication between a SINTRAN III file name and a logical unit device number within the program.
- A number of built-in functions. Extensions to existing set may be created by the user.
- May have independent subprograms like subroutines and functions, the same way as in FORTRAN, with a parameter list. Independently compiled subroutines may be invoked by CALL statements.
- Separately compiled functions or subroutines may be referenced with the EXTERNAL statement.
- Subprograms in FORTRAN, NPL and MAC may be arbitrarily mixed with a BASIC program.
- CHAIN statement to execute separate programs consecutively. May also be used for independently compiled programs which are to use the same data passed via COMMON.
- COMMON statement. Reserves storage areas which can be referenced by more than one program. Use of COMMON avoids disk accessing.
- Access to all facilities of the SINTRAN III system.
