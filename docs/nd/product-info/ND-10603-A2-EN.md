# ND-10603 FILE COMPARE FOR ND-500

## INTRODUCTION

FILE COMPARE is a utility for comparison of two data files. The files may be compared, regardless of data format, or record organization, on mass storage. FILE COMPARE will produce a report which describes in detail the differences between two files.

FILE COMPARE belongs to the set of Software Conversion Tools. The areas of application of this tool include comparison of output from two versions of a program; compare relocatable or even absolute code. While source programs may be compared, the SOURCE COMPARE utility is more appropriate when the source files contain FORTRAN programs.

## FEATURES

- Compares output from execution of a program, against known output.
- Detects any field which has been changed.
- Detects insertion/deletion of one or more blocks.
- Allows user to specify record sizes and terminators.
- Allows user to specify logical partitions of the file.
- Allows user to describe how the data fields are to be interpreted, and how the data is to be presented.
- Allows user to alter parameters to suit the contents of each set of data.

## PRODUCT DESCRIPTION

FILE COMPARE compares two files and outputs a report of the discrepancies found. Each file is treated as a set of Logical Units. The Units may be defined as Line, Source (i.e., program source), Record, Word, Halfword, Byte, Character or Double.

Each field defined may be presented in the output in a specified Display Format. The comparison process continues until two units are found to be unequal. A length may be specified for both a -parallel search- and a -serial search-, which will be carried out to try to find matching units in the files again.

## REQUIREMENTS

- ND-500 Computer System
- SINTRAN III version I or later
