# WinPrint

- **Print from MS-Windows®** programs directly to a network printer
- **Share** expensive printers among many PC users
- **As convenient** as a locally attached printer at a fraction of the cost
- **Access** to multiple printers from the same PC

## WinPrint from Norsk Data

WinPrint is a program that lets you print out files from MS-Windows programs directly on a printer attached to a Norsk Data SINTRAN server. With WinPrint you print your files in exactly the same manner as when you have a locally attached printer.

WinPrint takes care of the rest. WinPrint is designed so that you can start your print job and then continue working with other things while the files are being sent to the printer. In office situations where it is too expensive to have a "private" printer for each user, WinPrint is ideal. You can also change the link to a specific printer at any time, and therefore use many different kinds of printers from the same PC. Any printer defined in your ND server's SPRINT system can be used as if it were local.

WinPrint allows you to do the following:
- Print from MS-Windows applications (like AMI®, Excel® and Aldus PageMaker®, etc) directly to a network printer
- Share expensive printers (i.e., laser printers, colour printers, plotters, etc.) among many users
- Print on any printer defined in your ND server's SPRINT system

## Sharing printers with WinPrint lets you afford high-quality printing!

## Compatibility

WinPrint is compatible with Microsoft Windows/286 and Microsoft Windows/386 version 2.

## System Requirements

- IBM® PC/XT/AT, IBM PS/2, or Microsoft Windows-compatible personal computers
- Microsoft Windows/286 or Microsoft Windows/386 version 2.
- PC Starter Kit (ND 230123), for Ethernet® connection:
  ND Connect Module (ND 230125)
- SINTRAN programs on the ND server required for ND Connect and PC Starter Kit
- ND SPRINT on the ND server (ND 211056)
