# ND 10061 ND UTS-400 Emulator

## INTRODUCTION

The ND UTS-400 Emulator is a set of foreground programs in a NORD-10 or ND-100 computer which makes possible interactive communication with a Univac computer from screens of type Tandberg 2115 or Tandberg 2215, emulating the Univac UTS-400 terminal system. These programs are run under the SINTRAN III/VS operating system.

## FEATURES

- All facilities for receiving, transmitting and editing data. The screen is formatted from a central site, and data are entered from the central site or from the keyboard.
- Control keys may be redefined to adapt to the actual keyboard.
- Screen size is 24 lines long and 80 characters wide, line no. 25 is reserved for local messages.
- Up to 31 terminals on one communication line using a single RID (Remote IDentifier).
- Print output directed to file.
- Local printing of a screen page.
- Special service program to configure the system and for easy generation of the load procedure.
- Dynamic connection of terminals to SIDs (Station IDentifiers) by the service program. Terminals may easily be switched between local and remote processing.
- The service program also has other functions: start-stop communication, configuration report, communication status, display keyboard functions.
- Up to 15 FCC's (Field Control Characters) per line. A standard UTS-400 system has 15 FCC's, which limit the number of fields on each line.
- Received data are displayed on the screen immediately after receipt from the modem. Thus, extra delay is not introduced by the emulator.

## PRODUCT DESCRIPTION

The ND UTS-400 emulator is a set of foreground programs running on a NORD-10 or ND-100 computer under the SINTRAN III/VS system. There is one program for modem line communication, one for request from a background service program and one foreground program (data entry program) for each of the stations (terminals, up to 31).

The UTS service program may be started from any background terminal (also printer terminal). It has the following functions:

1. Connect terminal to UTS cluster. A special station (SID) may be specified, otherwise the first free SID is selected.
2. Communication status (gives number of good and bad records received).
3. Configuration report (gives number of stations, RID's, SID's, segments, program names, modem and connect device numbers, as well as device numbers of any connected terminals).
4. Start communication program.
5. Generate load procedure. Will ask for the following parameters: Number of stations, RID, lower SID, lower segment number, segment file number, user name for BRF-code, modem device number and program priority. The complete load file, UTS-LOAD is generated, ready to be run as a mode file.
6. Stop communication programs.
7. List keyboard functions. Gives the different data entry program functions with the corresponding keyboard button.

After connection to the UTS cluster, the terminal is communicating with a data entry program. A data entry program has the following key functions:

- All cursor movements.
- Forward and backward tabulator.
- Delete insert character.
- Delete insert line.
- Erase screen, erase field (erase line if no field).
- Program attention key (to send short messages).
- Local print.
- Transmit.
- Set start of entry (SOE).
- Refresh the screen.
- Control page (to change printer file name and define the transmit function).
- Terminate and disconnect station.
