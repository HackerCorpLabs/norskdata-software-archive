# ND TELETEX

## INTRODUCTION

ND TELETEX is a service for text communication. The ND TELETEX terminal facility provides a gateway to Teletex services, which is a means for sophisticated document-transfer. Through a conversion facility, the ND TELETEX subscriber also has access to the entire international Telex network. ND TELETEX fulfills all requirements set by the Consultative Committee for International Telephone and Telegraph (CCITT). In addition, ND TELETEX provides some special features available only from Norsk Data. ND TELETEX also makes extensive use of the NOTIS-WP Word Processing System for message editing and reading.

When compared to an ordinary Telex system, ND TELETEX offers the following advantages:

- **Fast communication.** ND TELETEX transfers at 300 characters per second (which means approximately one A4 page in 10 seconds) versus 10 characters per second (which means approximately one A4 page in 5 minutes) for Telex systems.
- **Extended character repertoire.** The basic Teletex character repertoire contains 309 characters, while a Telex system offers substantially less. When interworking between TELETEX and Telex however, only the Telex subset may be used.
- **Multifunctional terminals.** The TELETEX service can be offered on a general purpose computer system as an additional facility.
- **Document presentation directives.** These directives make it possible to reproduce a received document which is just like the sender's copy (i.e., page format, pitch, etc.).

## TELETEX Remote User Module

If several ND machines are connected in a COSMOS network, only one machine (the main one) needs to have a Teletex gateway. To run ND-TELETEX on the other ones, you have to install the program "Teletex Remote User Module". In XMSG-COMMAND on these, you must define a machine called * TELETEX as "Remote System". You then need to know the number of the main machine.

# ND TELETEX

## FEATURES

- **NOTIS WORD PROCESSING**  
  Interface with the NOTIS Word Processing System makes it possible to use NOTIS when preparing documents for later transfer by the TELETEX facility.

- **LISTS OF TELETEX ADDRESSES**  
  A programmable list of TELETEX addresses makes it possible to give selected short codes as destination instead of the entire network subscriber number.

- **TRANSMISSION BETWEEN TELETEX USERS**  
  By specifying the end user name in addition to the Teletex number, direct transmission between TELETEX users is possible. The document is then routed to this user without help from a TELETEX operator.

- **USERS ON THE SAME ND SYSTEM**  
  Both sender and receiver of the TELETEX message can be on the same ND system, and still take advantage of the TELETEX service.

- **TRANSPARENT MODE-TRANSMISSION**  
  In that conversion to/from the TELETEX character set need not be done, transmission between ND TELETEX subscribers is achieved in a transparent manner. Unformatted documents may therefore be transferred between different ND computers in this mode.

- **MENUS PROVIDE COMMANDS**  
  An advanced menu system makes it easy for the operator to use the system with a minimum of training and experience.

- **A JOURNAL OF DOCUMENTS SENT AND RECEIVED**

## PRODUCT DESCRIPTION

CCITT recommendations specify that the TELETEX service must be network independent, with conversion facilities included in the network. ND TELETEX provides facilities for connection to a Circuit-Switched X.21 Data Network through the standard HDLC interface. All the mandatory requirements set by the CCITT are supported in ND TELETEX.

## REQUIREMENTS

- ND-100 CPU
- SINTRAN III (Version I or later)
- Sufficient disk capacity (minimum 600 pages)
- NOTIS-WP (Version M or later)
- ND 730 or ND 733 HDLC-DMA interface and cables to DEC
- ND 447 or ND 448 Philips Printer
- User Environment (ND 10518) is recommended.
- TELETEX entry to the data network (NDPN-X.21). Consult your local PTT authorities.
