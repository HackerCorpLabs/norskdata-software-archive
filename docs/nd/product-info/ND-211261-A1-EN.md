# NOTIS - DCA CONVERT

## Introduction

NOTIS-DCA Convert (ND 211261) makes integration between ND-NOTIS and other vendors' word-processing systems possible. It is a software module for conversion of documents between Norsk Data's NOTIS and other vendors' document world. Document Content Architecture (DCA) was made by IBM and hence has been a worldwide de facto document standard. Most vendors provide the means to convert to the DCA format. DCA defines how a document is coded, from defined character sets to formatting rules.

The DCA format is used by IBM’s word-processing applications, from PCs to mainframes. Products using DCA are DisplayWrite/PC, Display-Write/370 and DISOSS.

IBM’s PROFS, Digital’s All-in-One, most PC software and many other vendors’ word-processing products can import from and export to the DCA format.

## Features

- Conversion to most vendors’ word-processing systems from PC to mainframes via DCA.
- NOTIS-DCA Convert is a menu-driven product in the ND-NOTIS family, with simple selection of various functions.
- NOTIS documents with all six character sets can be converted, except for some characters not supported by DCA.
- Files can be converted in batch or mode jobs if a customer needs to convert several files in one operation.
- Conversion from NOTIS Text format to DCA Revisable Form Text.
- Conversion from NOTIS Out format to DCA Final Form Text.
- Conversion from DCA Revisable Form Text to NOTIS Text format.
- Conversion from DCA Final Form Text to NOTIS Text format.

# NOTIS - DCA CONVERT

## Product Description

NOTIS-DCA Convert is a member of the NOTIS family running on all ND-1X0 and ND-5XX(X) systems. Like all NOTIS products it is menu-driven with simple selection of the various functions, and with readily available HELP texts.

The Norsk Data representation of documents is different from DCA. NOTIS-WP has more functions and characters defined than DCA and most known word-processing systems from other vendors. This makes it somewhat difficult to exchange documents with other word-processing systems. The NOTIS-DCA Convert product is designed to solve this problem.

Because of differences in the basic content architectures, there are a few features that may cause trouble during the conversion. If such problems are encountered, this will be reported on the user terminal.

IBM's DCA defines how a document can be coded. DCA is a set of rules about:

- how documents are to be formatted
- what the meaning of various control characters in the text is
- what character sets are used
- how documents are to be printed
- how non-text material can be incorporated

There are two types of DCA defined:

- Revisable Form Text (RFT) for documents to be edited later on
- Final Form Text (FFT) for documents only intended for printout

DCA is extensively used by IBM. Additionally, most of the widely used program packages running on PC systems are capable of handling DCA.

## Prerequisites

- Any ND-100/110 or ND-500/5000 running SINTRAN III version K
- NOTIS-WP version N
