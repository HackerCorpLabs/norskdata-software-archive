# ND 10176 COBOL for ND-100/NORD-10

## INTRODUCTION

The COBOL programming language is the industry wide accepted high level computer language oriented towards data processing tasks often found in business applications. The ND COBOL handles data types for:

- **binary (COMPUTATIONAL)**
  - range — 32768 to +32767

- **double binary (COMPUTATIONAL-1)**
  - +2147483648 to +2147483647

- **packed decimal (COMPUTATIONAL-3)**
  - up to 18 digits

- **REAL (COMPUTATIONAL-3)**

- **external decimal (DISPLAY)**
  - up to 18 digits

- **report edited**
  - up to 18 digits plus edit characters

- **alphanumeric**
  - up to 32767 characters

NUCLEUS at Level One, with many selections from Level Two. Among others:

- Levels 77, 01-49, 88.
- 88-level condition names, with value series or range of conditions.
- Conditional operators AND, NOT, OR, =, <, >, in conditions.
- Procedure names consisting of digits only.
- COMPUTE-verb with multiple receiving fields ADD, SUBTRACT, MULTIPLY, DIVIDE-verbs with multiple receiving fields.
- DIVIDE-verb with REMAINDER.
- PERFORM-verb with three indexes.
- Qualification of names.
- Sign and class tests.
- Nested IF-statements, parenthesized conditions, abbreviated conditions, implied subject and/or relation.
- Nested conditions.
- ACCEPT-verb with DATE/DAY/TIME/CPU-TIME clauses.
- INSPECT, STRING and UNSTRING-verbs.

TABLE HANDLING at full Level One, and

- SEARCH-verb, format 1, format 2.
- Relative indexing.

INPUT/OUTPUT for Sequential, Relative and Indexed access organizations at Level One, with the following selections from Level Two:

- Multiple operands in OPEN and CLOSE-verbs, with individual options per file.
- DYNAMIC access mode (READ NEXT).
- START-verb with/without key relations EQUAL, GREATER or NOT LESS.
- Up to 5 alternate keys.

Library module with Copy-verb at all divisions and sections. Inter-Program Communication module with Linkage Section. Using-clause in Procedure Division, and Call-verb with Using-clause.

Debugging module at Level One with the Debugging-Mode-clause in the Source-Computer paragraph, and debugging statements with a D in column 7 for conditional compilation.

## PRODUCT DESCRIPTION

The COBOL compiler conforms to the ANSI-74 COBOL standard as defined in American National Standards Programming Language COBOL, ANSI X3-23-1974 Level One and contains many extensions from Level Two, together with ND extensions including COBOL Screen handling, thus providing large-scale business data processing capabilities to the mini-computer world.

It includes the following "modules" at level and extensions specified:

| RELATIVE I/O  | INTER-PROGRAM         |

# ND Extensions

Some major extensions have been included. They are:

## Screen Handling

With many new options on the ACCEPT and DISPLAY statements, data can be displayed in any screen position. Parts of the screen, or the whole of it, can be blanked out using the new BLANK statement. Movement between any two data fields is provided for by control keys.

## Multi-user ISAM

New options on the OPEN statement allow indexed and Relative files to be opened in MULTI-USER-MODE, with or without MANUAL-UNLOCK, or with IMMEDIATE-WRITE. The READ statement now has a WITH LOCK option to prevent two programs from accessing the same record at the same time. There is also a new UNLOCK statement.

The DO statement and the IF THEN ELSE END-IF statement:

- A DO statement has been introduced which can contain any number of WHILE phrases.
- The IF statement has been extended to include the THEN phrase and its corresponding END-IF phrase.

## Inter-Program Communication

New EXPORT and IMPORT clauses in the Linkage sections of the calling and called programs, provide data access between them.

## Interactive Debugging

The ND COBOL system provides the user with a number of debug options indispensable to efficient program development. When the command DEBUG is entered prior to program compilation, the user can choose between a number of debug options during subsequent execution of the program.

The options that can be invoked in DEBUG-MODE are:

- HELP – List available DEBUG options
- BREAK-ADDRESS
- BREAK-RETURN
- ACTIVE-ROUTINES
- ALIGN-LISTING
- CHECK-OUT-MODE
- COMPARE-DATA
- COMPARE-PROGRAM
- DUMP-LOG
- FIND-SCOPE
- GUARD
- LOG-LINES
- LOG-CALLS
- DISPLAY variable
- EXIT – Exit to operating system

- STEP – Execute next statement in logical sequence
- RUN – Commence program execution
- LOOK-AT-DATA
- LOOK-AT-PROGRAM
- LOOK-AT-REGISTER
- LOOK-AT-STACK
- MACRO
- RESET-BREAKS
- and others

One or more options may be active during program execution.

Cross-referencer list available.

The COBOL Compiler produces object code in the ND standard binary relocatable format (BRF) which is suitable for linking to the COBOL run-time system routines and separately compiled COBOL, FORTRAN, PLANC, BASIC or MAC assembly program modules.

The ND Relocating Loader (NRL) is used to build executable programs from user program modules and to link to the necessary system run-time and library routines.

## Database Management

The inter-program communication module allows COBOL programs to interface with the advanced SIBAS Database Management System through the Call-verb. The SIBAS DBM system is designed for multi-user, on-line terminal applications in business environments with complex information structures.

## Two-Bank Mode

Programs may be compiled in two-bank mode making it possible to have programs with 128 Kb code and 128 Kb data. Programs compiled in two-bank mode must be loaded with the two-bank mode COBOL Library and can only call other programs that have also been compiled in two-bank mode, i.e. they can NOT call FORTRAN or BASIC Subroutines, they can NOT call SIBAS or ND Screen Handling.

# Requirements

The COBOL Compiler requires 128 Kw of memory. The Compiler executes as a reentrant subsystem under SINTRAN III/VS, thus enabling several active users to share common code.
