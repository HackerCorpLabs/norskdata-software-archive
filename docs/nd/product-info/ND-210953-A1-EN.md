# SNA 3270 PROGRAM ACCESS

## INTRODUCTION

The SNA 3270 Program Access enables an application on an ND computer to log on to an IBM mainframe application (IMS, CICS, TSO), and to read and update a central database.

The SNA gateway software runs in a separate processor (PIOC). This offloads much of the communication protocol handling from the ND-100 processor. Another advantage is that SNA 3270 Program Access works over the ND COSMOS network system. This cooperation with COSMOS allows distribution of SNA 3270 Program Access to several CPUs, while only one computer is connected to the IBM mainframe.

## FEATURES

- ND to IBM Program-to-Program communication
- Starts a session with the host application as a 3270 Terminal
- Separate communication processor (PIOC)
- SNA Gateway to host (SDLC)
- Connection to IBM 370, 30XX, 43XX, 8XXX computers
- Simultaneous use of other ND SNA products on the same line to the host
- Support through the COSMOS network to the ND SNA Gateway computer
- Multiple Program-to-Program sessions simultaneously

## PRODUCT DESCRIPTION

The ND SNA 3270 Program Access is a library of subroutines that can be used in local ND programs for communication with IBM programs. SNA 3270 Program Access is developed from the SNA 3270 Terminal Emulator, and many service routines are common to both programs.

The communication between the local ND program and the IBM program is logically divided into three phases:

- Logging on
- Dialogue
- Logging off

A Script file is used when logging on and off. This file contains the interactions that are to be performed. The advantage with this facility is that it makes application programming easier and simplifies application maintenance.

In the dialogue sequence, the local application may call the subroutines supplied for sending and receiving host application data. In addition, there are routines for reading and writing data into the screen buffer. Each field may be addressed as a buffer with field number, or by line and column number.

It is also possible to use the Script file in the dialogue phase.

The nature of the product demands familiarity with the host application to be communicated with. Knowledge of the screen formats as well as their sequence is a necessity. ND therefore recommends that the ND SNA 3270 Terminal Emulator be used when the format of the Script file is defined.

# SNA 3270 Program Access

The ND SNA Gateway software and hardware are required, and contain the communication part (SDLC protocol emulation) and the interactive part. To offload the main computer, these parts run in a separate processor (PIOC).

ND SNA 3270 Program Access emulates IBM's PU type 2, and LU type 2.
