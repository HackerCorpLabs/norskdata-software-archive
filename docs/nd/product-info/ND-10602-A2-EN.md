# ND-10602 SOURCE COMPARE FOR ND-500

## INTRODUCTION

SOURCE COMPARE is a utility for comparison of two program source files written in FORTRAN. SOURCE COMPARE belongs to the set of Software Conversion Tools. It is intended as a tool to be used in machine-to-machine conversion or source-code management jobs. SOURCE COMPARE will report the differences between the files compared, as source code differences or as a special Source Transformation Format.

## FEATURES

- Easy comparison of two program files.
- Detects any line which has been changed.
- Detects insertion/deletion of one or more lines.
- Allows usage of INCLUDE files.
- Outputs results as a report of source differences.
- Outputs results in STF (Source Transformation Format).
- Outputs a new source with the differences highlighted.

## PRODUCT DESCRIPTION

SOURCE COMPARE compares two source files and outputs a report of the discrepancies found. The report describes the differences in the source file. A description of the differences may also be output in STF, which is a very compact reporting format.

SOURCE COMPARE recognizes program modules/units, so it will compare successfully even if the order of the modules has been reorganized. INCLUDE files in the source program are allowed.

## REQUIREMENTS

- ND-500 Computer System
- SINTRAN III version I or later
