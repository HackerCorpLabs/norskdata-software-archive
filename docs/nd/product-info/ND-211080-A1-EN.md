# NOTIS-PRO

## Introduction

NOTIS-PRO is used to produce high-quality documents combining proportionally spaced text with different kinds of illustrations. The program is well suited to making reports, articles, newsletters or manuals, but may also be used for shorter documents like memos, brochures or letters. NOTIS-PRO is intended for documents that need a sharper, more professional look than documents made with a word processing program. It is also an alternative for documents that have previously been typeset. With NOTIS-PRO, the user retains control of the whole production process, saving time and money.

## Features

- Editor almost identical to NOTIS-WP
- Full on-line HELP facility
- 33 fonts in sizes 6 to 72 points
- Extra symbol characters
- Layout style masters for easy choice of layout
- Choice of basic document types
- Font sets for suitable font combinations
- Easy-to-learn set of markup codes
- UDK set for entering markup codes
- Up to three columns on each page
- Footnotes, itemized lists, lines and boxes
- Hanging paragraph indentation
- Automatic table of contents and index
- Hyphenation rules can be changed mid-text
- Clippings from NOTIS programs
- Illustrations from NOTIS-BG, NOTIS-DRAW and Technovision can be incorporated
- Scanned-in images in TIFF and IMAG formats
- Documents can be automatically prepared in NOTIS-PRO format by NOTIS-RG
- Batch formatting possible
- View formatted page(s) on Graphic option
- Formatting log to find errors
- Reformatting of one or several pages
- Printout on a PostScript laser printer

## Product Description

NOTIS-PRO is a tool for creating documents of typographical quality, combining text and illustrations. The editor is almost identical to NOTIS-WP, and working with the program is very much like using the text formatter NOTIS-TF.

It is quite simple to choose the basic layout: a single document type code at the top of the document is sufficient to define the entire layout. There are six different pre-defined document types, each available in A4 and B5 formats. There is also a Layout editor menu, which replaces the Print and NOTIS-TF menus in NOTIS-WP. The Layout menu can be used to overrule the default values defined by the document type. The user may choose to start making a document by fetching a Layout style master. This style master automatically gives the document a suitable combination of document type code and Layout menu values. The style masters may be customised by the company, ensuring that everyone follows the company standards.

The document consists of text and NOTIS-PRO markup codes. The set of markup codes is limited to about 300, some of which are used very rarely. Where possible, the names of the markup codes correspond to NOTIS-WP print directives. One part of NOTIS-PRO is a special UDK set for entering markup codes. These are used to indicate how NOTIS-PRO should format the text: where chapters start, the number of columns, margins, indentation in millimetres, numbered lists, placing of illustrations, and so on.

Normally, the document is created in the NOTIS-PRO editor. It is also possible to fetch documents created in NOTIS-WP or in NORTEXT, or 7-bit ASCII files as well as clippings from other NOTIS programs. The document may be fully prepared in NOTIS-WP or in NOTIS-RG for subsequent NOTIS-PRO formatting.

The marked-up text is then formatted, either interactively, or as a batch process. During formatting, NOTIS-PRO automatically inserts pagination codes in the document. A formatting log containing extensive information about each page makes it easier to locate problems or errors.

When the document has been formatted, it can be inspected on a Graphic option screen. There is a Graphic option menu which allows the user to specify how the pages are to be displayed on the screen. For example, one or more pages may be scaled down so that a full page fits on the screen, and the text may be displayed as lines rather than as characters. This makes it easy to check that the layout of the page is correct. It is also possible to split the screen, using one part for the marked-up text and another for the graphic display.

The formatted document may be edited freely just like a NOTIS-WP document. It is also possible to remove the pagination codes before starting to edit, but the codes must be present in order to inspect or print the document. In NOTIS-PRO, it is possible to format a single page or a range of pages, for example the rest of a chapter. This makes it easy to do the final polishing of a document.

When the document is ready in its final form and has been printed, a table of contents and an index (if the document contains these) may be generated automatically. These lists are generated in separate regions by NOTIS-PRO, and they can be edited and formatted as separate documents. This makes it possible to give them the same layout as the main document, while retaining editing flexibility.

There are also NOTIS-PRO document types for small documents like a memo, minutes or summons to a meeting. The corresponding Layout style masters include markup codes that generate suitable headings. Additional document types are prepared for company customisation.

NOTIS-PRO accepts the same text file formats as NOTIS-WP: S-format, 16-bit format, 7-bit ASCII format and NORTEXT 8-bit format. The formatted document may be stored in NOTIS-DS, which is considered the normal storage system, or in the SINTRAN III File System.

## Using illustrations

Illustrations may be integrated in the text with markup codes, just as in NOTIS-WP. Each illustration is generated in different programs, and given a name. A markup code is used to identify that name and to indicate the size of the illustration. A maximum width or height may be given, and the illustration is then automatically scaled by equal horizontal and vertical scaling factors so as not to distort the proportions. All kinds of illustrations are shown when the document is inspected.

NOTIS-DRAW, NOTIS-BG and Technovision all generate the CGM format which can be included in a NOTIS-PRO document. Any CGM illustration may be imported to NOTIS-DRAW in order to rotate, scale, add text, or otherwise polish it there. The two formats TIFF and IMAG are generated by different types of scanners. The scanner is controlled by an office workstation and contains software which makes it possible to edit the scanned illustration before it is included in the NOTIS-PRO document.

## Requirements

- ND-103200 NOTIS terminal. A graphic option is required for viewing the formatted document
- An ND-500 or ND-5000 series computer
- An ND Page Printer 720 or 730 with the Postscript option and/or an ND PostScript Printer 715
- ND-SPRINT, version A02 or later
- SINTRAN, version J or later. If using SINTRAN K, patchfile > = 3300 is needed, but if running from a remote computer, patchfile > = 4000 is needed
- User Environment, version B or later
