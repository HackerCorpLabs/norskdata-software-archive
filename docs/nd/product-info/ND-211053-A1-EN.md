# NOTIS Personal Manager

## Introduction

NOTIS-PM is a calendar program which can be implemented on any ND-100 or ND-500 computer. The program is very easy to use, based on a menu-oriented standard ND-NOTIS user interface. NOTIS-PM is a helpful tool for all those who need to schedule their time; for instance managers and secretaries who organise whole departments or groups of people.

## Features

- A three-level calendar consisting of a diary function, a monthly summary and a quarterly overview.
- Keywords from each day’s diary in the monthly summary.
- From the summary level it is possible to move directly to a diary page, and from the quarterly calendar it is possible to move directly to a summary or a diary page.
- Printout of screen pictures at all calendar levels.
- Easy display of other users’ calendars, provided the user has read access.
- If problems are encountered while NOTIS-PM is operated, the user will get extensive help information by pushing the HELP key.

# NOTIS Personal Manager

## Product Description

The diary page is displayed by selecting `Update-Diary` from the NOTIS-PM menu. Any date can be chosen simply by filling in the date one wishes to see; today's date always being the default value. When the desired diary page has been fetched, it can be edited by filling in information fields about location, actions, the daily schedule, etc.

The menu command `Summary` gives an overview of all activities for a whole month by listing dates and keywords for each day. From the summary level, the user can choose any date and go directly into the diary page for that date.

A quarterly calendar is displayed when the command `calendar` is chosen. Unless anything else is specified the three months with the current month at the centre are displayed. From this level the user can also pick any date and go directly into this date's diary page, or pick any month and go directly into that month's summary.

All printouts from NOTIS-PM contain a heading with the user's name, the date and hour, and the name of the diary owner, in addition to the contents of the diary page, summary or calendar.
