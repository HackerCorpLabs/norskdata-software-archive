# GKS 2D for ND-500

## INTRODUCTION

GKS-2D-500 is a set of FORTRAN subroutines for those who need graphics as part of an application.

GKS defines standard functions for 2D computer graphics programming and a configuration of graphic input and output devices. GKS is an ANSI and ISO standard. The current product is following the ISO 7942 standard.

The present version conforms to level 2B. (Will be extended to 2C.)

## FEATURES

- Basic graphical building blocks:
  - POLYLINE
  - POLYMARKER
  - FILL AREA
  - TEXT
  - CELL AREA
  - CIRCLES, ELLIPSES, SPLINES

- Display attribute on each primitive:
  - COLOR
  - LINE TYPE
  - LINE WIDTH
  - TEXT FONT

- Primitives can be "grouped" into segments.

- Segments can be copied, translated, rotated etc.

- Segment attributes:
  - HIGHLIGHTING
  - VISIBLE/INVISIBLE
  - DETECTABLE/UNDETECTABLE

- Through WISS (Workstation-Independent Segment Storage), segments may be shared between several GKS workstations.

- Input devices can be handled in Sample, Request or Event mode. (Event mode in level 2C)

- Standard drivers included:
  - HP 7475 plotter
  - Tektronix 4014 terminal
  - Tektronix 4105 terminal
  - ND 103240 terminal (ND 103200 with ND 103210 Graphic option.)

- Other drivers will be available later.

## PRODUCT DESCRIPTION

FORTRAN 77 subroutine library.

GKS includes all the capabilities for the whole spectrum of graphics, from simple passive output to highly interactive applications. The potential applications range covers business graphics, process control display systems, mapping, CAD/CAM, military graphic systems, etc.

The philosophy behind GKS is to provide a conceptual model of a workstation, the GKS workstation, shielding any hardware peculiarities from the application program easily portable.

By adhering to the GKS standards in application development, the users can benefit in several ways. Among the benefits are: Portability, flexibility in choosing graphical devices and extended life expectancy of the application package.

The capabilities of a GKS workstation are defined by the GKS standard. GKS is programming-language independent. For integration into a language, GKS is embedded in a language layer containing such language conventions as parameters and name assignments.
