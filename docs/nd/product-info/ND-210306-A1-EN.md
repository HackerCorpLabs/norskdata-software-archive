# SNA RJE Support

## INTRODUCTION

ND SNA RJE (Remote Job Entry) facilitates the ability to submit batch jobs to a remote computer and to receive the output of these jobs at the RJE workstation.

The ND SNA RJE is very similar to the ND-HASP II, but the SNA gateway software runs in a separate processor (PIOC). This offloads much of the communication protocol handling from the ND-100 processor. Another advantage is that ND SNA RJE will work over the ND COSMOS network system. This cooperation with COSMOS will allow distribution of RJE to several CPUs, while only one of them is connected to the IBM host.

## FEATURES

- Connection to IBM RJE systems (POWER, JES2, JES3).
- SNA gateway to Host (SDLC).
- SNA protocol conversion in a separate processor (PIOC).
- Simultaneous use of other ND SNA products on the same line to the host.
- Support through the COSMOS network to the ND SNA Gateway computer.
- Job Input independent of communication status.
- Job Output routing to any ND file or peripheral.
- Multiple users.
- Command Protection.
- Online HELP

# SNA RJE Support

## PRODUCT DESCRIPTION

ND SNA RJE is a real-time program which permits the ND system to function as an SNA Remote Job Entry Workstation for submitting jobs to the IBM host. This program appends jobs to the local reader queue, and when the communication is started the jobs are sent one by one to the IBM host computer. After execution, output from jobs will be routed to a destination ND file or printer.

The ND SNA Gateway software and hardware are required, and contain the communication part (SDLC protocol emulation) and the application part (interactive part). To offload the main computer, these parts run in a separate processor (PIOC). Communication between the ND SNA Gateway and the ND SNA RJE takes place through XMSG. This solution makes it possible to run COSMOS to the SNA Gateway computer. Only one gateway to the host is needed.

If you install ND SNA RJE software directly in the ND-100 part of the ND SNA Gateway computer, you need only XMSG Single System. If you install it in any other ND computer connected to COSMOS, you need XMSG Inter System.

ND SNA RJE emulates IBM's PU type 2, and LU type 1.
