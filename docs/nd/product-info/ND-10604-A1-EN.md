# ND 10604 FOREIGN MEDIA

## INTRODUCTION

FOREIGN MEDIA is a utility program, designed to read magnetic tapes written on foreign computer systems. The symbolic file formats will be converted to compatible ND-formats, and the tape files will be transferred. The product belongs to the set of Software Conversion Tools.

## FEATURES

- Tapes are checked against a set of acceptable foreign formats.
- Symbolic-file formats are converted.
- Optional copying of non-symbolic files.
- FORTRAN horizontal tab characters may be expanded automatically.
- Any number of files may be copied from the tape.
- The user may specify a subset of the files which are to be copied.
- File names are automatically translated.
- HELP or question mark (?) will assist the user in the use of the program.

## PRODUCT DESCRIPTION

FOREIGN MEDIA identifies the tape format and checks that the format is among the ones accepted by the FOREIGN MEDIA system. The program then reads and displays the tape label and if requested, it will list the names and sizes of the files contained in this volume.

The user can choose to copy all, or a subset of the files found on the tape, either symbolic or non-symbolic files. The set of files to be copied may be further specified by giving the initial character(s) of the files to be copied, for example all files starting with the letter F*. There is also an option allowing the user absolute control over the set of files to be copied, by prompting the user before each individual file is copied.

The files may be distributed to several user areas if there is not ample storage capacity in any one area (i.e., if the number of files in the volume exceeds the maximum number of files to be held by one user).

## REQUIREMENTS

- SINTRAN III version I or later
