# ND 10190 ND-500 FORTRAN

## INTRODUCTION
ND FORTRAN is a programming language based on the ANSI-77 standard (ANSI x 3.9 - 1978). The compiler generates very compact code for optimal utilisation of the ND-500 computer. One version of the compiler is a cross compiler, i.e., it runs on an ND-100 and generates code to be run on an ND-500. The other version is an ND-500 native compiler.

The language implemented is the full ANSI-77. Also, those features of the ND FORTRAN products ND 10023/10033 which are compatible with, and in addition to, ANSI-77 are implemented. Thus it maintains an upwards compatible path from existing programs.

## FEATURES

- Follows ANSI x 3.9 - 1978
- Inline functions for faster execution
- CHARACTER datatype for string manipulation
- Extended datatypes INTEGER*2, INTEGER*4, LOGICAL*2, LOGICAL*4, REAL*4, REAL*8, COMPLEX*8, COMPLEX*16
- DOUBLE COMPLEX for greater accuracy
- IMPLICIT statement to set default datatypes
- PARAMETER statement to name symbolic constants
- IF-THEN-ELSEIF-ELSE-ENDIF statements to improve program structure and readability
- DO FOR-ENDDO/DO WHILE-ENDDO loop constructs to improve program structure
- INCLUDE command for incorporating other symbolic files in the source text
- SIF-§THEN-§ELSEIF-§ELSE-§ENDIF commands to select part of a file for compilation
- CONSTANT command to set values of named constants globally, so as to allow multiple compilations with the same values
- Generation of tables for use by the symbolic debugger for rapid development
- Full diagnostic ability, including an option to show where a program is using a feature not included in ANSI-77
- Standardised calling interface for easy invocation of routines written in other languages (e.g. PLANC, COBOL)
- Ability to place compilation options in the program source file by preceding the commands by a $

## OPTIONS

The ND-500 FORTRAN compiler makes available several other facilities.

- §CROSS-REFERENCE command lists all names and labels, together with their datatypes and the statements which reference them. This list is provided for each program unit on a file, and finally, a summary of the global hierarchy of invocations
- §DEFAULT command establishes the default size for LOGICAL, REAL and INTEGER variables and constants
- §UNIT command to establish default units for READ and PRINT statements
- §OPTIMISE command to set or reject the compiler’s optimisation of DO-loops, and of commoning of expressions. The optimisation of COMMON variables, can be suppressed through the MOVE-COMMON-VARIABLES command
- §LIST command turn the listing option on and off
- §PAGE-SIZE command to establish the size of a page on the compiler’s list file
- §HEADING-TEXT command to provide the user with a title on each page of listing
- §STANDARD-CHECK command to diagnose breaches of ANSI x3.9-1978
- §CONDITIONAL-COMPILING command to retain compatibility with ND 10023 form of source code selection. In addition there is a SIF-§THEN construct to effect the same function
- §LIBRARY-MODE command to construct a library from the compilers object file
- §DEBUG-MODE command to generate tables for use by the symbolic debugger

For restrictions, deviations and incompatibilities, consult reference manual.
