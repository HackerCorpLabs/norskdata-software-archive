# ND 10375 TELEFIX

## Product Description

The TELEFIX system consists of software packages which reside in the host computer (the computer at the ND service center). This system is connected to the customer’s computer via public communication lines; it is operated from workstations at the service center. TELEFIX can accommodate an unlimited number of remote computers, and any ND system may be accessed.

When the TELEFIX system is activated by the customer, the service center’s workstations operate as though they are part of the customer’s computer system. The technician gives commands and instructions to the remote computer to diagnose the error. A series of commands given by the technician may be stored in a script file; and all diagnoses operations performed by be stored in a log file. These files are helpful to the technician in the case of a similar malfunction in the future.

TELEFIX also offers file transfer between the service center and the customer’s computer system.

## Introduction

ND 10375 TELEFIX provides remote diagnostics and maintenance services for its customers. TELEFIX makes it possible to trace and correct faults in a computer that is at a different location than the repair personnel via existing telecommunications network.

## Features

- Rapid response when a problem arises.
- Short fault tracing time.
- There is no limitation on the number of remote computers that can be accessed from the TELEFIX centers.
- Connection to remote computers is via pre-existing public communication lines.
- If a visit is required by a service engineer, it is more likely that s/he will be equipped with the proper tools and parts, thus avoiding another visit.
- Customers are not responsible for running diagnostic tests.
- The customer can permit or block access to his computer via the TELEFIX adapter. This affords the customer security and privacy.
- The customer can monitor the diagnosis operations closely by a log of activities on his console.

## Requirements

- A floppy diskette called “TELEFIX Files For User Sites”
- A TELEFIX adaptor if the adaptor is not built in to operator panel
- A telephone line and an asynchronous-type modem: 300 baud/V21, 600 baud/V22 or 1200 baud/V22
