# ND 10715 ND-BENCH Environment for ND-500

## INTRODUCTION

The ND 10715 ND-BENCH Environment is a tool which enhances the ND Operating System's _user friendliness_. ND-BENCH Environment is a task-oriented workbench for system designers, programmers and other project members cooperating in the task of designing an organization's Technical/Scientific data-processing systems of the future. ND-BENCH Environment provides a flexible and simple to use system of menus with which development, conversion and maintenance of application software can be accessed. Although this product was developed to help experienced computer programmers more efficiently utilize their time, the ND-BENCH Environment creates a milieu which is readily accessible to the less experienced programmer.

Users of ND-BENCH Environment can with ease and simplicity access a very wide range of application programs through the menu hierarchy. Menus may be tailored for each individual user, or user group, to include only the functions specifically required. User written programs can also be included so that an individual user sees them in a menu in the same manner as the system functions. Another valuable function built into the product is a hierarchy of HELP prompts, which aid the user in the event of questions and/or problems of procedure. The ND-BENCH Environment therefore expands the _user friendliness_ of the ND Operating System for both the experienced and inexperienced user alike.

## FEATURES

- Advanced Menu Hierarchy which is flexible and expandable.
- Quick access to a wide variety of programming tools, such as compilers, program editors, debuggers and many others.
- HELP key will give assistance specific to task being attempted.
- User written programs can be integrated into the menu system.
- Designed for the Advanced Programmer, but equipped to facilitate the first time programmer.
- Areas of usage include: program development and maintenance, software conversion, and software optimization.

## PRODUCT DESCRIPTION

The ND-BENCH Environment product is an interface between the user, the software tools and the Operating System. Previously a user could individually access all of the tools for program application through the Operating System. With ND-BENCH Environment however, the user need not search to find the tools, as immediate access to all of these is provided. Although the ND-BENCH tools are mainly aimed at solving problems within the Technical/Scientific area, a variety of programming languages and applications can be included. The purpose of this product then is to assist people making application systems-fitted to meet the specific needs of the organization.

The ND-BENCH menu system represents a common user environment for all kinds of users and ND-BENCH related applications. The menus may be adapted to the user profile (experience level, preferred language etc…). The main menu for an experienced programmer could appear as follows:
