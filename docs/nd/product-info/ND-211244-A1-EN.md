# NOTIS-DM

## Introduction

NOTIS-DM is a form-based document-managing and editing tool, with complete NOTIS-WP word-processing functionality. NOTIS-DM can access information stored in a SIBAS database and enables both free text and structured information to be processed on a NOTIS-WP simplicity level.

The database upon which NOTIS-DM operates is a SIBAS/R database, which may contain many different tables. Each table may contain rows, and each row may contain a number of fixed-length fields (name, number, time, date, ...) and a number of fields containing free text (description, abstract, letter content, ...).

Functionally, NOTIS-DM gives increased integration between the ND-NOTIS and ND-DIALOGUE families. It combines the user-friendliness and flexibility of NOTIS with the DIALOGUE family's potential for the creation of on-line, database-based ADP systems. NOTIS-DM may share information with DIALOGUE applications.

Whilst NOTIS-WP may be thought of as the electronic equivalent of working with blank typing paper, NOTIS-DM applications may be thought of as electronic forms.

NOTIS-DM is thus intended for organisations with a need for form-based document processing. Examples may be all types of forms. Forms contain certain fields for structured data such as name, customer number, telephone number, address, case number, references etc. In addition, they often have reserved fields for free text like letter text, explanations, comments, abstracts and so on.

## Product Description

- **NOTIS-DM is a product which enables an organisation to handle and manage documents, by:**

  1) Integrating structured and unstructured information.
  2) Giving the end user an easy-to-learn product of NOTIS-WP simplicity, while maintaining the ability to define complex document layouts and structures.
  3) Storing documents in an advanced database system providing high security and data sharing with other applications.

These products have initially been defined:

- NOTIS-DM, ND 211244
- NOTIS-DM with ABM Definition, ND 211475 consisting of NOTIS-DM, ND 211244 ABM Tool, ND 211267 ver. D01 or later
- NOTIS-DM upgrade for NOTIS-WP, ND 211494
- ABM Tool will also be available as a single product.

A tutorial named 'ND-PILOT tutorial for NOTIS-DM' (ND 211493) is available.

'NOTIS-DM upgrade for NOTIS-WP' works exactly like the full NOTIS-DM but is intended for customers which already have NOTIS-WP, to acknowledge the value of their present NOTIS-WP investment. The customer should already have NOTIS-WP installed.

ABM doesn’t need to be installed on the machine where NOTIS-DM is running; it is sufficient that the application library and the forms library exist on this machine. ABM is only used when and where the application is defined. Customers who already have ABM (ABM, ABM/PC or DIALOGUE-3) need not purchase NOTIS-DM with ABM Definition.

ND-PILOT tutorial for NOTIS-DM is an on-line tutorial allowing the user to teach himself NOTIS-DM by working through a number of interactive screen-based tutorials. The user should already be familiar with NOTIS-WP, e.g. through an ND-PILOT tutorial for NOTIS-WP.

A NOTIS-DM document may look like this:

```
+-------------+---------------+-------------+
| Program     | Regions       | Applications|
+-------------+---------------+-------------+
| Call        | Number        | Save        |
|   Enclose   | Modify        | List        |
|   Text      | Copy          | Delete      |
+-------------+---------------+-------------+
|               TELEPAK LIST                |
+-------------------------------------------+
| Beliggenhet       Uo.nr.   Torge/s         |
|   Torge.sol       Adresse  Best.nr.        |
|  +----------------+--------+---------------+
|  |Rendsburg       |Rendsburg|152,144-15-12|
|  +----------------+--------+---------------+
|  /NOTIS-1001      /NOTIS-2001             |
|  2P/87 SINUS / NOTIS-CAT / NOTIS-TM       |
+-------------------------------------------+

NOTE: On leave until March 1.
```

This illustration shows a form-based NOTIS-DM document, with a predefined layout, stored in SIBAS/R. A NOTIS-DM document can also be an ordinary NOTIS-DS or SINTRAN document.

Like NOTIS-WP, NOTIS-DM has regions which enable the user to edit several documents at a time. These documents may belong to different NOTIS-DM applications. Full WP functionality (mark, move, etc) is available for all kinds of documents.

ABM has to be used to define the database by filling in a set of forms, and ABM Screen-Form to define the document layout and field control. The document layout is defined by drawing it on the screen.

The definition process should be done by people experienced in the use of 4G tools. As such, it is too complex for ordinary users, but experienced users like system supervisors may wish to define applications after attending a NOTIS-DM Application Manager course.

In NOTIS-DM, the fixed-field part can fill only one screen. A form can refer to only one SIBAS table. Only one variable-length field can appear in a form, and it has to be presented at the end of the document (following the fixed-length field part). A document may, however, contain several variable-length fields, as long as different forms are used to display the fields.

Searching is possible only on the fixed-length fields in a DM document. Free-text search in the unstructured free-text part is not yet available.

# NOTIS-DM

## Features

- **NOTIS-DM** handles documents containing both structured fields and free-text fields.

- **NOTIS-DM** presents and processes forms with full NOTIS-WP functionality.

- **NOTIS-DM** forms (document layouts) are customised to suit individual needs.

- Forms are easy to modify, also after data has been entered into the database.

- **NOTIS-DM** has advanced input and syntax control, including the possibility to check the content of a field(-group) against data in the same or another database.

- **NOTIS-DM** allows the user to have several applications active at the same time in different regions. Cut and paste is possible between regions.

- **NOTIS-DM** is an on-line real-time document manager tool: updates are immediate, requiring no batch processing.

- **NOTIS-DM** uses the SIBAS/R database system with wide columns as a storage medium. NOTIS-DS and SINTRAN may also be used for storage of text documents.

- The database may be shared between NOTIS-DM and other applications. This enables key data to be shared and incorporated into different systems such as accounting, document maintenance, order & payments.

- Privacy and access controls on field, document and application levels let different user groups get different views, access rights and update rights to documents or parts of documents.

- Documents may contain sign-off fields, ensuring that document modification can be controlled and reported.

- A value typed in one field can be used to look up values in other documents and insert them automatically. For example, a user types a department number; the department name is filled in automatically.

- By partifying filling a form skeleton, you may search for documents. No search language has to be learned.

- A search results in a list of documents, which can be printed or included in a document. The resulting list may also act as input for a report produced with NOTIS-RP.

- User Defined Keys (UDKs) may be connected to a NOTIS-DM application. This allows you to perform complex operations with a single keystroke.

- You may use the full WP character set, including accented letters, Greek letters and other special characters, both in fixed-length fields and in variable-length text fields.

- **NOTIS-DM** includes advanced nationality-dependent sorting and searching on fixed-length fields, including searching on key terms inside a field.

- The same SIBAS document may be presented in different ways (using different forms) for different user groups or for different purposes.

- ABM must be used to define the application, the screen forms, the input controls, the databases, tables, columns etc.

- SIBAS/R is the document database, giving high database performance and security. All the SIBAS maintenance tools are provided, giving full backup, logging and recovery functionality.

- You may use NOTIS-RG/RP for producing reports from both the fixed-length fields and the variable-length text fields.

- Routines for converting from an existing NOTIS-IR database, or other external databases, to a NOTIS-DM SIBAS/R database are provided.

## Prerequisites

- Sintran III version K or later
- User Environment version B or later
- SIBAS/R version A06 or later. (For nationality-dependent searching on indexed fields, version A10 or later should be used.)
- Additional prerequisite for NOTIS-DM upgrade for NOTIS-WP, ND 211494: NOTIS-WP version N.

## Version requirements

- ABM tool D01 or later for defining DM applications.
- NOTIS-RG 008 or later for making reports.

## Technical Specifications

A NOTIS-DM SIBAS/R database will require 1.3 MB storage for the system files alone, i.e., before data is added. A typical A4-size document, half of which is fixed fields and half free text, will require from 2 KB onwards of storage.
