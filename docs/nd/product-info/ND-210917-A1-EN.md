# TECHNOTIS

## Introduction

TECHNOTIS provides a gateway between the two Norsk Data families TECHNOVISION and NOTIS. With the use of TECHNOTIS, complicated engineering drawings from TECH2D and hidden line pictures, cuts etc. from TECH3D can be included in text documents produced by the text processing system NOTIS-WP.

Using TECHNOTIS, a powerful additional value of the CAD/CAM system TECHNOVISION can be realized, as all drawing information will be available for use in the word processing system without manual cut and paste work. This can speed up the production of installation and maintenance manuals, spares catalogues etc., and it provides nice illustrations for tenders and proposals.

Some of application fields, in which TECHNOTIS provides a profitable support, are:

- Assembly documents
- Maintenance documents
- Handbooks
- Developments reports
- Tenders and quotations
- Scientific contracts
- Spare parts catalogues
- Company standards
- Stock archive

TECHNOTIS provides output to the matrix printer ND 104480, or to the high volume page printer ND 104760.

## Features

- Rasterization of TECHNOVISION drawings
- Output to printer or as NOTIS readable file
- Automatic scaling of graphics to fill specified space
- Automatic calculation of height or width to maintain correct proportions

## Product Description

TECHNOTIS is a rasterization program converting vector information stored in TECHNOVISION drawings into raster information. TECHNOTIS is a stand-alone program and can be run from any alphanumeric terminal. The program accepts input as a TECH2D file (filetype .XEO) or as a TECHPLOT plot file (filetype .PLT). Output may be directly to a printer, storing the picture in a file, or producing a NOTIS readable file. If the user chooses to produce a NOTIS readable file, he must specify:

1. The margin in the NOTIS document
2. Width of picture in characters
3. Height of picture in lines

If height or width is left out, TECHNOTIS will supply a value to achieve correct proportions of the picture. The graphic information in the input file is scaled to fit within the given borders. The rasterized result can then be included in a NOTIS-WP file.

# TECHNOVISION

TECHNOVISION is the 2D/3D CAD system developed by NORSK DATA for engineering design and related applications. It is an invaluable aid in every aspect of technical drawing (design, calculation and drafting) as well as in the management of all associated product data.

The modular nature of the system ensures that an economic configuration can be found to meet the requirements of every design office. In addition the open-ended structure of the system enables users to develop new functions themselves and incorporate them into the system, and facilitates the communication of product related information both within the company and to outside concerns.

A universal product data base represents the kernel of the CAD/CAM solution offered by TECHNOVISION and the key to the integration of product planning, product management, and office automation.
