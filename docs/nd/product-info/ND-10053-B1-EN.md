# ND 10053 NORD DATA ENTRY SYSTEM

## INTRODUCTION

The NORD Data Entry System consists of a set of software modules offering a flexible and easy way of entering and validating data in a NORD-100 / SINTRAN/VS computer system.

One big advantage of the NORD Data Entry System is that only proper data are accepted for further processing, avoiding unnecessary additional enterings, dominating expensive error-correction procedures and the nuisance of inaccurate reports.

## FEATURES

- Advanced screen handling operations using asynchronous display terminals with cursor control.
- Immediate reaction to errors both at the character entry level and at the data field entry level, such that when all data fields have been entered, they are correct as far as the system can judge. One does not wait until the screen is full before checking what has been typed in.
- Built-in field editing, storage conversion and field control functions.
- Standard field editing of numeric, decimal, alphabetic, alphanumeric fields, bank account and social security number, various data formats.
- User defined field editing if required.
- Storage control for automatic conversion to internal representation of integer, bytes and binary coded decimal forms.
- Field control by content checking defined as a part of picture definition:
  - legal and illegal values and range
  - default value
  - check digit verification (modules 10 or 11)
  - date-controls
  - field accumulation
- Easy corrections when altering field values, including copy of previous value, inserting or deleting characters, all by simple keystrokes.
- Screen handling library routines for user programs.

## PRODUCT DESCRIPTION

The NORD Data Entry System consists of two modules:
- **NORD DEE**: Data Entry Editor
- **NORD DEC**: Data Entry Compiler

The Data Entry Editor is used by the operator that actually keys in the required data. It replaces the common key-punch machine and is much more versatile.

The Data Entry Editor presents a picture of the required form on a display terminal and allows the operator to fill in various fields from the original form to the corresponding fields on the screen. The operator needs not consider actual column positions, the editor automatically moves from one field to the next, or can be positioned to a desired field by the operator.

Thus the operator may easily go back and modify any field that has been entered, and may at any time go back to previous forms and make changes, delete whole forms or insert new forms.

The editor may also be used for verification of already entered data, and when in this rather stringent mode gives a character by character and field by field comparison between what is now typed, and what was previously typed.

The Data Entry Compiler is used to specify data entry applications which may for example require the use of several forms, the performing of various calculations during the entry phase, and the combination of data fields from different forms to build data records to be used by existing programs.

The code produced by the Data Entry Compiler is used to control the way in which the Data Entry Editor is to function for a specific application.
