## Page 2

# NOTIS-TO-NORTEXT CONVERSION

## INTRODUCTION

NOTIS-TO-NORTEXT Conversion table is ready-made tables for converting text from NOTIS format to NORTEXT format.

## PRODUCT DESCRIPTION

NOTIS-TO-NORTEXT Conversion table gives the possibility to transfer text and commands from a NOTIS-WP system to NORTEXT.

Normally there shall not be any additional coding in NORTEXT-100 before sending the text to a typesetter or an advanced printer.

**NOTE:** The NOTIS-TO-NORTEXT Conversion table do not include the handling of the new S-format in the M-version of NOTIS-WP. The product description for NOTIS-TO-NORTEXT Conversion table will give details of the NOTIS-WP directives that will be automatically converted.

## REQUIREMENTS

- ND-10800 NORTEXT-100 Editor
- ND-10801 System Tables maintenance
- ND-10802 NORTEXT-100 Basic RT
- ND-10814 Typographic Tables maintenance
- ND-10806 String-to-string text conversion
