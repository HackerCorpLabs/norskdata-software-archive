# ND 10049 SINTRAN III/VS SPOOLING SYSTEM

## INTRODUCTION

In a multi-user system it is necessary to share common resources, like line printers, which are too expensive to be individually assigned. Even if each user has a hard-copy terminal, there will be occasions when a high volume of printing is required. It is both inconvenient and expensive for the user to have to wait until a line printer is free. For this reason, the concept of "virtual" line printers has been implemented in the NORD File System.

When a user or a program requests reports or data to be printed on a line printer, a disk file is assigned instead. Information is transferred in the same way as if a physical line printer had been assigned. Afterwards, the operating system automatically submits the disk file to a spooling queue. The information will be printed on the physical line printer when its turn comes according to the spooling queue.

The user program performs faster as the data is "written" to a much faster device than the line printer, and the printing capacity of the line printer increases, since it will be running at full speed all the time instead of waiting for user programs to perform operations not connected with printing.

## FEATURES

- "Virtual" line printers or output units (any number of virtual printers per system)
- Programs execute faster, not having to wait for the line printer to become available
- Printing capacity increases, as the line printer does not have to wait for user programs
- Users can produce output to the line printer while long printing tasks are in progress
- Output from different users is well separated by a cutting line at the beginning and end of print
- Users can submit their own disk files to be printed by the Spooling System, even specifying the number of copies
- Protected commands to maintain spooling queues

## PRODUCT DESCRIPTION

The Spooling System is an integral part of the SINTRAN III/VS Operating System and the NORD File System.

It utilizes the file version feature of the NORD File System, whereby a number of copies can exist for a given file or a peripheral unit.

The Spooling System consists of a set of small modules maintaining various parts of the system: assignment of a spooling disk file when operating a peripheral unit, inserting the file into the proper spooling queue, peripheral driver taking queue entries and transferring the contents of the file to the unit concerned, and processing commands to maintain the spooling queues.

When a user or a program requests a peripheral unit, and the Spooling System is started for this unit, a disk file is assigned with the logical device number 120 octal, selected from the next free file version available for the unit.

When closing the file, or terminating the program, the file name is inserted in the spooling queue for the peripheral unit. If the spooling queue was previously empty, a system program is activated. This opens the file, reads 2 Kbyte pages and outputs complete lines to the device driver. In the case of an electrostatic printer/plotter, the first page contains information to set the device in graphic (plot) mode if necessary.

# Requirements

The Spooling System can be generated with any SINTRAN III/VS Operating System.

A spooling program of approximately 1/2 Kwords in the resident part of the operating system is required. In addition, for each peripheral device a spooling data field of approximately 190 octal locations, a 2 Kword segment on the system disk, and some semaphores are required.

The maximum disk space allowed for the Spooling System is initially set to 500 pages, but may be increased or decreased by user commands.
