# XMSG BACKUP/TRANSFER

## INTRODUCTION

XMSG Backup/Transfer contains the functions for backup and transfer of text articles from one NORTEXT-100 system to another.

The XMSG Backup/Transfer is intended for backup of articles only and will NOT provide simultaneous access to articles from both systems at the same time.

## PRODUCT DESCRIPTION

The XMSG Backup/Transfer takes care of on-line backup of all text input.

Backup is taken automatically by combining the XMSG Backup/Transfer with the routing functions in the NORTEXT-100 system.

The text file for backup is located on another disk, connected either to the same computer or to another computer.

NORTEXT-100 Text system may support 8 XMSG lines through the Line System.

These lines are working independently with different conversion tables.

The NORTEXT-articles may have either the same or different article-numbers in the original version and the backup version.
