# Introduction

SINTRAN MS-DOS Service is a program which simulates an MS-DOS file system under SINTRAN, and enables users to operate on an MS-DOS floppy under SINTRAN.

SMS is useful in the following cases:
- where there is no physical communication link between a PC-AT and an ND system
- where such a link does exist, but is faulty
- where the printer is attached to either the ND system or to the PC-AT
- where there is a high workload on a limited number of PC-ATs (simple jobs like editing, etc. can then be done under SINTRAN, leaving the PC-AT for final tests and runs) or vice versa

# Features

- Menu-driven
- Uses SINTRAN 5 1/4" floppy drive
- Copy files on an MS-DOS floppy diskette to SINTRAN
- Copy SINTRAN files to an MS-DOS floppy diskette
- LIST, DISPLAY and DELETE files on an MS-DOS floppy diskette
- Format floppy diskette to MS-DOS format

# Prerequisite

Only for 5 1/4" 1.2 MB high-density, double-sided floppy diskettes (PC-AT type)

# Product Description

The SINTRAN MS-DOS SERVICE (SMS) is a utility for transferring files from SINTRAN to an MS-DOS-formatted floppy diskette, or from an MS-DOS-formatted floppy diskette to SINTRAN. The utility also provides facilities for showing file information and formatting high-density diskettes to MS-DOS format.

The SMS utility runs under the SINTRAN operating system on an ND system, and uses the SINTRAN floppy-drive.
