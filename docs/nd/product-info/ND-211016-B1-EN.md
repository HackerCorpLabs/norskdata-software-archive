# NOTIS-DRAW

## Introduction

NOTIS-DRAW is a powerful drawing program used to create illustrations with text. You can draw lines, boxes, frames, and curves – the result is displayed on the screen immediately. Recurrent drawing elements can be stored in symbol libraries.

The finished drawing can be stored and may be printed out on a printer or a plotter with up to six colours. Illustrations may be imported from NOTIS-BG and Technovision, and may also be included directly in a NOTIS-WP document.

## Features

- Use a mouse to draw lines, curves, arrows, frames and boxes
- Choose between four line types and two line widths
- Store recurrent elements in symbol libraries
- Use a grid of dots for accurate positioning
- The snap feature moves cursor to nearest corner
- Group objects to treat them as a single object
- Use function keys to move, copy and delete objects
- Cross-hatch or fill objects
- Scale, rotate or make mirrored copies of objects
- Zoom, scroll or look at the entire drawing
- Online information available by pressing HELP
- Fetch clippings from NOTIS-WP or diagrams from Technovision and NOTIS-BG
- Include illustrations in NOTIS-WP documents
- Print the drawing or part of it on a colour plotter
- Choose between a portrait or landscape orientation
- Select text direction, font, size, and type

## Product Description

NOTIS-DRAW is an interactive drawing program which is designed to be run with a mouse, but may also be used with a graphic-option terminal. It can be used to make diagrams, illustrations, charts, drawings, and overhead transparencies.

## Drawing and Editing

The drawing is created interactively on the screen. The basic building blocks are called objects. Menu commands are given to choose an object, like a box or a line, and the mouse is used to indicate the location and size of the object in the drawing. The objects may be drawn with solid, dashed, dotted, or combined lines of single or double width.

The drawing may be edited and manipulated in a number of ways. The grouping feature makes it easy to manipulate several objects as one. Objects may be copied, moved, rotated, or deleted. It is also possible to make mirrored copies and to scale an object up or down. During scaling, the user can define different horizontal and vertical scaling factors and thereby stretch the object. Objects may also be hatched, using several hatching patterns. There is also the possibility of repositioning corners in an object of connected lines.

Elements that are frequently used may be stored in symbol libraries and later fetched when needed. Each symbol library can contain up to 40 symbols which can be viewed and printed out. There is no limitation on the number of symbol libraries.

NOTIS-DRAW can also be used to produce text. Just like the other types of objects, text can be added and manipulated. A number of text-specific features are included, such as choice of typeface, text direction, and text size. Dynamic text fills the space between two indicated points. Text written in NOTIS-WP may be imported directly into NOTIS-DRAW as clippings.

## Tools and Features

Several tools are available when a drawing is being created. A grid of small dots can be turned on to make positioning and aligning of objects easier. The distance between the dots is set by the user. The snap function automatically moves the cursor to the nearest corner when you indicate a point, making it easy to draw continuous figures. In fast-mode, texts are represented by boxes, making NOTIS-DRAW redraw the screen faster. It is also possible to list available printers and check the color of existing objects. Online help information is available at all times.

Other NOTIS products may be started directly from NOTIS-DRAW without losing a drawing. Clippings may be imported from NOTIS-WP, and diagrams from NOTIS-BG and Technovision. Drawings or parts of drawings may be exported from NOTIS-DRAW to be included in NOTIS-WP documents.

Only a part of the drawing is normally visible on the screen at any one time. There are several ways to display the different parts, or "windows", of the drawing. They may be enlarged or reduced; it is also possible to pan and scroll to move a window. There is furthermore a command for displaying the entire drawing. To find out exactly where the window is placed, a small image of the entire drawing can be shown in the lower left-hand corner. The current window will be indicated on this image.

It is possible to print out the drawings on a printer or a plotter with up to six colours. NOTIS-DRAW can also plot directly onto overhead transparencies to create professional presentation material. It is possible to print out only part of a drawing.

The finished drawing may be stored in NOTIS-DS or in the SINTRAN III File System. It can be exported for later inclusion in a NOTIS-WP document, giving the user an excellent tool for combining text and illustrations.

## Integration with NOTIS-WP

NOTIS-DRAW is well integrated with NOTIS-WP, which is Norsk Data's powerful word-processing program. A drawing which is later to be included in a word-processing document is exported from NOTIS-DRAW with a menu command. When the text is prepared, a print directive is used to indicate which NOTIS-DRAW illustration is to be included in the text. The print directive has parameters allowing the user to specify the position and the size of the illustration. This means that the drawing is automatically enlarged or reduced during printing, to fill the space indicated with the print directive. In this way, the user does not have to return to NOTIS-DRAW to change the size of the drawing.

NOTIS-WP has a preview function called Inspect mode, which allows the user to look at the formatted document before printing it out. Drawings which are included with the print directive are shown as shaded boxes. The user presses a single key to have the illustrations shown with the text. It is also possible to suppress the NOTIS-DRAW illustrations when draft versions of the document are printed out.
