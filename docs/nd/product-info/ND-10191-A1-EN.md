# ND 10191 FORTRAN for ND-100/NORD 10

## INTRODUCTION

ND FORTRAN is a programming language based on the ANSI-77 standard (ANSI x 3.9 - 1978). The compiler generates very compact code for optimal utilisation of the ND-100/NORD 10 computer.

The language implemented is the full ANSI-77. Also, those features of the ND FORTRAN products ND 10023/10033 which are compatible with, and in addition to ANS1-77 are implemented. Thus it maintains an upwards compatible path from existing programs.

## FEATURES

- Follows ANSI x 3.9 - 1978
- Inline functions for faster execution
- CHARACTER datatype for string manipulation
- Extended datatypes INTEGER*2, INTEGER*4, LOGICAL*2, LOGICAL*4, REAL*4, REAL*8, COMPLEX*8, COMPLEX*16
- DOUBLE COMPLEX for greater accuracy
- IMPLICIT statement to set default datatypes
- PARAMETER statement to name symbolic constants
- IF-THEN-ELSEIF-ELSE-ENDIF statements to improve program structure and readability
- DO FOR-ENDDO/DO WHILE-ENDDO loop constructs to improve program structure
- INCLUDE command for incorporating other symbolic files in the source text
- SIF-THEN-SELSEIF-SELSE-SENDIF commands to select part of a file for compilation
- CONSTANT command to set values of named constants globally, so as to allow multiple compilations with the same values
- Generation of tables for use by the symbolic debugger for rapid development of programs
- Full diagnostic ability, including an option to show where a program is using a feature not included in ANSI-77
- Standardised calling interface for easy invocation of routines written in other languages (e.g. PLANC, COBOL)
- Ability to place compilation options in the program source file by preceding the commands by a $

## OPTIONS

The ND-100/NORD-10 FORTRAN compiler makes available several other facilities.

- SCROSS-REFERENCE command lists all names and labels, together with their datatypes and the statements which reference them. This list is provided for each program unit on a file, and finally, a summary of the global hierarchy of invocations
- SDEFAULT command establishes the default size for LOGICAL, REAL and INTEGER variables and constants
- SUNIT command to establish default units for READ and PRINT statements
- SOPTIMISE command to set or reject the compiler’s optimisation of DO-loops, and of commoning of expressions. The optimisation of COMMON variables, can be suppressed through the MOVE-COMMON-VARIABLES command
- SLIST command turn the listing option on and off
- SPAGE-SIZE command to establish the size of a page on the compiler’s list file
- HEADING-TEXT command to provide the user with a title on each page of listing
- STANDARD-CHECK command to diagnose breaches of ANSI x3.9-1978
- CONDITIONAL-COMPILING command to retain compatibility with ND 10023 form of source code selection. In addition there is a SIF-STHEN construct to effect the same function
- SLIBRARY-MODE command to construct a library from the compilers object file
- SDEBUG-MODE command to generate tables for use by the symbolic debugger
- Generation of separated code and data, so that the data can be placed in an alternate segment. This is in addition to allowing special COMMON blocks to reside in a separate segment
- Generation of reentrant programs for use on RT segments
- Cross-compilation between 48-bit and 32-bit floating point machines
- Taking advantage of the micro instruction in the extended instruction set
- Generation of ND-500 FORTRAN compatible storage mapping
