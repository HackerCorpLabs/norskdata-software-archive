# Office Workstation OWS-85

## Introduction

Norsk Data's popular range of office workstations combines the strengths of the personal computer with the power and functionality of the minicomputer. Fast, predictable response times are integrated with access to Norsk Data's extensive range of office and data processing systems, providing you with the tools to tailor applications to your own special needs.

Your office workstation is an integral part of the organization's computer network. As well as giving you access to all the corporate data you require, a wide selection of facilities is available directly from your own workstation – advanced later printers, database management systems, office automation software and fourth-generation tools, to mention just a few. Sophisticated communications networking provides the links you need all over the world for efficient operations, right from your own workstation.

## Desktop PC/AT-compatible super-microcomputer

The 386-based Office Workstation OWS-85 provides the computing power of a dedicated 32-bit super-microcomputer for the price of a personal computer. It has been designed for use as a high-performance CAP workstation, a network file server or as an extremely high-performance IBM® PC/AT-compatible computer. The OWS-85 is the ideal choice for applications that demand the highest level of performance.

## Integration with ND minicomputers

The OWS-85 is an integral part of an ND system. Disk space, files and printers on the minicomputer are available for the workstation users, and applications, networking and electronic mail are accessible to everyone who needs them.

The ND DeskTop Manager, also included in the OWS-85 package, is a user program containing a terminal-emulator function which allows the workstation to perform tasks using the ND-NOTIS and ND-DIALOGUE product families, making full use of the screen-handling and keyboard facilities. A file-transfer function makes information stored on the host computer available to programs in the MS-DOS® environment, and vice versa. Under DeskTop Manager the user can install Norsk Data's newest tool for computer aided publishing, NOTIS-PET, and NOTIS-WP word processing for MS-DOS. Both products can store and retrieve files from several sources: ND-NOTIS Document Server on a host ND computer, the SINTRAN file system on an ND-100, ND-500 or ND-5000 computer, or files stored on a local MS-DOS disk. From the office workstation, you can print out on printers connected to the workstation, or centrally shared ND minicomputer printers connected to the ND-SPRINT spooling system.

## The power of the 80386 processor

The OWS-85 utilises the 32-bit Intel 80386 CPU chip operating at 16MHz. The CPU is compatible with the 80286 and 8088 microprocessors, so that applications written for the IBM PC/XT/AT series can be run without being adapted. An optional 80387 numeric coprocessor can be installed for accelerating mathematical calculation speed.

## Flexibility and expandability

The OWS-85 is based on Norsk Data's Systems Architecture For Expansion (ND SAFE), which allows you to increase your system's performance easily as your needs grow. In addition to the option of adding a number of storage peripherals, a variety of board products can be plugged into the bus. Since the system maintains PC/AT-compatibility, it is possible to install a wide variety of industry-standard boards that satisfy such requirements as high-resolution graphics, EGA/VGA graphics and communication adaptors for networking.

## Performance plus

A dedicated 32-bit memory bus provides fast access up to three memory cards. These memory cards combine fast static-column RAM chips with an interleaving scheme to provide memory access that is unrivalled in a personal workstation. Up to five half-height storage devices can be installed in each computer. Four of these devices are accessible to the user when the drive cover on the front panel is lifted. The system status display shows important system messages, disk activity, system performance, date, time and processor speed.

## Compatibility built in

The OWS-85 is designed to be fully compatible with the IBM PC/AT. A switchable compatibility mode is provided to ensure that timing-sensitive software applications remain compatible. Hardware compatibility is guaranteed through the use of an 8MHz PC/AT-compatible system bus.

## Specification summary

### Key features

- OWS-85 Office Workstation based on the Norsk Data Systems Architecture For Expansion, including the Intel 80386 32-bit microprocessor running at 16MHz with zero wait-states
- Dedicated 32-bit memory bus
- System status display with front-panel controls indicates date/time, processor speed, disk access and system performance
- MS-DOS 3.21 Operating System with enhanced features
- Diskette/hard-disk controller
- 1.2 MB internal 5 1/4" diskette drive
- Switch and software-selectable 8MHz compatibility mode
- Socket for 80387 numeric coprocessor chip
- Serial/parallel adaptor
- Ten PC/AT-compatible accessory slots: seven 16-bit slots, three 8-bit slots (one half-size) in total. Four free slots available for optional cards
- PC/AT and ND-NOTIS-compatible keyboard
- Security keylock
- Horizontal or vertical mounting

# Office Workstation OWS-85

## Internal Memory
- 2MB static column page-mode parity-checked RAM standard
- Expandable to 18MB supporting two-bank interleaving in static column RAM

## Mass Storage Support
- Supports up to four half height, or one half height and two full height internal mass storage devices.
- Diskette/hard-disk controller supports up to two internal diskette drives and up to two internal hard-disk drives
- 40 MB 40 ms average seek time hard-disk.
- 40 MB 28 ms average seek time hard-disk.

## Operating System
- MS-DOS 3.21 Operating System with GW-Basic®3.21
- Under MS-DOS, enhanced features include:
  - online Help facility, a software security system and software emulation of the LIM and AST Expanded Memory Specifications
- MS-Windows® and DTM, ND terminal emulator plus file transfer is included.

## Keyboard
- 128-key PC/AT plus ND-NOTIS-compatible keyboard
- Labelled function keys
- Separate numeric and cursor keypads
- Programmable pushkeys. The pushkeys may store recurrent commands, program names and phrases

## Dimensions
- Width: 53.7cm (21.1 in)
- Height: 16.2cm (6.4 in)
- Depth: 44.7cm (17.9 in) without keyboard
- Footprint: 0.25m² (2.6 sq ft)
- Weight: 16.2kg (36lb) excluding keyboard, including one diskette drive

## Environmental
- Operating temperature: 10°C to 32°C (50°F to 91°F)
- Non-operating temperature: -20°C to 60°C (-40°F to 140°F)
- Humidity: 20% to 80% (noncondensing)
- Altitude: 0 to 10,000 ft (operating), 0 to 35,000 ft (non-operating)
- Maximum shock: system in shipping package meets NSTA standards for shock and vibration

## Regulatory Compliance
### Safety
- UL Listed
- CSA Certification
- TUV Approval
- NEMKO Approved

### RFI
- FCC Certified (Class B)
- VDE Level B (Radio Protection Mark-0871B)

## Input Voltage
- Externally switchable worldwide power supply: 90-132V at 47-63 Hz; 180-264V at 47-63Hz
- Fuse: 6 amp, slow-blow (Type T)
- Dropouts: 10 ms with no effect

## Power Consumption
- 315W maximum (convenience outlet unused)

## Availability
- Available effect from the power supply: 
  - 24A at +5V
  - 8A at +12V
  - 0.3A at -5V
  - 0.3A at -12V
- Switched convenience outlet

## Heat
- 1075 BTUs maximum

## Ergonomics
- Complies with German Standard ZH1/618

## Standard Configurations
- OWS-85, Intel 80386-based model with 2MB RAM and 1.2 MB 5 1/4" floppy drive

- Host connection

## Options

- Range of large and fast hard-disks
- Serial/parallel adaptor

## Monitors

- OWS 1600 * 1280 Resolution 19" B/W monitor w/adaptor
