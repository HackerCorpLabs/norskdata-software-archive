# NDIX

## Introduction

NDIX is Norsk Data's implementation of the UNIX<sup>1</sup> operating system. NDIX is based on the Berkeley 4.2 BSD version of UNIX. NDIX also provides most of the facilities specified in the kernel-base section of AT&T System V Interface Definition. NDIX runs on the ND-500/CX computer systems and makes full use of the ND-500 virtual memory architecture.

In addition to 4.2 BSD networking and communication facilities, NDIX has access to XMSG. Communication between NDIX and SINTRAN tasks can be established through XMSG, thus giving a gateway to SINTRAN. (SINTRAN is ND's proprietary operating system)

## Product description

The NDIX package consists of the UNIX operating system kernel, command interpreters, tools and utilities, text processing, FORTRAN, C, PASCAL, communication systems, SINTRAN and a utility program for NDIX/SINTRAN file transfer.

NDIX runs on ND-500/CX computer systems. (Must be second-generation hardware — MPM V and 500/2.) The ND-500/CX computer system comprises a ND-100 CPU and a ND-500 CPU. The NDIX operating system kernel runs in the ND-500 CPU while SINTRAN runs in the ND-100 CPU. A software interface has been defined between the two operating systems. Through this interface, NDIX has access to the well proven SINTRAN I/O system. Thus, the ND-100 CPU acts as an I/O processor for the ND-500 CPU. A terminal can be attached to either SINTRAN or NDIX.

# NDIX

## Features

### The Operating System:
- Virtual memory with demand paging
- Multi-user, multi-tasking
- System Services: Maintenance and administration tools
- Hierarchical File System

### Command interpreters:
- Bourne Shell
- C-Shell

### Languages:
- C
- F77
- PASCAL

### Programmers' tools:
- Program development and maintenance: make
- Source Code Control System: SCCS
- Symbolic Debugger: dbx
- Development aids: awk, diff, grep, sort, etc.

### Text processing:
- Screen editor: vi
- Line Editors: ed, ex
- Text formatting tools: nroff, tbl, eqn, refer

### Communications:
- Electronic mail
- uucp
- Ethernet support: TCP/IP, UDP/IP, tftp, ftp, telnet
- XMSG interface library giving access to XMSG/COSMOS

## SINTRAN Interface:
- Gateway: Inter-process communication through XMSG.
- File transfer between SINTRAN and NDIX: cps

## Portability of UNIX applications:
- Berkeley 4.2 BSD implementation
- All facilities specified in AT&T SVID kernel-base section, except for System V signal handling and System V terminal I/O

## Enhancements to standard Berkeley 4.2 bsd enhancements
- System V utilities: SCCS, cpio
- AT&T SVID: Most facilities described in the kernel-base level
- XMSG library giving access to SINTRAN/COSMOS
- Inter-process communications NDIX/SINTRAN
- Optimised virtual memory implementation
- Improved make to utilize the SCCS system
- Symbolic debugger (dbx) useable with all supported languages

## Requirements
ND-500/CX Computer Systems, (second generation)  
Minimum memory requirements:
- 2 MB in ND-100 CPU
- 4 MB in ND-500 CPU

Minimum of one disk drive, 140MB or 2x70 MB  
SINTRAN version K VSX  
SINTRAN XMSG software  
COSMOS Basic Module  
Ethernet interfacing tools for ethernet support
