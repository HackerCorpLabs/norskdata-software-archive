# ND 10338 ND-500 Microcode for Array Processing Functions

## INTRODUCTION

Within many areas of applied science and engineering there is the need for the processing of heavy compute bound iterative arithmetic.

For real-time data reduction, evaluation of data on site and many other time-critical tasks it becomes a necessity to increase the throughput to save time and money.

ND-10338 Microcode for array processing functions may be installed in any of the computers in the ND-500 series: ND-520, ND-540 and ND-560. Floating point arithmetic may be processed up to an order of magnitude faster with the array processing functions implemented in one of these CPUs. Cost effective solutions can be obtained for tasks as simple as basic signal processing up to the most complex scientific calculations.

Some of the applications that were in mind for the design of ND-10338 were: Image processing, seismic modelling and analysis, simulation programs, quantum mechanical and high energy physics calculations.

## HARDWARE

The ND-10338 Microcode is a microprogram which contains both the standard instruction set for the ND-500 series of computers and the ND-500 array processing functions. Together with the microcode the library for ND-500 array processing functions is installed.

The array processing functions for floating point operations are performed in 32 bits floating point format by the ND-500 floating point arithmetic.

The ND-500 gives possibilities of parallel processing. This means that indexing, memory access, floating point arithmetic, integer arithmetic and loop control may be run in parallel to obtain high speed operations. Temporary results to be used in later calculations, are kept in registers in the ND-500 CPU, accessed directly by both the floating point arithmetic and the integer arithmetic.

Arrays involved in an operation are accessed through the ND-500 memory management system. It then allocates memory automatically. Reservation of continuous memory space is not required for ND-500 array processing. The result of an array processing function is presented in an output array. The ND-500 array processing functions are fully interruptable to maintain the ND-500 CPU resources shared between the different processes running concurrently.

## USING THE ARRAY PROCESSING FUNCTIONS

The array processing functions may be called from FORTRAN. The array processing library is used to transfer the parameters from the call to the array processing instructions. Thus the array processing functions are connected to the main program at load time as part of the program.

Writing a FORTRAN program for array processing with ND-500 array processing functions is much the same as using the FORTRAN equivalent in the array processing function. Before starting an array processing function, input and output arrays for the operations must be defined. Initialization of the input arrays are required, that is, data for processing must be placed in the input arrays for the relevant array processing function. Then the desired function may be called. The result of the operation appears in the output array, which is returned by the function.
