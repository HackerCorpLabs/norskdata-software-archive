# MERCUR FOR ND-500

## INTRODUCTION

MERCUR is a high-level language for creation, manipulation and presentation of tabular information. The main objective of the language is to offer a powerful tool for building and running financial models on ND computers. MERCUR can be used to develop, maintain, extend and analyze different kinds of model constructions.

MERCUR is a tool for any organization which has stringent demands for efficient and continuous financial planning and analysis. It is used in a variety of businesses, including manufacturing industries, banks, insurance/shipping companies and local and national governments. It is suitable for people at all levels and in all departments.

In order to perform efficiently, a company's management must be provided with the proper resources and capabilities for budgeting, planning, analyses and simulation.

## PRODUCT DESCRIPTION

### Data

The MERCUR system is based on data tables. All tables are stored in a table database. Users have their own table library whereby data can be stored, accessed and manipulated. Manipulation of data is very simple, requiring no prior EDP experience. The system has the capacity to make rows, columns, text, titles, underlinings and other editing information that the user is likely to need. The formatted table is the user's finished report. A data table can be displayed on a screen, changed or updated, and MERCUR can recalculate the new values.

The ND version of MERCUR can exchange data with ND standard software like the Report Generator, ACCESS, NOTIS-WP and Business Graphics.

### Arithmetic

Besides addition, subtraction, multiplication and division, MERCUR contains expressions and standard functions to present economic status, calculations of annuities, internal dividends and statistical calculations.

### Where in the organization

Anyone involved in budgeting, calculation, reporting and analysis is a potential user of MERCUR. On the top management level MERCUR can be used to define company goals and set overall budget conditions and restrictions. On other levels in the organization, MERCUR can be used for tasks including cost allocation and distribution, pricing, calculation of sales cost, simultaneous equations etc.
