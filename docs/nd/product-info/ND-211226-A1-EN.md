# Backup Manager

## Introduction

The ND BACKUP MANAGER offers a variety of facilities and functions for copying files, directories (disks), databases and archives to and from disk, diskette, magnetic tape, streamer tape and optical disk.

The Backup Manager is useful for supervisors and operators responsible for safety copies on ND computers. End users will also find the functions for copying of personal files both useful and easy.

The Backup Manager concept consists of four modules: Backup Manager Operator, Backup Manager Definition, Backup Manager Scheduler and Backup Manager File Restore.

Occasional copying of files, disks and databases is done in the Operator module. Recurrent backup procedures may be predefined in the Definition module and started in the Operator module or scheduled for automatic start in the Scheduler module. Single files may be restored from an image copy on a volume, e.g. on a magnetic tape, streamer tape or a disk, from the File Restore module.

## The Backup Manager Operator module

The main module in Backup Manager. Backup Manager Operator has powerful commands for file copying, image copying of entire disks and the possibility for database copying.

![Screenshot of a software interface with various options for backup operations.](data:image/png)

## Product Description

### General

- Batch mode
- Erase volume
- List volume
- User-defined parameter settings

### File copy

- Multidirectory and multiuser search both locally and remotely in an ND-COSMOS network.
- Files to and from streamer tapes, magnetic tapes, diskettes and disks (directories)
- Inclusion or exclusion of files from a base selection
- Simultaneous backup/copy and file shrink

### Image copy

- Image copy to and from disk, streamer tapes, magnetic tapes and optical disks
- Copying of only those parts of the disk that are actually used
- Compare after copy
- Several images on one volume
- Mixing of images and files on the same volume
- Automatic splitting of images over several media, if needed
- Control of active users (messages, log out, open files)
- Resetting of "modified-bit" of all files on a directory

### Database copy

- Controlled closedown of database
- Control of active users (messages, disconnect)
- File copy of database
- Image copy of database
- Incremental copy of database
- Automatic reset of R-log
- Automatic start of database after copying

## The Backup Manager Definition module

Makes it possible to predefine backup jobs to be started from the Backup Manager Operator module or from the Backup Manager Scheduler Module. The Definition module stores each backup set in an ISAM database. Each set is built up of jobs in a hierarchical way.

# Backup Manager

## Product Description

- Definition of both backup and restore sets
- Access control to the defined sets
- Consistency check of sets defined
- Several jobs in one set

## The Backup Manager Scheduler Module

Makes it possible to automatically start backup sets defined in the Definition module at a given time. Ordinary SINTRAN batch jobs may also be scheduled in the same way. The Scheduler module consists of a menu-oriented user interface with powerful commands for editing and monitoring the queue of scheduled jobs. A server running in the ND-100 part updates the queue and starts the batch jobs when the specified time arrives. This server may be accessed through an ND-COSMOS network.

Product Description:

- Scheduling of both backup sets and SINTRAN batch jobs
- Scheduling possible once, daily, weekly, monthly and at specified intervals
- Scheduling in an ND-COSMOS network
- The queue is automatically updated if interval specified
- Editing of queue possible
- User-defined messages to terminals at startup

## The Backup Manager File Restore Module

Makes it possible to restore SINTRAN files from an image backup. The File Restore module is based on the DMA server.

## Product Description

- Restore file
- File statistics
- User statistics
- Multimedia images

## Features

- All Backup Manager modules have a simple, menu-oriented user interface with online help facilities
- Database backup in one command
- Predefinition of backup sets reduces the level of expertise required for operators to take backup
- Automatic start of backup sets and SINTRAN batch jobs reduces the need for manual intervention
- Copies of several images to one volume make it possible to back up the data storage of whole computers in one operation
- Separate files can be stored on streamer tapes
- Single restore of files from image volume copies

## Prerequisites

- ND-500/5000 CPU
- SINTRAN-III version L
- DMA server (part of Backup System) version C
- SIBAS-II for ND-500(i) if database backup features are used
