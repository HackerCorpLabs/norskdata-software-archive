# NOTIS-BG BUSINESS-GRAPHICS

## Introduction

- NOTIS Business-Graphics (NOTIS-BG) is a program for graphical presentation of numerical data. Data may be entered with a user-friendly input form, or fetched from existing files made with NOTIS-CALC or NOTIS-RG, for example.
- With the help of pre-defined chart descriptions, NOTIS-BG presents the data as pie charts, bar charts, column charts or line charts. There is also a chart type for charts that only contain text. Charts may be displayed on the screen or output to a printer or a multicolour pen plotter.

## Features

- Once data is entered and a chart description chosen, only two keystrokes are needed to produce the chart on a screen or a printer.
- Charts may be stored on a file and included in a NOTIS-WP document.
- Any data may be used with any chart description. One set of data can be shown in three different charts, or a single standard chart description used several times with many different data sets.
- Chart descriptions are pre-defined to save time; however, any part of the chart description may be edited to give the exact appearance desired.
- Data tables and chart descriptions are presented as simple forms. Standard NOTIS form-editing features.
- Standard NOTIS command menus.
- Extensive online HELP. Direct HELP for any cursor position in any form.
- Optional automatic HELP: A continual, online display of parameter choices for the current cursor position.
- Several charts per page.
- With plotter, colours are available. Plot in colour on paper or overhead transparencies.
- Store either in NOTIS-DS archive system or in SINTRAN.
- Simple NOTIS-BG command language available as alternative to interactive chart definition. NOTIS-BG command language files may be generated by other programs, for example NOTIS-CALC or NOTIS-RG.

# NOTIS-BG BUSINESS-GRAPHICS

## Product Description

To produce a chart, NOTIS-BG uses one or several data tables and a chart description. Empty data tables may be generated with a menu command. Data may be entered manually or fetched from existing data files.

Chart descriptions may be generated with a menu command. The user must specify the chart type. The chart description consists of several forms with entries for items such as chart size, position and framing, axis appearance, chart texting, and colour and patterns for chart elements. To save time, the chart description is completely filled in with default values. All fields may be edited by the user. Personal standard-chart descriptions may be stored and used again with any data. Online HELP shows the options for each field in a form. Default values may be recovered by pressing the CANCEL key.

If non-interactive chart definition is preferred, the user may create a file containing NOTIS-BG command language and data. Command language files can also be created automatically with programs such as NOTIS-RG.

NOTIS-BG can display a chart on the screen, or output it to a printer, a plotter, or another file. All charts produced on a printer will be in black and white, while charts produced on a plotter may be in colour. The plotter may also be used to produce charts on overhead transparencies. When a chart is output to a file, the file may be included by reference in a NOTIS-WP text document. The printout of the text document will then contain both text and chart.
