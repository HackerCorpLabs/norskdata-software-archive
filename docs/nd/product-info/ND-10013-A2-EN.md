# ND 10013 NSHS - NORD SCREEN HANDLING SYSTEM

## INTRODUCTION

The **NORD Screen Handling System (NSHS)** enables the user to define screen picture formats interactively at display terminals with cursor control, and to use these pictures for the input and output of data to and from programs.

It is possible to create interactively screen layouts or pictures for data entry forms by typing in leading texts, and data input field descriptions. Data input fields can be specified with various editing formats and storage codes; input control functions can be specified for each individual input field.

Pictures are stored on a disk file, and can be retrieved via user programs written in FORTRAN, BASIC, COBOL or RPG II. The pictures may be used for entering or displaying data records which are stored on user files or databases. Programs may also use the same pictures as input media to directly update local data bases. Hardcopy pictures can be produced on a line printer.

## FEATURES

- Advanced screen handling operations using asynchronous display terminals with cursor control
- Immediate reaction to errors both at the character entry level and at the data field entry level, such that when all data fields have been entered, they are correct as far as the system can judge. One need not wait until the screen is full before error checking takes place
- Built-in field editing, storage conversion and field control functions
- Standard field editing of numeric, decimal, alphabetic, alphanumeric fields, bank account and social security number, various data formats
- User defined field editing if required
- Storage control for automatic conversion to internal representation of integer, bytes and packed decimal forms
- Field control by content checking defined as a part of picture definition:
  - legal and illegal values and range
  - default value
  - check digit verification (modules 10 or 11)
  - date-controls
  - field accumulation
  - user supplied control procedures
- Easy to alter field values, by copying previous value, inserting or deleting characters. All done by simple keystrokes
- Screen handling library routines for user programs

- NORD Screen Picture Maintenance Program

# NORD Screen Handling Library

The **NORD Screen Picture Handling Library** is a collection of subroutines to be used from a user program written in FORTRAN, BASIC, COBOL or RPG II.

There are routines to retrieve compiled picture definitions into the program, to write leading texts and fields with or without data to the screen, and to read data as keyed in by the operator.

The program may gain control for each field when a series of fields has been entered, or when a special function key has been depressed. Data is read into and written out from a program area according to the storage codes for each field.

In addition, there are routines to clear individual fields or the whole screen; to set and reset read-fields; to lock fields so that they effectively become protected areas; to set mandatory read fields; to write messages on the last line of the screen. Both reentrant and non-reentrant versions of the Screen Handling Library exist. When many active programs are using the system, one should use the reentrant version.
