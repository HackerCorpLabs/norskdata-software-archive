# ND 10333 ND-500 MONITOR

## INTRODUCTION

The ND-500 Monitor is an extension to the multi-user SINTRAN III/VSE Operating System. It supervises the execution of programs running concurrently in the high-speed 32 bit ND-500.

The ND-500 Monitor's tasks are:

- Initialization and control of programs running in the ND-500
- Allocation of physical memory to programs
- Timesharing of user programs
- Execution of input/output operations and other system functions requested by user programs
- Control of communication between the ND-500 processor and the ND-100 auxiliary processor

In addition a number of system functions are incorporated:

- Initialization of the ND-500 down load of control store
- Initial memory allocation for the ND-500

## FEATURES

- Easy to use
- Simple commands
- Abbreviated commands
- Parameter prompting
- Macro facilities
- Sophisticated time-sharing algorithm
- Runs program consisting of from 1 to 30 program segments and from 1 to 30 data segments
- No practical limitation to user program size (4GB program + 4GB data)
- May treat data files as arrays (i.e. equivalence between data files and segments)
- Memory usage control
  - can fix segments in memory
  - maximum/minimum number of pages per segment
- Performance measurement and logging
- Handles standard SINTRAN III monitor calls

## PRODUCT DESCRIPTION

The monitor consists of several programs. The page-fault handling and memory administration routine runs on the ND-500 processor. The others, for example the interactive command processor, run on the ND-100. The monitor itself is interactive and its command fall into 4 main groups:

- Commands to execute programs
- Debugging commands
- Commands to measure and log performance
- System supervisor commands

### Commands to execute programs

A domain containing a program may be fetched into memory and the program started up. Execution may be halted and later restarted, if required.

### Macro

Commands composed of other commands may be constructed using the macro facility. Logic statements may be included in order to terminate macro execution if an error stop occurs.

### Debugging commands

A set of LOOK-AT commands enable the inspection and modification of registers, memory and segments. Instructions may be modified symbolically, and addresses may be entered either absolute or relative to base addresses, register values, etc. Different output formats may be used. TRACE GUARD and BREAK commands enable speedy location of errors.

The ND Symbolic Debugger is the normal tool for debugging high level language source programs.

The ND-500 hardware is able to trap a number of error or exception conditions. Some such conditions will result in a program stop automatically. Action on non-fatal conditions may be decided by the user.

# Performance Measurement

A histogram showing CPU use as a function of (logical) memory address areas may be compiled. This may be used in order to investigate in which areas of a program most processor time is used.

# Supervisor Commands

Commands for initiating ND-500 system memory configuration and other supervisor commands may only be executed by user SYSTEM. The supervisor may choose how much memory may be used by the ND-500.

The control store (microprogram) of the ND-500 may be loaded and a number of tests run. The control store may also be edited.

A data segment may either be swapped out onto its original file, or a system selected swap file. Commands for the definition and deletion of such files are present.

# REQUIREMENTS

ND-500 system with minimum 1/2 MBytes memory.  
SINTRAN III/VSE-500.
