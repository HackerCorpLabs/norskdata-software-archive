# ND 10072 DATACON

## INTRODUCTION

Transfer of data files from one computer system to another is often a costly and time-consuming process demanding massive efforts by the DP staff.

DATACON is a general purpose data conversion utility system for users of NORD computers running under the SINTRAN III/VS Operating System. It is primarily designed to ease interchange of data between NORD computers and computers of a different origin. However, its capabilities may also be employed to secure the integrity of "hot" data on an installation or for simple report generation.

## FEATURES

- User defined alphabets and mapping tables
- Coding/decoding of confidential data for higher security
- Inspection of all sorts of data files
- Simple report generation
- Conversion of record fields from upper to lower case letters and vice versa

## PRODUCT DESCRIPTION

DATACON is a software system implemented on NORD computers to run under the SINTRAN III/VS Operating System. It offers facilities which can be used for applications that extend beyond mere computer-to-computer data conversion, as it permits a wide range of options for data manipulation on the user's own system. A DATACON user can define his own alphabets, create mapping tables, design and alter record layouts and file characteristics and submit the descriptions of data fields within a record which are to be inspected or extracted.

A DATACON statement sequence is entered via the QED Editor, and stored as a source file named DATACON-ALPHA:SYMB, and can be executed either interactively or in batch mode. For instance, the need may arise in a certain application to convert data from EBCDIC to ASCII format, and then to change file and record properties. The necessary DATACON statements may in such a case be predefined and reside permanently in the system, and be called and executed every time that particular application is run.

A standard set of character conversion tables is delivered by NORSK DATA with the object version of DATACON. Copies thereof can be modified to suit the individual requirements. The DATACON-ALPHA file may contain any number of alphabets and mapping tables, and the user is free to create his own coding conversions to protect the integrity of sensitive data.

Complete files or subsets can be processed interactively or in batch mode without any operator intervention. DATACON includes a DISPLAY command which enables the user to present records on the terminal or any desired output device with additional information such as page numbers, field headings, record numbers and interfield spacing. Control characters and characters defined by more than one letter in an alphabet convention can be fully presented by use of the command.

# Command Summary

The DATACON command repertoire comprises three different categories:

## Table Definition/Conversion Commands

- **ALPHABET**
  - `<alphabet name> BYTESIZE <n> BITS`
  - `<decimal ch value 0>`
  - `<character name>`
  - `<decimal ch value n-1>`
  - `<character name>`
  - — defines an alphabet.

- **MAPPING**
  - `<alphabet name A> TO <alphabet name B>`
  - `<decimal ch value 0 alpha A>`
  - `<decimal ch value alpha B>` etc.
  - — defines the conversion rules between different alphabets.

## Record Description Statements

- **FILE**
  - `<logical file name>`
  - `[RECORD-TYPE <alphabet name>\<field size>]`
  
- **RECORD**
  - `<record name>`
  - `<file name 1>\<alphabet name>\<field size>`
  - `<file name 2>\<alphabet name>\<field size>`
  
- **[RECORD-TYPE]**
  - = "`<record type identification>`"
  - `<file name x>\<alphabet name>\<field size>`
  
- **END RECORD**
- **END FILE**

## Run-time Commands

- **DATACON**
  - — invokes the DATACON Utility System
  
- **PAGE SIZE**
  - `<no of lines> LINES <no of options> POSITION`
  - — describes output media page size

- **STATUS**
  - — lists on the terminal the current values entered by preceding DATACON commands

- **SYNONYM**
  - `<n>:<file name A> = <file-name B>`
  - — assigns a physical file to a logical file name
  
- **CONVERT**
  - `<set> FROM <file name> TO <file name>`
  - — executes a regular data conversion from one file to another
  
- **DISPLAY**
  - `<set> FROM <file name> ON <file name>`
  - — provides a simple report showing records processed by DATACON

- **EXIT**
  - — terminates DATACON mode with return to SINTRAN.
