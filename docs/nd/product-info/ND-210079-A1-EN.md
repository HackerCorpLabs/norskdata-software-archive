# WORD PROCESSOR

## Introduction

NOTIS-WP is a powerful and flexible word processor constructed to satisfy office users as well as others who require a complete word-processing facility. It is easy to learn and simple to use. NOTIS-WP is suitable for users at any level of experience, trained or not. NOTIS-WP can be used wherever documents of any type are created and/or modified, e.g., for report writing, journalism, technical specifications and correspondence.

The menu structure of NOTIS-WP makes all functions easily accessible to the inexperienced or occasional user, and to those who prefer a menu-driven system. Users who prefer a command structure can turn the menus off.

Editor menus allow users to tailor document layouts and editor functions to meet their own needs.

NOTIS-WP has an extensive HELP system with context-oriented HELP pictures. HELP is available via a function key and via keywords.

NOTIS-WP is a member of the powerful ND-NOTIS family. All products within this family are closely integrated. This means that information entered in one product can migrate through the rest of the family when needed in another context.

## Features

- Integrated with the ND-NOTIS and ND-DIALOGUE families
- Separate keys for all important word-processing functions
- User-definable keys and standard texts
- Edit multiple documents
- Greek, mathematic and graphic character sets
- Full Teletext and national character sets
- Include pictures generated by NOTIS-BG, NOTIS-DRAW and Technovision
- Column arithmetic
- Hyphenation assistance
- Context-oriented HELP
- Automatic chapter and section numbering
- Automatic table of contents
- Arithmetic functions
- Sorting
- Box graphics

## Storage

Documents are stored in a hierarchical structure. Documents are stored in folders, which are grouped into drawers that belong to users, within a cabinet. In addition to the document name, 60 characters of subject information may be stored at each level of the hierarchy. A document may be given a name of up to 30 characters, freely chosen by the user. A document may also have three keywords of up to 20 characters each. These may be used to locate documents. Access to documents may be restricted to one user, or may be open to a list of selected users or to all users. Several machines can share a cabinet, if desired. More information about storage can be found in the data sheet for NOTIS-DS.

## Document Storage

An alternative storage method is storing within the operating system SINTRAN. The documents are then stored in separate user areas, but with no search facility.

## Text Formatter

When a document has been prepared by the NOTIS-WP editor, it is in most cases completed and can be printed on any ND printer. In some cases, further processing of the document is required.

The Text Formatter, NOTIS-TF, is an advanced document design and programming tool that may create indexes, handle footnotes, references and standard documents, and so on. It may also be used to create individual letters to clients on the basis of information extracted by other ND-NOTIS and ND-DIALOGUE products.

## Features

- Powerful macro programming
- Footnotes
- Appendices
- Standard-letter addressing
- References
- User designed layouts

## Requirements

User Environment, version B or later  
Operator Environment, version A or later
