# ND SNA Gateway II

## Introduction

The ND SNA Gateway II allows an ND system with locally attached devices to connect to an IBM® SNA network. The SNA Gateway II is the second generation of SNA Gateways. This implementation gives support to LU6.2 which is one of the main elements in IBM's SAA (System Application Architecture).

The gateway runs one communication line. The product emulates the SNA PU type 2 secondary, and consists of the following:

- ND 210569 PIOC Basic Software.
- ND 211277 SNA Gateway II.

## Features

- Supports different LU types (0, 1, 2, 3 and 6.2)
- Supports 65 LUs
- Supports IBM maintenance applications (NCCF, NPDA etc.)
- Logging facility
- Configuration facility
- Supports COSMOS
- Up to four PIOCs/SNA Gateways in one ND system.

## Product Description

The ND SNA Gateway II includes the ND SNA Basic Software which covers the data-link control, the path control, the transmission control and the data-flow control of the SNA architecture. As can be seen from figure 1, the SNA Basic Software is implemented in the PIOC (ND Programmable Input/Output Controller). This relieves the ND-1xx of much of the communication protocol handling. The PIOC is built around a Motorola 68000 processor with 512 Kbyte RAM. The communication lines on the PIOC use RS232 C (V.24) interface.

# ND SNA Gateway II

The application in the ND system can be a background program (SNA 3274 emulation or a customer-written application), or a real-time program (Remote Job Entry). Application programs can be distributed on different ND computers using the COSMOS network, giving all users access to all applications from any computer in the network. SNA Gateway II supports APPC-LU6.2 Program Library.

## Network Management

The SNA Gateway Supervisor, which is part of the Gateway Module, is a menu-oriented RT program. The program performs such functions as starting and stopping the links, monitoring and configuration. Among the monitoring functions are:

- Indicating configuration status
- Getting the LU status
- Checking the performance of the Gateway
- Indicating the quality of the line
- Getting DLC statistics

The configuration functions are:

- Allocating CPUs, terminals or applications to dedicated LUs
- Giving passwords to each LU

## Requirements

- SINTRAN III VSE/VSX version K or later
- PIOC, 512 Kbyte - ND 108670
- PIOC Basic Software - ND 210569
- XMSG Single System (Included in SINTRAN) or
- XMSG Inter System (Included in COSMOS Basic Module)
