# ND 10178 ND IDT MSV2 Siemens Emulator

## INTRODUCTION

Remote Job Entry – RJE – offers both economical and functional advantages. An inexpensive RJE-terminal gives a user access to the processing power of a host mainframe, or one of several organizations can share the same data and programs. This is the current trend – towards increasingly complex computer networks.

The ND IDT MSV2 Emulator is specifically designed for remote job entry to Siemens computer systems of types 4004 and 7000. The range of possible RJE configurations provides the user with numerous options concerning the mix of local and remote processing. For instance, data entry, program editing etc. can be performed locally while compilations and file updating routines can be submitted by RJE to the host mainframe.

ND IDT MSV2 Siemens Emulator is a software system running under the SINTRAN III/VS with the ND File System for use on NORD-10/S and ND-100 computers. NORSK DATA has extensive experience with RJE applications and markets and supports RJE terminals and software protocols compatible with all major makes of mainframes. Our product covers the range from simple core-only configurations to multiple remote operation systems with sophisticated features.

## PRODUCT DESCRIPTION

The ND IDT MSV2 Emulator is a software system developed for the ND-100 computer series with the SINTRAN III/VS operating system. This emulator is a communication system which enables ND computers to interact with Siemens 4004 and 7000 systems.

The software package comprises a set of asynchronous real-time programs, each assigned specific functions. Based on a modular design, it is a software concept which prevents bottlenecks due to slow peripherals from degrading overall system performance.

The ND IDT MSV2 Emulator provides a communications protocol with the Siemens 4004 and 7000 host systems. It handles operations like spooling of I/O files, job priority scheduling and assignment of peripherals. Normally, the Siemens system supports a configuration comprising card reader, console, punch and line printer.

The ND IDT MSV2 Emulator leaves the user free to substitute any other type of device for the card reader, the punch and the line printer. In addition, disk files can be used as storage devices for I/O files, alternatively diskettes (i.e. FLOCON).

## FEATURES

- Transmission rates from 1200 to 9600 bps 
- Supports both transparent and non-transparent communication protocols as user options 
- Communication via private or dial-up lines 
- Advanced versions support I/O spooling 
- Comprehensive repertoire of local commands with SINTRAN syntax with command and parameter abbreviation 
- Multiple console support 
- Console log on dedicated disk file

## COMMAND SUMMARY

All local commands conform to familiar SINTRAN syntax, and may thus be abbreviated as long as they remain unambiguous. Local commands fall into three categories – initialization, general and service commands.

Remote commands are listed in the ND MSV2 Operator's Guide.

# COMMENTS

Several users may communicate with the host computer simultaneously. Any unsolicited message from either site is logged on a dedicated disk file. Both local and remote commands are available to the users, however, command protection can be established by use of passwords.
