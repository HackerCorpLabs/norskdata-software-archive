# Software Conversion Tools

## ND 10605 FORTRAN CONVERTER for ND-500

### INTRODUCTION

The FORTRAN CONVERTER is a tool for the conversion of FORTRAN programs. The tool is used to assist the programmer in the task of converting foreign FORTRAN programs to run on ND computers. The FORTRAN CONVERTER belongs to the set of Software Conversion Tools.

### FEATURES

- Diagnostic capabilities will highlight non-ND FORTRAN constructs.
- Automatic translation of a range of syntax constructs:
  - ENCODE/DECODE, ACCEPT/TYPE
  - ! as comment indicator
  - XOR intrinsic function
  - foreign forms of constants
  - DO statements
  - etc.
- References to translation rules for other non-converted constructs.
- Optional handling of INCLUDE statements and commands found in source.

### PRODUCT DESCRIPTION

The FORTRAN CONVERTER tool translates a series non-ND FORTRAN constructs to their equivalent ND FORTRAN statements. The constructs which are not translatable, are automatically highlighted by error messages. Accompanying the error messages, are references to the possible correctives actions (to be performed manually) which are described in the FORTRAN CONVERTER manual.

The resulting programs may, depending upon size, be compiled for an ND-100 and/or ND-500 machine. The FORTRAN CONVERTER handles INCLUDE files as separate files or optionally as one output stream.

### REQUIREMENTS

- ND-500 Computer System
- SINTRAN III version I or later
