# ND 10358 X.21 Option for RJE-Packages and Terminal Concentrators

## INTRODUCTION

The X.21 option for RJE (Remote Job Entry) -packages and terminal concentrators provides a simple method for establishing connection with other subscribers over an X.21 Public Data Network – for running RJE-packages.

All ND Remote Job Entry packages and terminal concentrators can use this option. Instead of an ND-701 synchronous modem interface the HDLC interface is then used.

This program package guides the operator through informative HELP messages. In case of an error, messages are displayed or given on an appropriate device.

## PRODUCT DESCRIPTION

The X.21 option for RJE-packages and the Terminal Concentrator program package consist of a software system which defines symbolic names and attributes for subscriber numbers.

Users may establish connections through the X.21 Public Data Network by referring to symbolic names rather than to long, tedious identification numbers. Of course numbers may be used as well.

For each name, attributes may be defined, such as «selective direct call» or «reversal of charges».

This program package provides elaborate help commands and accepts abbreviated commands, where possible.

# Features

- Symbolic representation of subscriber numbers in a library
- Library routines for dealing with pre-defined subscriber numbers
- Parallel running for different RJE on different lines
- Changing information
- Logging of calls
- Mode-files facility

# Prerequisite

ND-720 HDLC-interface or ND-733 HDLC-DMA interface.

# Available Commands

| Command    | Description                                           |
|------------|-------------------------------------------------------|
| HELP       | List available commands.                              |
| DEFINE     | Enter subscriber number, name and attributes in library. |
| DELETE     | Delete subscriber from library.                       |
| DIRECTORY  | List names/numbers/attributes in library.             |
| CALL       | Call predefined subscriber number in library.         |
| DIAL       | Dial number not in library.                           |
| READY      | Indicate that incoming calls are now accepted.        |
| GSTAT      | Get status of this line.                              |
| CLEAR      | Clear connection from the Public Data Network.        |
| LOG        | Log next call.                                        |
| LIST       | List last logged calls.                               |
| EXIT       | Exit from the ND 10358 program.                       |
