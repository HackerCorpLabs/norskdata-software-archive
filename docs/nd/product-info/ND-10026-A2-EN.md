# ND 10026 NORD IDT CDC 200 USER EMULATOR

## INTRODUCTION

The Remote Job Entry approach to data processing offers several significant advantages. Without having to incur large capital outlays, an RJE terminal user may share the processing power of a host mainframe computer and gain access to centrally stored programs and data.

The NORD IDT CDC 200 User Emulator is specifically designed for remote job entry to CDC CYBER/6000 series systems, and provides a range of options that affords the user the freedom to configure his RJE terminal in accordance with his particular applications and functional requirements. For instance, it is possible to perform such typical operations as data entry and program editing locally at the terminal site, while file updating routines and compilations are submitted to the host mainframe.

With several years of experience in the field, NORSK DATA can offer RJE terminals for all major makes of mainframes, from simple core-only configurations to multiple remote operation systems with elaborate spooling facilities.

## PRODUCT DESCRIPTION

The NORD IDT CDC 200 User Emulator is a software system running on NORD-10/S under the SINTRAN III/VS operating system with spooling of I/O files, alternatively available as a core-only system running under SINTRAN III/RT.

The software package consists of a set of asynchronous real-time programs, each assigned a specific task. By designing a high degree of modularity into the software, bottlenecks related to slow peripherals are prevented from occurring in the system.

The NORD IDT CDC 200 User Emulator enables the NORD-10/S computer to communicate with Control Data Corporation CYBER/6000 series host computer systems and handles such functions as spooling, job priority scheduling and operation of peripheral equipment.

Standard peripherals consist of card reader, line printer and operator console, however, these may be substituted by alternative NORD devices. The SINTRAN III/VS also supports spooling of I/O files on disk.

## FEATURES

- Space compression/expansion, can reduce transmission time by up to 50 per cent and motivate the use of faster peripherals
- Full Duplex transmission
- Transmission rates from 1200 to 9600 bauds
- Communication via private or dial-up lines
- Comprehensive repertoire of both local and remote commands

## COMMAND SUMMARY

The command repertoire for the NORD IDT CDC 200 User Emulator has been developed with special regards to the following objectives:

- to simplify operation of the terminal
- to ensure a continuous job-flow
- to improve the operator's overview
- high throughput

# Commands

All commands, such as requests for status information, device assignments, etc. can be entered via the operator console. Likewise, messages and acknowledgements from the system are also routed to the console, providing smooth and uninterrupted operation of the terminal and boosting terminal throughput. Consequently, the operator is relieved from such time-consuming chores as card punching and halting of input and output streams.

The following list contains a few sample commands:

## Local Commands

- `:CO`  
  Copy from current input unit to current output unit

- `:XXXIN`  
  Change input unit number to octal value XXX

- `:XXXUT`  
  Change output unit number to octal value XXX

- `:AB`  
  Abort terminal — release peripheral units and close files

## Remote Commands

- `LOGIN`  
  Establish contact with host computer

- `FILES`  
  List all files

- `Q`  
  Display number of jobs in different queues

- `DROP`  
  (jobname) — Drop a job from input, execute or dependency queue

- `M`  
  Message — Transmit message to central site operator

In addition to the local and remote IDT 200 User commands, a time-sharing user may submit jobs for batch processing and manipulate his local files by the following SINTRAN III commands:

- `APPEND-REMOTE-QUEUE <queue> <file name>`  
  Permits the user to submit a job to the host computer

- `LIST-REMOTE-QUEUE<queue>`  
  Lists the job entries in the input queue to the host computer

- `DELETE-REMOTE-QUEUE-ENTRY <file name>`  
  Deletes a job from the remote batch queue before execution has started

Once the terminal has been logged on to the host computer, it remains in this mode until the operator decides to terminate the session by issuing the LOG-OUT command.
